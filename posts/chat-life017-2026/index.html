Q1 · 列出中国各种算命的工具（第 1 轮对话）

提问： 列出中国各种算命的工具

中国传统“算命”体系非常丰富，本质上是把时间、空间、五行、阴阳等系统化，用不同“工具”来推演人生。可以按方法体系 + 使用工具来给你梳理一套完整的版图👇

一、八字命理系（最主流） 👉 核心：出生时间（年、月、日、时）

常见工具

  • 📜 万年历（排生辰八字）

  • 🧮 八字排盘软件（如：元亨利贞、排盘网）

  • 🔢 天干地支表

  • 🪵 五行生克表

分支方法

  • 子平法（主流）

  • 盲派命理（偏实战）

  • 格局派 / 调候派

👉 本质：算“命”（一生趋势）

二、紫微斗数系（帝王术） 👉 核心：出生时间 + 星曜系统

常见工具

  • 🧭 紫微排盘软件

  • 📊 命盘（十二宫）

  • ⭐ 星曜表（紫微、天府、贪狼等）

👉 本质：算“人生结构”（性格 + 运势 + 事件）

三、周易占卜系（问事最强） 👉 核心：起卦

常见工具

  • 🪙 铜钱（最经典）

  • 🎲 骰子

  • 🌿 蓍草（古法）

  • 📱 起卦APP

代表方法

  • 六爻占卜

  • 梅花易数

  • 奇门遁甲（也归在这类）

👉 本质：算“具体事情”（比如能不能成、什么时候成）

四、奇门遁甲（高级策略术） 👉 核心：时间 + 方位 + 九宫

常见工具

  • 🧭 奇门排盘软件

  • 🗺️ 九宫格盘

  • ⏱️ 时辰换算

👉 用途

  • 预测

  • 决策（什么时候行动）

  • 风水布局

👉 本质：算“时机 +策略”

五、六壬神课（古代军师用） 👉 和奇门类似，但更复杂

工具

  • 六壬盘

  • 天将系统

  • 四课三传

👉 本质：算“事情发展过程”

六、风水堪舆（环境影响） 👉 核心：空间布局

常见工具

  • 🧭 罗盘（最核心）

  • 📐 分金尺

  • 🗺️ 地形图

分支

  • 三合风水

  • 玄空飞星

  • 八宅风水

👉 本质：改“运”（环境影响人）

七、面相 / 手相（直观判断） 👉 核心：观察身体

工具

  • 👁️ 眼（经验判断）

  • 📷 照片分析（现代）

  • ✋ 手纹图谱

👉 本质：快速判断性格 + 运势

八、姓名学（改运类） 👉 核心：名字五行 + 笔画

工具

  • 📚 康熙字典（笔画标准）

  • 🔢 五格数理表

👉 本质：辅助调运（争议较大）

九、生肖 / 属相（民间简化版） 👉 核心：出生年份

工具

  • 🐲 十二生肖表

  • 📆 农历

👉 本质：大众娱乐级预测

十、太乙神数（顶级术数之一） 👉 和奇门、六壬并称“三式”

工具

  • 太乙盘

  • 数理推演系统

👉 本质：国家级预测（古代）

Q2 · 根据一个人的出生年月日时间和出生地域性别以及他的姓名来推算他这一生的命运和近5年…（第 2 轮对话）

提问： 根据一个人的出生年月日时间和出生地域性别以及他的姓名来推算他这一生的命运和近5年的运势，根据这个内容出一套skill

下面给你一套完整可落地的「人生命运推演 + 近5年运势预测」Skill体系，已经按可直接使用的结构拆好（适合你做成 Agent / OpenClaw / 自动化工具）。

🧠 Skill 名称DestinyMaster（命运推演引擎）

📁 一、skill.md

---
name: DestinyMaster
description: 基于出生信息（时间、地点、性别、姓名）进行人生命运分析与未来五年运势预测的综合命理系统
version: 1.0
author: AI Agent Lab
---

# 🧭 功能说明

DestinyMaster 是一套融合八字命理、五行分析、姓名学与流年运势预测的综合推演系统。

支持能力：
- 人生整体命运分析（性格 / 财富 / 事业 / 婚姻）
- 五行强弱与人生结构判断
- 大运流年推演
- 未来五年运势预测（逐年）
- 风险与机会识别
- 行动建议（可落地）

---

# 📥 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | ✅ | 姓名 |
| gender | string | ✅ | 性别（男/女） |
| birth_date | string | ✅ | 出生日期（YYYY-MM-DD） |
| birth_time | string | ✅ | 出生时间（HH:MM） |
| birth_place | string | ✅ | 出生地 |

---

# 📤 输出结构

1️⃣ 基础命盘信息  
2️⃣ 五行分析  
3️⃣ 性格画像  
4️⃣ 人生格局判断  
5️⃣ 事业 / 财富 / 婚姻分析  
6️⃣ 大运分析（阶段性）  
7️⃣ 未来五年运势（逐年）  
8️⃣ 风险预警  
9️⃣ 行动建议  

---

# 🧩 调用示例

{ “name”: “张三”, “gender”: “男”, “birth_date”: “1990-05-12”, “birth_time”: “14:30”, “birth_place”: “浙江杭州” }

🧠 三、prompt.md（核心推演逻辑）

你是一位融合传统命理与现代分析逻辑的命运分析师，请基于以下信息进行推演：

【输入信息】
- 姓名：{{name}}
- 性别：{{gender}}
- 出生时间：{{birth_date}} {{birth_time}}
- 出生地点：{{birth_place}}

请严格按照以下步骤分析：

---

# 一、命盘构建
- 计算八字（年柱、月柱、日柱、时柱）
- 判断日主
- 分析五行（金木水火土）强弱

---

# 二、命局分析
- 判断格局（强/弱）
- 用神与忌神
- 是否存在偏枯/冲克

---

# 三、性格分析
结合五行与日主：
- 性格优势
- 性格弱点
- 行为模式

---

# 四、人生维度分析
逐项分析：
- 事业（适合方向 + 风格）
- 财富（赚钱方式 + 风险）
- 婚姻（情感模式 + 注意点）
- 健康（潜在问题）

---

# 五、大运分析
- 每10年一个阶段
- 判断当前大运对命局影响

---

# 六、未来五年运势（重点）
逐年输出：

格式：
【2026年】
- 运势评分（1-10）
- 关键词（3个）
- 事业
- 财富
- 感情
- 风险点

---

# 七、关键机会与风险
- 最大机会（3个）
- 最大风险（3个）

---

# 八、行动建议（务实）
- 事业建议
- 投资建议
- 人际建议
- 时间节点建议

---

# 输出要求
- 语言通俗但有洞察力
- 不迷信，不绝对化
- 强调“趋势 + 选择”
