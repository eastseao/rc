你这套已经很接近“能用”，但问题是：它更像工具说明文档，还没真正进化成一个可调用、可扩展、可控输出质量的 Skill。

我帮你直接升级成一套可落地 + 更产品化 + 去工具味的版本，并给一个更贴切的名字。

✅ 技能名称（重命名建议）

👉DeepDigest（深度信息萃取器）

比 “summarize” 更贴近实际用途：

  • 不只是“总结”，而是 提炼 + 结构化 + 复用

  • 支持多模态 → “Digest”比“Summary”更高级

  • 适合你后续做 Agent 扩展（调研 / 竞品 / 内容生产）

📦 Skill 结构（完整）

deep-digest/
├── skill.md
├── prompt.md
├── config.yaml

🧠 一、skill.md（入口定义）

---
name: deep_digest
description: 深度解析URL或文件（网页 / PDF / 图片 / 音频 / YouTube），输出结构化、可复用的信息摘要
version: 1.0
author: Gervas
---

# DeepDigest · 深度信息萃取器

一个面向信息工作者的多模态总结工具。

不仅做摘要，还做：

- 信息提纯
- 结构重组
- 关键洞察提炼
- 可复用输出（适合报告 / 内容创作 / 决策）

---

## ✅ 支持输入

- 🌐 网页 URL
- 📄 PDF / 文档
- 🖼 图片（OCR + 理解）
- 🎧 音频（转录 + 总结）
- 🎬 YouTube 视频

---

## 🎯 输出能力

- 分层摘要（短 / 中 / 长）
- 核心观点提取
- 关键数据抓取
- 逻辑结构重建
- 行动建议（可选）

---

## 🚀 使用方式

deep_digest “<URL或文件路径>” —mode insight


---

## 🧩 模式说明

| 模式 | 说明 |
|------|------|
| brief | 快速摘要 |
| structured | 结构化总结 |
| insight | 深度洞察 |
| extract | 仅提取信息 |

---

## 🧠 适用场景

- 市场调研
- 竞品分析
- 行业报告阅读
- 内容二次创作
- 视频速读

🧠 三、prompt.md（核心能力）

👉 这是整个 Skill 最关键的部分（我帮你做了“去AI味 + 更像人类分析”的版本）

你不是在“总结内容”，而是在做一次“信息提纯”。

请基于输入内容，完成以下任务：

---

# 🧠 一、核心摘要（必须自然）

用接近人类表达的方式说明：

- 这段内容在讲什么
- 核心结论是什么

⚠️ 禁止套路：
不要使用“本文主要讲述”“首先其次最后”等AI痕迹表达

---

# 🔍 二、关键信息提取

提取最有价值的信息：

- 数据
- 观点
- 结论
- 方法

---

# 🧱 三、结构重建

将原内容重构为更清晰结构：

- 背景
- 问题
- 解决方案
- 结果

---

# 💡 四、深度洞察（重点）

结合常识 + 经验判断：

- 内容真正想表达什么
- 有没有隐藏信息
- 有无偏见或局限

---

# ⚡ 五、可行动信息（可选）

如果适合，给出：

- 可执行建议
- 可复用思路

---

# ✍️ 风格要求（关键）

- 像人写的，而不是模型生成的
- 允许有观点
- 句子长短自然变化
- 避免模板化结构

⚡ 四、run.py（执行逻辑）

import subprocess
import json

def run(input_path, mode="insight", length="medium"):
    cmd = [
        "summarize",
        input_path,
        "--length", length
    ]

    # YouTube 特殊处理
    if "youtube.com" in input_path or "youtu.be" in input_path:
        cmd.extend(["--youtube", "auto"])

    result = subprocess.run(cmd, capture_output=True, text=True)

    if result.returncode != 0:
        return {"error": result.stderr}

    return {
        "raw": result.stdout,
        "mode": mode
    }
