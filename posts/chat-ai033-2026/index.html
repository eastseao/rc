# SKILL: WeChatHotRebuilder

## 🧠 技能简介
自动提取最近7天微信公众号10万+爆款文章，并完成内容重构、去AI化、排版优化与配图生成，输出可直接发布的公众号成品文章。

---

## 🚀 能力列表

1. 📊 爆款文章采集
- 抓取最近7天内阅读量 ≥10万的公众号文章
- 按分类输出（默认：情感 / 商业 / 认知 / 热点 / 成长）
- 每个分类30篇
- 输出标题 + 公众号 + 时间 + 阅读量 + 原文链接

2. ✍️ 内容重构
- 保持原文核心思想不变
- 重写标题（更吸引点击）
- 重构正文（逻辑更清晰、表达更自然）

3. 🧬 去AI味处理
- 消除模板化表达
- 增强人类写作特征（情绪、节奏、口语化）
- 降低重复率

4. 🎨 排版优化
- 公众号风格排版（短段落 + 留白）
- 小标题优化
- 强化阅读节奏

5. 🖼️ 图片生成提示
- 封面图 prompt
- 正文配图 prompt（插入位置标注）

6. ❤️ 结尾引导
- 自动生成点赞 / 在看 / 关注引导文案

---

## 📥 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| categories | list | 否 | 分类列表 |
| rewrite_style | string | 否 | 重写风格（如：情感/犀利/理性） |
| tone | string | 否 | 语气（如：走心/冷静/故事化） |

## ⚙️ 执行流程

1. fetch → 抓取爆款文章
2. rewrite → 重构标题与内容
3. deai → 去AI风格
4. layout → 排版优化
5. image → 生成图片prompt
6. ending → 添加结尾引导

---

## 🧩 使用场景

- 公众号矩阵运营
- 内容洗稿与二创
- 自媒体批量生产
- SEO内容扩展

🧠 run.py（核心执行逻辑｜一体化）

from prompts import fetch, rewrite, deai, layout, image, ending

class WeChatHotRebuilder:

    def __init__(self, config):
        self.config = config

    def run(self):
        # 1. 获取爆款文章
        articles = fetch.get_hot_articles(self.config)

        results = []

        for art in articles:
            # 2. 重构
            rewritten = rewrite.process(art)

            # 3. 去AI味
            humanized = deai.process(rewritten)

            # 4. 排版
            formatted = layout.process(humanized)

            # 5. 图片
            images = image.generate(formatted)

            # 6. 结尾
            final_content = ending.append(formatted)

            results.append({
                "origin_title": art["title"],
                "new_title": rewritten["title"],
                "account": art["account"],
                "publish_time": art["time"],
                "views": art["views"],
                "url": art["url"],
                "content": final_content,
                "images": images
            })

        return {"articles": results}

✍️ prompt/fetch.md

请提取最近7天内微信公众号阅读量超过10万的文章：

要求：
- 按分类输出（情感 / 商业 / 认知 / 热点 / 成长）
- 每个分类30篇
- 输出：
  - 标题
  - 公众号名称
  - 发布时间
  - 阅读量
  - 原文链接

✍️ prompt/rewrite.md

请对以下文章进行重构：

要求：
1. 保持核心观点不变
2. 重写标题（更有吸引力）
3. 内容逻辑更清晰
4. 避免逐句改写，要结构重组

输出：
- 新标题
- 新正文

🧬 prompt/deai.md

请对以下内容进行“去AI味”处理：

要求：
- 避免模板句式
- 增加人类表达（情绪、停顿、口语）
- 适当加入细节或类比
- 保持自然流畅

输出优化后的正文

🎨 prompt/layout.md

请将以下文章优化为公众号排版：

要求：
- 每段不超过3行
- 添加小标题
- 留白增强阅读体验
- 重点句加粗

输出排版后的内容

🖼️ prompt/image.md

请为文章生成配图提示：

1. 封面图 prompt（Midjourney / SD 可用）
2. 正文插图（3-5处）

要求：
- 风格统一
- 具象表达主题
- 带情绪感

输出：
{
  "cover": "",
  "inline": []
}

❤️ prompt/ending.md

请为文章生成结尾引导段：

要求：
- 引导点赞 👍
- 引导在看 ❤️
- 引导关注
- 语气自然，不生硬
