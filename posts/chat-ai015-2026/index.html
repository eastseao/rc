🧩 一、Skill完整目录结构

your-skill-name/
├── skill.md          # ✅ 技能说明 + 调用入口（核心）
├── config.yaml       # ✅ 参数定义（输入结构）
├── prompt.md         # ✅ Prompt模板（AI执行逻辑）
├── run.py            # ✅ 执行逻辑（数据处理/调用API）
├── requirements.txt  # （可选）依赖库
├── utils/            # （可选）工具函数
│   └── helpers.py
└── data/             # （可选）缓存/数据

🧠 二、各文件作用详解（核心理解）

1️⃣ skill.md（大脑入口）

👉 作用：定义这个 Skill 是干嘛的 + 怎么被调用

---
name: food_market_analysis
description: 食品行业市场调研与竞品分析工具
---

# 🍔 食品市场分析 Skill

## 功能
- 市场趋势分析
- 竞品分析
- 用户画像分析

## 使用方式
输入：
- 产品名称
- 市场（如：中国/日本/欧美）

输出：
- 行业分析报告

2️⃣ config.yaml（参数控制中心）

👉 作用：规范输入，让 Skill 更稳定

inputs:
  product_name:
    type: string
    description: 要分析的产品名称
    required: true

  market:
    type: string
    description: 目标市场（中国、日本、欧美等）
    required: true

  analysis_depth:
    type: string
    default: medium
    options: [low, medium, high]

3️⃣ prompt.md（AI大脑逻辑）

👉 作用：定义 AI 怎么思考（核心价值）

你是一位食品行业资深分析师，擅长市场调研、竞品分析和趋势判断。

请根据以下信息生成分析报告：

产品：{{product_name}}
市场：{{market}}
分析深度：{{analysis_depth}}

请输出：
1. 市场现状
2. 竞品分析（3个以上）
3. 用户画像
4. 发展趋势
5. 建议

4️⃣ run.py（执行引擎）

👉 作用：真正“干活”的地方（可选但很关键）

import json

🧠 四、utils/cost_engine.py（核心引擎🔥）

def estimate_costs(idea, cost_level):
    """
    根据产品类型 + 成本等级估算成本
    """

    # 基础原料成本模型（可扩展）
    if "鸡胸肉" in idea:
        raw_cost = 6.5
    elif "饮料" in idea:
        raw_cost = 2.5
    elif "坚果" in idea:
        raw_cost = 8.0
    else:
        raw_cost = 5.0

    # 成本等级调整
    level_factor = {
        "低": 0.8,
        "中": 1.0,
        "高": 1.3
    }.get(cost_level, 1.0)

    raw_cost *= level_factor

    # 包装成本
    packaging_cost = 1.2 * level_factor

    # 生产成本
    production_cost = 1.5 * level_factor

    total_cost = raw_cost + packaging_cost + production_cost

    return {
        "raw_material_cost": round(raw_cost, 2),
        "packaging_cost": round(packaging_cost, 2),
        "production_cost": round(production_cost, 2),
        "total_cost": round(total_cost, 2)
    }


def calculate_profit(cost_data, channel):
    """
    根据渠道计算售价和利润
    """

    total_cost = cost_data["total_cost"]

    # 渠道扣点
    channel_fee_rate = {
        "电商": 0.25,
        "商超": 0.35,
        "代理": 0.4
    }.get(channel, 0.25)

    # 目标毛利率
    target_margin = 0.5

    # 反推售价
    suggested_price = total_cost / (1 - channel_fee_rate - target_margin)

    # 实际利润
    profit = suggested_price * (1 - channel_fee_rate) - total_cost

    return {
        "suggested_price": round(suggested_price, 2),
        "channel_fee_rate": channel_fee_rate,
        "profit_per_unit": round(profit, 2),
        "profit_margin": round(profit / suggested_price, 2)
    }
