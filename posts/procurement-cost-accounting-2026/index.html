01 · 采购合同金额自动计算表格（00157 · 2025-10-02）

采购经常做合同，需要一张网页计算表：第 1 列数量、第 2 列单价，填好后底部自动统计金额。笔记给出的设计是动态行 + 实时计算。

00157 · 设计与核心代码

可动态加行、自动合计的合同金额计算表

表格结构
六列：序号 / 项目名称 / 数量 / 单价(元) / 金额(元) / 操作；表尾合计行「总计金额」。
设计思路
响应式表格；动态添加与删除行；自动计算每行金额与总金额；数据验证与错误处理；简洁界面。
核心计算
单行金额 = 数量 × 单价；总金额 = 遍历所有金额单元格累加，toFixed(2) 保留两位小数。
// 计算单行金额 function calculateRowAmount() { const row = this.closest('tr'); const quantity = parseFloat(row.querySelector('.quantity').value) || 0; const unitPrice = parseFloat(row.querySelector('.unit-price').value) || 0; const amountCell = row.querySelector('.amount'); const amount = quantity * unitPrice; amountCell.textContent = amount.toFixed(2); calculateTotal(); } // 计算总金额 function calculateTotal() { const amountCells = document.querySelectorAll('.amount'); let total = 0; amountCells.forEach(cell => { const amount = parseFloat(cell.textContent) || 0; total += amount; }); totalAmountElement.textContent = total.toFixed(2); }

自动计算功能

输入数量与单价时自动算每行金额，底部实时显示所有项目总金额。

动态管理与体验

「添加项目行」加行、每行「删除」按钮、「重置表格」清空重填；响应式适配手机与电脑，输入框焦点高亮、行悬停、非数字输入容错。

02 · 成本 A · 出厂 B · 零售 C 三段毛利核算（00759 · 2026-03-18）

成本是 A、出厂价是 B、渠道零售价是 C，怎么核算供货方与渠道各自的毛利？一句话逻辑：站在谁的角度，就用谁的「收入」减去谁的「成本」。

00759 · 公式照录

两段毛利的计算公式

核算对象毛利金额毛利率
你的毛利（生产商/供货商）你的毛利 = B − A你的毛利率 = (B − A) / B × 100%（分母是你的收入即出厂价 B）
渠道毛利（经销商/零售商）渠道毛利 = C − B渠道毛利率 = (C − B) / C × 100%（行业内通常以零售价 C 作分母）

举例：成本 A = 50 元、出厂价 B = 100 元、零售价 C = 200 元。

你的毛利

金额：100 − 50 = 50 元 毛利率：(50 / 100) × 100% = 50%

渠道毛利

金额：200 − 100 = 100 元 毛利率：(100 / 200) × 100% = 50%
注意事项（照录）：三人各赚 50% 毛利率，但计算基数不同——你的基数是出厂价，渠道的基数是零售价。含税与不含税要先明确，开票业务建议用不含税金额算毛利；渠道另有运费、进场费、促销员等杂费时，前台毛利先用 C − B 估算；渠道说的「倒扣」即以零售价为基准、「顺加」即以进货成本为基准，本节算的是零售行业通用的标准「倒扣毛利率」。

03 · 所有权总成本 TCO：一则「分驴」寓言（01011 · 2026-04-23）

笔记用黄河故道边两家粮行收粮运粮的故事，把「所有权总成本（Total Cost of Ownership，TCO）」讲透：只盯采购单价，就像当年的钱东家一样把所有隐性成本的绳子都丢给了供应商。

01011 · 寓言骨架

《分驴》：整驴计价 vs 按袋算钱

镇上新风是「整驴计价」——不论拉什么货走什么路，用一趟驴就收一趟的钱，省心。钱东家立刻跟风，周东家却翻了三年夜账本后决定仍按「袋」算脚钱。三年下来高下立判：

钱家（整驴计价）周家家（按袋算钱）
脚行装袋松垮，路上颠簸麦粒流失，同样收 1000 袋入库少几十斤。袋子装得越满越沉，脚行脚钱越多，自然愿意把车装实。
麻袋成消耗品，破洞断绳，补换开销不小；脚行一句「讲好整驴计价」概不负责。装车怎么装、路上怎么走、袋子怎么爱惜，都成了脚行自己的事。
旺季好驴好车好伙计优先派给周这类按袋计价的主顾，留给钱家老驴破车。把「看不见的绳子」接到看得见的那根计价绳上，剩下的不用操心。

红线 · 寓言点题

所有权总成本 TCO：别只买「一头驴的价格」

纸箱抗压不够运输压瘪的退货补发、托盘含水率不达标发霉污染货物的报废索赔、缠绕膜延展性差被迫多缠几圈的超耗——这些「算谁的」就是周东家说的「看不见的绳子」。专业采购做的不是「买便宜箱子」，而是用合同条款、验收标准和计价方式，把供应商的利益拴到你想控制的隐性成本上。

TCO 组成部分说明
搜寻与询价成本找供应商、比价、打样、测试所花的时间与资源。
采购单价合同上白纸黑字的价格，只是浮在水面上的冰山一角。
运输与仓储成本包装材料本身占据的物流空间、叠放效率、仓储周转率。
使用成本产线上打开、折叠、填充、封合所耗人工与能耗，以及打包效率对整条产线节拍的影响。
损耗与浪费成本来料不良率、运输破损率、因包装设计不合理导致的过量填充或过度包装。
逆向物流与处置成本退货包装能否重复使用；废弃后焚烧、填埋还是回收，每种选择的处理费与环境合规成本。

04 · 成本降幅百分比的两种口径（01370 · 2026-07-06）

表格的「结算成本」是出厂成本，要按对方的「期待工厂成本」算每行产品降了几个百分点。差额 = 期待工厂成本 − 结算成本；由于所有差额均为负，结算成本其实高于期待成本，即实际是涨价而非降价。
