Q4 · 阅读时间的插件加在哪里（第 4 轮对话）

提问： 阅读时间的插件加在哪里

非常好的问题——阅读时间 (readtime) 并不是 Jekyll 自带的功能，而是一个可选的插件或生成逻辑。 它的作用是自动计算文章字数，然后估算读完需要的分钟数（例如“阅读时间：3分钟”）。

在你的post.html中，{{ page.readtime }}这一变量不会自动生效，除非我们在构建阶段让 Jekyll 生成它。

下面我详细告诉你两种实现方式：插件自动计算和脚本生成，你只需选择一种即可。

✅ 方法一：使用插件（推荐，最简洁）

如果你用的是GitHub Pages + Jekyll，那么你只能使用白名单插件。 幸运的是，有个插件叫jekyll-reading-time，GitHub Pages 支持它！

1️⃣ 在你的_config.yml里添加：
plugins:
  - jekyll-reading-time

如果已经有其他插件（例如 sitemap、feed 等），只需在它们下面加一行：

plugins:
  - jekyll-feed
  - jekyll-sitemap
  - jekyll-reading-time
2️⃣ 插件会自动在每个page或post对象里添加：
{{ page.reading_time }}

它默认是英文（例如"1 min read"），我们可以自己在模板里汉化成：

阅读时间：{{ page.reading_time | replace: " min read", "分钟" }}

或者更细一点：

{% assign mins = page.reading_time | remove: " min read" %}
阅读时间：{{ mins }} 分钟

⚠️ 注意：你原本用的是{{ page.readtime }}，改成{{ page.reading_time }}才能和插件对接。

✅ 方法二：不用插件（纯 Liquid 实现，适合无法安装插件的情况）

在你的_layouts/post.html里，在文章开头添加这段逻辑计算阅读时间（假设每分钟读 200 字）：

{% assign words = content | number_of_words %}
{% assign minutes = words | divided_by:200 %}
{% if minutes < 1 %}
  {% assign minutes = 1 %}
{% endif %}
<span class="reading-time"><span class="middot d-none d-md-inline">&middot;</span> 阅读时间：{{ minutes }} 分钟</span>

替换掉原先的：

{% if page.readtime %}
  <span class="reading-time">
    <span class="middot d-none d-md-inline">&middot;</span>
    阅读时间：{{ page.readtime }} 分钟
  </span>
{% endif %}

✅ 建议总结

场景推荐方法优点
你在 GitHub Pages 上部署使用插件jekyll-reading-time自动计算，无需改模板
你不能启用插件使用 Liquid 脚本计算字数不依赖插件，兼容所有环境

解决方案
  1. 确认插件是否正确安装

GitHub Pages 不支持直接安装任何插件（除非在whitelisted插件列表中）。jekyll-reading-time插件不在 GitHub Pages 的白名单中，因此无法在 GitHub Pages 上直接使用。

  1. 移除jekyll-reading-time插件

由于 GitHub Pages 不支持jekyll-reading-time插件，建议你移除插件并使用手动计算阅读时间的方法，即使用 Liquid 代码手动计算每篇文章的字数。

如何修改_config.yml文件：
  1. 从插件中删除jekyll-reading-time
  • 删除_config.yml中的jekyll-reading-time插件配置。
   plugins:
     - jekyll-paginate
     - jekyll-sitemap
   # - jekyll-reading-time  # 删除这一行
  1. 添加手动计算阅读时间的 Liquid 代码

使用 Liquid 手动计算文章字数，并估算阅读时间。以下是更新后的代码。

手动计算阅读时间

在layouts/post.html中，使用以下 Liquid 代码来计算每篇文章的阅读时间：

{% assign words = content | number_of_words %}
{% assign minutes = words | divided_by: 200 %}
{% if minutes < 1 %}

{% endif %}

  • 这段代码计算文章字数，并估算每篇文章的阅读时间，假设每分钟能读200个字。如果字数少于200个，会自动显示为 1 分钟阅读时间。
总结

  • 删除插件 ：GitHub Pages 不支持 jekyll-reading-time 插件，因此需要删除它。

    function generate() {
      const title = document.getElementById("title").value.trim();

      const filename = `${y}-${m}-${d}-${title.replace(/\s+/g, "-")}.md`;

${content || "这里是正文内容……"}
