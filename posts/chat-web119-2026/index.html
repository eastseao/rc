Q2 · 用hugo模板（第 2 轮对话）

提问： 用hugo模板

很好，选Hugo 做多语言企业站是非常正确的，比纯 HTML 更规范、扩展性也强，而且GitHub Pages 完全支持（即使你不本地操作也能搞定）。

我给你一套**“纯网页操作 + Hugo + 多语言”完整落地方案**，直接能上线。

一、核心思路（你要理解这一点）

你现在的限制是：

👉 不能本地运行 Hugo 👉 只能用 GitHub 网页

✅Hugo + GitHub Actions 自动构建

三、把模板“变成你的网站”

现在做这一步👇

方法（纯网页操作）

  1. 打开模板仓库代码页

  2. 点 Code → Download ZIP

  3. 解压（本地这一步可以做）

  4. 打开你自己的仓库 radiantpack.github.io

  5. 点击 Upload files

  6. 把所有文件拖进去

四、开启 Hugo 自动部署（核心）

你必须加一个 GitHub Actions👇

创建文件：

路径：

.github/workflows/hugo.yml

内容👇（直接复制）

name: Deploy Hugo site

on:
  push:
    branches:
      - main

jobs:
  build-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Setup Hugo
        uses: peaceiris/actions-hugo@v2
        with:
          hugo-version: 'latest'

      - name: Build
        run: hugo

      - name: Deploy
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./public
