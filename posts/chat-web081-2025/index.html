你想要把时间轴改成“日期在左、文章在右”的布局，这可以通过调整 HTML 结构和 CSS 来实现。可以用 flex 布局让每一条文章在同一行内左边显示日期，右边显示文章标题。下面是修改后的示例：

---
layout: page
title: "时间轴"
permalink: /pages/archives/
icon: fas fa-archive
---

<div class="archives-container">
  {% assign years = site.posts | group_by_exp: "post", "post.date | date: '%Y'" %}
  {% for year in years %}
    <div class="year-section" id="{{ year.name }}" style="margin-bottom: 40px;">
      <h2 style="font-size: 24px; color: #333; margin-bottom: 20px;">{{ year.name }} 年</h2>
      <ul style="list-style: none; padding-left: 0;">
        {% for post in year.items %}
          <li style="display: flex; align-items: center; margin-bottom: 10px;">
            <span style="width: 120px; font-size: 14px; color: #777;">{{ post.date | date: "%Y-%m-%d" }}</span>
            <a href="{{ post.url }}" style="font-size: 18px; color: #333; text-decoration: none;">{{ post.title }}</a>
          </li>
        {% endfor %}
      </ul>
    </div>
  {% endfor %}
</div>
样式说明：

  • display: flex; align-items: center; → 每条文章一行，左日期右标题。

  • width: 120px; → 给日期固定宽度，使对齐整齐。

  • 文章标题自适应剩余空间。

如果你希望整个时间轴看起来更像“纵向时间线”，我可以帮你再加左边的年份标记和竖线连接，效果会更直观。

      </div>
    {% endfor %}
  </div>

</div>

  • 月日 占 80px 固定宽度，与标题对齐。

  • 文章标题 占剩余空间，自适应。

  • 每条文章一行，左右对齐整齐。

要在 Beautiful Jekyll 中实现点击头像放大效果，可以通过简单的 CSS 和 HTML 调整来实现。下面给出一个无需修改主题核心文件的方案：

1. 在_config.yml保持头像路径

你已经配置了：

avatar: "/assets/img/avatar.jpg"
round-avatar: true
2. 在页面或全局 CSS 添加放大效果

你可以在assets/css/custom-styles.css中加入如下 CSS：

/* 头像点击放大效果 */
.avatar-container img {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
  cursor: pointer;
}

.avatar-container img:hover {
  transform: scale(1.2); /* 放大 20% */
  box-shadow: 0 8px 20px rgba(0,0,0,0.3); /* 添加阴影效果 */
}

/* 可选：点击弹出大图（模态效果） */
.avatar-modal {
  display: none; 
  position: fixed; 
  z-index: 9999; 
  padding-top: 60px; 
  left: 0;
  top: 0;
  width: 100%; 
  height: 100%; 
  overflow: auto; 
  background-color: rgba(0,0,0,0.8); 
}

.avatar-modal img {
  margin: auto;
  display: block;
  max-width: 90%;
  max-height: 80%;
}

.avatar-modal span {
  position: absolute;
  top: 20px;
  right: 35px;
  color: #fff;
  font-size: 40px;
  font-weight: bold;
  cursor: pointer;
}
3. 在导航栏头像 HTML 外层加容器

在header.html（或_includes/header.html）找到头像的<img>标签，并改为：

<div class="avatar-container">
  <img id="avatarImg" src="{{ site.avatar | relative_url }}" alt="头像" />
</div>

<!-- 模态放大图 -->
<div id="avatarModal" class="avatar-modal">
  <span id="closeModal">&times;</span>
  <img id="modalImg" src="{{ site.avatar | relative_url }}">
</div>
4. 添加放大点击交互 JS

在全局 JS 或页面底部加入：

<script>
  const avatar = document.getElementById("avatarImg");
  const modal = document.getElementById("avatarModal");
  const modalImg = document.getElementById("modalImg");
  const closeBtn = document.getElementById("closeModal");

  avatar.onclick = function() {
    modal.style.display = "block";
  }

  closeBtn.onclick = function() {
    modal.style.display = "none";
  }

  // 点击模态背景也可关闭
  modal.onclick = function(e) {
    if(e.target === modal) {
      modal.style.display = "none";
    }
  }
</script>

这样实现后效果如下：

  • 鼠标悬停头像时轻微放大（增加交互感）。

  • 点击头像弹出模态大图，支持关闭。

  • 不影响主题原有布局，适用于 Beautiful Jekyll 任何版本。

  • max-width / max-height → 确保大图在小屏幕上不超出

  • 关闭按钮字体和位置 → 移动端更适合手指点击

2. 更新 JS (assets/js/avatar.js)

不需要改动太多，只加上一个判断，保证在移动端点击也能全屏显示：

document.addEventListener("DOMContentLoaded", function() {
  const headerAvatar = document.querySelector("header img.avatar");
  if (!headerAvatar) return;

  // 创建模态 HTML
  const modal = document.createElement("div");
  modal.className = "avatar-modal";
  modal.innerHTML = `
    <span id="closeModal">&times;</span>
    <img src="${headerAvatar.src}" alt="头像">
  `;
  document.body.appendChild(modal);

  const closeBtn = modal.querySelector("#closeModal");
  const modalImg = modal.querySelector("img");

  // 点击头像打开模态
  headerAvatar.addEventListener("click", () => {
    modal.style.display = "block";

    // 移动端自动居中并适配屏幕
    if (window.innerWidth <= 768) {
      modalImg.style.maxWidth = "95%";
      modalImg.style.maxHeight = "90%";
    } else {
      modalImg.style.maxWidth = "90%";
      modalImg.style.maxHeight = "80%";
    }
  });

  // 点击关闭按钮
  closeBtn.addEventListener("click", () => {
    modal.style.display = "none";
  });

  // 点击背景关闭
  modal.addEventListener("click", (e) => {
    if (e.target === modal) modal.style.display = "none";
  });
});
