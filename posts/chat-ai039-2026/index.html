# SKILL: RawMaterial Intelligence System

## 技能描述
针对任意指定原料，进行全链路、多维度、数据驱动的深度调研分析，输出可用于采购决策、选品开发、供应链优化的结构化报告。

---

## 核心能力

### 1. 原料基础认知
- 分类（植物 / 动物 / 化工 / 添加剂等）
- 理化性质
- 标准与规格（国标 / FDA / 欧盟等）

### 2. 市场调研
- 市场规模（全球 / 中国 / 区域）
- 增长趋势
- 主要应用行业
- 热门产品形态

### 3. 供应链分析
- 上游来源（产地 / 原材料）
- 中游加工（工艺 / 工厂类型）
- 下游应用（品牌 / 产品）

### 4. 价格体系
- 当前价格区间
- 历史价格波动
- 价格影响因素（季节 / 政策 / 供需）

### 5. 应用场景
- 食品行业应用
- 工业应用
- 新兴趋势（功能食品 / 健康概念）

### 6. 风险分析
- 政策风险
- 质量风险
- 替代品风险
- 供应不稳定风险

### 7. 供应商调研（重点）
- 国内供应商
- 国际供应商
- 平台数据（1688 / Alibaba / Made-in-China）
- 头部企业分析

---

## 输入要求

{ “原料名称”: “必填”, “应用场景”: “可选（如：饮料 / 烘焙 / 保健品）”, “目标市场”: “可选（如：中国 / 日本 / 全球）”, “调研深度”: “基础 / 深度 / 投资级”, “是否需要供应商”: “是 / 否” }


---

## 输出内容

### 1. 原料全景图
### 2. 市场分析报告
### 3. 价格趋势分析
### 4. 供应链结构图
### 5. 供应商清单（可选）
### 6. 风险评估矩阵
### 7. 最终采购建议

---

## 工作流程

1. Intake（理解原料）
2. 分类与定义
3. 市场扫描
4. 供应链拆解
5. 价格分析
6. 应用分析
7. 风险识别
8. 供应商挖掘
9. 输出结构化报告

---

## 特点

- 多渠道数据整合（行业报告 + B2B平台 + 搜索引擎）
- 自动结构化输出
- 支持持续迭代（Memory机制）
- 适用于采购 / 产品经理 / 投资分析

🧠 skill.md（严格规范版）

# Skill: RawMaterialIntelligence

## Description
End-to-end intelligence system for researching a specific raw material across market, supply chain, pricing, applications, risks, and suppliers.

This skill is designed for procurement, product development, and investment decision-making.

---

## Capabilities

- Raw material classification and definition
- Market size and trend analysis
- Supply chain structure mapping
- Price intelligence and forecasting
- Application scenario analysis
- Risk assessment
- Supplier discovery and evaluation
- Final procurement recommendation

---

## Inputs

{ “material”: “string (required)”, “application”: “string (optional)”, “target_market”: “string (optional)”, “depth”: “basic | advanced | pro”, “include_suppliers”: “boolean” }


---

## Outputs

- Structured research report (markdown)
- Supplier list (optional)
- Risk matrix
- Price analysis
- Procurement recommendations

---

## Workflow

1. Intake & normalize input
2. Define and classify material
3. Analyze market
4. Analyze supply chain
5. Analyze pricing
6. Analyze applications
7. Assess risks
8. Discover suppliers (optional)
9. Synthesize final report

---

## Execution Rules

- Prefer structured data over narrative
- Use estimation ranges when exact data is unavailable
- Avoid hallucinated precision
- Clearly separate facts vs inference
- Supplier data must include source hints when possible

---

## Output Format

- Markdown
- Sectioned with headings
- Tables where applicable
- Concise but information-dense

---

## Memory Usage

- Persist key findings
- Track completed modules
- Store price anchors
- Store shortlisted suppliers

---

## Constraints

- Do not fabricate exact pricing
- Do not assume supplier credibility without signals
- Clearly mark uncertain data

version: 1.0

  language: zh-CN
  output: markdown

execution:
  mode: pipeline
  depth_levels:
    basic:
      modules: [intake, market, price]
    advanced:
      modules: [intake, market, supply, price, application, risk]
    pro:
      modules: [intake, market, supply, price, application, risk, supplier, synthesis]

modules:
  intake:
    prompt: prompts/intake.md
  market:
    prompt: prompts/analysis_market.md
  supply:
    prompt: prompts/analysis_supply.md

  - company_websites
  - ecommerce_platforms

  enabled: true

  update_strategy: append

  template: templates/final_report.md

# SKILL: RawMaterialIntelligence

## PURPOSE
对指定原料进行全方位调研分析，覆盖市场、供应链、价格、应用、风险及供应商信息，
输出可用于采购决策与产品开发的结构化报告。

---

## INPUT

{ “material”: “string (必填)”, “application”: “string (可选)”, “target_market”: “string (可选)”, “depth”: “basic | advanced | pro”, “include_suppliers”: true }


---

## OUTPUT
输出一份结构化 Markdown 报告，包含：

1. 原料概述
2. 市场分析
3. 供应链分析
4. 价格分析
5. 应用分析
6. 风险评估
7. 供应商列表（可选）
8. 采购建议

---

## WORKFLOW

按顺序执行以下步骤：

### Step 1: 原料定义
- 定义原料
- 分类（天然 / 合成 / 食品添加剂等）
- 核心功能
- 常见形态
- 替代品

---

### Step 2: 市场分析
- 全球市场规模（区间即可）
- 区域市场（重点市场）
- 增长率
- 核心驱动因素
- 主要应用行业

---

### Step 3: 供应链分析
- 上游来源
- 生产工艺
- 核心产地
- 供应集中度
- 潜在瓶颈

---

### Step 4: 价格分析
- 当前价格区间
- 历史趋势（上涨 / 下跌 / 波动）
- 价格驱动因素
- 未来趋势判断
- 采购时机建议

---

### Step 5: 应用分析
- 主要行业
- 产品形态
- 高附加值场景
- 新兴趋势

---

### Step 6: 风险评估
构建风险矩阵：

| 风险类型 | 等级 | 描述 | 应对策略 |

风险类型包括：
- 政策风险
- 供应风险
- 价格波动
- 替代品风险
- 质量风险

---

### Step 7: 供应商调研（可选）
当 include_suppliers = true 时执行：

渠道：
- 1688
- Alibaba
- Made-in-China
- 搜索引擎

输出表格：

| 供应商 | 国家 | 产品类型 | MOQ | 价格区间 | 类型 | 备注 |

要求：
- ≥10 家
- 优先工厂
- 避免重复

---

### Step 8: 综合结论
输出决策建议：

- 是否值得进入该原料
- 推荐采购策略（现货 / 长协 / 观望）
- 价格判断（高位 / 低位 / 周期中）
- 供应商选择建议

---

## RULES

- 使用结构化表达（优先表格）
- 数据可用区间表示，不强求精确
- 明确区分「事实」与「推测」
- 不编造具体企业数据
- 不输出无法验证的精确价格
- 信息不充分时标注“估算”

---

## MEMORY

在每次执行后更新以下内容：

- 原料名称

- 关键结论
- 价格锚点
- 重要供应商
- 风险记录

用于避免重复分析与信息丢失

---

- 专业
- 简洁
- 高信息密度
- 面向采购决策
