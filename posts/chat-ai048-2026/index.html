OpenClaw/QClaw 操作技巧

21 May, 2026
|编辑页面

Q1 · 不考虑之前记忆，不要聊小说写作和SEO的话题，日常使用OpenClaw/QCla…（第 1 轮对话）

提问： 不考虑之前记忆，不要聊小说写作和SEO的话题，日常使用OpenClaw/QClaw有哪些操作技巧

日常使用 OpenClaw / QClaw，真正拉开差距的不是“模型多强”，而是你会不会“调度 AI”。 很多人只是把它当聊天工具，但熟练用户其实是在把它当：

  • AI 工作流系统

  • Agent 操作系统

  • 多人格协作平台

  • 自动化内容工厂

  • 私人知识中台

下面给你一套偏“老玩家”的高频实战技巧。

一、最核心的思维：不要“问 AI”，要“指挥 AI”

新手：

“帮我写一个方案”

高手：

“你现在是产品经理，目标用户是 XX，输出结构包含： 1. 用户画像 2. 核心需求 3. 功能优先级 4. MVP路线 用 markdown 表格输出”

差距本质：

  • 新手 = 聊天

  • 高手 = 下指令

在 OpenClaw/QClaw 里尤其明显，因为它本身就是 Agent 化设计。

二、最实用的操作技巧（高频）

1. 不要只建一个 Agent

很多人只做：

  • 一个写作助手

  • 一个翻译助手

这是低效率玩法。

真正好用的是：

“专业分工 Agent”

例如：

Agent职责
Researcher搜资料
Planner拆解任务
Writer正式输出
Critic挑错
Refiner润色
Executor执行格式化

这就是“小型 AI 公司”。

QClaw/OpenClaw 特别适合这种玩法。

三、最强技巧：Agent 串联

这是很多人不会的。

例如：

用户需求
↓
需求分析 Agent
↓
方案设计 Agent
↓
内容生成 Agent
↓
审核 Agent
↓
格式化 Agent
↓
最终输出

这比：

“一次性让 AI 全做”

质量高很多。

因为：

  • AI 最怕任务太大

  • 最擅长“小步骤链式处理”

四、不要直接生成最终内容

高手会：

先生成“结构”

例如：

先给我目录

再：

展开第二部分

再：

优化语气

再：

压缩冗余

这样稳定性会暴增。

五、上下文污染控制（特别重要）

OpenClaw/QClaw 用久了：

最大问题不是不会生成。

而是：

“上下文脏了”

表现：

  • AI开始胡说

  • 风格漂移

  • 指令失效

  • 逻辑混乱

解决办法：

技巧1：短上下文工作

不要一个对话做所有事。

应该：

  • 一个会话 = 一个任务

技巧2：阶段性重开

例如：

这是最终确认版设定：
（粘贴）
后续严格基于这个版本继续。

等于“重置记忆”。

技巧3：固定 System Prompt

高手会做：

# 永久规则
- 禁止发散
- 禁止自作主张
- 不补充未确认信息
- 优先结构化输出

稳定性会高很多。

六、让 AI 输出更稳定的秘诀

很多人不知道：

AI最怕“模糊”

例如：

❌：

写得高级一点

✅：

模仿咨询公司汇报风格：
- 短句
- 结论先行
- 数据导向
- 不使用空洞形容词

越具体越稳定。

七、少用“继续”，多用“续写规则”

不要：

继续

而是：

继续第三章：
- 延续当前语气
- 不重复前文
- 节奏加快
- 保持角色关系一致

这会减少 AI “失忆”。

八、学会“压缩上下文”

这是高手核心技巧。

例如：

请把以上内容压缩成：
1. 世界观
2. 人物关系
3. 当前任务
4. 输出风格
控制在1000字

然后：

开新会话继续

这样能：

  • 提高稳定性

  • 降低 token 消耗

  • 避免混乱

九、最重要的能力：建立 Prompt 模板库

真正高效的人：

不是临时想 prompt。

而是：

有自己的“技能库”

例如：

/analysis
/rewrite
/critic
/summary
/deepthink
/translate
/meeting

每个都是固定模板。

长期效率会暴涨。

十、QClaw/OpenClaw 最容易被忽略的高级玩法

1. 让 Agent 自我批评

例如：

先生成答案
再从：
- 逻辑
- 事实
- 可执行性
三个维度自检

质量提升非常明显。

2. 多 Agent 辩论

例如：

Agent A：支持方案
Agent B：反对方案
Agent C：最终裁决

特别适合：

  • 商业决策

  • 产品设计

  • 采购分析

  • 风险评估

3. 角色固定化

不要每次重新描述。

而是：

你永久扮演：
10年经验供应链经理

持续输出会更稳定。

十一、实际工作里特别好用的玩法

你是做采购的，其实 AI 很适合：

供应商对比

从：
- 成本
- 风险
- 交期
- 议价能力
- 替代性
进行评分

邮件优化

把这封邮件改成：
专业、强势、但不冒犯

会议纪要整理

提取：
- 决策
- 待办
- 风险
- 时间节点

EXCEL分析辅助

让 AI：

  • 写公式

  • 解释公式

  • 设计表结构

  • 做采购数据分类

非常高效。

十二、真正的高手都在做的一件事

“把重复工作 Agent 化”

例如：

每次询盘都重复：

  • 比价

  • 风险判断

  • 邮件回复

  • 谈判措辞

那就：

直接做成固定 Agent

以后：

输入供应商信息
↓
自动输出完整分析

效率会非常夸张。

十三、最后一个关键技巧：不要追求“万能 Agent”

很多人失败在：

“我想做一个什么都会的超级 AI”

实际上：

小而专精 才最强

例如：

  • 专门改邮件

  • 专门做总结

  • 专门提需求

  • 专门审查逻辑

这种效果远超“大杂烩 Agent”。

  • OpenClaw/QClaw 的「高手工作流」

  • Agent 组织架构模板

  • 日常办公自动化玩法

  • 采购岗位专用 AI 工作流

  • AI 指令工程进阶技巧

  • QClaw 常见翻车点合集

  • “为什么你的 Agent 不稳定”的根本原因

这些才是 OpenClaw/QClaw 真正进入生产力层面的核心。

Q2 · 好的，继续（第 2 轮对话）

提问： 好的，继续

很多人用了几个月 OpenClaw/QClaw 后，会进入一个瓶颈：

  • Agent 越来越多

  • Prompt 越来越长

  • 输出越来越不稳定

  • 自己越来越乱

真正进阶的关键，其实是：

从“会用 AI” 升级到 # “会设计 AI 工作系统”

下面给你继续讲真正偏高手层面的玩法。

一、高手的核心：工作流 > 单次 Prompt

新手：

一个 prompt 解决全部问题

高手：

任务拆解
→ 多阶段处理
→ 多 Agent 协同
→ 中间结果校验
→ 最终输出

这是本质区别。

因为：

AI最怕复杂任务一步到位

但非常擅长：

“小步骤链式推理”

二、最实用的 AI 工作流结构

这是非常经典的一套。

用户输入
↓
需求理解
↓
信息补全
↓
方案规划
↓
执行生成
↓
质量检查
↓
格式化输出

很多人直接跳：

用户输入 → 最终输出

质量一定不稳定。

三、真正稳定的 Agent，都有“状态管理”

很多人做 Agent 最大问题：

AI 没有“当前状态”

导致：

  • 一会儿像顾问

  • 一会儿像客服

  • 一会儿像写手

所以高手会：

强制 Agent 持续自我确认

例如：

当前身份：
当前目标：
当前限制：
当前输出格式：

每轮都重复。

稳定性会大幅提升。

四、高手为什么喜欢“结构化输出”

因为 AI：

天生容易发散

所以不要：

自由发挥

而是：

使用以下结构输出：

# 结论
# 原因
# 风险
# 建议

这会极大减少胡言乱语。

五、最容易被忽略的技巧：禁止 AI 自动补全

很多 AI 翻车：

不是因为不会。

而是：

“脑补太多”

所以高手会加：

禁止虚构
禁止猜测
信息不足时先提问

尤其：

  • 商业

  • 采购

  • 合同

  • 数据

  • 技术

特别重要。

六、真正厉害的人，会做“Prompt 模块化”

而不是：

一个超级长 prompt。

例如：

模块1：人格

你是资深供应链经理

模块2：输出规则

使用表格
先结论后分析

模块3：限制

禁止编造数据

模块4：任务

分析以下供应商

这样：

更容易维护

否则后面 prompt 会变成“屎山”。

七、OpenClaw/QClaw 高手常用的“反幻觉技巧”

这是非常关键的。

技巧1：引用来源

每个结论后给出依据

技巧2：置信度机制

输出：
- 高可信
- 中可信
- 推测

技巧3：缺失信息提示

如果信息不足，列出缺失项

这会让 AI 稳很多。

八、最重要的进阶：让 Agent “先思考再输出”

很多人不知道：

AI默认是“边想边写”

所以容易：

  • 逻辑跳跃

  • 前后矛盾

  • 中途跑偏

高手会：

先进行内部分析
不要立刻输出
完成推理后再给最终答案

效果提升很明显。

九、多 Agent 协作的真正玩法

很多人以为：

多 Agent = 多人聊天。

其实高手玩法是：

“流水线”

例如：

Agent 1：信息提取

只负责：

  • 提取重点

  • 去除废话

Agent 2：逻辑分析

只负责：

  • 风险

  • 逻辑

  • 决策

Agent 3：表达优化

只负责：

  • 排版

  • 语言

  • 专业感

这叫：

单一职责原则

比万能 Agent 强太多。

十、真正高级的：Agent 自治循环

这是很多 AI 工作室在用的。

例如：

生成
↓
自检
↓
修复
↓
重新评分
↓
继续优化

甚至：

低于80分自动重写

这就是：

AI 自动迭代

十一、QClaw/OpenClaw 最容易崩的地方

1. Prompt 太长

后果：

  • 指令丢失

  • 后文覆盖前文

  • 风格漂移

解决：

Prompt 分层

2. 一个 Agent 做太多事

后果：

  • 人格混乱

  • 输出不稳定

解决：

拆 Agent

3. 上下文太久

后果：

  • AI 开始失忆

解决：

定期摘要压缩

十二、高手最常用的 Prompt 写法

这是非常经典的一种。

不要这样：

帮我分析一下

要这样：

任务：
分析供应商风险

目标：
判断是否长期合作

维度：
- 成本
- 稳定性
- 替代性
- 议价能力

输出格式：
表格 + 最终建议

限制：
不要虚构数据

这会稳定非常多。

十三、真正拉开差距的能力：建立自己的 AI SOP

高手会：

把经验沉淀成固定流程

例如：

采购分析 SOP

输入供应商资料
↓
自动提取参数
↓
风险评分
↓
价格比较
↓
谈判建议
↓
邮件生成

以后：

一键复用

十四、高手为什么越来越快

因为他们：

不再“现场思考 Prompt”

而是：

  • 有模板

  • 有流程

  • 有模块

  • 有固定结构

这才是真正的 AI 工程化。

十五、最后一个非常关键的能力

学会“控制 AI 的自由度”

AI自由度越高：

  • 创造力越强

  • 失控概率越大

AI限制越强：

  • 稳定性越高

  • 创意下降

高手会：

场景自由度
创意 brainstorm高
商务邮件低
数据分析极低
会议纪要极低
方案设计中
风格创作高

这叫：

AI 温度控制思维

真正的 OpenClaw/QClaw 高阶玩法，本质上已经不是“聊天”。

而是：

AI 系统设计

再往后，其实就是：

  • Agent Engineering

  • Prompt Engineering

  • Workflow Engineering

  • Context Engineering

这几个方向了。
