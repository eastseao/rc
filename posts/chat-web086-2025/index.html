我帮你修改了这段 Jekyllpage布局代码，把英文内容汉化，并把标签移到日期右侧，同一行显示。整理后如下：

## layout: page

{{ content }}

{% assign posts = paginator.posts | default: site.posts %}

{% for post in posts %}
  {%- capture thumbnail -%}
    {% if post.thumbnail-img %}
      {{ post.thumbnail-img }}
    {% elsif post.cover-img %}
      {% if post.cover-img.first %}
        {{ post.cover-img[0].first.first }}
      {% else %}
        {{ post.cover-img }}
      {% endif %}
    {% endif %}
  {% endcapture %}
  {% assign thumbnail = thumbnail | strip %}

  {% if thumbnail != "" and site.feed_show_excerpt == false %}
    <div class="post-image post-image-normal">
      <a href="{{ post.url | absolute_url }}" aria-label="缩略图">
        <img src="{{ thumbnail | absolute_url }}" alt="文章缩略图">
      </a>
    </div>
  {% endif %}

  <a href="{{ post.url | absolute_url }}">
    <h2 class="post-title">{{ post.title | strip_html }}</h2>
    {% if post.subtitle %}
      <h3 class="post-subtitle">{{ post.subtitle | strip_html }}</h3>
    {% endif %}
  </a>

  {% if post.author %}
    <span>作者：<strong>{{ post.author | strip_html }}</strong></span>
  {% endif %}

  <p class="post-meta">
    {% assign date_format = site.date_format | default: "%Y年%-m月%-d日" %}
    发布于 {{ post.date | date: date_format }}
    {% if site.feed_show_tags != false and post.tags.size > 0 %}
      &nbsp;|&nbsp;
      {% for tag in post.tags %}
        <a href="{{ '/tags' | absolute_url }}#{{- tag -}}" class="post-tag">{{ tag }}</a>{% if forloop.last == false %}, {% endif %}
      {% endfor %}
    {% endif %}
  </p>

  {% if thumbnail != "" %}
    <div class="post-image post-image-small">
      <a href="{{ post.url | absolute_url }}" aria-label="缩略图">
        <img src="{{ thumbnail | absolute_url }}" alt="文章缩略图">
      </a>
    </div>
  {% endif %}

  {% unless site.feed_show_excerpt == false %}
    <div class="post-entry">
      {% assign excerpt_length = site.excerpt_length | default: 50 %}
      {{ post.excerpt | strip_html | truncatewords: excerpt_length }}
      {% assign excerpt_word_count = post.excerpt | number_of_words %}
      {% if post.content != post.excerpt or excerpt_word_count > excerpt_length %}
        <a href="{{ post.url | absolute_url }}" class="post-read-more">[阅读全文]</a>
      {% endif %}
    </div>
  {% endunless %}
{% endfor %}

{% if paginator.total_pages > 1 %}
  <div class="pagination">
    {% if paginator.previous_page %}
      <a href="{{ paginator.previous_page_path | absolute_url }}" class="newer-posts">上一页</a>
    {% endif %}
    {% if paginator.next_page %}
      <a href="{{ paginator.next_page_path | absolute_url }}" class="older-posts">下一页</a>
    {% endif %}
  </div>
{% endif %}
修改说明：
  1. 所有英文文字都汉化：

-Read More→阅读全文-By→作者：-Tags:→ 标签直接显示在日期右边 - 分页按钮Newer Posts / Older Posts→上一页 / 下一页

  1. 标签现在在日期右侧，用  |  分隔，显示在同一行。

  2. 保留了缩略图、摘要和作者显示的逻辑。

如果你愿意，我可以帮你加一点 CSS，让标签在同一行显示更美观，不会换行或者太拥挤。

Q2 · 好的（第 2 轮对话）

提问： 好的

可以在你的博客 CSS 文件（比如assets/css/style.css或_sass/custom.scss）里添加如下样式，让标签在同一行整齐显示，并和日期对齐：

.post-meta {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: 0.5em; /* 日期和标签间距 */
  font-size: 0.9rem;
  color: #666;
}

.post-meta a.post-tag {
  background-color: #f0f0f0;
  color: #333;
  padding: 2px 6px;
  border-radius: 4px;
  text-decoration: none;
  font-size: 0.85rem;
  margin-right: 4px;
  transition: background-color 0.2s;
}

.post-meta a.post-tag:hover {
  background-color: #d0d0d0;
}
效果：

  • 日期和标签在同一行显示。

  • 标签有浅色背景，带圆角，间距均匀。

  • 标签悬停会有颜色变化，便于区分。

如果你希望“标签靠右、日期靠左”，我可以帮你改成左右两端对齐的布局，这样更像新闻网站风格。

Q3 · 好的（第 3 轮对话）

提问： 好的

那我们可以把日期靠左、标签靠右，整行对齐，同时保持美观。可以在 CSS 中这样写：

.post-meta {
  display: flex;
  justify-content: space-between; /* 左右两端对齐 */
  align-items: center;
  flex-wrap: wrap;
  font-size: 0.9rem;
  color: #666;
  margin-bottom: 0.5em;
}

.post-meta .post-date {
  /* 日期左对齐 */
}

.post-meta .post-tags {
  display: flex;
  gap: 0.4em;
  flex-wrap: wrap;
}

.post-meta .post-tags a {
  background-color: #f0f0f0;
  color: #333;
  padding: 2px 6px;
  border-radius: 4px;
  text-decoration: none;
  font-size: 0.85rem;
  transition: background-color 0.2s;
}

.post-meta .post-tags a:hover {
  background-color: #d0d0d0;
}

然后在你的post.html模板中，把日期和标签分别加上类名：

<p class="post-meta">
  <span class="post-date">
    {% assign date_format = site.date_format | default: "%Y年%-m月%-d日" %}
    发布于 {{ post.date | date: date_format }}
  </span>

  {% if site.feed_show_tags != false and post.tags.size > 0 %}
    <span class="post-tags">
      {% for tag in post.tags %}
        <a href="{{ '/tags' | absolute_url }}#{{- tag -}}">{{ tag }}</a>
      {% endfor %}
    </span>
  {% endif %}
</p>

这样效果是：

  • 日期固定在左边

  • 标签固定在右边

  • 多个标签之间间距均匀，不会换行堆叠
