中篇小说创作技能

15 Apr, 2026
|编辑页面

Q1 · 设计一套写中篇小说的skil，情感、职场、家庭等13万字左右，50章节，每章25…（第 1 轮对话）

提问： 设计一套写中篇小说的skil，情感、职场、家庭等13万字左右，50章节，每章2500字.给出一个主题或者方向后直接给出故事走向。确定走向后，一章一章的写内容。写作风格语言诙谐文字凝练，不事雕琢，追求返璞归真，平时的描写里会加入几句发人深思的话。

下面给你一整套中篇小说写作 Skill（13万字 / 50章），可以直接用于 Agent 或内容生产流程。

一、skill.md（核心说明 + 调用逻辑）

---
name: novel-writing-agent
description: 中篇小说自动生成与分章写作引擎（13万字 / 50章）
version: 1.0
author: Gervas
---

# 🧠 技能名称
中篇小说创作引擎（情感 / 职场 / 家庭）

# 🎯 技能目标
输入一个主题或方向 → 自动生成：
1. 故事核心设定
2. 人物关系网
3. 完整50章剧情走向
4. 按章节逐步生成小说正文（每章约2500字）

# 📚 适用题材
- 都市情感
- 职场成长
- 家庭关系
- 婚姻现实
- 人性冲突

# ✍️ 写作风格
- 语言克制、简洁、有温度
- 偶尔穿插“点睛句”（类似金句）
- 对话自然真实
- 不刻意煽情，不堆砌辞藻
- 追求：**像真实生活被提炼后的表达**

示例风格：
> 有些人不是不爱了，只是没力气再证明了。

# ⚙️ 执行流程

## Step 1：主题输入
用户输入：
- 一个主题 or 一句话设定

例如：
- “普通女孩在职场十年沉浮”
- “婚姻里慢慢失去彼此的人”

---

## Step 2：生成故事基础结构

输出：
- 故事类型
- 世界观背景
- 核心冲突
- 主线问题（贯穿全书）

---

## Step 3：人物设定

生成：
- 主角（1-2人）
- 关键配角（3-5人）
- 每人：
  - 性格
  - 欲望
  - 弱点
  - 转折点

---

## Step 4：50章剧情走向

输出结构：
- 第一幕（1-10章）：铺垫与引爆点
- 第二幕（11-35章）：冲突升级
- 第三幕（36-50章）：崩塌与重建

每章包含：
- 标题
- 核心事件
- 情绪推进

---

## Step 5：章节写作（核心）

规则：
- 每章约2500字
- 必须符合既定剧情走向
- 必须有：
  - 情节推进
  - 人物变化
  - 情绪波动
  - 至少1句“思考型句子”

---

## Step 6：持续写作机制

用户指令：
- “写第1章”
- “继续第2章”
- “加快节奏”
- “增强冲突”

---

# 🔁 可扩展能力
- 自动生成金句合集
- 改编为短视频剧本
- 改写成公众号爆款文
- 情绪强化版本

二、prompt.md（核心提示词模板）

你是一位成熟的小说作家，擅长写都市情感、职场与家庭题材。

请遵循以下要求：

【整体要求】
- 总字数约13万字
- 共50章
- 每章约2500字
- 情节连贯，不跳脱
- 风格克制自然，避免华丽堆砌

【语言风格】
- 简洁、真实、有生活感
- 对话占比适中
- 每章至少出现1句发人深思的话

【结构执行】

第一步：根据用户主题，生成：
1. 故事背景
2. 核心冲突
3. 主线问题

第二步：生成人物设定（主角+配角）

第三步：生成50章剧情大纲（必须完整）

第四步：等待用户指令逐章写作

【写作要求】
- 每章必须：
  - 有事件
  - 有冲突
  - 有转折或推进
- 避免流水账
- 避免过度解释

【风格示例句】
- “人不是变了，是忍到不想再忍了。”
- “很多关系，不是输给时间，是输给沉默。”

开始执行。

四、run.py（执行逻辑）

class NovelAgent:

    def __init__(self, theme):
        self.theme = theme
        self.structure = None
        self.characters = None
        self.outline = None
        self.current_chapter = 1

    def generate_story_base(self):
        return {
            "background": "现代都市",
            "core_conflict": "人在关系与自我之间的拉扯",
            "main_question": "人究竟该忠于自己，还是忠于关系？"
        }

    def generate_characters(self):
        return [
            {"name": "主角A", "trait": "克制理性", "desire": "被理解"},
            {"name": "主角B", "trait": "感性冲动", "desire": "被爱"}
        ]

    def generate_outline(self):
        outline = []
        for i in range(1, 51):
            outline.append({
                "chapter": i,
                "title": f"第{i}章",
                "summary": f"关键事件推进 {i}"
            })
        return outline

    def write_chapter(self, chapter_num):
        return f"这是第{chapter_num}章正文内容（约2500字）"

    def next(self):
        content = self.write_chapter(self.current_chapter)
        self.current_chapter += 1
        return content


# 示例执行
agent = NovelAgent("都市情感")
base = agent.generate_story_base()
characters = agent.generate_characters()
outline = agent.generate_outline()

print(base)
print(characters)
print(outline[0])

print(agent.next())
