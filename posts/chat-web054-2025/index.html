🏗️ 一、系统总体设计：采购数据整合平台

🎯 系统目标

构建一个本地网页前端系统，实现对多个数据文件（成品、BOM、采购台账、供应商）的集中展示、查询、联动、统计与可视化分析。

💾 数据来源（全部本地 JSON 文件）
模块文件路径数据结构功能用途

产品BOMD:\采购管理系统\产品bom查询\bom_data.json成品与物料的对应关系用于展开物料组成与成本分析

供应商信息D:\采购管理系统\供应商管理\data.json编号、联系方式、信用等级、供应品类等供应商档案与协作状态管理

🧭 二、页面结构规划

1️⃣ 整体布局（左右分栏）

  • 左侧导航栏（可折叠）

  • 成品信息 - 产品BOM - 采购台账 - 供应商管理 - （可扩展）统计仪表盘、系统设置

  • 右侧内容区（动态加载）

  • 根据左侧导航显示对应模块的内容页面 - 支持表格展示、查询筛选、数据联动、统计可视化

📊 三、功能模块初步定义

（1）📦 成品信息模块

  • 从 成品查询/data.json 读取数据

  • 功能：

  • 按项目号 / 品名 / 品牌 / 渠道 查询 - 点击某条成品 → 自动加载对应BOM组成 - 可导出查询结果（CSV/Excel）

（2）🔩 产品BOM模块

  • 从 产品bom查询/bom_data.json 读取数据

  • 功能：

  • 按项目号 / 品名 查询BOM明细 - 点击“物料项目号” → 查询对应采购单价（引用采购台账data.json） - 自动计算单品总成本（数量 × 单价） - BOM层级展示（成品 → 组件 → 物料）

（3）💰 采购台账模块

  • 从 物料查询/data.json 读取数据

  • 功能：

  • 可查询物料项目号 / 供应商名称 / 合同编号 - 显示数量、单价、订单总额 - 统计： - 🧾 总采购金额 - 💼 各供应商采购占比（饼图） - 📈 月度采购趋势图（柱状图）

（4）🏭 供应商管理模块

  • 从 供应商管理/data.json 读取数据

  • 功能：

  • 查询供应商名称 / 品类 / 信用等级 - 显示供应商档案详情 - 状态筛选（合作中 / 已终止） - 点击供应商 → 关联显示其采购记录（引用采购台账data.json）

（5）📈 数据仪表盘模块（汇总展示）

  • 汇总来自各模块的关键指标

  • 总采购金额 - 各品牌成品数量 - 各品类供应商数量 - 平均单价趋势（折线图）

  • 使用 Tailwind + Chart.js 实现可视化

⚙️ 四、技术结构建议

项目技术选型
前端框架原生 HTML + TailwindCSS + 原生 JS（或 Vue.js 可选）
可视化Chart.js
数据存取fetch('data.json')本地加载（需放同目录或通过file://访问）
页面结构index.html + 各模块独立的 JS 文件（按功能区分）
交互模块切换、数据筛选、联动查询

🧩 五、页面交互设计

  • 左侧菜单点击后右侧内容区 动态切换

  • 各模块数据支持 搜索框 + 筛选条件

  • 表格支持排序、导出、分页（或自动加载全部）

  • 可选主题（浅色 / 深色）

  • 仪表盘入口在顶部菜单或左侧第一个位置

🧠 六、数据联动逻辑

  1. 成品信息 → BOM ：点击成品项目号 → 读取对应 BOM。

  2. BOM → 采购台账 ：在 BOM 中物料项目号 → 查询单价并计算成本。

  3. 采购台账 → 供应商 ：点击供应商名称 → 展示供应商档案。

  4. 仪表盘 ：动态汇总各模块数据统计结果。

🔒 七、运行方式

  • 放置在本地文件夹结构中，如：
  D:\采购管理系统\
  ├── index.html
  ├── 成品查询\data.json
  ├── 产品bom查询\bom_data.json
  ├── 物料查询\data.json
  └── 供应商管理\data.json
  • 用浏览器直接打开 index.html 即可运行（无需服务器）。

Q5 · 点击查询没有反应，怎么办（第 5 轮对话）

提问： 点击查询没有反应，怎么办

明白了，你遇到的问题是“查询按钮点击没有反应”。原因可能有几个，结合我们现有代码，我分析如下：

1️⃣ 问题原因分析

  1. 事件作用域问题
   event.target.classList.add('active');

在showModule()里用到了event.target，但是函数没有明确传event，导致报错或不执行，影响整个 JS。

  1. 浏览器本地 fetch 安全限制
  • 如果你直接用file://打开 HTML，fetch('成品查询/data.json')会被浏览器拦截，数据加载失败，查询自然也不工作。 - 解决方法：用本地服务器（如 VSCode Live Server、Pythonhttp.server）运行 index.html。
  1. 查询函数逻辑问题

-JSON.stringify(p).includes(keyword)匹配很宽松，但如果 keyword 为空或者输入类型不一致，可能没有匹配结果。 - 没有在查询函数里阻止默认表单提交或刷新，所以可能没有渲染表格。

2️⃣ 解决方案

方法 A：使用本地服务器

  1. 安装 VSCode Live Server ，右键 index.html → Open with Live Server

  2. 或者在命令行里进入 D:\采购管理系统\

   python -m http.server 8000

浏览器访问http://localhost:8000/index.html✅ 可以解决 fetch 数据无法加载问题

方法 B：修正showModule()函数

在按钮 HTML 中加上onclick="showModule('products', event)"，然后 JS 改为：

function showModule(module, event) {
  document.querySelectorAll('.content > div').forEach(d=>d.classList.add('hidden'));
  document.querySelector(`#${module}-module`).classList.remove('hidden');
  document.querySelectorAll('.sidebar button').forEach(b=>b.classList.remove('active'));
  if(event) event.target.classList.add('active');
}
方法 C：改进查询函数

把查询函数改为更严格的匹配，比如忽略大小写：

function queryProducts() {
  const keyword = document.getElementById('productSearch').value.trim().toLowerCase();

    tbody.appendChild(tr);
  });
}

Q7 · 还是不行（第 7 轮对话）

提问： 还是不行

明白了，你遇到的问题很可能是浏览器安全限制导致 fetch 无法读取本地 JSON 文件，这是浏览器对file://协议的限制，不是 JS 逻辑错误。即使查询函数、事件都改好了，如果直接双击打开 HTML，查询仍然不会生效。

原因分析
  1. 本地文件跨域限制
  • Chrome/Edge/Firefox 都不允许通过fetch('成品查询/data.json')访问本地文件，返回CORS错误或者null。 - 因此productsData等数组为空，查询按钮自然没有效果。
  1. 事件和渲染本身没问题
  • 你的queryProducts()、renderProducts()、showModule()都是正确的。问题在数据没有加载。
解决方案
方法 1：本地服务器（最简单）
  • 用 VSCode Live Server 插件：
  1. 打开 VSCode，打开D:\采购管理系统\目录 2. 右键index.html→Open with Live Server3. 在浏览器访问http://127.0.0.1:5500/index.html（端口可能不同） ✅ fetch 可以成功加载 JSON，查询和渲染都生效
  • 或者 Python 本地服务器：
  cd "D:\采购管理系统"
  python -m http.server 8000

方法 2：把 JSON 文件嵌入 JS
  • 如果不想启动服务器，可以把 JSON 数据直接写到 JS 文件中：
  let productsData = [ /* 这里直接复制 data.json 内容 */ ];

  • 这样就不依赖 fetch，查询按钮可以立即生效

  • 缺点：每次更新数据都要手动修改 JS 文件

  • 可以实现 真正读写本地文件

  • 保存按钮也可以直接覆盖原 JSON 文件

  • 如果你只是用浏览器直接打开 HTML 文件，查询功能无法工作，这是浏览器限制。

  }
});
