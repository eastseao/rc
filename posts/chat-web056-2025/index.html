Q2 · 成品BOM明细显示真实采购单价； 优化这一条就可以了（第 2 轮对话）

提问： 成品BOM明细显示真实采购单价； 优化这一条就可以了

明白，你希望在成品信息查询中点击“查看BOM”时，每条物料显示对应的真实采购单价，而不是当前的“—”。

结合你现在的代码，修改cpShowBOM函数即可：

function cpShowBOM(projectId) {
  const section = document.getElementById("cp-bomSection");
  const tbody = document.getElementById("cp-bomBody");
  const list = bomData.filter(i => String(i.项目号) === String(projectId));
  if(!list.length) { 
    section.classList.remove("hidden"); 
    tbody.innerHTML = "<tr><td colspan='5' class='text-gray-500'>未找到BOM</td></tr>"; 
    return;
  }

  tbody.innerHTML = list.map(row => {
    // 查找物料的采购单价
    const purchasePrice = tzDataCache.find(item => String(item.物料项目号) === String(row.物料项目号))?.采购单价 || "—";

    return `
      <tr class="hover:bg-red-50 transition">
        <td class="p-2 border-b">${row.物料项目号}</td>
        <td class="p-2 border-b">${row.物料名称}</td>
        <td class="p-2 border-b">${row.数量}</td>
        <td class="p-2 border-b">${row.计量单位}</td>
        <td class="p-2 border-b">${purchasePrice}</td>
      </tr>`;
  }).join("");
  section.classList.remove("hidden");
}

✅ 说明：

  1. 新增一行 const purchasePrice = … ，从 tzDataCache 里匹配物料项目号。

  2. 显示采购单价，如果没有匹配则显示 “—”。

这样点击“查看BOM”时，BOM表里的采购单价就是实际值了。
