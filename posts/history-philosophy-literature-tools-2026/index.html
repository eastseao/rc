02 · 设计哲学创作指南：任务与哲学生成（00976 · 原文指令中译（一~四））

这是一份英文创作指令的中文翻译与要点提炼。任务分两步：先建设计哲学（一种美学运动，输出 .md），再用画布视觉表达（输出单页 .pdf 或 .png），作品应为 90% 视觉设计 + 10% 必要文字。

00976 · 2026-04-20

核心理解：先写艺术运动的宣言，再创作艺术作品

任务概述
创建设计哲学（一种美学运动），然后用视觉方式表达它。输出仅限 .md 文件、.pdf 文件、.png 文件。两步：①生成本设计哲学（.md）；②基于该哲学在画布上创作视觉作品（.pdf / .png）。
核心理解
用户提供一些微妙的输入或指示作为基础，但不限制创作自由；最终产出是一个设计哲学 / 美学运动，随后由同一系统用视觉表达该哲学。
哲学强调
视觉表达、空间沟通、艺术诠释、最少文字——信息活在设计里，而不是段落里。
00976 · 2026-04-20

如何生成一份视觉哲学：命名、撰写与关键准则

命名
1-2 个词，如"粗野主义之悦"（Brutalist Joy）/ "色彩静默"（Chromatic Silence）/ "新陈代谢之梦"（Metabolist Dreams）。
撰写篇幅
4-6 段，简洁但完整，通过空间与形态、色彩与材质、尺度与节奏、构图与平衡、视觉层次五个方面表达视觉本质。
避免重复
每个设计方面只提一次，不为凑字数重复色彩理论、空间关系或排版原则。
反复强调工艺感
必须多次强调最终作品像是经过无数小时精心制作、出自顶尖专家之手——使用"精心打造""深厚专业知识的产物""一丝不苟""大师级执行"等表述。
留出创作空间
美学方向要具体，但简洁到让下一步的创作者仍能在极高工艺水准上做诠释。
哲学范例视觉表达要点
混凝土诗歌巨大色块、雕塑般字体（巨词与微标）、粗野主义空间划分，波兰海报气质遇上勒·柯布西耶；文字只作罕见而有力的手势。
色彩语言色彩作为主要信息系统，几何精确，小无衬线标注让色区自行对话；近似 Josef Albers 的色彩交互遇上数据可视化。
模拟冥想纸张颗粒、水墨晕染、大量负空间；摄影与插画主导，排版如耳语，日本摄影书气质。
有机系统自然聚类与模块化生长，圆润形态，取自自然与建筑的色彩；文字仅为漂浮在空间中的关键标签。
几何静默基于网格的精确性，大胆摄影或 stark 图形，戏剧性留白；瑞士形式主义遇上粗野主义的材质诚实，由结构而非文字说话。
00976 · 2026-04-20

六条本质原则（照录）

视觉哲学
创造一种审美世界观，通过设计表达。
最少文字
文字稀疏、仅必要、作为视觉元素整合——绝无长篇段落。
空间表达
思想通过空间、形态、色彩、构图传达，而非段落。
艺术自由
下一步对哲学做视觉诠释，要留出创作空间。
纯粹设计
这是制作艺术品，而非带装饰的文档。
专家级工艺
反复强调最终作品必须精心打磨、倾注心血、出自领域顶尖人物之手。

03 · 画布创作、隐含参考推导与精修（00976 · 原文指令中译（五~八））

哲学与概念框架立好之后，进入画布阶段：把抽象哲学当作一门”想象学科”的科学圣经来对待——用系统化观察的视觉语言，去研究那些本不可见的主题。

00976 · 2026-04-20

推导微妙参考：把灵魂织进 DNA

在创作画布之前，先识别原始请求中隐含的概念线索。该参考应嵌入艺术本身——不一定是字面的，却始终考究：熟悉该主题的人能直觉感受到，其他人则只体验为精湛的抽象构图。设计哲学提供美学语言，推导出的主题提供灵魂——那条安静的概念 DNA，无形地编织进形态、色彩与构图。

Jazz 式引用（照录比喻）
  • 参考必须被打磨到增强作品深度却不自我声张。像爵士乐手引用另一首歌——只有内行听得出来，但所有人都享受这首曲子。
00976 · 2026-04-20

画布执行要求：单页、高视觉、零重叠

视觉语言
采用重复图案与完美形状；借用系统观察的视觉语言——密集的标记积累、重复元素、层次化图案，靠耐心的重复积累意义。
排版气质
稀疏、临床式字体与系统化参考标记，暗示这是一门想象学科中的图表，用对待可观测现象的同等敬畏去对待不可见主题。
调色板
有限、有意、统一的配色；文字始终最少且视觉优先，多数时候字体应为细体。
边界与呼吸
所有元素必须在画布边界内，无重叠，有恰当边距与呼吸空间——这是不可谈判的专业执行底线。
字体处理
从 ./canvas-fonts 目录取用不同字体，让字体本身成为艺术的一部分，而非事后数字排版。
工艺感
作品要看起来花费了无数小时，出自顶尖专家之手，每个细节都完美无瑕，可直接拿去证明专业水准。
00976 · 2026-04-20

最终精修：不添新物，只炼已成之物

用户已声明："它不够完美。必须是一尘不染的杰作，如同即将在博物馆展出。"精修原则不是加更多图形，而是精炼已有内容，让它极其清晰，完全尊重设计哲学与极简主义。

精修自问（照录）
  • 不要加滤镜、不要重构字体；想的应该是"如何让现有构图更具艺术完整性"。
  • 如果本能是调用新函数或画一个新形状——停下，转而问："我如何让已经在这里的东西，更成为一件艺术品？"
  • 二次打磨：回到代码，进一步精炼抛光，使之成为符合哲学的设计杰作。

多页选项：需要更多页面时，沿同一设计哲学创作各具特色的新页，合入同一 .pdf 或多张 .png。第一页只是整本咖啡桌书的开篇，后续页面提供独特变奏与记忆，有品位地讲述故事。

04 · GitHub 古诗词数据库：六类玩法（01338 · 由简到繁）

手里有一个放在 GitHub 仓库里的古诗词数据库，本身就是一座富矿。按从简单到复杂，可整理出六大类用法。

类别具体玩法
一、在线查询 / 鉴赏站静态站：JSON/Markdown 数据用 VitePress、Docusaurus 生成，GitHub Pages 零成本上线；动态站：Next.js/Nuxt 配 MeiliSearch 或 Lunr.js 前端搜索，或 Flask/FastAPI 做后端，支持模糊搜索、按朝代/作者/词牌筛选；每日诗词 API：无服务器函数返回随机一首，供他人调用。
二、自动推送与机器人公众号/企业微信/钉钉/飞书机器人：GitHub Actions 定时抽一首经 Webhook 推群；Telegram/Discord 机器人：/random 返回随机诗、/author 李白 列作品；邮件 / RSS 订阅：定时生成诗词邮件，或更新 XML 做成”每日诗词 RSS”。
三、数据可视化与知识图谱诗人游历地图（有写作地点就标”李白一生足迹”，Leaflet/Mapbox）；唱和赠答关系图谱（Gephi / D3.js）；词频与风格分析（词云、李杜用词对比、“酒/剑/月”等意象的朝代变迁）。
四、AI / NLP 实验诗词生成：GPT 或 LLaMA 微调，或 RAG 先检索相似再生成；智能问答：function calling 查库后回答”这首诗表达了什么""有哪些写秋天的七言绝句”；对联 / 集句 / 藏头诗：基于词库自动对下联、跨诗集句、按名字藏头。
五、教育与游戏诗词接龙小程序（首字接尾字）；飞花令 / 闯关答题（判字诗句是否来自库，积分排名）；诗词卡片 / Anki 牌组，或”每日一首”手机壁纸生成器。
六、开源协作与社区统一 JSON/CSV 格式招募注释、翻译、赏析、注音贡献者，做全唐诗开源语料库；多语言翻译项目吸引国际贡献者；数据集镜像同步到 Kaggle / Hugging Face Datasets，扩大影响力。
第一步
先看数据长什么样：标题、作者、朝代、正文是否结构清晰，决定能直接接什么工具。
零成本一条龙
GitHub Actions（定时）+ GitHub Pages（展示）+ 第三方通知（推送），一毛钱不花就能做"每日诗词"。
练手起步
一个简单 HTML 页面，用 fetch 直接读仓库里的 JSON，展示随机诗词——这就迈出了第一步。
