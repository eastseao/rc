01 · 显卡内存解读：5966MB VRAM 与 10010MB 总显存（00727 · 2026-03-14）

原笔记里用户的查询结果是：显卡总内存10010MB、显卡内存（VRAM）5966MB。这两个数字揭示了一种「分工合作」模式：一块约 6GB 显存的独立显卡，再加系统借调约 4GB 的后备内存。

数字含义
5966MB 显卡内存（VRAM）独立显卡上的专用「高速工作台」，存储 GPU 正在实时处理的图像、纹理和数据，读写极快，对 Photoshop 大画布、大型 3D 游戏至关重要。
10010MB 总显存「总仓库」概念：5966MB 专用 VRAM + 从系统内存条划分出来的「共享系统内存」约 4GB。专用显存用满时系统自动调用这部分，速度慢一些但防崩溃。

Photoshop 创作：得心应手

  • 6GB 显存远超 Adobe 官方推荐的 2GB 以上配置，几千像素高清照片、数十图层复杂合成都流畅。
  • 神经滤镜、创成式填充等 AI 生成功能依赖显卡算力与显存，这个配置足以很好支持。

编程与 AI：大有可为

  • 6GB 是本地 AI 开发的「黄金起步容量」：可跑通并微调 7B–8B 开源大模型（Llama 3、Mistral 等），也能跑通 Stable Diffusion。
  • 瓶颈在超大规模模型——训练数十亿参数或 FLUX.2 这类可能需 90GB 以上显存的模型会吃力，可用 CPU + 系统内存分担但很慢。
  • Web / 移动 / 桌面软件开发等传统场景，显卡绰绰有余。
6GB 显存精选模型清单

适合这个配置的图像生成模型

模型特点与优势上手难度
Stable Diffusion WebUI开源社区万金油，生态最完善、插件极多（ControlNet 等）。6GB 是入门推荐配置，开--medvram后可流畅生成 1024×1024 及以下。中等
阿里 Z-Image-Turbo专为 6GB 显存优化的「快枪手」，1024×1024 数秒出图；6B 参数单流架构，中文理解极佳、文字生成准确。简单
美团 LongCat-ImageFLUX 风格高质量模型，约 6B 参数，复杂布局指令和摄影级写实人像出色，配强大图像编辑工具。中等
腾讯混元 DiT已推出小显存版本，明确适配 6GB，与 LoRA、ControlNet 插件无缝衔接。简单

建议路径：新手先把 SD WebUI 跑起来理解提示词、采样器、LoRA；再尝鲜 Z-Image-Turbo 感受速度。运行时启动参数加--medvram（中等显存优化）或--lowvram（低显存优化），分辨率从 512×512 逐步提到 1024×1024。

02 · Windows 安装 Z-Image Turbo（ComfyUI 新手方案）（00728 · 2026-03-14）

6GB 显存跑 Z-Image Turbo 完全可行，关键是选对量化模型版本 + 显存优化。新手最稳路径：装 ComfyUI 免安装版 → 下载三个量化模型文件放到指定目录 → 搭工作流 → 按 KSampler 推荐参数出图。

项目推荐配置低显存配置
GPUNVIDIA，16GB 及以上显存，可用标准模型NVIDIA，6–8GB 显存，必须用 FP8/INT8 量化版模型
系统Windows 10/11Windows 10/11
存储50GB 以上可用空间20GB 以上可用空间
第一步 · 装 ComfyUI

免安装版 + 首次启动

下载
官方 GitHub Releases 页找同时含windows、portable、nvidia的压缩包（ComfyUI_windows_portable_nvidia.7z）。
解压
解压到好找的目录（如D:\ComfyUI），路径不要含中文和空格。
启动
双击run_nvidia_gpu.bat；首次启动自动下载依赖，看到Starting server...或http://127.0.0.1:8188即成功，浏览器打开该地址进入界面。
git 报错
提示「'git' 不是内部或外部命令」说明没装 Git：装 Git（安装时 PATH 界面选「Git from the command line and also from 3rd-party software」），或手动把 GitHub 上ComfyUI-GGUF的 Code → Download ZIP 解压到ComfyUI/custom_nodes/。
第二步 · 模型三件套

放到 ComfyUI 指定目录（放错是新手最常见错误）

组件文件名（照录）放置目录
扩散模型z-image-turbo_fp8_scaled_e4m3fn_KJ.safetensors（约 6.5GB，FP8 量化版）ComfyUI\models\checkpoints\（新版也可能要求models\diffusion_models\，以节点下拉能看到为准）
文本编码器Qwen3-4B-Q4_K_M.gguf（约 2.5GB）ComfyUI\models\text_encoders\
VAEae.safetensors（约 335MB，不需量化）ComfyUI\models\vae\

来源：Hugging Face 搜索drbaph/z-img、bartowski/Qwen_Qwen3-4B-GGUF、black-forest-labs/FLUX.1-dev；官网慢可用镜像hf-mirror.com。遇「rate limit / IP 限制」需注册免费 HF 账号生成 read 权限的 Access Token 登录后再下。文本编码器 Q4_K_M 在质量与显存间平衡；显存再紧换 Q4_K_S，质量有余换 Q5_K_M。放好后点右下角「刷新」或重启 ComfyUI。

第三步 · 工作流与采样参数

节点连接 + KSampler 推荐值

双击画布空白处添加节点：Load Checkpoint（主模型）→ 两个 CLIP Text Encode（正/负提示词）→ Empty Latent Image（尺寸）→ KSampler → VAE Decode → Save Image，按接口连线。Z-Image Turbo 负向提示词影响很弱，可简单填low quality, blurry或置零。

KSampler 参数推荐值
steps9（该模型专为低步数优化，9 步即可出高质量图）
sampler_nameres_multistep或euler
schedulersimple或normal
cfg1.0–1.5（模型已内置提示词引导，不要高 CFG）
宽×高先 512×512 / 768×768 试跑，稳了再上 1024×1024
denoise文生图保持1.0

出图：点右上角「Queue Prompt / 队列提示」，图片落在 ComfyUI 目录的output文件夹。6GB 显存若报CUDA out of memory：启动脚本run_nvidia_gpu.bat里main.py后加--medvram（或设置里把 VRAM 管理模式设为 lowvram、UNET 精度设 fp8_e4m3fn），并降低分辨率、关掉占显存程序。

排障 · GGUF

文本编码器用不了 GGUF 的连环坑

  • 报ModuleNotFoundError: No module named 'gguf'：在 ComfyUI 目录地址栏输cmd打开命令行，运行.\python_embeded\python.exe -m pip install gguf（慢则加-i https://pypi.tuna.tsinghua.edu.cn/simple），装完重启。
  • CLIP 下拉没有可用选项：标准 CLIP Text Encode 不认识 .gguf。在 ComfyUI Manager 里安装ComfyUI-GGUF扩展并重启，改用DualCLIPLoaderGGUF（加载 gguf 文本编码器）、UnetLoaderGGUF（加载主模型）、VAELoader（加载 ae.safetensors）三个节点重连。
  • 加载器里看不到模型文件：文件放对目录（文本编码器在text_encoders\，扩散模型在diffusion_models\，别改名）；删节点重新添加或完全重启；还不行就更新 ComfyUI 核心（update\update_comfyui.bat）和 GGUF 扩展。
  • working around nvidia conv3d memory bug：不是报错，是 ComfyUI 检测到已知 CUDA 3D 卷积显存问题后自动启动绕过方案，正常忽略继续即可。

03 · 电脑配置查询命令（Windows / macOS / Linux）（01218 · 2026-05-26）

查配置不靠第三方软件也够用：系统自带图形工具 + 一行命令覆盖绝大多数需求。下表按操作系统整理原笔记收录的常用命令。

系统命令 / 工具用途
Windowsmsinfo32Win+R 运行，软硬件配置、主板、BIOS 版本等最全面的信息。
dxdiagDirectX 诊断工具，重点看显卡型号、显存、驱动版本，「显示」选项卡查看。
systeminfoCMD / PowerShell 运行，输出含网络配置和系统补丁的详细清单。
任务管理器Ctrl+Shift+Esc，「性能」标签页实时看 CPU、内存负载。
wmic cpu get name灵活提取特定硬件字段（如 CPU 型号），部分新版 Windows 需额外安装。
Get-ComputerInfoPowerShell 下获取结构化系统信息。
macOSsystem_profiler SPHardwareDataType终端运行，硬件概览，最全面的系统报告工具。
sysctl hw.memsize/sysctl hw.physicalcpu查内存大小 / 物理核心数等内核底层信息。
sw_versmacOS 版本号、构建号等系统版本信息。
Linuxsudo lshw -short列出详细硬件配置摘要（需 sudo）。
lscpuCPU 架构、型号、核心数和线程数。
lspci | grep -i vga列出 PCI 设备并筛选显卡。
free -h/df -h/inxi -Fxz内存与交换分区 / 硬盘分区空间 / 整合硬件摘要加温度（inxi 需另装）。

想更直观深入：Windows 可用CPU-Z（CPU 与内存时序）、GPU-Z（显卡 BIOS 与显存带宽）；跨平台全面检测选HWiNFO（支持 Windows / macOS / Linux）。

04 · Visual C++ 运行库修复多次无效的根治流程（01349 · 2026-06-26）

运行库修复多次无效，通常是旧版本残留、注册表损坏、系统文件被锁定或杀软干扰——单纯覆盖安装治标不治本。按「彻底清理 → 官方重装 → 系统修复」逐级深入，不必全部执行。

第一步 · 明确症状

先缩小范围

确认具体报错再动手：打开软件/游戏提示「缺少 MSVCP140.dll」「VCRUNTIME140.dll」；安装程序自身报错（如 0x80070643、1935）；或程序直接崩溃无提示。有错误代码可针对性搜索，没有就直接走下面的「清洁大法」。

第二步 · 核心修复

安全模式彻底卸载所有版本运行库

进安全模式
重启出现 Windows 标志前反复按F8；或按住Shift点开始菜单「重启」→ 疑难解答 → 高级选项 → 启动设置 → 重启 → 选安全模式。避免第三方软件和驱动锁定文件。
全卸
控制面板 → 程序和功能，按名称排序，把所有Microsoft Visual C++ 20XX Redistributable（x86 / x64 都算）从最新年份往旧年份全部卸载；卸载出错就用微软官方「Program Install and Uninstall Troubleshooter」选「卸载」处理。卸完重启。
清残留
Geek Uninstaller / CCleaner 清残留注册表项（先备份注册表）；C:\Windows\System32与SysWOW64里确认不属于当前系统的msvcp*.dll、vcruntime*.dll先剪切到备份文件夹再删。
第三步 · 官方重装

winget 一键装全（照录命令）

开始菜单右键开「终端(管理员)」，依次执行；或去微软官方下载中心搜「Visual C++ Redistributable 最新支持的下载」手动装（64 位系统 x64 和 x86 都要）。

# 安装最新的 2015-2022 合并包（x64 和 x86） winget install Microsoft.VCRedist.2015+.x64 winget install Microsoft.VCRedist.2015+.x86 # 安装老版本（按需） winget install Microsoft.VCRedist.2013.x64 winget install Microsoft.VCRedist.2013.x86 winget install Microsoft.VCRedist.2012.x64 winget install Microsoft.VCRedist.2012.x86 winget install Microsoft.VCRedist.2010.x64 winget install Microsoft.VCRedist.2010.x86 winget install Microsoft.VCRedist.2008.x64 winget install Microsoft.VCRedist.2008.x86

关键版本：2015–2022（一个包含 2015/2017/2019/2022）、2013、2012、2010、2008 SP1。装完重启。

第四~六步 · 逐级深入

系统修复 → 工具兜底 → 排除干扰

修系统文件
管理员命令提示符先跑DISM /Online /Cleanup-Image /RestoreHealth，再跑sfc /scannow，完成后重启测试。
DirectX 修复工具
「DirectX 修复工具增强版」里 工具 → 选项 → 高级，勾选「强力修复」和「同时更新 C++」，点检测并修复，强制注册所有 DLL 并修注册表。
排除外部干扰
装库时临时关杀毒软件/防火墙（装完恢复）；chkdsk c: /f查磁盘错误；校正系统时间（证书校验依赖）；精简版/Ghost 系统天生缺组件，最干净的办法是装微软原版 Windows。
终极方案
以上全无效时，用 Windows 安装介质做「保留个人文件和应用」的原地修复安装——重置所有系统组件而不丢数据。
原笔记叮嘱
  • 不要跳过「安全模式卸载」这一步——绝大多数「修复很多次没用」的死结，都是因为没卸干净旧版本残留。
