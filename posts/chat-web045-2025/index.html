Q2 · 采购单价加载失败，请检查路径或格式（第 2 轮对话）

提问： 采购单价加载失败，请检查路径或格式

明白了，这说明你的页面无法正确加载TZ/data.json文件。出现这个问题的原因通常有以下几种：

1️⃣ 路径错误

你现在的 fetch 是：

fetch('TZ/data.json?_v=' + Date.now())

  • 这个路径是相对于当前 HTML 页面的。

  • 如果你的 HTML 在 根目录/index.html ，而 data.json 在 根目录/TZ/data.json ，这个写法是对的。

  • 如果 data.json 在别的目录或 HTML 在子目录里，就会找不到文件。

✅解决办法：

  • 确认 HTML 文件位置与 TZ/data.json 相对路径正确。

  • 如果 HTML 在 root/page/index.html ，而 data.json 在 root/TZ/data.json ，就要改为：

fetch('../../TZ/data.json?_v=' + Date.now())
2️⃣ JSON 格式错误

  • fetch 成功返回，但 JSON 格式有问题（例如不是数组，或者字段名不对）。

  • 你可以在浏览器直接访问 http://你的域名/TZ/data.json ，看看能否正常打开。

  • 脚本里我写了：

if (!Array.isArray(data)) throw new Error("采购单价数据格式错误，必须为数组");

如果 JSON 是对象而不是数组，就会报错。

✅解决办法：

  • 确认 data.json 是数组形式：
[
  {"物料项目号":"M001", "采购单价":12.3},
  {"物料项目号":"M002", "采购单价":9.8}
]
3️⃣ CORS / 本地直接打开问题
  • 如果你直接用浏览器打开本地 HTML（ file:// 协议），浏览器可能禁止 fetch 本地 JSON 文件，导致加载失败。

✅解决办法：

  • 使用本地服务器：
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000/index.html
  • 或者把 JSON 文件放在和 HTML 同目录下，直接 fetch data.json 。
🔹 建议步骤

  1. 打开浏览器直接访问 TZ/data.json ，确认能看到 JSON 内容。

  2. 确认 JSON 是数组形式，并且字段名为 物料项目号 和 采购单价 。

  3. 确认 HTML 和 JSON 相对路径正确。

  4. 如果是本地打开 HTML，使用本地服务器解决跨域问题。

  • 假设文件结构是：

root/
 ├─ assets/
 │   └─ icons/
 │       ├─ currency.svg
 │       ├─ bom.svg
 │       └─ ...
 ├─ bom/
 │   └─ index.html
 ├─ tz/
 │   └─ index.html
 └─ index.html

那么在bom/index.html中写assets/icons/currency.svg实际路径会被解析为：

bom/assets/icons/currency.svg

是不存在的，所以无法显示。

✅ 解决方案：

使用绝对路径从网站根目录开始：

<img src="/assets/icons/currency.svg" class="mx-auto mb-2 h-10 w-10" alt="">

这样不管 HTML 文件在哪个子文件夹，都能正确加载。

2️⃣ 文件名大小写
  • 确保文件名完全匹配大小写，比如 Currency.svg 和 currency.svg 是不同的，尤其在 Linux 或 GitHub Pages 上。
3️⃣ SVG 文件问题

  • 确认 currency.svg 可以直接在浏览器打开显示。

  • 有些 SVG 里面用了外部字体或样式，可能导致看起来“空白”，可以尝试用 Chrome 打开测试。

明白，你希望产品系列的图标用在线图标库能稳定显示。我给你一个可直接使用的方案，使用**Font Awesome**的在线 SVG 图标。只需要在<head>引入 CDN，然后在卡片里用<i>标签即可。

示例修改你的“产品系列”卡片：

<!-- 引入 Font Awesome -->
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css" integrity="sha512-yF6n5K8XjV9s4VqI5G/wbI5uBjgx8VtLzoq8jVx+GHxjJXqvUpy2u5F0kM8kZf0V1OY1N0nXavfH4v0P/8mB9g==" crossorigin="anonymous" referrerpolicy="no-referrer" />

<!-- 产品系列卡片 -->
<a href="product/index.html" target="_blank" class="card bg-gradient-to-r from-yellow-400 to-yellow-500 text-white p-6 rounded-2xl text-center font-semibold shadow-md hover:shadow-lg">
  <i class="fas fa-box-open fa-2x mb-2"></i>
  <div>产品系列</div>
</a>

✅说明：

  1. 使用 替代 ，保证在线显示。

  2. fa-2x 控制图标大小，你也可以用 fa-3x 放大。

  3. mb-2 给图标和文字留间距。

  4. Font Awesome CDN 全部在线，不会再出现找不到图片的问题。
