Q2 · 进入文章页面，文章的宽度在哪个模块里修改（第 2 轮对话）

提问： 进入文章页面，文章的宽度在哪个模块里修改

在 Beautiful Jekyll 或类似 Jekyll 主题中，文章页面（单篇文章）的宽度通常不是在 Markdown 文件里设置的，而是在CSS 样式或布局模板中控制的。你可以从两个方向去修改：

1️⃣ 修改布局模板（HTML 文件）

文章页一般使用post或default布局。例如：

---
layout: post
---

对应的布局文件可能在：

_layouts/post.html
_layouts/default.html

里面通常有一个容器<div class="post-container">或<div class="content">控制文章区域。示例：

<div class="post-container container">
  <div class="row justify-content-center">
    <div class="col-lg-8 col-md-10">
      {{ content }}
    </div>
  </div>
</div>

  • col-lg-8 决定文章宽度占屏幕的 8/12（大约 66%）

  • col-md-10 中等屏幕时占 10/12（大约 83%）

  • 如果想加宽或缩窄文章内容，修改这两个类即可，例如 col-lg-10 col-md-12 。

2️⃣ 修改 CSS

如果你只想通过 CSS 调整宽度：

.post-container {
  max-width: 900px; /* 控制最大宽度 */
  margin: 0 auto;   /* 居中显示 */
  padding: 0 20px;  /* 左右内边距 */
}

  • max-width ：文章区域的最大宽度

  • margin: 0 auto ：水平居中

  • padding ：控制左右留白

💡总结

  • 最直接 ：修改 _layouts/post.html 或 _layouts/default.html 中的 .col-xx-x 类。

  • 灵活控制 ：在 CSS 里设置 .post-container 的 max-width 和 padding 。

Q3 · 修改default，宽度占col-lg-8:<ht…（第 3 轮对话）

提问： 修改default，宽度占col-lg-8: {{ page.title | default: site.title }} {% include header.html %}

你想让文章宽度固定为col-lg-8，可以直接在<main>的容器里改为container+row+col-lg-8的 Bootstrap 布局，例如这样修改你的default布局：

<main>
  <div class="container">
    <div class="row justify-content-center">
      <div class="col-lg-8">
        
        <!-- 页面内容前的额外 include -->
        {% if page.before-content %}
          <div class="before-content">
            {% for file in page.before-content %}
              {% include {{ file }} %}
            {% endfor %}
          </div>
        {% endif %}

        <!-- 正文内容 -->
        {{ content }}

        <!-- 页面内容后的额外 include -->
        {% if page.after-content %}
          <div class="after-content">
            {% for file in page.after-content %}
              {% include {{ file }} %}
            {% endfor %}
          </div>
        {% endif %}

      </div>
    </div>
  </div>
</main>
说明：

  1. 外层用 container 保持响应式布局。

  2. row justify-content-center 让内容水平居中。

  3. col-lg-8 设置大屏宽度为 8/12（约 66%），中小屏幕会自动撑满或缩小。

如果你希望中小屏幕宽度也有控制，可以加上col-md-10 col-sm-12，例如：

<div class="col-lg-8 col-md-10 col-sm-12">

这样文章在手机端、平板和桌面端都能有合理宽度和居中效果。

        <div class="col-lg-8 col-md-10 col-sm-12">

              {% for file in page.before-content %}

            </div>

      </div>
    </div>
  </main>

</body>
</html>
✅ 关键点：

  1. container ：保持响应式整体布局。

  2. row justify-content-center ：让文章区域水平居中。

  3. col-lg-8 col-md-10 col-sm-12 ：大屏占 8/12，中屏占 10/12，小屏占满屏。

这样，无论是桌面、平板还是手机端，文章都居中且宽度合理。
