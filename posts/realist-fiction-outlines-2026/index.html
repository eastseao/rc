01 · 四篇构思总览（00899 / 00946 / 00965 / 01227）

四篇都是现实向，但体量与体裁不同：一篇五卷长篇年代史诗、一篇主题式故事群（一轮轮迭代梗概）、一则盐选短情感系列人设、一个 30 章中篇慢爱情。按由大到小、由史诗到恋爱排列。

02 · 《流水人家》：杭州四十年五卷史诗（00899 · 2026-04-11）

仿《活着》笔法，第一人称口述体——晚年王浩向孙辈讲述。以「水」为意象：西湖静水、钱塘江潮、大运河活水、数字经济数据流。历史大事不正面铺陈，化作粮票换盒饭、BP 机换 iPhone、老宅拆迁搬滨江公寓等生活切面。

卷次时间 / 主题行业变迁 · 城市空间 · 人物命运
卷一 水上人家1980-1990
运河船民第三代。水运衰落 / 纺织技改；运河—拱宸桥；父亲王德发 1987 年被迫「上岸」买二手货车。尾声搬离运河，把祖传船桨挂上新家墙。
卷二 潮涌钱塘1990-2000
旧城改造 / 汽车消费兴起；老城—庆春路；父亲开杭州第一批搬家公司，母亲环北小商品市场卖服装，王浩 1999 开汽车美容店。望江对岸萧山仍是一片漆黑。
卷三 数字浪潮2000-2010
电商崛起 / 房地产起飞；滨江—钱江新城；娶阿里客服林晓雨，2008 金融危机三店关门、地铁征迁，2010 转做二手车并打通淘宝。
卷四 大城崛起2010-2020
移动互联 / G20 与亚运；全城—国际舞台；2017 晓雨查出癌症晚期、2018 病逝，王浩酗酒，疫情后被儿子教用钉钉、决定重新开始。
卷五 江流入海2020-2026
AI 浪潮 / 新能源；全域—智慧城市；改行经典车修复工作室，2023 父亲八十八岁睡梦中辞世，儿子王远帆机器人社团拿全省冠军。全书终幕回到拱宸桥。

四条核心意象（照录）

水
运河（传统）→ 钱塘江（开放）→ 西湖（底蕴）→ 数据流（未来）。
船桨
王德发刻字「1987 上岸，2014 运河申遗」，王浩补「2023，江河入海」。
方向盘
货船舵轮 → 货车方向盘 → 经典车方向盘 → 自动驾驶，人与工具关系的变迁。
桥
清泰立交桥（1985）、钱江三桥（1997）、拱宸桥（古桥），连接过去与未来。

写作五要

叙事声调
《活着》式冷抒情——大事轻描淡写，细节反复摩挲；情感藏在动作里。
行业融入
五卷对应水运+纺织 / 城建+汽车 / 电商+地产 / 移动互联+会展 / AI+新能源。
城市空间
王浩活动半径随时代迁移：运河→老城→城西滨江→钱江新城→全域。
杭州味道
对话自然植入片儿川、葱包烩、吴山夜茶、运河边拆迁争执。
避免宏大
G20 只写停业一周与西湖灯光秀；金融危机只写关门那天抽的烟。

03 · 「向下扎根」故事群：多轮迭代梗概（00946 · 2026-04-15）

立意句：「向下扎根从来不是懈怠，而是最清醒的成长……那些不为人知的积累，都是你未来向上的力量。」笔记围绕此立意跑了四轮梗概，另附一个完整三幕大纲《深根者》。下表按轮次照录主角与点睛。

基线大纲：《深根者》三幕（植物学家林深）完整三幕

主角林深：沉默寡言、专注力惊人但社交笨拙的植物学博士；导师苏韵是追求快速突破的天才，护林员老陈是「向下扎根」的活化身。课题为研究数十年才开花一次的孑遗植物「星尘」。

幕次核心
第一幕 不被看见的扎根期同事沉迷基因编辑，林深却花大量时间改培养土微生态、模拟地下温度波动、记录根系分泌物；无无论文无数据，只有几本厚笔记。
第二幕 沉淀与转折实验室遇瓶颈、竞争团队将抢先发表；林深带最弱幼苗住进老陈守护的原生山林，做「倾听泥土」三件笨事，发现「地下交响乐」营养交换脉冲。
第一轮：四则偏「静水流深」的故事5 则
故事 / 主角核心梗概与点睛
《荒原上的树》林远城规毕业生被分到西北林业站，种树看着八成死去；挖出五年前胡杨根系是地上七倍，懂「向下扎根触水脉」。十年成最年轻治沙英雄。
《沉默的琴》陈知微12 岁拿全国金奖后被父亲要求「三年不弹曲」，只练一个单音；三年后触弦即成山河，大师评「老僧入定后的功夫」。
《暗夜书店》苏晚辞职开「没有畅销书」的书店亏五年，手写三千份荐书单、办四百场读书会；暴雨淹街时读者从四面八方来相帮，重新开业人流五年最多。
《地下室里的八年》陆鸣基础数学研究员八年发五篇论文引用不足二十，独自证明困扰学界半世纪的「模形式算术性质猜想」，受邀国际数学家大会报告。
《竹农的等待》老周毛竹前三年几乎不见长、根系地下蔓延几十米，第五年雨季六周长到十五米；后山新竹终成百里最茂盛竹海。
第二轮：跌宕起伏 · 符合当下阅读口味（一）4 则
故事 / 主角标签与梗概
职场透明人 林盏#大女主逆袭 旧业务数据管理部「透明人」，被请进会议室拿出 300 页复盘报告（17 个失败节点+重启方案），原来早把「死掉的业务」当课题研究。
乒乓球陪练 陆鸣#体育竞技 天才少年得罪教练被下放市队当陪练三年，收集 37 种打法数据、自创破解旋转球肌肉记忆法，世锦赛奇兵逆袭。
误诊笨小孩 陈默#情感治愈 从小被当「笨小孩」，实为罕见「听觉处理障碍」，拥有常人 300% 视觉记忆与模式识别，终成顶级医学影像分析师。
直播仓管 老周#中年逆袭 线下代理商倒闭后做仓管，三年手工整理 3000 多 SKU、10 万条评论，白板画出爆款生命周期图谱、精准预言爆品。
第二轮：跌宕起伏 · 符合当下阅读口味（二）4 则
故事 / 主角标签与梗概
芯片偏执狂 江一舟#硬核创业 坚持自研 RISC-V 被裁、被业界联合拉黑，回乡四年二手服务器零产出；制裁断供时拿出完全自主方案，低端机海外爆火。「风没来时，我就造风车。」
00后入殓师 苏蓝#治愈职业剧 殡仪馆三年，为毁容女孩复原面容、记逝者喜好、自学手语；以一张折成千纸鹤的旧照击中名导，催生电影《入殓师的手》。
电竞数据幽灵 林北#电竞逆袭 手速慢被所有青训拒绝，当「替补的替补」三年画满 87 本对手走位热图；被迫顶上时「开了全图挂」般预判，后转战术教练。
代驾深夜图书馆 赵国强#现实温情 45 岁下岗工跑代驾，三年记录 1200 个深夜乘客故事，被出版社编辑发现，《深夜代驾笔记》出版销量破百万。
第三轮：全新领域 · 反差感更强4 则
故事 / 主角标签与梗概
清洁工画家 沈悬#艺术打脸 美院生在顶级画廊当清洁工，深夜用拖把水、咖啡渍练线条，默背大师真迹成「视觉数据库」；「清洁工系列」被顶级藏家抢购。
草籽博士 林远#乡村振兴 农学博士回乡五年只种根系极深的冰草，大旱时冰草锁住深层水、发现固氮耐旱菌种，800 万买断专利。
盗墓村阿木#考古身份反转 盗墓贼后代考北大考古系，三年手铲清理 3000 多片陶片、绘出遗址分布图，国际会议上以残留土壤锁定流失文物墓葬编号。
盲人攀岩 赵石#残障励志 失明前是国青攀岩种子，三年用手掌「读」遍全国 37 个馆、记住 2 万+手点；首届残攀锦标赛全盲 B1 级夺冠，快第二名 47 秒。

四轮梗概共通结构：前期被误解 / 被低估 / 被遗忘 → 中期低谷里无人问津的积累 → 后期环境或机遇反转时一举爆发。

04 · 盐选情感系列：单身时光 · 陈小麦（01227 · 2026-05-28）

系列立意：「大学单身期即自我增值期」。每篇围绕一位因专注学业 / 事业 / 成长而错过校园恋爱的毕业生，串起从自我怀疑到释然自信的弧光，传递「先成为更好的自己，再遇见更好的爱情」。

陈小麦 · 22 岁

《大学四年没谈过恋爱，毕业后我才懂：单身的那几年，其实很好》

基本信息
985 高校优秀毕业生，连续三年国家奖学金；长得好看却本人不在意。
性格
认真踏实、宁缺毋滥；内向孤独、表面坚强内心敏感自卑；坚韧独立。
情感经历
暗恋大一学生会主席陈浩、表白被拒（「我有喜欢的人了」）；追求者赵亮（送早餐写情书）、李明（送奶茶买药）均因「没感觉」拒绝；最终伴侣——公司老板顾晨，因欣赏她实习那份严谨的竞品分析报告，年会当众表白。
人物弧光
从「优秀但孤独、因没谈恋爱而自我怀疑」的毕业生，成长为「认可自我价值、相信对的人会在对的时间出现」的自信女性。

50 字一句话简介（照录）：陈小麦——985 优秀毕业生，认真努力、宁缺毋滥。暗恋被拒后专注成长，最终遇见欣赏她的顾晨。

05 · 《四站心动》：地铁邂逅 30 章慢爱情（00965 · 2026-04-16）

灵感即开头那一幕：早高峰地铁挤到脸贴脸，男生双手举高四站没动，女孩终于小声说「你可以放下来的……放我腰上」。书名建议《四站心动》或《地铁三十三号线》。时间跨度从初遇到结婚约 2-3 年。

阶段章节节拍
一、相遇1-6四站的距离 → 借你的手 → 第三天默契 → 她叫沈溪（广告公司设计师）→ 公司隔一条街、带早餐回赠咖啡 → 第一次约饭。
二、靠近7-14周末看展 → 撞见她前任 → 深夜送回家 → 他告白咽回 → 她在他怀里抬头问「你到底要不要和我在一起」→ 确定关系、见朋友。
三、深陷15-20第一次争吵 → 地铁上她握他手无声和解 → 她生日惊喜 → 回家见父母 → 他工作低谷她陪着。
四、考验21-26她异地三个月、他写日记 → 他偷偷飞去在地铁站等她下班 → 她有留任升职机会 → 她放弃机会回来「好工作到处有，好人只有一个」→ 在最初站台求婚。
五、余生27-30筹备婚礼 → 婚礼上伴郎讲「举了四站的手」全场笑 → 蜜月 → 婚后回到那个站台闭环：「现在不用举了，我有扶手了。」
他 · 陆鸣
28 岁，互联网公司产品经理；温和内敛、有点笨拙但真诚，因尊重女性显得「慢半拍」，骨子里是教养。
她 · 沈溪
27 岁，广告公司设计师；外表安静内心勇敢，观察力强，关键时刻总推他一把。
核心主题
不是「拥挤地铁上的暧昧」，而是一个懂分寸的男孩与一个敢主动的女孩，在快节奏城市里选择慢慢靠近。
贯穿配角
那句「你口水流出来了」的大叔，可作贯穿全文的温暖配角；首尾呼应地铁站完成闭环。
