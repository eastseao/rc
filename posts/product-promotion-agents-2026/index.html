01 · 铝罐企业推广双方向：GEO + 海外社媒（00905）

以上海瑞迪成包装科技有限公司为例（气雾罐、螺纹瓶、饮料铝瓶、二元阀门、塑料配件），推广分国内、国外两条线。

国内：GEO 语料投喂

  • 持续向 DeepSeek、豆包、文心、Kimi、通义投喂语料，让 AI 搜索引用品牌；
  • 3—6 个月目标：AI 答案引用率 ≥ 30%，核心词首屏展现 ≥ 70%，内容覆盖 ≥ 50 篇；
  • 渠道：官网 News、知乎、百家号、公众号、小红书、抖音/B 站、1688/慧聪。

国外：社媒引流独立站

  • TikTok 工厂实拍、LinkedIn 专业 B2B、Facebook 广告、Instagram 视觉、YouTube 深度内容；
  • 引流闭环：社媒 → Bio/评论链接 → 官网落地页 → Inquiry Form → WhatsApp/邮件 → 报价 → 样品 → 成交；
  • 3 个月目标：粉丝 5000+，月询盘 100+，官网流量增长 50%+。

03 · 推广与采购 Agent 设计（00907）

把「市场推广产品经理」和「采购」两个岗位固化成 Agent：一个快速出方案，一个稳重控成本。

快速推广 Agent

  • 定位：市场推广产品经理，快速出推广方案；
  • 输入产品卖点与目标人群，输出渠道组合与节奏；
  • 风格：反应快、给选项、可直接执行。

稳重采购 Agent

  • 定位：采购 Agent，稳重、比价、控风险；
  • 输入物料清单，输出供应商对比与建议；
  • 风格：重数据、留缓冲、不拍脑袋。

04 · 内容 Agent：爆款记者与写作人设（00978 / 01050）

推广内容的产量与质量，靠固定人设的内容 Agent 来稳定。两类参考：一位「爆款记者」人设，一套从爆款网文里提炼的写作规范。

美琪 · 爆款记者人设

用记者视角做推广内容

定位
「美琪」是一位爆款记者式内容 Agent，擅长把产品信息写成有钩子、有节奏的内容。
手法
抓冲突、给数据、留悬念，让推广稿不像广告。
产出
标题 + 开头钩子 + 正文卖点 + 结尾转化，成稿可直接排期。

另一类参考是从爆款网文（如《仙官有令》《大奉打更人》）里反推的写作规范，照录几条最可迁移的：

写作规范要点
节奏张弛紧张—放松—专注循环，不长时间保持单一密度。
人设反差笑点靠人物性格反差，不靠硬堆段子。
爽点服务剧情爽点要推动后续剧情/关系，不为打脸而打脸。
文风简洁短句为主，描写克制，信息密度高。

05 · 京东产品信息拉取失败的教训（00583）

事件

自动从京东拉取产品信息失败。

原因是京东页面结构变化/反爬策略导致原定拉取脚本拿不到字段。教训：自动化拉取要做容错与降级，失败时不要静默，要提示并给出人工补录路径。

改进动作

  • 拉取失败时明确报错，不假装成功；
  • 保留人工补录入口，不让流程卡死；
  • 对依赖外部页面的脚本，定期做可用性检查。
