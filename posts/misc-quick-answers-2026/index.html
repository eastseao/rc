PDF 与图片导出设置

PDF 页面尺寸/方向/页边距在「文件 > 导出 > PDF」弹窗直接设置；默认导出路径、导出后行为在「偏好设置 > 导出 > 通用」配置。通过编辑当前主题 .css 文件可添加页眉页脚、避免代码块跨页、设置跨平台字体族。

@page { @top-center { content: "文档标题"; } @bottom-right { content: "第 " counter(page) " 页"; } } @media print { pre { break-inside: avoid-page; overflow: hidden; } } body { font-family: "Helvetica Neue", Arial, "Hiragino Sans GB", "Microsoft YaHei", sans-serif; }

图片导出：原生支持 PNG/JPEG，在「偏好设置 > 导出 > 图片」指定图像宽度（像素）与字体大小。

00953 · 常识

什么是制服

制服是特定团体（军队、警察、学校、公司）统一规定成员穿着的服装。核心作用有二：一是标识身份，一眼看出职业或所属机构；二是建立统一感，规范团队形象、增强纪律性与归属感。常见类型包括军警服、护士服、校服、酒店/航空职业装。与工装的区别：工装更侧重功能性（防尘、防静电），制服更强调身份象征与视觉统一；两者有时交叉（如厨师服）。

00897 · 科普

长江为什么不能用来输电

「水能导电」是错觉——纯水几乎不导电，我们说的导电是因为溶解了矿物质与盐分。长江水含大量矿物质和泥沙，电阻率比铜高约 10 亿倍，直接输电有四个致命问题：

问题原理
巨大能量损耗电流通过江水大部分变成热量耗散，电还没送到用户就在河里「烧」光了
短路与漏电长江与大地相连，整个河道是巨大接地体，电流迅速向两岸土壤地下水泄漏，无法形成受控回路
电解与腐蚀通直流电在电极上产生氢气/氯气并溶解金属电极；交流电也加速腐蚀，电极可能几小时内耗尽
生态灾难电解气体与金属离子毒害水生生物，泄漏电流电死鱼类，整个流域生态遭毁灭性打击

真正输电需要高纯度金属导线（铜、铝）利用自由电子定向移动高效传输。长江水不是「导电体」而是「漏电体」。
