中药饮片包装空隙率 · 包装孔隙率测算笔记

30 Apr, 2026
|编辑页面

本文合并自以下笔记：00130-2025-09-26-中药饮片包装空隙率要求探讨.md；01076-2026-04-30-包装孔隙率测算方法.md。

01 · 中药饮片包装空隙率的合规现状（00130）

目前没有专门针对中药饮片的统一、明确的强制性国家标准，但并非毫无约束：原则性要求与地方 / 团体标准正在发展。

要求类别适用对象核心要求与来源
药品包装物减量指南片剂和胶囊剂包装层数不宜超过三层；对包装空隙率有相应限定。系全国首个团体标准《药品包装物减量指南 片剂和胶囊剂》，重点针对集采药品，上海率先发布。
限制商品过度包装通用要求所有商品（含药品）依《固体废物污染环境防治法》，生产经营者应遵守限制过度包装的强制性标准，为监管提供法律依据。

操作建议

  • 参考相近标准精神：层数建议不超三层、控制不必要空隙，避免「大盒装小产品」。
  • 关注地方药品监管部门通知与医院 / 医药公司客户的内部要求。
  • 从企业自身做起：减层、选可循环 / 易降解材料、降本，符合绿色包装趋势。

02 · 两种「孔隙率」与测算公式（01076）

「包装孔隙率」涉及两种上下文：① 包装材料的物理性能（密封阻隔）与② 商品包装的合规性（销售包装是否过度）。

材料孔隙率

综合材料
基于密度算总孔隙率（含开孔闭孔）：P = (1 − ρb / ρt) × 100%，ρb 体积密度、ρt 真密度。
瓦楞纸板
空气渗透法测表面孔隙率：Gurley 法（测固定体积空气穿过时间）、Sheffield / 本特生法（测空气流量）。
内部结构
图像分析法算二维截面孔隙面积占比或三维重建；压汞法测孔径分布。

商品包装空隙率（GB 23350-2021）

公式
X = [ Vn − ∑(k·V0) ] / Vn × 100%
Vn
销售包装总体积（mm³），由外包装长宽高计算。
k
商品必要空间系数，反映保护性空间。
V0
内装物体积（mm³）；1g 或 1ml 对应 1000mm³，多种商品各自 k×V0 相加。

03 · 食品空隙率分段限值与 k 值（01076 · GB 23350-2021）

商品包装空隙率受法规限制。例如单件净含量 >50g 的茶叶，空隙率须**≤30%**。

单件净含量 Q空隙率上限
Q > 50 mL 或 g≤ 30%
30 mL 或 g < Q ≤ 50 mL 或 g≤ 40%
Q ≤ 30 mL 或 g≤ 75%

典型 k 值与关键更新

商品类别k 值 / 说明
茶叶（其他茶叶及相关制品）k = 13.0（与酒类、化妆品相比偏高）
紧压茶k = 9.0
11 类特定茶叶（太平猴魁、六安瓜片、安吉白茶、武夷岩茶等）k = 20.0
叶类和花类代用茶k = 60.0
月饼k 从 12.0 降至7.0
粽子k 从 12.0 降至5.0
酒类 / 粮食 / 糕点（对照）酒类 k=4.5、粮食 k=5.0、糕点 k=12.0

判定细节

  • 礼盒含不同净含量商品：按净含量最大的那个判定空隙率要求。
  • 「仅一层包装」豁免：直接接触食品的那一层无需计算空隙率和层数。
  • 包装层数：粮食及其加工品、月饼、粽子不超 3 层；其他商品（含茶叶）不超 4 层。
  • 算达标需先确认商品 k 值与净含量，再代入公式求最大允许包装体积。
