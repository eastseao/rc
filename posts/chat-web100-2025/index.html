{{ page.title | strip_html }}

{% endif %}

可以通过调整一些样式和结构，使文章页面的呈现更加美观，尤其是在响应式布局和排版方面。我做了一些优化，主要是增强可读性和视觉效果，包括对封面图、正文、以及标签和分类部分的改进。以下是修改后的代码：

---
layout: default
---

{% assign date_format = site.date_format | default: "%Y年%-m月%-d日" %}

<div class="post-container py-5" style="background-color:#fff;">
  <div class="container">
    <div class="row justify-content-center">
      <!-- 大屏 col-lg-8，中屏 col-md-10，小屏 col-sm-12 -->
      <div class="col-lg-8 col-md-10 col-sm-12 px-3">

        <article class="post-content">

          <!-- 文章标题和副标题 -->
          <header class="post-header text-center mb-4">
            <h1 class="post-title">{{ page.title | strip_html }}</h1>
            {% if page.subtitle %}
              <h2 class="post-subtitle text-muted">{{ page.subtitle | strip_html }}</h2>
            {% endif %}

            <!-- 元数据一行显示，手机端自动换行 -->
            <div class="post-meta mt-3 small text-muted d-flex flex-wrap justify-content-center gap-3">
              {% if page.author %}
                <span class="author">作者：<strong>{{ page.author | strip_html }}</strong></span>
              {% endif %}
              <span class="published-date">&middot; 发表于 {{ page.date | date: date_format }}</span>
              {% if page.last-updated %}
                <span class="updated-date">&middot; 更新于 {{ page.last-updated | date: date_format }}</span>
              {% endif %}
              {% assign words = content | number_of_words %}
              {% assign minutes = words | divided_by:200 %}
              {% if minutes < 1 %}{% assign minutes = 1 %}{% endif %}
              <span class="reading-time">&middot; 阅读时间：{{ minutes }} 分钟</span>
            </div>
          </header>

          <!-- 封面图 -->
          {% if page.cover-img %}
            <div class="post-cover text-center mb-4">
              {% if page.cover-img.first %}
                <img src="{{ page.cover-img[0].first.first | relative_url }}" alt="Cover image" class="img-fluid rounded shadow-sm">
              {% else %}
                <img src="{{ page.cover-img | relative_url }}" alt="Cover image" class="img-fluid rounded shadow-sm">
              {% endif %}
              {% if page.cover-img-desc %}
                <p class="img-desc mt-2 text-muted small">{{ page.cover-img-desc }}</p>
              {% endif %}
            </div>
          {% endif %}

          <!-- 正文内容 -->
          <div class="post-body" style="line-height:1.8; font-size:1.1rem;">
            {{ content }}
          </div>

          <!-- 页脚：标签和分类 -->
          <footer class="post-footer mt-5 pt-3 border-top d-flex flex-wrap gap-3 justify-content-between">
            {% if page.tags %}
              <div class="post-tags">
                <strong>标签：</strong>
                {% for tag in page.tags %}
                  <a href="{{ '/tags#' | append: tag | relative_url }}" class="tag-badge">{{ tag }}</a>
                {% endfor %}
              </div>
            {% endif %}

            {% if page.categories %}
              <div class="post-categories">
                <strong>分类：</strong>
                {% for category in page.categories %}
                  <a href="{{ '/categories#' | append: category | relative_url }}" class="category-badge">{{ category }}</a>
                {% endfor %}
              </div>
            {% endif %}
          </footer>

        </article>

      </div>
    </div>
  </div>
</div>
主要修改点：

  1. 封面图： 增加了 shadow-sm 类来为封面图添加轻微的阴影效果，使其视觉效果更加立体。

  2. 标题副标题： 副标题使用 text-muted 进行淡化，提升视觉层次感。

  3. 正文内容： 增加了 font-size: 1.1rem; ，使文章内容的字体稍大一些，提升可读性。

  4. 元数据： 对于元数据（如作者、发布时间、阅读时间等），增加了 gap-3 ，使其在手机端展示时更加灵活。

  5. 标签和分类： 在页脚部分，将标签和分类部分的展示方式调整为更加简洁的 d-flex 布局，避免了过多的占位符，使页面更具现代感。

这样改进后，页面在大屏设备上仍然保持良好的布局，在中小屏上也会自动调整，从而保证了响应式的效果。你可以尝试应用这些修改，看效果如何！

Q2 · 在电脑端网页上的呈现，两边完全没有页边距（第 2 轮对话）

提问： 在电脑端网页上的呈现，两边完全没有页边距

如果你在电脑端查看时发现文章页面的两侧没有页边距，可能是因为容器的宽度过于填满整个视窗，或者container类没有适当的padding或margin设置。可以通过调整container或外部容器的样式来增加页边距。以下是针对电脑端的优化，确保页面内容不会紧贴两边。

你可以通过修改以下代码来为文章页面加上左右的页边距：

---
layout: default
---

{% assign date_format = site.date_format | default: "%Y年%-m月%-d日" %}

<div class="post-container py-5" style="background-color:#fff;">
  <div class="container" style="padding-left: 15px; padding-right: 15px;">
    <div class="row justify-content-center">
      <!-- 大屏 col-lg-8，中屏 col-md-10，小屏 col-sm-12 -->
      <div class="col-lg-8 col-md-10 col-sm-12 px-3">

        <article class="post-content">

          <!-- 文章标题和副标题 -->
          <header class="post-header text-center mb-4">
            <h1 class="post-title">{{ page.title | strip_html }}</h1>
            {% if page.subtitle %}
              <h2 class="post-subtitle text-muted">{{ page.subtitle | strip_html }}</h2>
            {% endif %}

            <!-- 元数据一行显示，手机端自动换行 -->
            <div class="post-meta mt-3 small text-muted d-flex flex-wrap justify-content-center gap-3">
              {% if page.author %}
                <span class="author">作者：<strong>{{ page.author | strip_html }}</strong></span>
              {% endif %}
              <span class="published-date">&middot; 发表于 {{ page.date | date: date_format }}</span>
              {% if page.last-updated %}
                <span class="updated-date">&middot; 更新于 {{ page.last-updated | date: date_format }}</span>
              {% endif %}
              {% assign words = content | number_of_words %}
              {% assign minutes = words | divided_by:200 %}
              {% if minutes < 1 %}{% assign minutes = 1 %}{% endif %}
              <span class="reading-time">&middot; 阅读时间：{{ minutes }} 分钟</span>
            </div>
          </header>

          <!-- 封面图 -->
          {% if page.cover-img %}
            <div class="post-cover text-center mb-4">
              {% if page.cover-img.first %}
                <img src="{{ page.cover-img[0].first.first | relative_url }}" alt="Cover image" class="img-fluid rounded shadow-sm">
              {% else %}
                <img src="{{ page.cover-img | relative_url }}" alt="Cover image" class="img-fluid rounded shadow-sm">
              {% endif %}
              {% if page.cover-img-desc %}
                <p class="img-desc mt-2 text-muted small">{{ page.cover-img-desc }}</p>
              {% endif %}
            </div>
          {% endif %}

          <!-- 正文内容 -->
          <div class="post-body" style="line-height:1.8; font-size:1.1rem;">
            {{ content }}
          </div>

          <!-- 页脚：标签和分类 -->
          <footer class="post-footer mt-5 pt-3 border-top d-flex flex-wrap gap-3 justify-content-between">
            {% if page.tags %}
              <div class="post-tags">
                <strong>标签：</strong>
                {% for tag in page.tags %}
                  <a href="{{ '/tags#' | append: tag | relative_url }}" class="tag-badge">{{ tag }}</a>
                {% endfor %}
              </div>
            {% endif %}

            {% if page.categories %}
              <div class="post-categories">
                <strong>分类：</strong>
                {% for category in page.categories %}
                  <a href="{{ '/categories#' | append: category | relative_url }}" class="category-badge">{{ category }}</a>
                {% endfor %}
              </div>
            {% endif %}
          </footer>

        </article>

      </div>
    </div>
  </div>

修改点：

  1. container样式： 我在 container 上添加了 padding-left: 15px; padding-right: 15px; ，这样可以确保内容两侧有一定的边距。根据需要，你可以调整 15px 的值，增加或减少边距宽度。

  2. 外部容器调整： 如果 container 之外的某个容器（比如 .post-container ）也需要页边距，可能需要给它加上合适的 padding 或 margin 。如果你发现它依旧太紧，可以给 .post-container 添加一些内外边距：

   .post-container {
     padding-left: 15px;
     padding-right: 15px;
   }
注意：
  • 如果你的页面是响应式的，且手机端也需要保持良好的边距，最好使用 @media 查询来设置不同屏幕尺寸下的页边距。例如：
   @media (min-width: 768px) {
     .container {
       padding-left: 15px;
       padding-right: 15px;
     }
   }

这样，你就可以根据设备的不同尺寸适当调整边距。

Q4 · 分页按钮放在两侧（第 4 轮对话）

提问： 分页按钮放在两侧

要将分页按钮放在两侧（即“上一篇”和“下一篇”分别位于分页的两端），可以调整现有的分页按钮的布局方式。以下是修改后的代码：

<ul class="pagination blog-pager justify-content-between">
  {% if page.previous.url %}
  <li class="page-item previous">
    <a class="page-link" href="{{ page.previous.url | relative_url }}" data-toggle="tooltip" data-placement="top" title="{{page.previous.title | strip_html | xml_escape}}">
      <i class="fas fa-arrow-left" alt="上一篇"></i>
      <span class="d-none d-sm-inline-block">上一篇</span>
    </a>
  </li>
  {% endif %}
  
  {% if page.next.url %}
  <li class="page-item next">
    <a class="page-link" href="{{ page.next.url | relative_url }}" data-toggle="tooltip" data-placement="top" title="{{page.next.title | strip_html | xml_escape}}">
      <span class="d-none d-sm-inline-block">下一篇</span>
      <i class="fas fa-arrow-right" alt="下一篇"></i>
    </a>
  </li>
  {% endif %}
</ul>
主要修改点：
  1. justify-content-between类： 在
      上添加了 justify-content-between 类，它会自动将分页按钮分布到左右两边。

-justify-content-between是 Bootstrap 的一个 Flexbox 类，用于将子元素（在这里是“上一篇”和“下一篇”按钮）均匀分布在两侧。

  1. 分页按钮布局：
  • “上一篇”按钮会显示在左侧，只有在page.previous.url存在时才会显示。 - “下一篇”按钮会显示在右侧，只有在page.next.url存在时才会显示。
额外的样式调整：

如果你觉得按钮之间的间距不合适，可以根据需要进一步调整样式，比如增加margin或调整按钮的宽度。

这样，分页按钮就会被放置在页面的两侧，提升布局的整洁度和用户体验。

Q5 · 顶部导航栏右侧太过拥挤，在哪里修改（第 5 轮对话）

提问： 顶部导航栏右侧太过拥挤，在哪里修改

如果你的顶部导航栏右侧看起来过于拥挤，通常可以通过调整 CSS 来修改右侧元素的布局。以下是几种可能的修改方式，帮助你解决这个问题：

1. 调整导航栏右侧内容的间距

你可以通过添加或修改margin和padding来调整右侧内容的间距，确保它们不那么拥挤。

例如，在导航栏的 CSS 样式中，你可以给右侧元素（比如社交媒体链接、搜索框等）添加margin-right或padding-right：

/* 通过增加右侧间距来拉开内容 */
.navbar-nav {
  margin-right: 20px; /* 调整右侧的间距 */
}

.navbar-nav .nav-item {
  margin-right: 15px; /* 为每个导航项增加右边距 */
}

.navbar-right {
  padding-right: 20px; /* 增加右侧的内边距 */
}
2. 使用justify-content-between或justify-content-end

如果导航栏的右侧内容过于紧凑，可能是布局的原因。你可以使用 Flexbox 进行调整。确保导航栏的父容器使用justify-content-between或justify-content-end类来调整导航项的位置。

<nav class="navbar navbar-expand-lg navbar-light bg-light">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">Logo</a>
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarNav" aria-controls="navbarNav" aria-expanded="false" aria-label="Toggle navigation">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="navbarNav">
      <ul class="navbar-nav ms-auto"> <!-- ms-auto = margin-start auto -->
        <li class="nav-item">
          <a class="nav-link active" aria-current="page" href="#">首页</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#">功能</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#">关于</a>
        </li>
      </ul>
    </div>
  </div>
</nav>

解释：

  • ms-auto （ margin-start: auto ）用于将导航栏中的内容推到右边。如果你使用的是 navbar-nav 来容纳导航项，这样会将所有导航项推到右侧，并且给右侧的内容留出空间。

  • justify-content-between （如果你需要两边分布）可以帮助把导航栏中的项目分开。

3. 调整导航栏元素的宽度

如果你的导航栏右侧内容（如社交链接、搜索框等）占据了过多的空间，考虑通过调整这些元素的宽度来优化布局。

/* 如果右侧有搜索框或按钮，设置最大宽度 */
.navbar-right .search-box {
  max-width: 200px; /* 设置最大宽度 */
}
