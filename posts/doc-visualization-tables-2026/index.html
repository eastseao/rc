01 · 多场景文档视觉化：六类文档的提示词模板（00739）

一套「明确场景 → 列必要模块 → 给原始信息占位符 → 指定输出格式」的方法，覆盖日常约 80% 的文档需求；统一用内联 CSS、Flex 卡片、样式化表格、任务列表与流程图呈现。

场景核心要素输出格式建议
会议纪要基本信息（时间/地点/参会人）、讨论点、决议、待办（负责人+DDL）Markdown 表格
Excel 报表列标题、数据行、合计行Markdown 表格
PDF 文档主副标题、作者/日期、摘要、分章节正文、页脚页码Markdown 标题 + 段落
产品提案背景与问题、目标用户、解决方案、核心功能、预期收益、资源与风险项目符号 + 表格
调研报告背景/目的、方法（可配流程图）、关键发现、交叉分析、结论建议图表 + 表格
项目复盘按 STAR（情境/任务/行动/结果）回顾，附经验教训与改进计划任务列表 + STAR

提示词核心心法：明确场景 → 列出必要模块 → 提供原始信息（占位符）→ 指定输出格式（表格/列表/图表）→ 一键生成专业文档。

04 · 17 项审计问题：责任清单与整改口径（00822）

围绕审计反馈 17 项问题逐条讨论：每项「情况说明」须按逐项逐条原则撰写，区分「部分属实」或「不属实」并附佐证，避免简单定性；责任人当日内完成并提交宋总审核。

#问题描述责任人关键要求 / 调整方向
1采购个人虫草孟宏元逐条补充详细情况说明。
2采购及销售核查孟宏元 + 祁光福按问题补充解释。
3存货盘点（过期原料、长期积压、包材）甘宝晨 / 孙称意 / 祁光福 / 孟宏元每条逐条说明 + 佐证资料。
4无形资产土地使用权（330 万补贴）库进良确认补贴文件性质；若为「土地财政补贴」存在收回风险，需重新定性。
5应收账款许丹红 / 朱生莉逐条补充说明。
6主营业务收入直播销售朱生莉写「情况部分属实，补充如下」。
7主营业务收入虫草销售许丹红 / 孙称意说明礼盒与简易包装价差原因，修正客户信息。
8存货核查（2000 万存货成本）孙称意采用分期摊销，避免一次性转回影响利润。
9研发费用非员工报销朱生莉明确代报费用真实情况；将陈超改为重大专项负责人身份。
10促销费用孙称意 / 朱生莉 / 魏晓军修正「审批人陈超」表述；「客勤费用」改为「当地政府领导参观试吃试用」。
11在建工程布达拉解释停工原因附审批单；说明纯净水项目因集团要求暂停。
12固定资产库进良补充情况说明。
13–17第 13、14、15、16、17 项佛永春逐条补充说明及佐证资料。

撰写三原则：格式规范（以「关于审计取证单第 x 项第 x 条的情况说明」起头）、佐证解释（提供合理性/效益说明）、风险规避（涉收回风险事项如土地财政补贴不轻易承认「属实」）。
