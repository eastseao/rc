写入令牌

添加 / 编辑 / 删除需要 GitHub 写入权限。令牌只保存在当前浏览器，不会上传到任何服务器。

  1. 打开 github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories →rc
  3. Permissions → Contents →Read and write
  4. 生成后粘贴到上方保存
