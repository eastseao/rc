01

Windows 一键脚本与桌面客户端

01040 / 01042

安装 OpenClaw 主要有两条官方途径：一键安装脚本（官方推荐，一行命令自动配置环境）和官方/第三方桌面客户端（图形界面、解压即用）。开始前先备份重要数据，并暂时关闭 360、腾讯电脑管家、火绒等第三方杀毒软件及 Windows Defender 实时防护，避免误报导致安装失败。

项要求
操作系统Windows 10/11（建议 64 位专业版/企业版）、macOS 12+，或主流 Linux 发行版（如 Ubuntu 22.04+）。
内存空间建议 4GB 以上内存，以及至少 4GB 的空闲硬盘空间。
安装时长脚本全自动完成（含检测安装 Node.js 等环境），全程约 3-5 分钟。
方法一 · 官方推荐

一键安装脚本

Windows：在开始菜单搜索 PowerShell，右键选择「以管理员身份运行」。国内用户推荐镜像加速：

iwr -useb https://open-claw.org.cn/install-cn.ps1 | iex

国际用户则用官方源：

iwr -useb https://openclaw.ai/install.ps1 | iex

macOS / Linux：打开终端，国内用户用镜像加速：

curl -fsSL https://open-claw.org.cn/install-cn.sh | bash

国际用户：

curl -fsSL https://openclaw.ai/install.sh | bash
初始化
脚本完成后自动进入 onboard 交互式配置向导；意外中断后可随时运行 openclaw onboard 重新进入。
验证安装
终端输入 openclaw --version 并回车，能正确显示版本号即核心程序安装成功。
方法二 · Windows

OpenClaw Desktop 桌面客户端

  1. 从 GitHub Releases 页面或网盘链接下载对应系统的安装包，务必先解压到纯英文路径（如 D:\OpenClaw），切勿在压缩包内直接运行。
  2. 双击 Openclaw Windows 一键启动.exe；出现 Windows 安全提示时，点「更多信息」→「仍要运行」。
  3. 图形化安装界面中，安装路径务必使用纯英文路径，不能包含中文、空格或特殊符号。
  4. 勾选同意用户协议，点「开始安装」，等待自动部署完成（约 3-5 分钟）。
  5. 首次运行初始化，当主界面右上角显示「Gateway 在线」时，即表示部署成功。
常见问题排查
  • 安装中断/失败：检查是否已关闭所有杀毒软件，安装路径无中文字符/空格，建议以管理员身份运行。
  • 网络连接问题：优先使用国内镜像加速命令。
  • 提示缺少 Node.js：一键脚本通常自动安装，未成功可手动从 Node.js 官网下载安装 LTS 版本。
  • Windows 安全中心拦截：出现「Windows 已保护你的电脑」弹窗时，点「更多信息」→「仍要运行」即可。

OpenClaw Desktop（小龙虾）专业控制台开源免费、功能全面，可视化管理面板，支持远程连接管理远端实例，适配 Windows/macOS/Linux。

02

Ubuntu 命令行：从登录到初始化

01297

在 TTY 命令行模式下看到 HomePC login: 很正常——系统在等待你手动登录后才能继续安装。OpenClaw 强烈依赖 Node.js 环境，需要先更新系统并装好 Node.js。

第一步

登录 Ubuntu 系统

输入用户名
在 login: 后输入用户名，按 Enter。
输入密码
出现 Password: 提示后输入用户密码（屏幕上不会显示，属正常），回车即登录，看到类似 username@HomePC:~$ 的提示符。

习惯图形化界面的话，可试按 Ctrl + Alt + F1 或 Ctrl + Alt + F7 切换回桌面环境。

第二步

准备环境：更新系统并安装 Node.js 22.x

OpenClaw 需要 Node.js 22.x 或更高版本。先更新软件源：

sudo apt update

添加 NodeSource 官方仓库（自动配置 Node.js 22.x 安装源）：

curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -

安装 Node.js：

sudo apt install -y nodejs

验证是否安装成功，正确显示版本号（如 v22.x.x）即装好：

node --version

（可选但推荐）安装基础开发工具包，确保编译过程顺利：

sudo apt install -y build-essential
第三、四步

安装 OpenClaw 并初始化

优先用官方安装脚本，它能自动处理大部分配置：

curl -fsSL https://openclaw.ai/install.sh | bash

验证安装：

openclaw --version

初始化向导自动启动，也可手动运行（首次安装直接一路回车选默认 QuickStart 最顺畅）：

openclaw onboard --install-daemon
AI 提供商
快速上手可优先选 Qwen（通义千问），对初次体验提供免费额度，熟练后再切换其他服务商。
模型选择
保持默认即可。
聊天渠道
初始化阶段可直接「跳过」，不影响核心功能。
技能和钩子
先保持默认或跳过，后续有需要再详细配置。

通过 Web 界面使用（推荐）

浏览器访问 http://127.0.0.1:18789/ 进入 Web 管理界面；提示配对时，终端运行 openclaw dashboard，把输出的带令牌完整链接复制到浏览器打开。

通过终端界面使用

openclaw tui
Ubuntu 常见问题与排查
  • Command 'openclaw' not found：重启终端，或重新运行安装脚本。
  • 端口占用：Web 界面无法访问时检查端口，sudo lsof -i :18789。
  • Token 不匹配：重新运行 openclaw dashboard，把输出完整链接复制到浏览器。
  • AI 认证失效：第二天重启可能需重新认证，如用 Qwen 运行 openclaw models auth login --provider qwen-portal。
  • Qwen 登录问题：默认 qwen-portal 通常指向国际版，可能无法用支付宝或国内手机号登录，需用 Google 或 GitHub 账号。
  • Permission denied：命令前加 sudo 重试。
  • 服务不自启动：启用 linger 服务 sudo loginctl enable-linger $(whoami)。
  • Gateway closed 报错：在 openclaw 目录下运行 npm run gateway 重启网关。
03

API 的三种设置方式

01298

配置大模型 API 是使用 OpenClaw 的关键一步——OpenClaw 本身并非 AI 模型，需要接入外部大模型服务（它的「大脑」）才能理解并执行指令。设置 API 主要有三种途径。

① 图形界面 GUI

最直观，适合桌面客户端（尤其 Windows/macOS）。

② 命令行/环境变量

适合服务器部署或技术用户，灵活度高。

③ 配置文件编辑

适合批量或精准配置，改 openclaw.json。

方法一

图形界面（GUI）设置 · 以阿里云百炼为例

  1. 主界面右上角点「设置」。
  2. 左侧菜单栏选「模型配置」板块。
  3. 右侧模型提供商列表中点需要的服务商（如「阿里云百炼」）。
  4. 把从服务商获取的 API Key（通常 sk- 开头）粘贴到对应输入框。
  5. 点「测试」检查连接是否成功，通过后点右上角「保存全部配置」。
  6. 回聊天页面，在模型下拉列表选刚配置好的模型即可对话。
方法二

命令行 / 环境变量设置

用向导配置（configure 与 onboard 等效）：

openclaw onboard

常驻运行的服务器场景推荐环境变量，OpenClaw 检测到后会自动启用对应提供商：

# 例如，为 NVIDIA 设置 API 密钥
export NVIDIA_API_KEY="nvapi-..."
环境变量存放位置：临时运行直接在终端 export 即可；守护进程（如 systemd、launchd）建议写入 ~/.openclaw/.env，守护进程才能读到。
方法三

配置文件编辑 openclaw.json

核心配置文件 openclaw.json 默认存放在 ~/.openclaw/ 目录下，替换 apiKey 字段即可：

{
  "env": {
    // 如果你想用环境变量，可以把 API Key 写在这里
  },
  "models": {
    "providers": {
      "siliconflow": {
        "baseUrl": "https://api.siliconflow.cn/v1",
        "apiKey": "你的_API_密钥", // 将你的 API 密钥粘贴到这里
        "api": "openai-completions"
      }
    }
  }
}
关键命令 / 路径作用
~/.openclaw/openclaw.json核心配置文件。
openclaw doctor诊断命令。
openclaw models status测试/查看模型连接状态。
openclaw config file查看活动配置文件路径。
openclaw config schema查看配置结构。
Web 控制台 http://127.0.0.1:18789浏览器中进行配置管理和修改。
/etc/openclaw/conf.d/ 下 .env 文件生产环境更规范的密钥管理方式。
实操示例

把 DeepSeek API 配置进 OpenClaw

方式一：用官方推荐的一键配置 onboard，按提示选择 Yes 免责声明 → QuickStart 模式 → 服务提供商选 DeepSeek → 粘贴 API 密钥 → 默认模型新手推荐 deepseek-v4-flash：

openclaw onboard --install-daemon

方式三：在 openclaw.json 的 models.providers 中为 DeepSeek 添加/修改如下配置：

{
  "models": {
    "providers": {
      "deepseek": {
        "baseUrl": "https://api.deepseek.com",
        "apiKey": "你的_DeepSeek_API_密钥"
      }
    }
  }
}

配置完成后验证：聊天界面模型选择框搜索 deepseek 并选中（如 deepseek-v4-flash），或终端运行 openclaw models status 查看连接状态。

从哪里获取 API Key

国内/免费平台
阿里云百炼、MiniMax、Kimi、智谱 AI 等，免费额度多、访问稳定。
国际商业平台
OpenAI（GPT 系列）、Anthropic（Claude 系列），能力强但需海外支付、国内访问可能不稳。
本地模型
Ollama、LM Studio 等，数据隐私好、无需联网，但对显卡有要求。

OpenAI 兼容接口关键参数

API Key
服务凭证，示例 sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx。
Base URL
服务地址，如 https://api.openai-proxy.com/v1；官方 OpenAI 用户无需填写。
Model Name
实际能用的模型名，如 gpt-4-turbo、claude-3-opus-20240229。
04

接入大模型：以 Qwen2.5 7B 为例

01063

通过 OpenClaw 调用 Qwen2.5 7B Instruct，意味着拥有一位由大语言模型驱动的「智能数字员工」——它能听懂自然语言指令，并实际操作电脑完成任务。两者结合了 Qwen2.5 强大的指令遵循、中文处理与代码数学能力和 OpenClaw 操作执行工具的能力。

办公与开发自动化

  • 会议纪要助手：读取录音/文字记录，生成要点突出的纪要。
  • 智能文档处理：批量处理合同、报告，提取关键信息、格式转换、生成摘要。
  • 邮件与报表：草拟邮件、分析 Excel 数据生成图表、撰写分析报告。
  • 代码生成与调试：自然语言生成代码、审查问题、执行 Git 命令与测试脚本。

数据信息与生活服务

  • 智能爬虫与分析：抓取网页/新闻/商品信息并输出总结报告。
  • 结构化信息抽取：从客户评价、问卷中提取信息输出规整 JSON。
  • 个人知识库问答：基于本地笔记、PDF 问答，保障数据隐私。
  • 信息管家：通过微信、Telegram 下达指令，获取会议提醒、天气、新闻推送；支持 29+ 种语言，可做翻译伙伴。
配置与使用关键提醒
  • 模型选择：务必选通用对话模型（如 qwen2.5:7b-instruct），不要选专为特定任务的 coder 模型，否则 Agent 在聊天等任务中可能无法正常回复。
  • 上下文窗口：为最大化 32K 长上下文能力，建议把 OpenClaw 配置文件中的上下文长度设为 32K 或更高。
  • 善用技能扩展：官方插件库（如 clawhub.ai）安装技能包，如 File System 读写本地文件、Shell Execution 执行终端命令。
  • API 与本地运行：可通过阿里云 DashScope 调用 Qwen2.5 的 API，或用 Ollama 等本地运行，本地运行更保护隐私、避免 API 费用。

模型局限性

纯文本模型，不具备视觉能力；7B 规模复杂推理弱于更大版本

它是纯文本模型，不具备识别和解读图像、视频等视觉信息的能力；7B 参数规模在极其复杂的推理任务上效果不如 72B 或更大版本；联网搜索等操作通常需要额外工具支持，而非模型本身直接支持。
