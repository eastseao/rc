01

十大算命体系版图

2026-04-15

传统算命本质是把时间、空间、五行、阴阳系统化，用不同「工具」推演。一句行内概括：八字看命，奇门看局，六爻看事，风水改运。

体系核心 / 工具算什么
八字命理出生年月日时；万年历、排盘软件、天干地支表、五行生克表一生趋势（子平法为主流，另有盲派、格局派、调候派）。
紫微斗数出生时间 + 星曜；十二宫命盘、星曜表人生结构：性格 + 运势 + 事件，号称帝王术。
周易占卜起卦；铜钱、骰子、蓍草、起卦 APP具体事情：六爻、梅花易数。
奇门遁甲时间 + 方位 + 九宫；九宫盘、时辰换算时机与策略：预测、决策、风水布局。
六壬神课六壬盘、天将系统、四课三传事情发展过程，古代军师用。
风水堪舆空间布局；罗盘、分金尺、地形图环境影响人、改运（三合、玄空飞星、八宅）。
面相/手相观察身体；手纹图谱快速判断性格与运势。
姓名学名字五行 + 笔画；康熙字典、五格数理表辅助调运，争议较大。
生肖属相出生年份；十二生肖表、农历大众娱乐级预测。
太乙神数太乙盘、数理推演与奇门、六壬并称「三式」，古代国家级预测。
02

把推演流程设计成 DestinyMaster Skill

2026-04-15

第二问要求：凭出生年月日时、出生地、性别、姓名推一生命运与近五年运势，并做成一套 Skill。拆成了可落地的结构。

输入参数
姓名、性别、出生日期（YYYY-MM-DD）、出生时间（HH:MM）、出生地。
推演步骤
命盘构建（四柱、日主、五行强弱）→ 命局分析（格局强弱、用神忌神、偏枯冲克）→ 性格画像 → 事业/财富/婚姻/健康 → 大运（每 10 年一步）→ 未来五年逐年运势 → 机会与风险 → 务实行动建议。
逐年输出格式
运势评分（1–10）、3 个关键词、事业、财富、感情、风险点。
模块配置
bazi_core / five_elements / personality / destiny_structure / career / wealth / marriage / luck_cycle / five_year_forecast / risk_control / strategy_advice；时区 Asia/Shanghai，农历，输出「叙事 + 结构化」、理性口吻。
当时的关键判断
  • 真正有价值的不是「算命」，而是用结构化方法给出决策参考——强调「趋势 + 选择」，不迷信、不绝对化。
  • 后续可接真实八字排盘 API、做命运报告/合婚/用人分析等产品化形态。

  • 夫妻关系总体稳定，家庭越来越和谐，对子女帮助较大。
