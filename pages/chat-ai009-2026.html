一个OpenClaw的skill的结构是什么样的

OpenClaw 的 SKILL.md 本质上是一个“带 YAML 头信息的结构化提示工程文件”，核心目的是让 Agent 能正确理解、调用、约束该技能。整体可以理解为：

YAML（定义能力） + Markdown（定义行为与规则）

下面给你一套标准结构模板（通用 + 实战可用版）👇

---

# 一、SKILL.md 标准结构

---
name: skill_name
description: 简要描述这个技能是干什么的
version: 1.0.0
author: your_name
tags:
  - 分类标签1
  - 分类标签2
inputs:
  - name: input1
    type: string
    description: 输入参数说明
  - name: input2
    type: string
    description: 输入参数说明
outputs:
  - name: output1
    type: string
    description: 输出内容说明
---

# 🧠 Skill Overview（技能概述）
说明这个技能的用途、适用场景、解决什么问题

---

# 🎯 Objectives（目标）
- 目标1
- 目标2
- 目标3

---

# 📥 Input Requirements（输入要求）
详细说明输入格式，比如：
- 必填项
- 可选项
- 格式限制
- 示例

---

# ⚙️ Execution Logic（执行逻辑）
按步骤写清楚 Agent 要怎么做：

1. 第一步：解析输入
2. 第二步：处理逻辑
3. 第三步：生成结果

---

# 📤 Output Format（输出格式）
定义输出结构（非常关键）：

示例：

{ "title": "", "summary": "", "content": "" }


或 Markdown 格式要求

---

# 🚫 Constraints（约束）
- 不允许做什么
- 风格限制
- 数据限制
- 禁止编造 / 必须客观 等

---

# 💡 Examples（示例）
## 示例1
输入：
xxx

输出：
xxx

---

# 🧩 Prompt Template（核心提示词模板）
（这是灵魂部分）

你是一个xxx专家，请根据以下输入完成任务：

输入：
{{input1}}

要求：
1.
2.

输出：
（严格按照Output Format）

---

# 🔄 Edge Cases（边界情况处理）
- 输入为空怎么办
- 数据冲突怎么办
- 无法判断时如何处理

---

# 📌 Notes（备注）
补充说明、版本记录等

# 二、核心结构拆解（重点理解）

1️⃣ YAML头（必须有）

这是Skill的元数据，OpenClaw靠它识别技能

关键字段：

字段作用
name技能唯一标识
description给Agent看的简介
tags用于检索
inputs定义输入参数
outputs定义输出结构

👉 重点：inputs / outputs = 半API化设计

---

2️⃣ Prompt Template（最核心）

这是决定技能质量的关键：

  • 相当于“系统提示词”
  • 决定输出风格、逻辑、稳定性

👉 好的 skill ≠ 写很多 👉 好的 skill = 提示词 + 输出结构清晰

---

3️⃣ Execution Logic（让AI更稳定）

很多人忽略这一块，其实非常关键：

👉 它的作用是：

  • 防止AI乱发挥
  • 提高一致性
  • 让复杂任务可控

---

4️⃣ Output Format（必须严格）

这是你做“工程化”的关键：

  • JSON（适合程序调用）
  • Markdown（适合阅读）
  • 固定结构（防止漂移）

---

# 🧠 Skill Overview
该技能用于输出一份结构完整、逻辑严谨、具备商业决策参考价值的市场调研报告，适用于产品立项、渠道拓展、投资分析等场景。

---

# 🎯 Objectives
- 梳理行业发展现状与规模
- 分析竞争格局与核心玩家
- 提炼产品与消费趋势
- 输出可执行的商业机会建议

---

# 📥 Input Requirements
输入需包含：
- 调研主题（必填）
- 目标市场（建议填写）
- 调研深度（默认：标准）

示例：
- research_topic: 人工冬虫夏草
- target_market: 中国
- depth_level: 深度

---

# ⚙️ Execution Logic

1. 行业定义与范围界定（避免分析偏差）
2. 宏观环境分析（政策 / 经济 / 消费趋势）
3. 市场规模与增长（可用估算逻辑）
4. 竞争格局分析（品牌、渠道、价格带）
5. 产品结构分析（形态、规格、价格）
6. 消费者分析（人群画像、使用场景）
7. 趋势洞察（3-5条核心趋势）
8. 商业机会判断（重点）
9. 风险与不确定性分析

---

# 📤 Output Format（必须严格遵守）

# 📊《{{research_topic}}市场调研报告（{{target_market}}）》  

## 一、核心结论摘要
（300-500字，直接给结论）

---

## 二、行业概况  
- 行业定义  
- 产业链结构  

---

## 三、市场规模与增长  
- 当前市场规模（可估算）  
- 增长率（说明逻辑或来源）  

---

## 四、竞争格局  
- 主要品牌  
- 渠道分布  
- 价格带划分  

---

## 五、产品结构分析  
- 产品类型（如：口服液 / 粉剂 / 饮料）  
- 主流规格  
- 核心卖点  

---

## 六、消费者分析  
- 核心人群  
- 使用场景  
- 购买动机  

---

## 七、趋势洞察  
（3-5条，必须具体）

---

## 八、商业机会分析（重点）  
（必须给出可执行方向）

---

## 九、风险与挑战  
- 政策风险  
- 技术风险  
- 市场风险  

---

## 十、结论与建议  
（总结 + 行动建议）

---

# 🚫 Constraints
- 禁止空泛描述，必须结构化
- 数据需说明来源或估算逻辑
- 不确定数据需标注“估算”
- 不得编造具体公司财报数据
- 语言偏商业分析风格，避免口语化

---

# 💡 Prompt Template（核心提示词）

你是一名资深市场分析专家，擅长食品与消费品行业分析。

请围绕以下主题输出一份结构化市场调研报告：

调研主题：{{research_topic}}  
目标市场：{{target_market}}  
调研深度：{{depth_level}}

要求：
1. 严格按照Output Format输出
2. 所有分析必须有逻辑支撑
3. 尽可能提供数据或合理估算
4. 商业机会部分必须具体可执行
5. 输出内容适用于产品决策与商业判断

---

# 🔄 Edge Cases
- 若数据缺失：采用行业常识 + 合理估算
- 若市场较小：重点分析细分机会
- 若竞争信息不足：从渠道或价格侧推

---

# 📌 Notes
适用于：
- 产品立项前调研
- 新赛道评估
- 投资判断
- 品类机会挖掘
