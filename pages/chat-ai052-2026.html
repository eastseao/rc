# 主题簇生成系统（Topic Cluster Engine） 适用于 OpenClaw / QClaw / Claude Skill 的完整规范版 Skill

这套技能的核心目标是：

  • 自动生成 SEO + GEO 双适配的主题簇
  • 支持企业站 / 博客 / 知识库 / B2B 官网
  • 自动拆分：

- 核心主题（Pillar） - 子主题（Cluster） - 长尾问题（Long-tail） - GEO 问答节点 - 内容发布顺序

  • 自动构建：

- 内链结构 - 权重流转 - 用户搜索意图 - AI搜索适配结构

尤其适合：

  • 铝瓶铝罐企业
  • 食品行业
  • 工业制造
  • SaaS
  • AI工具站
  • 小说/知识类博客
  • 独立站SEO

# TopicClusterEngine

## 技能目标

围绕某个核心主题，
自动构建：

- Pillar Page（支柱页面）
- Topic Cluster（主题簇）
- GEO问答矩阵
- 长尾关键词
- 搜索意图分类
- AI搜索适配结构
- 内容发布顺序
- 权威内容地图

适用于：

- 企业SEO
- 独立站
- B2B官网
- 博客矩阵
- AI搜索优化
- 知识库建设

---

# 输入格式

用户输入：

核心主题： 行业： 目标用户： 目标地区： 竞争对手： 内容目标：


示例：

核心主题：铝瓶 行业：包装制造 目标用户：饮料品牌商 目标地区：欧美 竞争对手：Trivium Packaging 内容目标：获取Google自然流量和AI搜索曝光

# 系统执行流程

## STEP 1：核心主题拆解

自动识别：

- 核心关键词
- 商业关键词
- 信息型关键词
- GEO问答关键词
- 采购型关键词
- 长尾问题

输出：

- Topic Seed
- Search Intent
- User Journey

---

## STEP 2：建立Pillar Page

生成：

- 支柱页面标题
- 页面结构
- H1-H4结构
- FAQ模块
- GEO引用结构

要求：

- 能成为行业权威页面
- 支持AI引用
- 支持Google精选摘要

---

## STEP 3：生成主题簇

自动输出：

- Cluster Topic
- 对应搜索意图
- 难度
- 商业价值
- GEO价值
- 推荐字数
- 推荐发布日期

每个主题簇必须：

- 与Pillar强相关
- 支持内链
- 支持长尾流量
- 支持AI搜索引用

---

## STEP 4：生成GEO结构

自动扩展：

- AI搜索问题
- 对话式问题
- Reddit风格问题
- Perplexity问题
- ChatGPT风格提问

包括：

- Why
- How
- What
- Best
- Comparison
- Supplier
- Cost
- Manufacturing
- OEM
- MOQ
- Sustainability

---

## STEP 5：建立权威地图

输出：

- 内容层级
- 权重流向
- 内链逻辑
- 权威路径
- 收录优先级

---

## STEP 6：生成发布日历

自动规划：

- 30天
- 60天
- 90天

包括：

- 发布时间
- 发布顺序
- 更新顺序
- 内链插入时机
- 社媒扩散节点

---

# 输出规范

必须输出：

# 1. 核心主题分析

# 2. Pillar Page

# 3. Topic Cluster列表

# 4. GEO问题矩阵

# 5. 长尾关键词

# 6. 内链结构

# 7. 权威地图

# 8. 内容发布计划

# 9. AI搜索适配建议

输出格式必须为Markdown。

禁止：

- 空泛建议
- 只有关键词无结构
- 无搜索意图分类
- 无用户阶段划分
