除了首页和文章页面，其他页面的底部信息如版权等，都不是居中，怎么解决

第 3 轮对话
提问

除了首页和文章页面，其他页面的底部信息如版权等，都不是居中，怎么解决

明白了，你遇到的问题是：在非首页、非文章页（比如自定义 page 页面、分类页、关于页等），底部的版权信息没有居中显示。原因很可能是 布局的 HTML 结构或 CSS 样式没有统一应用，尤其是 page.html 或自定义页面模板没有正确使用 Bootstrap 的居中类。

我帮你分析原因并给出解决方案：

---

1️⃣ 原因分析

  • 你的 base.html 页脚部分使用了：
<div class="row justify-content-center">
  <div class="col-xl-8 col-lg-10 text-center">

这会让内容在 大屏幕下居中，同时 text-center 确保文字居中。

  • 但是在 page.html 或其他非文章页模板中，你可能使用了：
<main class="{% if page.full-width %} container-fluid {% else %} container-md {% endif %}">

如果 full-width 被设置为 true，或者页面结构中 <footer> 没有和 container-md、row、col 配合，Bootstrap 的居中效果就会失效。

  • 另外，如果自定义页面直接写了 <footer>，没有用 container 和 text-center，也会导致版权信息偏左。

---

2️⃣ 解决方案

方法一：统一页脚布局

确保所有页面的 <footer> 使用 和 base.html 一致的结构：

<footer>
  <div class="container-md beautiful-jekyll-footer py-4">
    <div class="row justify-content-center">
      <div class="col-xl-8 col-lg-10 text-center">

        {% include social-networks-links.html %}

        {% if page.footer-extra %}
          <div class="footer-custom-content my-3">
            {% for file in page.footer-extra %}
              {% include {{ file }} %}
            {% endfor %}
          </div>
        {% endif %}

        <p class="copyright text-muted mb-0">
          {% if site.author %}
            {{ site.author }} &nbsp;&bull;&nbsp;
          {% endif %}
          {{ site.time | date: '%Y' }}
          {% if site.url-pretty %}
            &nbsp;&bull;&nbsp;
            <span class="author-site">
              <a href="{% if site.url-canonical %}{{ site.url-canonical }}{% else %}{{ '/' | absolute_url }}{% endif %}">
                {{ site.url-pretty }}
              </a>
            </span>
          {% endif %}
        </p>

      </div>
    </div>
  </div>
</footer>

✅ 关键点：

  1. container-md 保证页脚宽度与内容一致。
  2. row justify-content-center + col-xl-8 col-lg-10 text-center 保证文字和图标水平居中。

---

方法二：通过 CSS 强制居中

如果不想改 HTML，可以在 beautifuljekyll.css 添加：

.beautiful-jekyll-footer {
  text-align: center;
}

.beautiful-jekyll-footer .row {
  justify-content: center !important;
}

.beautiful-jekyll-footer .col {
  margin: 0 auto;
  float: none;
}
  • text-align: center → 文字居中
  • justify-content: center → row 居中
  • margin: 0 auto + float: none → 列居中

这种方法适用于所有非首页、非文章页。

---

方法三：确保所有页面继承 base.html

  • 首页：index.html
  • 文章页：_layouts/post.html
  • 其他页面：_layouts/page.html 或自定义布局

重点：所有页面的 <footer> 都应该通过 base.html 渲染，而不是在各个页面单独写 footer。否则就无法统一居中。

---

---

(2) index.html 或 post.html 也单独写了 footer

如果首页 (index.html) 或文章页 (_layouts/post.html) 模板里，又单独写了类似：

{% include footer.html %}

或者直接复制了 base.html 的 footer 结构，那么 页面就会渲染两次 footer。

---

(3) 其他页面没重复写 footer

  • page.html 没有重复 footer，所以只显示一个。
  • 说明问题只在首页和文章页模板里存在重复引入。

---

2️⃣ 解决方案

方法一：只在 base.html 渲染 footer

  1. 删除首页和文章页模板里的 footer 代码（如果有的话）。

- index.html / post.html / home.html 等页面不要再手动写 <footer> 或 {% include footer.html %}。

  1. 所有页面统一继承 base.html，通过 {{ content }} 渲染页面内容，页脚由 base.html 控制。

---

方法二：在 page.html 也不要重复 footer

  • 如果你在 page.html 里也手动加了 footer，把它删除，因为 base.html 已经处理页脚。
  • 保留 before-content / after-content / comments 即可。

---

方法三：CSS 隐藏重复 footer（不推荐）

body.home footer:last-of-type,
body.post footer:last-of-type {
  display: none;
}
这种方法只是临时隐藏重复显示，不解决根本问题。长期维护不方便。

---

3️⃣ 建议做法

  1. base.html 保留 footer
  2. 首页和文章页模板只渲染内容，不写 footer
  3. page.html 也不写 footer
  4. 确保 _includes/footer.html 仅在 base.html 中被引用一次

这样所有页面都会统一显示一个底部栏，布局居中，逻辑简单。
