GitHub 多语言企业网站

2026-04-03 · auto · 32 条消息

为上海瑞迪安特包装（radiantpack）在 GitHub 上搭多语言企业官网，从静态 HTML 模板一路折腾到 Hugo + GitHub Actions，反复卡在 404 和权限问题。

  • 公司背景：铝罐/铝瓶/BOV 喷雾罐/灌装机，外贸独立站。
  • 技术路线演进：纯静态 HTML → Hugo 静态站 + GitHub Actions 自动部署。
  • 多语言方案：hreflang 标签 + 子目录（/en/、/es/）。
  • 踩坑：404 是因 defaultContentLanguageInSubdir=true 导致根目录无 index.html。
  • 踩坑：git exit 128 是 Actions 旧版本权限不足，需改 workflow 权限设置。
  • 最终建议：直接上传静态文件到 gh-pages 分支，绕过 Hugo Actions 复杂配置。

域名解析到 GitHub

2026-04-11 · auto · 2 条消息

域名绑定到 GitHub Pages 的两步指南，DNS 记录配置和 GitHub 端设置。

  • www 子域名：CNAME 记录指向 username.github.io。
  • 裸域：4 条 A 记录指向 185.199.108.153 ~ 185.199.111.153。
  • GitHub 端：Settings → Pages → Custom domain 填入域名，自动生成 CNAME 文件。
  • 勾选 Enforce HTTPS 开启强制 HTTPS。
  • 常见坑：404 多半是 CNAME 写错或缺 CNAME 文件；HTTPS 打不开需等证书签发。
