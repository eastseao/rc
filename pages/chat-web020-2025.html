我还需要增加项目号和物料名称查询的功能

明白，你是希望在你的前端台账工具里，增加按“项目号”和“物料名称”查询的功能，对吧？我可以帮你规划一个具体实现方案，既可以在本地网页，也可以用 GitHub Pages 发布。下面给你一个完整思路：

---

1️⃣ 数据准备

假设你已有台账数据，建议用 JSON 或 CSV 格式存储。例如 JSON 结构：

[
  {
    "项目号": "XM2025001",
    "物料名称": "纸箱A",
    "规格": "50*40*30cm",
    "数量": 100,
    "日期": "2024-01-15"
  },
  {
    "项目号": "XM2025002",
    "物料名称": "胶带B",
    "规格": "宽5cm",
    "数量": 200,
    "日期": "2024-02-10"
  }
]

---

2️⃣ HTML 查询界面

增加两个输入框和一个查询按钮：

<div class="query-container">
  <input type="text" id="projectInput" placeholder="请输入项目号">
  <input type="text" id="materialInput" placeholder="请输入物料名称">
  <button id="searchBtn">查询</button>
</div>

<table id="resultTable">
  <thead>
    <tr>
      <th>项目号</th>
      <th>物料名称</th>
      <th>规格</th>
      <th>数量</th>
      <th>日期</th>
    </tr>
  </thead>
  <tbody>
    <!-- 查询结果显示在这里 -->
  </tbody>
</table>

---

3️⃣ JavaScript 查询逻辑

// 假设 data 是你的台账数组
let data = []; // 可以通过 fetch() 加载 JSON 文件

document.getElementById("searchBtn").addEventListener("click", function() {
  const projectQuery = document.getElementById("projectInput").value.trim();
  const materialQuery = document.getElementById("materialInput").value.trim();

  const filtered = data.filter(item => {
    return (projectQuery === "" || item.项目号.includes(projectQuery)) &&
           (materialQuery === "" || item.物料名称.includes(materialQuery));
  });

  const tbody = document.getElementById("resultTable").querySelector("tbody");
  tbody.innerHTML = ""; // 清空上次结果

  filtered.forEach(item => {
    const row = document.createElement("tr");
    row.innerHTML = `
      <td>${item.项目号}</td>
      <td>${item.物料名称}</td>
      <td>${item.规格}</td>
      <td>${item.数量}</td>
      <td>${item.日期}</td>
    `;
    tbody.appendChild(row);
  });
});

---

4️⃣ 可选优化

  • 实时搜索：用 input 的 oninput 事件代替按钮点击。
  • 大小写忽略：把 .toLowerCase() 用于比较。
  • 分页显示：数据量大时，分页显示可以提升速度。
  • 排序功能：点击表头排序按项目号、日期等。

---
