通过以上base.html、footer.html的修改，一些页面的页脚还是居左

可能是页脚的样式没有完全适配到所有页面，或者特定页面的CSS样式有覆盖的情况。你可以检查以下几个方面来确保页脚在所有页面中都居中：

  1. 检查CSS样式：

在你的base.html或footer.html中，确保页脚的容器有正确的CSS类来居中对齐。你可以尝试以下CSS代码来确保页脚居中：

   footer {
     width: 100%;
     text-align: center; /* 确保文字居中 */
     margin: 0 auto;
   }
  1. 确保页脚容器有足够的宽度：

你的footer容器可能没有设置足够的宽度，导致它无法居中。可以尝试给它设置max-width，并且确保外部容器的布局没有影响到它：

   footer {
     width: 100%;
     max-width: 1200px;  /* 你可以根据实际情况调整宽度 */
     margin: 0 auto;     /* 居中对齐 */
   }
  1. 检查其他页面特定样式：

如果某些页面的页脚依旧不居中，可能是这些页面有独立的样式或布局代码覆盖了全局设置。你可以在浏览器的开发者工具中检查这些页面的CSS，查看是否有其他特定的样式影响了页脚的对齐。

  1. 更新HTML结构：

确保base.html和footer.html中的HTML结构没有问题。例如，页脚的容器应该有一个正确的类或ID来进行样式设置：

   <footer class="site-footer">
     <div class="container">
       <p>© 2025 Your Site Name. All rights reserved.</p>
     </div>
   </footer>

如果这些方法都不行，可以分享一下相关的base.html和footer.html部分代码，我可以帮助你更精确地定位问题。

我看了你提供的 footer.html 和 base.html 代码，结构本身是居中的，使用了 Bootstrap 的 row justify-content-center + col-xl-8 col-lg-10 text-center。所以在大多数页面应该是居中的。页脚偏左的问题通常有几个原因：

---

1. 外层容器宽度被限制

你的 <main> 和 <footer> 都在 <div class="container-md"> 内。container-md 在 Bootstrap 中是响应式固定宽度的（最大宽度约 720px~960px），当屏幕较宽时，容器就不会全宽，会显示“居左”的感觉。

解决方法：如果希望页脚在大屏幕上真正居中，可以换成 container 或 container-fluid，或者单独给 footer 使用 container-fluid：

<footer>
  <div class="container-fluid beautiful-jekyll-footer py-4">
    <div class="row justify-content-center">
      <div class="col-xl-8 col-lg-10 text-center">
        ...
      </div>
    </div>
  </div>
</footer>

这样，footer 会占满整个屏幕宽度，内容仍然居中。

---

2. 页面单独覆盖样式

有些页面可能有自定义样式或在 _config.yml 设置了 page-col 或 text-align 的全局覆盖，导致 text-center 失效。 排查方法：打开浏览器开发者工具，检查页脚 <p> 或 <div> 的 text-align 样式，看是否被覆盖。

---

3. 社交链接的宽度

{% include social-networks-links.html %} 输出的内容，如果用 <ul> 或 <div> 并设置了 float:left 或 display:inline-block，也可能让整体视觉看起来偏左。 解决方法：确保社交链接也使用 text-center 或 justify-content-center：

.beautiful-jekyll-footer .social-networks {
  display: flex;
  justify-content: center;
}

---

✅ 综合建议

修改 footer 结构如下可以保证大部分情况居中：

<footer>
  <div class="container-fluid beautiful-jekyll-footer py-4">
    <div class="row justify-content-center">
      <div class="col-xl-8 col-lg-10 text-center">
        {% include social-networks-links.html %}
        {% if page.footer-extra %}
          <div class="footer-custom-content my-3">
            {% for file in page.footer-extra %}
              {% include {{ file }} %}
            {% endfor %}
          </div>
        {% endif %}
        <p class="copyright text-muted mb-0">
          ...
        </p>
      </div>
    </div>
  </div>
</footer>

这个改法保证：

  1. 页脚宽度全屏 (container-fluid)；
  2. 内部内容在大屏和小屏都居中；
  3. 保留原有的 Bootstrap 栅格和自定义内容。

明白了，你的情况很典型：页脚在博客文章页面正常，但在归档、关于页等非文章页面偏左。这背后的原因主要是 页脚的容器宽度和正文容器的列偏移不一致。我来详细分析：

---

1️⃣ 原因分析

  1. 文章页 vs 非文章页的容器差异

- 博客文章页通常使用类似 col-xl-8 offset-xl-2 的列布局，正文居中，同时页脚宽度也跟随文章列宽，视觉上自然居中。 - 归档页、关于页等可能直接使用 container-md 或 col 布局，没有 offset 或者列宽更窄，页脚在大屏幕上就显得偏左。

  1. full-width 的影响

- 页面模板中 full-width: true 会让内容和页脚全屏宽度。 - 默认 full-width: false 时，正文列有偏移，页脚却没有，导致视觉偏左。

  1. 页脚在 base.html 中是固定的 container-md

- 文章页内容和页脚宽度一致，非文章页内容列可能宽度变化，页脚依然是 container-md，导致不居中。

---

2️⃣ 解决方案思路

方法 A：页脚始终全屏 + 内部列居中（推荐）
<footer>
  <div class="container-fluid beautiful-jekyll-footer py-4">
    <div class="row justify-content-center">
      <div class="col-xl-8 col-lg-10 text-center">
        {% include social-networks-links.html %}
        {% if page.footer-extra %}
          <div class="footer-custom-content my-3">
            {% for file in page.footer-extra %}
              {% include {{ file }} %}
            {% endfor %}
          </div>
        {% endif %}
        <p class="copyright text-muted mb-0">
          ...
        </p>
      </div>
    </div>
  </div>
</footer>
  • 页脚占满整个屏幕宽度 (container-fluid)。
  • 内部列和文章列宽度相同 (col-xl-8 col-lg-10) 并居中。
  • 归档页、关于页、文章页都适配。
方法 B：页脚跟随正文列宽 + 支持 full-width
<footer>
  <div class="{% if page.full-width %} container-fluid {% else %} container-md {% endif %} beautiful-jekyll-footer py-4">
    <div class="row justify-content-center">
      <div class="{% if page.full-width %} col {% else %} col-xl-8 offset-xl-2 col-lg-10 offset-lg-1 text-center {% endif %}">
        {% include social-networks-links.html %}
        ...
      </div>
    </div>
  </div>
</footer>
  • 非文章页时，页脚宽度和正文列宽一致并居中。
  • full-width 页面页脚全屏。

---

3️⃣ 建议

  • 方法 A 更简洁，保证所有页面视觉统一，页脚不会因为页面类型不同而偏左。
  • 方法 B 更严格跟随正文宽度，但需要确保所有页面模板（归档页、关于页等）也能正确设置 full-width 或 container。

现在出现了两个页脚

出现两个页脚的原因可能是在 base.html 和 pages.html 中都包含了页脚的代码。根据你之前提供的信息，base.html 中已经包含了页脚部分，而在 pages.html 中，你也可能不小心再次引入了页脚，导致重复渲染。

解决方法

你只需要确保页脚 只在一个地方 渲染，通常是放在 base.html 中，然后在 pages.html 中去掉重复的页脚代码。

步骤：

  1. 确认页脚只在 base.html 中渲染

在 base.html 中已经有了完整的页脚结构，所以你不需要在 pages.html 中再次添加页脚。

  1. 修改 pages.html

在 pages.html 中，删除页脚的部分，只保留正文和其他内容。你可以修改 pages.html 为如下：

   ---
   layout: base
   ---

   {% include header.html type="page" %}

   <main class="{% if page.full-width %} container-fluid {% else %} container-md {% endif %}">
     <div class="row justify-content-center">
       <div class="{% if page.full-width %} col {% else %} col-xl-8 offset-xl-2 col-lg-10 offset-lg-1 {% endif %}">
         {% if page.before-content %}
           <div class="before-content">
             {% for file in page.before-content %}
               {% include {{ file }} %}
             {% endfor %}
           </div>
         {% endif %}

         {{ content }}

         {% if page.after-content %}
           <div class="after-content">
             {% for file in page.after-content %}
               {% include {{ file }} %}
             {% endfor %}
           </div>
         {% endif %}

         {% include comments.html %}
       </div>
     </div>
   </main>
  1. 确保 base.html 中包含页脚

在 base.html 中的页脚部分已经修复过了，现在页脚部分应当只出现在 base.html 中。

结果：

这样处理之后，页脚只会出现在 base.html 中，不会在 pages.html 中重复显示。

---

请确保 base.html 中的页脚部分已经正确渲染，并且 pages.html 中没有重复的页脚代码。如果仍然有问题，可以检查是否在其他模板中重复引用了 footer.html。
