三个引擎的分工

同一天连续设计
引擎解决什么类比人脑
DeepDigest长文档/多文档信息萃取阅读与提炼
GraphMind把萃取结果组织成知识图谱联想与关系
CortexMemory四层记忆的存取与遗忘短期/长期记忆

三者关系：DeepDigest 是入口（吃原文出结构化信息），GraphMind 是存储结构（信息之间连边），CortexMemory 是生命周期管理（什么留、什么忘、什么时候调出来）。

01

DeepDigest 四模式

来源：027

不是所有长文档都用同一种"总结"。按目标分四种模式。

模式输出适用
摘要模式一段话核心结论快速浏览、邮件、新闻
要点模式结构化要点清单会议纪要、报告、文档
问答模式按预设问题抽取答案调研、合规、信息核对
图谱模式实体 + 关系三元组喂给 GraphMind 建图谱
02

GraphMind 图谱大脑

来源：028 / 10 条消息

从 ontology（本体论）出发，定义"有哪些实体类型、哪些关系类型"，再往里塞数据。不是先建图库再想结构，是先定 ontology。

底层用什么跑

  • State Machine：每个节点有生命周期状态（新建 / 已确认 / 已合并 / 已废弃）
  • DAG：依赖关系用有向无环图，避免循环引用
  • EventBus：节点变更发事件，触发下游更新

好处：图谱不是静态存数据，而是一个会"联动"的系统——一个实体改了，所有相关节点自动感知。

03

CortexMemory 四层记忆

来源：030

CortexMemory 用 SQLite 实现，把记忆分四层，每一层存取策略不同。

层存什么保留时长
L1 工作记忆当前对话上下文会话内
L2 情景记忆最近几次重要交互、决策数天到数周
L3 语义记忆沉淀下来的事实、偏好、规则长期
L4 程序记忆反复验证过的工作流程、Skill 触发条件永久
实现要点：SQLite 单文件、按层分表、按重要性打分决定保留多久、过期自动归档不直接删。Agent 启动时只加载 L3+L4 的索引，不把全部记忆塞进上下文。
