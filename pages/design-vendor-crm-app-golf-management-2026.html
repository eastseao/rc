02

客户管理 APP · 产品需求文档

手动录入 · 离线可用

目标是一款轻量级、以手动录入为主的 CRM：客户分四级，每个客户下手动添加其产品采购记录（产品、时间、金额）。V1.0 单机离线、本地存储、无需登录。

客户四级分类（颜色标签）

  • 资深客户：金色；VIP 客户：紫色
  • 普通客户：蓝色；潜在客户：灰色（默认）
  • 列表支持按分类筛选、关键词模糊搜索（名称/电话/备注）
  • 分类完全由用户手动调整，不设自动升降级

采购记录（客户详情页手动添加）

  • 字段：产品名称（必填，自由输入）、采购时间（默认当天）、金额（两位小数）、数量（选填）、备注（选填）
  • 按时间倒序排列；同客户可加多条、产品名不要求唯一
  • 保存后即时更新客户列表"最近采购摘要"
数据模型（两表）
客户表 Customer类型说明
id / name主键 / 文本唯一标识 / 客户名称（必填）
phone / level文本 / 枚举电话（选填）/ senior·vip·normal·potential
notes / created_at / updated_at文本 / 时间戳备注 / 创建时间 / 最后修改
采购记录表 PurchaseRecord类型说明
id / customer_id主键 / 外键唯一标识 / 关联客户（删客户级联删除）
product_name / purchase_date文本 / 日期产品名称（必填）/ 采购时间（必填）
amount / quantity / notes浮点 / 整型 / 文本金额两位小数 / 数量 / 备注

非功能：1000 条客户内滚动流畅、启动 ≤2s、本地读写 ≤100ms；iOS 12+/Android 8.0+；飞行模式全功能可用；支持 CSV/Excel 导出。验收含分类筛选准确、无级联残留、必填与金额校验等 8 条。
