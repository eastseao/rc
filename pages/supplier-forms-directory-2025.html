01

联系表单与统计表单字段设计对照

00143 / 00375

一份是“供应商主动来联系我们”的轻量联系表单，一份是食品企业建供应商档案的完整统计表单。前者字段少而精，后者按六大分部展开，可对照取用。

包装供应商联系表单 · 字段与必填项（00143）

用途：包装供应商主动联系时填写基本信息，便于后续对接。设计思路为现代 UI、清晰布局、响应式与直观表单验证。

字段必填选项/说明
公司名称必填文本
联系人姓名必填文本
联系电话必填电话
电子邮箱必填邮箱
公司地址选填文本
主营业务类型必填下拉：纸制品包装 / 塑料包装 / 金属包装 / 玻璃包装 / 木质包装 / 复合材料包装 / 其他
主要产品范围选填占位示例：纸箱、礼品盒、食品包装等
年生产能力选填下拉：小型（10 万件以下）/ 中小型（10-50 万件）/ 中型（50-100 万件）/ 大型（100 万件以上）
相关认证选填占位示例：ISO9001、FSC 认证等
附加信息选填多行文本

食品企业供应商信息统计表单 · 六大分部（00375）

设计理念：建立统一供应商档案，便于寻源、评估、比价、风险管控与合规管理。品类下拉含外包装、内包装、原料、辅料、设备。

分部字段要点
一、基础信息供应商编号（如 SUP-2024-001）；名称全称；简称；国家/省/市；详细地址；企业类型（生产商/授权经销商/贸易商/个体）；合作状态（潜在/合格/暂停/黑名单）。
二、联系信息主要联系人+职位；联系电话+手机；电子邮箱；传真；公司总机/前台；QQ/微信；官网地址；备注（最佳联系时间等）。
三、品类与产品信息主营品类（外包装/内包装/原料/辅料/设备/其他）；具体供应产品/物料名称；产品执行标准/等级（如 GB 4806.7-2016、FCC-V）；最小起订量 MOQ；供货周期/交货期。
四、财务与商务信息报价有效期；付款方式（预付/货到付款/月结 N 天/其他）；付款币种；开票类型（增值税普票/专票）+税率；开户银行；银行账号；账期与信用额度记录。
五、资质与证照（食品安全核心）营业执照（统一社会信用代码/注册资本/法定代表人）；生产/经营许可证（编号）；体系认证（ISO 9001、ISO 22000/FSSC 22000、HACCP、BRC、IFS）；产品检测报告；食品接触材料符合性声明（内外包装供应商）；清真/有机等特定认证。
六、评估与绩效首次合作日期；上年度采购总额（用于 ABC 分类）；绩效评分（质量合格率%、交货准时率%、价格竞争力 1-5 分、服务配合度 1-5 分）；现场审核记录（已/未审核、日期、结果：优秀/合格/整改中/不合格）；主要优缺点/备注。
Excel 落地要点（照录）
  • 下拉选项来源串：企业类型 生产商,经销商,贸易商,个体；合作状态 潜在,合格,暂停,黑名单；主营品类 外包装,内包装,原料,辅料,设备,其他；付款方式 预付款,货到付款,月结,其他；付款币种 人民币,美元,其他；开票类型 增值税普票,增值税专票。
  • 电脑端：数据 → 数据验证 → 允许“序列”，来源用英文逗号分隔；手机端 WPS：长按选中单元格 → 工具栏“数据” → “插入下拉列表”，手动添加或从单元格区域选择。
  • 使用建议：电子化便于筛选排序；财务、资质等敏感信息设查看权限；专人每季度/半年更新证照、绩效与财务；增“附件”列链接营业执照、许可证、检测报告扫描件。
02

常用打样供应商名录表结构

00275

名录是“一行一家、随时可调”的表，核心是类别、打样能力、报价特点、打样周期与合作评价五列。表名建议“常用打样供应商名录”，并注明制表部门/人与更新日期。

列名说明
序号自动编号，便于快速查找和统计。
类别核心列，一级分类方便按需筛选：印刷类 / 包装类 / 塑胶·模具类 / 五金类 / 硅胶·橡胶类 / 样品·手板制作 / 纺织·服装类。
供应商名称公司全称。
主要打样能力核心列，写最擅长的打样领域与具体产品，如“精密塑胶零件模具”“高速 SMT 贴片”“高端服装面料”。
联系人/电话/邮箱关键联系信息，建议把最常用联系方式（如微信）放前面。
地址/网址物理地址与公司网站，网址帮助新同事快速了解供应商实力。
报价参考/特点核心列，记录大致价格水平（偏高/适中/有竞争力）与核心优势（质量顶尖、交期快、支持复杂结构、服务好）。
打样周期核心列，常规项目平均打样时间（如 3-5 天、1 周），对项目排期至关重要。
合作评价/备注核心列、表格“灵魂”：星级（⭐~⭐⭐⭐⭐⭐）或“优秀/良好/一般”；备注特殊信息（需提供 3D 图、最小订单金额、曾交期延误需紧盯等）。
最后合作时间记录最后一次下单打样时间，便于识别长期未合作供应商、清理更新名录。
进阶优化建议（照录）
  • 用 Google Sheets、腾讯文档、飞书文档等在线表格，方便团队多人实时查看与更新。
  • 增加“状态”列，用颜色或文字标识 活跃 / 备用 / 停止合作。
  • 在线表格中可在供应商名称旁加超链接，直接链到资质文件、合同或历史报价单。
  • 指定专人每季度或每半年审核名录，更新信息并淘汰不合格供应商。
03

邀填说明与提交感谢语

00380

同仁堂健康青海基地采购用于“邀供应商填信息”的两段话术：一段是表单开头的邀填说明（商务润色版），一段是提交成功后的感谢语（三种风格备选）。

邀填说明 · 商务润色版

我是同仁堂健康青海基地的采购负责人，为便于日常联络及推进潜在合作，现诚挚邀请您填写基本信息，以便我们更好地了解贵司所能提供的服务内容。若我们尚未建立合作关系，也期待通过此表开启沟通，为未来合作奠定基础。感谢您的支持与配合！

改写说明：将口语化表达调整为商务书面语；重组顺序先讲身份与目的、再表合作期望；补充“诚挚邀请”“感谢支持与配合”等礼貌用语。

提交成功后的感谢语（三种风格备选）

① 标准商务版（正式、清晰告知后续步骤）

感谢您的填写！我们已成功收到您提交的信息。同仁堂健康青海基地采购部会仔细审阅，如有合作需求，我们将尽快与您联系。

② 简洁高效版（语言精炼、快速确认接收）

提交成功！感谢您的支持，我们已收到您的资料，并将尽快审阅。

③ 温馨合作版（表达期待携手、语气主动热忱）

感谢信任，提交成功！您的信息对我们非常重要，我们已妥善收录。期待未来能与贵公司携手合作，共创价值！
