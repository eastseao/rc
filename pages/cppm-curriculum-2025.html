CPPM六大课程模块详解

CPPM（注册职业采购经理）认证的六大课程模块，涵盖供应商选择与评估、采购谈判技巧、采购合同管理、供应链管理、采购成本管理、采购战略及风险控制，系统梳理采购与供应链管理的知识体系。

发布日期 2025-09-30 文档版本 V1.0
CPPM 采购认证 供应链管理 供应商评估
01

六大课程模块概览

CPPM 认证核心框架

CPPM（注册职业采购经理）认证的培训课程围绕采购与供应链管理的核心领域，分为六大模块，旨在系统提升采购从业人员的专业能力。

模块名称核心内容要点
模块一：供应商选择与评估供应市场的种类与经济学分析；供应商的信息来源；供应商评估的指标与权重；供应商的等级评定与管理；供应商关系冲突与协调
模块二：采购谈判技巧采购谈判的认识；采购谈判的挑战；如何制定谈判计划；如何实施有效的谈判；谈判技能训练
模块三：采购合同管理合同的形式；合同的管理；合同修改、签约；合同违约和争议解决；采购合同的价格形式
模块四：供应链管理供应链管理的核心；供应链管理前后级管理；需求管理流程；供应链运营管理流程；在供应链上发展和实施伙伴关系
模块五：采购成本管理成本管理的采购战略；采购价格及采购成本分析技术；采购成本财务分析；供应商成本现场改善之道；降低采购成本的手法
模块六：采购战略及风险控制采购战略管理；成本管理的采购战略；采购风险的识别与控制技术；内部控制风险；采购的内部管理——控制和审计
认证级别
CPPM 认证分为三个级别：注册职业采购助理（CAP，入门级）、注册职业采购专员（CPP，有经验的专员）、注册职业采购经理（CPPM，经理级，侧重管理、领导技能及战略层面）。
认证价值
CPPM 是国家人力资源和社会保障部引进的国际采购认证，证书被纳入国家职业资格证书统一管理体系，实现国际和国内"双认证"。
02

模块一：供应商选择与评估

供应市场 → 信息来源 → 评估 → 等级 → 关系

供应商选择与评估是采购工作的起点。从供应市场分析入手，通过多渠道信息收集、科学的指标权重体系、等级评定与差异化管理，最终建立健康的供应商关系。

知识要点核心内容
供应市场分析系统进行供应商、供应价格、供应量、供应风险等基础数据的搜集、整理和分析。驱动因素包括技术创新、市场变化、社会环境、汇率变动、产品生命周期与产业转移。常用工具：波特五力、SWOT、PEST。
供应市场种类按竞争程度分为：完全竞争市场（价格由供需决定，策略是降本招标）、垄断竞争市场（产品有差异，平衡价格与价值）、寡头垄断市场（供应商极少，建立战略合作）、完全垄断市场（单一供应商，风险管理与寻找替代）。
供应商信息来源内部来源（历史交易数据、现有供应商档案）；外部来源（线上资源、行业渠道、官方与第三方机构、直接接触）。
评估指标与权重五大维度：质量与工艺、价格/成本、交付与服务、技术与管理、财务与风险。权重设定引入卡拉杰克矩阵——战略型物资重质量技术，杠杆型物资重价格成本，瓶颈型物资重交付保障，常规型物资重流程效率。
等级评定与管理A级（战略/核心供应商）深化合作；B级（优选/良好）正常往来；C级（合格/待改进）辅导整改；D级（不合格/淘汰）启动更换。
关系冲突与协调冲突根源包括目标差异、信息不对称、利益分配不均。协调策略：战略层面构建协同框架，战术层面优化流程沟通，操作层面解决日常摩擦。

模块二：采购谈判技巧

认知 → 挑战 → 计划 → 实施 → 训练

采购谈判不是"零和博弈"，而是"创造价值"的过程。专业的采购谈判关注总拥有成本而非单价，谈判的胜负80%在开始前就已决定。

谈判核心认知

  • 不是零和博弈，而是创造价值——扩大"蛋糕"而非争夺固定份额
  • 不仅是价格，更是总拥有成本（物流、质量、运营、风险成本）
  • 不仅是技巧，更是准备——了解己方BATNA、对方成本结构、市场供需
  • 不是对抗，而是沟通与影响——采购是合作伙伴而非敌人

谈判典型流程

  1. 准备与规划：设定目标、分析优劣势、制定策略议程、组建团队
  2. 开局与探索：建立氛围、交换立场、积极倾听捕捉信息
  3. 讨价还价与让步：每次让步都要索取回报，坚守核心利益
  4. 协议与收尾：总结共识、形成书面纪要
  5. 履行与关系维护：确保协议执行，维护合作关系
谈判黄金法则
  • 信息就是权力——你知道的越多，地位越有利
  • 永远让对方先开口——了解对方期望和底线
  • 沉着冷静，保持耐心——不要暴露紧迫感
  • 对事不对人——聚焦问题和利益，不攻击个人
  • 知道何时离开——有更好的BATNA时，要有勇气终止谈判

模块三：采购合同管理

形式 → 管理 → 修改签约 → 违约争议 → 价格形式

合同管理是采购风险控制的第一道防线。理解合同形式的法律效力，坚持"书面为王"，是采购专业人士的基本功。

合同形式法律效力采购实践建议
书面形式最强，是证明合同内容最直接的证据采购的首选和标准做法。合同书、信件、数据电文（电子邮件、EDI）均视为书面形式。
口头形式有效，但难以举证尽量避免。仅用于低价值、即时清结交易，随后补发邮件或订单书面确认。
其他形式（默示）有效，但内容可能不完整风险较高。注意不要轻易接收未达成书面协议的货物，以免被"造成既成事实"。
格式条款提醒：供应商提供的格式合同中，提供方必须合理提示免责、违约金等重大利害关系条款。未尽提示义务的，采购方可主张该条款不成为合同内容；不合理免除己方责任、加重对方责任的条款无效。

模块四：供应链管理

核心 → 前后级 → 需求管理 → 运营流程 → 伙伴关系

供应链管理的核心是"全局观"——通过高效协同内外资源，以最小的总成本，实现从原材料到最终顾客的端到端增值管理与服务。

核心目标

  • 提升客户服务水平：正确的时间、地点、数量、状态提供正确的产品
  • 优化供应链总成本：不是降低采购价格，而是最小化从原材料到分销所有环节的总成本

核心流程（五大）

  • 计划 → 采购 → 制造 → 交付 → 退货
  • 由信息流、物流、资金流"三流"贯穿协同，形成闭环
传统思维现代供应链核心思维
部门职能导向端到端的流程导向
关注局部成本最低追求供应链总成本最优
与供应商是竞争关系与核心伙伴建立战略协作
基于预测推动生产响应真实需求的拉动式生产
信息孤立、不透明信息共享、协同规划

模块五：采购成本管理

战略 → 价格分析 → 财务分析 → 现场改善 → 降本手法

现代采购成本管理的核心，是从"价格"思维转向"总拥有成本"思维，从"交易"角色转向"价值创造"角色。

核心战略要点
战略寻源与品类管理不能对所有采购物品采用同一种成本管理方法。用卡拉杰克矩阵分类：战略型建伙伴关系，杠杆型集中招标，瓶颈型保供应，常规型自动化。
总拥有成本（TCO）分析TCO = 购买前成本 + 采购价格 + 使用期成本（运输、安装、能耗、维护、操作人工）+ 生命周期结束成本（处置、环保回收）。
供应商关系与协同降本早期供应商参与（ESI）、联合成本降低项目、价值工程/价值分析（VE/VA）。
流程优化与数字化电子采购、电子招标、电子合同减少人工操作；数据分析识别节约机会；合同合规管理避免 Maverick 采购。
价值分析与价值工程价值分析针对现有产品，寻求以更低成本实现同等功能的替代方案；价值工程针对新产品设计，在研发阶段就致力于最低生命周期成本。

模块六：采购战略及风险控制

战略 → 风险识别 → 内控 → 审计

采购风险管理是一个闭环：风险识别 → 风险评估 → 应对策略制定 → 实施与控制 → 持续监控与复审。内部控制和审计则是保护公司资产、保障采购人员职业安全的管理工具。

风险类型风险描述控制技术
供应风险供应商破产、质量不稳定、交付延迟、单一供应源供应商多元化、尽职调查与绩效管理、安全库存、战略伙伴关系
价格/成本风险原材料价格波动、汇率风险、通货膨胀长期协议与价格锁定、金融对冲（期货期权）、价值工程替代
需求风险需求预测不准、订单频繁变更、产品生命周期短S&OP 销售与运营规划、柔性合同、模块化设计延迟差异化
物流与库存风险运输延迟、货物损毁、库存积压或短缺物流路线多元化、购买保险、先进库存管理系统
合规与道德风险供应商违反环保法规、使用童工、贪污腐败、侵犯知识产权供应商行为准则、合规审计、举报机制

采购内部控制五要点

1. 请购控制
采购需求必须来自经批准的部门，按预算和授权审批。
2. 供应商选择
严格资质审核和现场评估。主要采购项目从 AVL 中选取，执行招标、比价或竞争性谈判。
3. 采购执行
使用标准采购订单和合同模板，经法务、财务评审，PO 经审批流生成。
4. 验收入库
独立验收环节，核对数量规格并质量检验，出具入库验收单（付款必要依据）。
5. 付款控制
"三单匹配"——发票、采购订单、入库验收单严格一致，不匹配暂停付款并调查。
