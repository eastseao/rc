01

数据结构 data.json

物料 / BOM / 成品

物料（tz）数据是数组，每条一个合同行：〔2025-10-27〕

[
  {
    "合同编号": "SC2022-1-4-04",
    "供应商名称": "四川鼎晟塑料制品有限公司",
    "项目号": "81003852",
    "项目名称": "雪菊瓶身",
    "数量": "7000", "单位": "个",
    "采购单价": "1.21", "订单总额": "8470"
  }
]

BOM 查询要求：品名模糊搜索、项目号精准搜索，只有这两个框；有重置按钮（不搜索时不显示）。结果列顺序固定为项目号、品名、规格、零售价、物料项目号、物料名称、数量、单位；项目号是父项，下面挂物料子项（父子合并）。〔2025-10-28〕

成品（CP）查询：输入项目号（精准）+ 品名（模糊），输出项目号、品名、规格、单位、零售价、产品属性、保质期、品牌、可供应渠道。〔2025-10-30〕

02

单页查询实现要点

fetch + 表格渲染
  • 页面放在仓库根目录子文件夹，如 gervasw.github.io/tz/、/CP/，data.json 与 index.html 同目录。〔2025-10-26〕
  • 进页面 fetch('data.json') 读数据，输入框监听 input 事件过滤，渲染到 <tbody>。
  • 「点查询无反应」多为 data.json 路径错、fetch 跨域（本地 file:// 打开）或 JS 报错——线上 Pages 上按相对路径即可。〔2025-10-26〕
  • 加序号列、调整表格列顺序、修成品页标题，都是在渲染函数里调列映射。〔2025-10-31 / 11-14〕
风格统一：物料、BOM、成品三套页面沿用同一套 Tailwind 卡片 + 表格风格，新页面「仿照 BOM 查询系统的风格提供代码」，保持视觉一致。〔2025-10-30〕
