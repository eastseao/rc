主流客户端对照（跨年份）

2023 搜索 + 2026 实测推荐

2023 年那批会话几乎全是 Web 搜索结果沉淀，当时主流是 v2rayNG（安卓）、WinXray（Windows）、Clash for Windows；到 2026 年再问同类问题时，推荐已经整体切换到 Clash Verge Rev、Hiddify、Mihomo Party 这一代。

客户端平台内核 / 协议特点与备注
v2rayNGAndroidXray / v2fly 内核安卓端最经典客户端，支持 VMess，可编译；GitHub 仓库 2dust/v2rayNG。
WinXrayWindowsXray 内核（aardio 开发）支持 vmess/vless、SS、SSR、Trojan、Trojan-go、NaiveProxy；自动测速切最快节点，服务器异常自动换；仅 Windows 平台。
Clash for WindowsWindowsClash 内核支持 TUN/TAP 虚拟网卡模式；0.18.7 后更推荐 TUN。
Clash Verge RevWindowsMihomo 内核2026 年首推，Windows 用户最稳，界面完善、社区活跃。
Hiddify全平台Clash/Mihomo、Sing-box界面漂亮、更新活跃，支持 VLESS、Reality、Hysteria2；跨平台体验好。
Mihomo PartyWindowsMihomo 内核UI 现代，体验不错。
v2rayNWindowsXray / v2fly老牌稳定，兼容性最好，资源占用低。
FlClash全平台Flutter 开发依赖 WebView2，Windows 上常见「后台有进程、窗口不显示」。
2026 年的推荐顺序（Windows 11 x64）
  • 首选 Clash Verge Rev — 最成熟稳定，兼容 Mihomo 配置。
  • 次选 Hiddify — 协议最多、更新频繁。
  • 备选 v2rayN — 老牌经典，资源占用低。
  • 订阅是 Clash/Mihomo 格式，上面三个基本都能直接导入。
02

Clash 的 TUN 与 TAP 模式

2023-04-06 搜索整理

浏览器走系统代理就够了；但游戏、Git、不遵循系统代理的软件需要虚拟网卡接管全部三层流量。TUN 与 TAP 的区别是当年那批搜索笔记里信息密度最高的一段。

对比项TUNTAP
工作层三层（网络层，IP 数据包）二层（数据链路层，以太网帧）
MAC 地址无，不能与物理网卡 bridge有，可 bridge、支持 MAC 层广播
Windows 性能更好，0.13.8 后更推荐较老方案
UDP 处理更强，可做 DNS 劫持一般
安装依赖需下载 Wintun（wintun.net，amd64 目录），把 wintun.dll 放到 Clash Home Directory需安装虚拟网卡驱动
配置步骤

Clash for Windows 开 TUN 模式

触发场景
游戏加速、Git、WSL 等不走系统代理的软件；专业开发建议直接 TUN。日常浏览器浏览用系统代理即可，不必开全局。
安装 Wintun
从 wintun.net 下载压缩包，按系统选 amd64 目录，把 wintun.dll 复制到 Clash 的 Home Directory（General 页面点击可打开该目录）。
服务模式
General 页面 → Service Mode → Manage，安装服务模式后再开启 TUN。
mixin 配置
Mixin 选项编辑文件，清空原有内容后粘贴 TUN 配置片段。

WinXray：导入、测速与常见故障

2023-04-06 三篇会话合并

WinXray 是 Windows 上的 Xray 内核通用客户端，aardio 写的，绿色解压即用。三篇同天会话分别查了它的功能、故障、再次确认，合并后是下面这套使用笔记。

导入节点三种方式

  • 剪贴板批量导入：右键列表 → 从剪贴板批量导入分享链接和订阅源，双击节点启用。
  • 扫屏幕二维码：右下角托盘图标右键 → 扫一扫导入节点。
  • 手动 JSON 配置：配置页手写节点参数，不推荐，易错。

优缺点（照录）

优点
支持多协议；导入即用；自动测速切最快节点；服务器抽风自动换；自实现 PAC 服务器解决了 PAC 用久卡死的问题。
缺点
启动切节点响应略慢；新增节点手动配置难；仅 Windows。
「代理改不了 / 用不了」排查顺序
  • 先把 WinXray 加入杀毒软件 / Windows Defender 信任列表（常见于安全软件静默拦截）。
  • 仍不行：Win+R 输 regedit，定位到 HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Internet Settings\Connections，删除 Connections 项后注销系统。
  • 订阅更新无变化时，完全退出软件再启动（客户端缓存问题）。

免费节点源与订阅转换工具

2023-04 四篇搜索合并

2023 年那批搜索记录里反复出现的免费节点 GitHub 仓库和 ACL4SSR 订阅转换站，本质上是一套「拿公共节点 → 转成自己客户端能用的配置」的流程。

资源用途
Pawdroid/Free-serversGitHub 免费节点仓库，实时手动测速，6 小时更新。
aiboboxx/v2rayfreev2ray 公益免费节点订阅，每日更新，附 Telegram 频道。
aiboboxx/clashfreeClash 免费节点订阅，每日更新。
ermaozi/get_subscribe提供 clash.yml / v2ray.txt 原始订阅链接。

ACL4SSR 在线订阅转换acl4ssr-sub.github.io / sub.v1.mk / sub-zh.vercel.app 等，把各机场链接转成 Clash 配置，可过滤、重命名、排序、合并多订阅。

FlClash 安装后点不开：Windows 11 x64 实测排查

2026-06-27

现场症状：Windows 11、x64，双击 FlClash 后任务管理器能看到进程但窗口不弹。这说明程序起来了，UI 没渲染出来，不是配置文件问题。

按优先级排查

五步定位

① 装 WebView2（成功率最高）
FlClash 界面依赖 Microsoft Edge WebView2 Runtime（Evergreen）。系统没装或运行时损坏就会后台有进程、前台无窗口。装完重启电脑再启动。
② 删配置目录
彻底退出 FlClash，备份后删除其配置目录，再启动（配置损坏也会导致窗口不显示）。
③ 管理员身份运行
右键 FlClash.exe → 以管理员身份运行。
④ 查安全软件拦截
Defender 或第三方杀软有时会阻止 Flutter 程序创建窗口。
⑤ 下最新版覆盖安装
老版本 Flutter 兼容问题直接换最新版。
不想折腾就换客户端
  • Windows 11：Clash Verge Rev（首推）> Hiddify > v2rayN。
  • FlClash 是 Flutter 写的，显卡驱动 / 运行环境兼容问题会偶发；上面三个社区使用人数更多、更稳。

Quetta 浏览器：电脑版与公司背景核查

2026-08-24

Quetta 是一款定位「video-first」的 Chromium 浏览器，主打 AI 广告拦截 + 隐私保护 + 内置视频下载。2026 年 8 月才刚出 Windows Beta，公司背景需要单独盘一遍。

核查项结论
Windows 版有，Beta，首个版本 2.0.2 发布于 2026-08-04，基于 Chromium，同时有 macOS 版。
运营主体Quetta Networks Limited，注册地址 Office Suite 29A, 23 Wharf Street, London, SE8 3GG，英国伦敦。
公司体量小型新兴团队，2023 年开始运营；产品负责人 Stephen，产品管理 Cherysun。不是 Google/Mozilla/Brave 那种大厂。
核心功能AI 广告拦截、Tracker 拦截、指纹防护、HTTPS 优先、内置视频下载（HLS/M3U8/MP4/WebM）。
隐私政策默认不要求注册、不收集个人信息；但集成 Google Analytics 收集匿名使用数据，可在设置里关。
开源程度非完全开源浏览器路线；安全审计公开信息有限。

使用建议

日常看视频、拦广告可以试；敏感账号别放。

银行、券商、企业后台、密码管理器、邮箱主账号、重要 GitHub 账号仍用 Firefox / Brave / Edge / Chrome。Quetta 装完第一件事先把 Analytics、匿名使用数据、Crash Report 全关掉，裸装观察一段时间更新与崩溃，再决定要不要装扩展、导密码。
