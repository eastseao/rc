去掉背景留千纸鹤 · 图像处理小任务

SVG 中嵌入的"千纸鹤"是位图而非矢量图形，无法通过删改 SVG 代码直接去背景。本页记录用图像处理工具抠出透明 PNG 再放回 SVG 的完整做法。

发布日期 2026-07-01 文档版本 V1.0
SVG 去背景 图像处理 remove.bg
01

问题本质：位图无法靠删代码去背景

关键认知

用户需求是"去掉代码里的背景，只要千纸鹤"。但这个 SVG 里的"千纸鹤"是嵌在 PNG 背景图片中的位图，不是矢量图形，所以无法通过删改 SVG 代码直接去掉背景。

红线 · 位图 vs 矢量

千纸鹤是 PNG 位图，不是 SVG 矢量路径

位图由像素点组成，每个像素的颜色和透明度是固定的。要"去掉背景"，必须在像素层面把背景像素的透明度改为 0，而不是删除 SVG 里的某段代码。

02

推荐工具

在线 / 桌面 / 命令行

使用图像处理工具把千纸鹤从背景中抠出来，保存为透明背景的 PNG，然后再放到 SVG 里。

工具类型推荐工具特点
在线工具remove.bg自动去背景，上传图片即可获得透明 PNG，最简单快捷。
电脑软件Photoshop / GIMP / Krita功能强大，支持手动精修蒙版和边缘。GIMP 为免费开源替代。
命令行ImageMagick 配合蒙版适合批量处理或自动化脚本场景。
03

处理后的 SVG 写法

透明 PNG base64 嵌入

把抠好的透明背景千纸鹤 PNG 转成 base64，填回 SVG 的 <image> 元素的 href 中。

SVG 示例

嵌入透明背景 PNG 的 SVG 结构

<svg xmlns="http://www.w3.org/2000/svg"
     width="1024" height="1024" viewBox="0 0 1024 1024">
  <image width="1024" height="1024"
    href="data:image/png;base64,（这里放透明背景的千纸鹤PNG的base64数据）"/>
</svg>
如果你只有原图，没有透明版
  • 先把原图下载下来。
  • 用推荐的在线工具（如 remove.bg）去除背景。
  • 把生成的透明 PNG 转成 base64，填回 <image> 的 href 中。
核心结论：位图去背景不能靠删 SVG 代码，必须用图像处理工具在像素层面抠图，再把透明 PNG 以 base64 形式嵌回 SVG。
