00

设计范式：从一段 Prompt 到一套文件

4 个角色 · 半年演进

这四个 Agent 共享同一套设计方法：不写一段长 system prompt，而是拆成 identity（我是谁）+ soul（怎么想）+ principles（原则）+ capabilities（能力清单）+ workflow（工作流）。角色越专业，拆得越细。

01

阿紫 · 食品全栈 Agent

来源：003 / 2026-04-07

最早的垂直人格，定位是食品行业全栈助手——从原料、配方、包装、成本到上市全链路都能聊。这是后续所有食品类 Agent（采购、PM）的母版。

02

食品行业采购 Agent

来源：050 / 2026-05-25

从阿紫细分出来，专做采购。核心是 8 维度评分 + 产业带匹配 + 3 个高级模式。

评分维度看什么
资质合规SC、ISO、检测报告齐全
产品质量COA、批次稳定性、客诉
价格竞争力市场价对比、阶梯价
交付能力MOQ、交期、产能、应急
服务响应沟通速度、打样配合
合作意愿账期、独家、配合度
财务健康注册资本、经营年限
风险环保处罚、法律诉讼、单一来源依赖
3 个高级模式：紧急寻源、年度比价、新供应商导入。每个模式有独立的流程和输出模板。产业带匹配表是硬编码知识库——枸杞走宁夏、沙棘走西北、坚果走安徽/浙江。
03

SiteMaster V3 · 网站建站规划师

来源：064 / 2026-05-31

不局限于食品行业——这是一个专门规划"企业网站应该怎么建"的 Agent。六件套文件：identity / soul / principles / capabilities / workflow / output-format。

七层框架

  1. 战略层：这个网站要达成什么商业目标
  2. 流量层：SEO / GEO / 投放 / 私域，流量从哪来
  3. 内容层：栏目结构、内容生产节奏
  4. AI 层：GEO 规划引擎、企业知识库、Agent 集成、MCP 规划
  5. 转化层：CTA、表单、留资路径
  6. 数字资产层：域名、数据、内容版权沉淀
  7. 数据层：埋点、分析、转化追踪

口号：网站不是页面集合，而是企业知识操作系统（Enterprise Knowledge OS）。

04

大健康食品产品经理 Agent

来源：074 / 2026-09-09

这一组最新、最完整的一个。不是问答助手，而是贯穿"机会发现 → 产品定义 → 研发 → 成本 → 包装 → 生产 → 上市 → 复盘"全生命周期的中枢。

1 总控 + 10 专业 Skill + 4 基础能力

10 个专业 Skill
  1. market-intelligence 市场情报
  2. ingredient-opportunity 原料机会
  3. product-concept 产品概念
  4. formula-rd 配方研发
  5. compliance 合规审查
  6. supplier-cost 索样成本
  7. packaging-engineering 包装工程
  8. production-management 生产管理
  9. project-management 立项推进
  10. product-review 结题复盘
4 个基础能力
  • bom-management BOM 梳理
  • inventory-management 库存查询
  • cost-engine 自动成本计算
  • product-database 产品数据库

产品机会评分权重：市场需求 20% / 消费者需求 15% / 差异化 15% / 原料优势 10% / 技术可行性 10% / 合规 10% / 成本 10% / 供应链 5% / 营销 5%。

核心设计原则：用户说"帮我设计一个黑枸杞饮料配方"，不能直接开始配。要先问产品定位、目标人群、规格、价格带、卖点——信息不足时基于合理假设继续，但必须明确标注假设。最终目标不是给答案，是推动项目向下一阶段走。
