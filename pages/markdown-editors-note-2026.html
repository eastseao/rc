01

Typora 官方现状：没有手机版

2025-10-16 两次确认

2025 年 10 月连续两天问了两次「Typora 安卓版 / 手机版」，答案一致：官方只做桌面，没有移动版，也没有公布排期。

项目结论
官方支持平台Windows / macOS / Linux，三端桌面
安卓版无，官网明确「暂无计划或发布日期」
iOS 版无
开源情况商业闭源软件，GitHub 上没有源码；官方组织只维护 issue 仓库、主题站、多语言翻译、默认主题和主题开发工具
购买方式一次性付费，导出 PDF / Word / HTML
手机上继续写 Typora 文件的现实做法
  • 把 .md 文件放在 GitHub / Dropbox / Google Drive / OneDrive / Syncthing。
  • 手机用 Markor / Obsidian / iA Writer 打开编辑。
  • 回到桌面用 Typora 无缝继续。

安卓端 Markdown 编辑器对照

2026-03 / 2026-09 两次横评

3 月那次按「像不像 Typora」分层推荐，9 月那次加了一列「本地 .md 文件管理」和「导出图片」。合并后是下面这张总表。

App免费所见即所得本地 .md云同步定位
Markor免费开源部分直接编辑真实文件Syncthing/Nextcloud/Dropbox理工男最爱，纯 Markdown 文件编辑器，离线无广告；F-Droid 下载，APK 约 11MB，Android 4.3+
Obsidian基础免费是设备存储 Vault官方付费同步 / 自建知识库 + 双链 + 图谱 + 插件生态；偏 PKM 而非纯写作
Joplin免费开源分屏预览数据库存储WebDAV / OneDrive / DropboxEvernote 替代型笔记，多端同步成熟
iA Writer付费是是Google Drive / Dropbox作家工具，专注模式极强，最接近 Typora 的沉浸感
JotterPad免费+付费是是Google Drive / Dropbox美观写作界面，专注模式
SilverBullet开源是是弱Markdown notebook，程序员向
MarkText Android开源是（Muya 内核）是无非官方移植，Typora 体验最像；支持 CommonMark/GFM/公式/表格/Mermaid，导出 PDF
MerMD—是是云存储主打 Markdown 实时渲染 + 导出高清图片，见第 05 节
Markor 下载渠道：首选 F-Droid（开源官方商店，自动更新）；备选 Uptodown 下 APK（约 11MB）；APKPure 也有。国内主流应用商店搜不到，因为是纯开源项目、无商业推广，作者只在 GitHub / F-Droid 发布。GitHub: gsantner/markor，最新版 v2.16.1（2026-03-19）。

桌面端（macOS / Windows）对照

2026-04-02 / 04-16

Mac 上找 Typora 平替、Windows 上管理 .md 文件，两次问题合并成桌面端选型。

软件平台价格定位与特点
TyporaWin/Mac/Linux付费所见即所得天花板，支持大纲/图片拖拽/导出 PDF/Word/HTML
MarkTextWin/Mac/Linux开源免费公认第一开源平替，Electron+Vue，实时预览无分栏；UI 比 Typora 略糙
MacDownmacOS免费Mac 原生感，分屏预览 + 导出 PDF，偏经典编辑器
Obsidian全平台基础免费本地 Markdown + 双链 + 插件生态，第二大脑；编辑不如 Typora 纯粹
Joplin全平台开源免费写+存+同步，WebDAV
iA Writer全平台付费极简写作，专注模式，作家用书
VS Code全平台免费Markdown All in One 插件，写 README / 技术文档
Zettlr全平台开源免费偏学术写作，支持引用和论文结构
Notion全平台免费+付费数据库+页面强，团队协作；但不是本地 .md，可迁移性弱
推荐组合

写作 / 管理 / 项目三层搭配

写作输出
Typora（所见即所得，干净）
长期管理
Obsidian（双链 + 插件 + 图谱）
项目工程
VS Code + GitHub（README / 多文件）
目录结构
/skills/<skill-name>/ 下放 skill.md / prompt.md / run.py；/docs/ 放笔记与方法论
04

Obsidian 日记模板（实战精简版）

2026-04-07

先要了一套通用模板，又按自己的作息时间段（8:30~17:30）精简，去掉打分和心情。下面是最终那版。

模板正文

每日日记（中文星期版）

# {{date:YYYY-MM-DD}} ｜ 星期{{date:dddd}} --- ## 今日核心目标（Top 3） - [ ] - [ ] - [ ] --- ## 今日待办（To-Do） ### 高优先级 - [ ] - [ ] ### 中优先级 - [ ] - [ ] ### 低优先级 - [ ] - [ ] --- ## 时间记录 | 时间段 | 事项 | 完成 | |--------|------|------| | 08:30 - 09:30 | | | | 09:30 - 10:30 | | | | 10:30 - 12:00 | | | | 13:30 - 14:30 | | | | 14:30 - 15:30 | | | | 15:30 - 16:30 | | | | 16:30 - 17:30 | | | --- ## 今日工作记录（Log） - - - ## 关键产出 / 成果 - - ## 遇到的问题 - - ## 今日复盘 ### 做得好的 - ### 做得不好的 - ### 可优化点 - ## 明日计划 ### 明日三件事 - [ ] - [ ] - [ ] ### 未完成迁移 - [ ] #日记 #工作 #复盘
中文星期
Templater 插件设置里把 Moment.js locale 切成 zh-cn；或直接写「星期{{date:ddd}}」更稳。
配套插件
Templater（自动日期）、Tasks（跨日任务）、Calendar（点日期建日记）、Dataview（周/月报汇总）。
Dataview 周报示例
TABLE file.name, 今日评分 FROM #日记 WHERE file.day >= date(today) - dur(7 days) SORT file.day DESC
上手建议
刚开始只写「核心目标 + 待办 + 复盘」三块，别一次塞满，容易弃用。
05

编辑 Markdown 并导出长图 PNG

2026-09-01

最后一次（9 月 1 日）把需求收窄成「打开 .md → 实时渲染 → 导出一张高清长图分享」。这和 Typora 导 PDF 不是一回事，候选一下少了很多。

方案导出图片说明
MerMD（mermd.tech）高清 PNG / PDF / HTML首推。支持 GFM / 表格 / 代码高亮 / Mermaid / KaTeX，本地离线渲染，Smart Export 直接出图。
Obsidian + Export Img 插件PNG（含水印/倍率）排版质量最高；支持 Callout / Code / Math / Mermaid / Embed / Frontmatter / 自定义主题。代价是要接受 Obsidian 的知识库模式。
MarkText Android仅 PDF（PNG 未明确）最像 Typora，但导出长图能力不明。
Markor不支持纯编辑器，无导出图片。
用途：这种「Markdown → 长图」流程适合把行业研究、AI 资料、产品方案直接发到微信 / 朋友圈 / 小红书 / 飞书分享图。选 App 时重点看：中文字体、图片宽度、长图高度上限、代码/表格/公式渲染、自定义 CSS 主题、水印开关。

手机写、电脑排版：跨端同步组合

贯穿多次对话

这是反复出现的一条「骚操作」：手机端用 Markor 写，桌面端用 Typora 排版，中间用同步工具连起来。

角色选什么
手机写Markor（开源离线）或 Obsidian（知识库）
电脑排Typora（所见即所得）
同步Syncthing（P2P 免费）/ Git（版本管理）/ 坚果云 / WebDAV
底层数据真实的 .md 文件散落在文件夹里，不锁进任何 App 数据库
