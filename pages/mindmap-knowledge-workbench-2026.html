GitHub 上的 App 能不能装：先分清四类

2025-10-26

在选开源项目之前先问了个更底层的问题——GitHub 上挂着的「App」到底是什么、能不能装。答案按风险分四类。

类型示例能不能装风险
官方 GitHub Apps / ActionsDependabot、Pages、Copilot官方界面装低（官方审核）
第三方 Marketplace 集成Vercel、Netlify、CodeCovMarketplace 装中（需审权限）
仓库里的 .exe / .apk / 脚本「点这里下载安装包」不建议高（可能含恶意代码）
clone 源码自己 build开源项目自编译可行取决于代码可信度
装之前过一遍清单
  • 看作者是否可信机构 / 知名开发者；Star 数和更新频率。
  • 看权限请求：不要随便给写权限、私有库访问、secrets 读取。
  • 看是否在 Marketplace 上架（经过 GitHub 审核）。
  • 下载链接跳转到 GitHub 外部云盘 = 直接拉黑。
02

mindmap 库选型：第一梯队

2026-06-13

目标是做一个媲美 XMind / ProcessOn / 幕布的 Windows 桌面应用。结论是不要只找一个库，而是参考成熟项目 + 核心渲染库 + 图形引擎三层组合。

项目技术栈定位
BlinkMind（awehook/blink-mind-desktop）React + TS + Electron最推荐先研究。完整桌面应用，节点编辑 / 拖拽 / Undo / 多 Sheet / 导出图片 / 快捷键 / 主题 / 富文本 / Markdown。Document 与 UI 分离，以后接 AI 方便。
jsMind（hizzgdev/jsmind）Canvas/SVG，无框架经典库，Star ~3.8k，API 简洁稳定，很多国产项目参考过它。可直接当渲染引擎。
Mind Elixir（ssshooter/mind-elixir-core）纯 TS，几十 KBUI 现代，布局算法优秀；支持无限缩放 / Drag / Keyboard / Rich Text / SVG。代码质量比 jsMind 现代。
Open MindMap（XiangFaGitHub/open-mindmap）React + SVGAI Native，支持 Markdown 实时生成、Streaming。适合做 AI 自动生成导图。
Remind（luvsic3/remind）ReactUndo/Redo/Shortcut/Drag，UI 比 BlinkMind 简洁，适合读源码学习。
drichard/mindmapsHTML5老牌，支持离线，代码偏旧但架构可参考。
03

开源思维导图项目横评

2026-06-18

五天后又问了一次「GitHub 上开源的思维导图软件」，这次偏完整应用而非库。增加了几个重量级项目。

项目技术特点
SimpleMindMap（wanglin2/mind-map，~8k Star）Vue3 + TS + SVG/Canvas国内最完整。插件化、节点样式丰富、导出 PDF/PNG/SVG、Markdown、大纲模式、协同基础。支持 Fishbone / Timeline / Logic Chart / Org Chart / MindMap 五种结构。准备做产品最推荐直接 Fork。
Markmap（markmap/markmap）JSMarkdown 标题自动生成思维导图。# 一级 → ## 二级 → ### 三级 直接变树。很多知识库在用。
KityMinder（fex-team/kityminder）百度出品功能完整：富文本、大纲、Markdown、导图。
Freeplane / FreeMindJava老牌桌面软件，FreeMind 是鼻祖，Freeplane 插件多。
XMind 旧版开源（xmindltd/xmind）Java旧版开源可学文件格式 / UI / 导出 / 布局；新版已闭源。
tldraw / Excalidraw / Affine / AppFlowy—不是纯 mindmap，但无限画布 + 导图是未来趋势，适合参考架构。

YouMind：AI 第二大脑是什么

2026-04-17

在设计自研工作台之前，先调研了一下 YouMind 这种现成的「第二大脑 + AI」网站工具，拿来对标。

层YouMind 做什么
收集（输入）网页链接、PDF、YouTube 视频、笔记都往里丢
AI 理解（处理）自动总结、提重点、生成结构化笔记、多内容互相关联（5 篇行业报告 → 一张行业认知地图）
组织（结构）卡片式内容 + 关联图谱 + 项目/主题管理
输出（应用）基于自己的知识库写文章、做总结、出报告、生成观点
和普通 ChatGPT 的区别：数据来源是你自己的资料库（不是公共训练数据）、上下文是长期积累（不是临时对话）、有知识体系（不是无结构）、输出更贴合你的认知。一句话：YouMind = 带记忆的 AI + 你的私人知识库。缺点：上手有学习成本，必须持续喂数据才有价值，免费版有限制。

「知屿」知识工作台产品设计

2026-06-19

这是本页最重的一篇会话。把前面调研过的 Typora、MarkItDown（微软把 Office/PDF 转 Markdown）、KillerPDF、SimpleMindMap 四个项目揉成一个自研应用，定名「知屿」。

产品定位

Everything → Markdown → AI → MindMap → Export

不是 Typora，也不是思维导图，而是 Markdown + PDF + Office + AI + MindMap 五位一体。

参考项目
Typora（Markdown 编辑）★★★★★、MarkItDown（Office/PDF 转 MD）★★★★★、SimpleMindMap（导图）★★★★★、Obsidian（双链）★★★★、KillerPDF（PDF 处理）★★★★、XMind（导图交互）★★★、Logseq（大纲）★★★、Excalidraw（手绘）★★★。
整体布局
像 VSCode：左侧文件/知识库/AI/导图/PDF/插件侧栏；中间 Tabs + Markdown 编辑器；右侧永远有 AI Copilot；底部 Terminal。
首页 Dashboard
不直接开编辑器，而是「今天想做什么？」入口：新建 MD / 导入 PDF / 导入 Word / 导入 PPT / 导入 Excel / 新建 MindMap / AI 写文章 / AI 总结 PDF / AI 读论文，下面是最近项目与知识库。

建议的技术栈（两次会话合并）

2026-06-13 + 06-18
模块推荐方案
桌面壳Electron（首选，未来可迁 Tauri）
UIReact 19 + TypeScript + Tailwind
画布引擎ReactFlow（无限画布 / 节点 / Edge / MiniMap / Zoom / 右键菜单免费），再用 ELK.js 做 Tree Layout 把图编辑器变成思维导图

状态管理Zustand + Immer（Undo/Redo）
富文本Lexical 或 Slate
本地存储SQLite + IndexedDB
同步/协作Y.js + CRDT（预留）
AIOpenAI / Claude / Gemini；LLM → Markdown → AST → MindMap JSON → ReactFlow，一句话生成导图
插件系统Plugin API + Command Pattern + 事件总线（预留 MCP）
关键判断：不要直接基于 BlinkMind 二次开发，而是把它当参考；用 ReactFlow 当底层画布、ELK.js 自动布局，从第一天就按 AI Native 设计（JSON ↔ Markdown ↔ MindMap 双向转换），预留插件、命令系统和 CRDT 协作能力。
