Excel 函数分类总览

Excel 有数百个函数，全部罗列并不实用。原笔记把它们按用途归成十一个大类，并指出：掌握核心的 50-100 个常用函数即可解决 90% 以上的问题。下表照录分类与代表函数。

函数类别代表函数与用途
财务函数PMT 贷款支付额、FV 投资未来值、PV 现值、NPV 净现值、IRR 内部收益率、RATE 利率。
日期与时间NOW 当前日期时间、TODAY 当前日期、DATE 拼日期、DATEDIF 日期间差、YEAR/MONTH/DAY 取年月日、WORKDAY/NETWORKDAYS 工作日计算。

统计函数AVERAGE 平均、AVERAGEIF(S) 条件平均、COUNT 数数字、COUNTA 数非空、COUNTIF(S) 条件计数、MAX/MIN 极值、MEDIAN 中位数、MODE 众数、STDEV 样本标准差、RANK 排名。

现代函数（365 / 2021+）XLOOKUP 替换 VLOOKUP/HLOOKUP、FILTER 筛选、SORT 排序、UNIQUE 去重、SEQUENCE 生成序列、LET 定义变量、LAMBDA 自定义函数。

在 Excel 里查完整函数列表

入口
顶部【公式】选项卡 →【函数库】分组，按类别（财务、逻辑、文本等）分组排列主要函数。
全部函数
点 fx【插入函数】按钮，「或选择类别」下拉选「全部」，列表按字母显示所有可用函数，选中后下方显示功能与语法。
官方文档
微软支持站搜索「Excel 函数（按类别列出） - Microsoft 支持」。

学习路径建议

优先掌握
SUM、AVERAGE、IF、VLOOKUP/XLOOKUP、INDEX/MATCH、COUNTIF、SUMIF、TEXT、DATE。
遇到问题
再用【插入函数】对话框按类查找，或直接搜「Excel 如何按条件求和」学新函数。

03

一整列除以固定单元格：绝对引用

00761

高频问题：表格里 I 列的很多数据要除以 M9，用什么公式？答案是 绝对引用——行和列都加 $ 锁定，下拉填充时 M9 才不会跟着漂移。

00761 · 2026-03-18

操作四步走

步骤做法
1. 写公式在 J1 输入 =I1/$M$9。$M$9 表示无论往下拉多少行，除数始终是 M9。
2. 双击填充柄选中 J1，鼠标移到单元格右下角小方块（填充柄），变黑十字时双击左键，自动填充到与 I 列同行的高度；数据量小也可按住往下拖。
3. 校验J2 应为 =I2/$M$9，J3 应为 =I3/$M$9。
4. 覆盖回 I 列（可选）先在新列算出结果 → 复制整列新结果 → 右键 I 列 → 选择性粘贴 → 数值。

红线 · 除零错误

M9 为空或为 0 时公式会报 #DIV/0!

务必先确认 M9 里已输入正确的除数，否则整列结果都是 #DIV/0!。

Excel 转 JSON 的三套方案

00333

原笔记担心在线工具可用性随时变化，于是给出「在线工具 + 本地代码 + 本地软件」三条路，并附一份选型对比。敏感数据一律先脱敏。

方案一 · 在线工具

Table Convert Online（处理不敏感的临时数据）

网址
https://tableconvert.com/excel-to-json
优点
功能专一、支持复杂表格结构；可直接粘贴 Excel 内容或上传 .xlsx/.csv；右侧 Options 可调生成格式（如第一行作键名），自动生成 JSON 后复制即用。
安全提醒：文件含敏感或机密数据时最安全的做法是先脱敏再上传。
方案二 · 本地代码（最安全灵活）

另存 CSV，用浏览器控制台一段 JS 转换

把 Excel 另存为 CSV，再在浏览器开发者工具控制台运行下面这段 csvToJson：

function csvToJson(csvString) {
    const lines = csvString.split('\n');
    const result = [];
    const headers = lines[0].split(',');
    for (let i = 1; i < lines.length; i++) {
        const obj = {};
        const currentline = lines[i].split(',');
        for (let j = 0; j < headers.length; j++) {
            obj[headers[j].trim()] = currentline[j] ? currentline[j].trim() : '';
        }
        result.push(obj);
    }
    return result;
}

以示例数据 id,name,age / 1,张三,30 / 2,李四,25 运行，输出为：

[{"id":"1","name":"张三","age":"30"}, {"id":"2","name":"李四","age":"25"}]
// 用 JSON.stringify(jsonData, null, 2) 可格式化输出
方案三 · 本地软件

VS Code + 转换插件

做法
装免费的 VS Code，在扩展商店搜索安装 Excel Viewer 或 CSV to JSON 等插件，用 VS Code 打开 CSV 后由插件侧边栏预览或一键转 JSON。
方案优点缺点适用场景
在线工具方便快捷，无需安装有数据安全风险，依赖网络不敏感的、一次性或临时数据
本地代码最安全、最灵活、免费需要基本代码知识任何数据，尤其是敏感数据
本地软件功能丰富，安全性高需要安装软件需要频繁做格式转换
同篇延伸：绑定域名后的查询地址
  • 库绑定域名 gervas.wang、且在 gervasw.github.io 根目录建了 tz 文件夹与 index 等文件后，主访问地址为 https://gervas.wang/tz/（或 /tz/index.html）；子文件如 /tz/css/style.css 按路径直接拼。
  • 排查：GitHub Pages 的 Source 设为 main 分支、Custom domain 已配置、CNAME 文件在仓库根目录；推送与构建生效通常有几分钟延迟。
