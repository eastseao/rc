我想设计一套SKILL # SKILL: WeChatHotArticleExtractor

技能描述

提取发表时间在最近一周以内、阅读量达到10万及以上的微信公众号爆款文章，并输出包含标题、公众号名称、发表时间、阅读量及文章链接的列表。

输入要求

  • 无强制输入，但建议用户提供可用的微信公众号数据获取渠道（如：搜狗微信搜索、新榜API、清博大数据接口等）的访问权限或API密钥。
  • 若用户未提供任何渠道，本技能将基于公开可访问的模拟搜索步骤（需用户配合提供 Cookie 或使用代理）进行指导。

输出格式

以 Markdown 表格形式输出，包含以下列：

| 序号 | 文章标题 | 公众号名称 | 发表时间 | 阅读量 | 文章链接 |

|------|----------|------------|----------|--------|-----------|

并按发表时间倒序排列。

执行步骤

第一步：确定时间范围

  • 计算当前日期的前7天作为截止时间（例如今天是 2026-04-20，则范围为 2026-04-13 00:00:00 至 2026-04-20 23:59:59）。

第二步：获取候选文章数据

根据用户可用的数据源，选择以下方式之一：

方式A：使用搜狗微信搜索（模拟网页请求）
  1. 访问 https://weixin.sogou.com/
  1. 在搜索框输入任意关键词（如“热点”、“爆款”），或直接按“时间排序”浏览。
  1. 对每一页结果，提取文章标题、摘要、公众号、发布时间（需解析相对时间如“1天前”转换为绝对时间）。
  1. 注意：搜狗搜索结果不直接显示阅读量。需要进入每篇文章的详情页（通过点击链接跳转到微信公众号文章原始链接），使用模拟工具（如 requests + beautifulsoup）解析文章页面中的阅读量（通常在文末或通过脚本加载）。由于微信限制，可能需要设置合适的 User-Agent 和 Cookie。
方式B：使用第三方数据服务（推荐）
  • 新榜（https://www.newrank.cn/）：通过其公开API或数据平台，筛选“微信”->“文章”->“时间范围”=“近7天”->“阅读数”>=100000，导出列表及链接。
  • 清博（http://www.gsdata.cn/）：类似操作。
  • 若用户提供了API密钥，则直接调用相应接口。
方式C：假设已有数据库或RSS订阅源
  • 如果用户维护了微信公众号文章数据库，则执行 SQL 查询：SELECT * FROM articles WHERE publish_time >= DATE_SUB(NOW(), INTERVAL 7 DAY) AND read_count >= 100000 ORDER BY publish_time DESC;

第三步：过滤与去重

  • 只保留 publish_time 在最近7天内的文章。
  • 去除重复链接或相同标题的文章（保留最新的一条）。

第四步：整理输出

  • 将结果按发表时间从近到远排序。
  • 生成 Markdown 表格。
  • 若结果为空，输出：“未找到最近一周内阅读量10万+的文章。”

注意事项

  1. 反爬限制：直接抓取微信公众号文章阅读量非常困难，因为微信页面需要登录态且阅读量常通过异步加载。建议优先使用正规第三方数据平台（新榜、清博）获取数据。
  1. 法律与合规：请确保使用合法渠道，遵守微信和第三方平台的 robots.txt 及服务条款。
  1. 时效性：每周运行一次即可，结果可能因平台数据更新延迟有1-2小时误差。

# ⚙️ 八、run.py（执行引擎）

👉 这是关键，我帮你写成“可扩展 + 可接API + 可Mock”的版本

import datetime

def run(params):
    days = params.get("days", 7)
    min_read = params.get("min_read", 100000)

    # 1. 时间范围
    now = datetime.datetime.now()
    start_time = now - datetime.timedelta(days=days)

    # 2. 模拟数据（可替换为API）
    articles = [
        {
            "title": "AI行业大爆发",
            "account": "科技前沿",
            "time": now - datetime.timedelta(days=1),
            "read": 120000,
            "link": "https://mp.weixin.qq.com/s/xxx"
        },
        {
            "title": "城市经济趋势",
            "account": "财经观察",
            "time": now - datetime.timedelta(days=3),
            "read": 95000,
            "link": "https://mp.weixin.qq.com/s/yyy"
        }
    ]

    # 3. 过滤
    filtered = []
    seen = set()

    for a in articles:
        if a["time"] >= start_time and a["read"] >= min_read:
            key = a["title"]
            if key not in seen:
                seen.add(key)
                filtered.append(a)

    # 4. 排序
    filtered.sort(key=lambda x: x["time"], reverse=True)

    # 5. 输出
    md = "| 序号 | 标题 | 公众号 | 发布时间 | 阅读量 | 链接 |\n"
    md += "|------|------|----------|----------|--------|------|\n"

    for i, a in enumerate(filtered, 1):
        md += f"| {i} | {a['title']} | {a['account']} | {a['time'].strftime('%Y-%m-%d')} | {a['read']} | {a['link']} |\n"

    return md
