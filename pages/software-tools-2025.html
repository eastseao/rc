GitHub App 安全性分析

2025-10-26 · auto · 2 条消息

询问"GitHub 里的 App"是否安全，得到按四类区分的风险分级判断。

  • 官方 GitHub 扩展（如 Copilot）：低风险，微软背书。
  • Marketplace 第三方 App：中风险，需审查授权范围和隐私政策。
  • 仓库里的 exe/apk 可执行文件：高风险，可能含恶意代码，勿随意运行。
  • 自编译开源软件：看仓库 star 数、维护活跃度、issue 区有无安全投诉。
  • 核心判断：看签名、看权限范围、看来源可信度。
