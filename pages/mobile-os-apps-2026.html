华为鸿蒙 2.0 装谷歌 GMS 三件套

2023-04-06

Google 对华为断供后，鸿蒙 2.0 机型要出境用谷歌服务只能手动装 GMS。当时搜出来的教程大同小异，合并成一套步骤。

通用步骤

HarmonyOS 2.0 装 GMS

前提
系统升级到鸿蒙 2.0 最新版；Mate40 / P50 / P40 / P30 / Mate30 / 荣耀 V30 等实测机型。原生鸿蒙（Next）无法安装。
退出纯净模式
设置 → 系统和更新 → 纯净模式 → 退出。
开开发者模式
设置 → 关于手机 → 连点版本号 7 次。
先卸旧套件
设置 → 应用和服务 → 应用管理，搜 Google，卸载已有 Google Play 服务框架/服务/商店。
装三件套
文件管理里装 2-GMS 文件；顺序：Google Play 服务框架 → Google Play 服务 → Google 账户管理程序 → Google Play 商店。
清数据重启
强行停止 Play 商店 / 服务框架 / 账户管理并删除数据 → 重启。
开商店
挂代理打开 Play 商店，能正常显示即成功；可能仍报「未获得 Play 保护机制认证」，需单独解决。

Windows 11 安卓子系统装 Play Store

2023-04-11

Win11 自带 WSA（Windows Subsystem for Android），但官方镜像不带 Google Play。当时的教程需要走 Linux 子系统 + OpenGApps 路线。

环节操作
装 WSA微软商店下载 Windows 安卓子系统。
装 WSL启用 Linux 子系统，微软商店下 Ubuntu；终端跑 sudo apt update && sudo apt install unzip lzip。
做 GApps 包OpenGApps 网站选 x86_64 / Android 11 / Pico 包，下载。
解包 msixbundle下 7-Zip，解压 WSA 的 .msixbundle，找与硬件架构兼容的版本。
进 Play 商店开始菜单搜 Play Store 启动，登录 Google 账号，即可装安卓 App（如 Candy Crush）。

普通笔记本装安卓 x86：三大流派

2026-03-17

把安卓塞进 x86 PC 是「跨物种移植」，驱动、架构、UI 逻辑三重冲突。系统分三类，按折腾程度排。

流派代表特点
原教旨派Android-x862009 年起的开源项目，最接近纯安卓；兼容性靠运气（驱动=玄学）；适合折腾党 / 开发测试。
桌面强化派Bliss OS最推荐。在 Android-x86 上做 PC 化改造：有任务栏、窗口模式像 Windows；桌面/平板双模式；跟到 Android 11/12/13。缺点：显卡/WiFi 仍有驱动坑。
云/兼容层派Google Play Games on PC、Waydroid不是真装系统，是在 Windows/Linux 里跑安卓环境；省心但受限。

Google Play 里怎么找有意思的 App

2026-04-06

多数人只会搜名字下载，真正的宝藏藏在官方榜单和分类深处。

方法怎么做
官方榜单搜「Best Apps」「年度最佳应用」；重点看 Hidden Gems（隐藏宝藏）、Best for Productivity、Most Innovative。
分类深挖商店 → Categories，重点看 Tools / Productivity / Lifestyle / Personalization。别看热门，往下翻；找评分 4.5+、下载量 10 万~100 万的冷门精品。
关键词搜索直接搜 minimal / launcher / AI / automation / habit / note / widget，会挖出小众神器。
创意类代表Forest（种树专注）、Locket Widget（锁屏社交）、Nothing Widget（极简风）。

iPad 配 163 邮箱报「无法验证 mail.163.com 身份」

2026-04-06

本质是 SSL 证书验证失败，iPadOS 配 163 邮箱很常见。按顺序排查。

163 邮箱正确配置

IMAP / SMTP 参数

收件服务器
imap.163.com，端口 993，SSL 加密
发件服务器
smtp.163.com，端口 465 或 994，SSL 加密
用户名
完整邮箱地址
密码
授权码，不是登录密码。登录 163 网页版 → 设置 → POP3/SMTP/IMAP → 开启服务 → 获取授权码。
检查时间
设置 → 通用 → 日期与时间 → 自动设置。时间错会直接导致证书验证失败。
网络
公司 WiFi 可能做证书拦截，换蜂窝或家庭 WiFi 试。
