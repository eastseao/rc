明白了，你希望文章底部只显示标签（去掉分类），并且标签和分类如果同时显示的话要在同一行、字号一致。按照你的要求，我帮你修改一下模板代码： 

---
layout: base
---

{% include header.html type="post" %}

<main class="{% if page.full-width %} container-fluid {% else %} container-md {% endif %}">
  <div class="row">
    <div class="{% if page.full-width %} col {% else %} col-xl-8 offset-xl-2 col-lg-10 offset-lg-1 {% endif %}">

      <!-- 文章标题和元数据部分 -->
      <div class="post-header mb-4">
        <h1 class="post-title">{{ page.title }}</h1>
        <div class="post-meta text-muted">
          <span class="post-author">作者: {{ page.author | default: "未知" }}</span>
          <span class="post-date">发布时间: {{ page.date | date: "%Y年%-m月%-d日" }}</span>
          {% if page.last-updated %}
            <span class="post-updated">更新时间: {{ page.last-updated | date: "%Y年%-m月%-d日" }}</span>
          {% endif %}
        </div>
      </div>

      <!-- GitHub 按钮部分 -->
      {% if page.gh-repo %}
        {% assign gh_split =  page.gh-repo | split:'/'  %}
        {% assign gh_user =  gh_split[0]  %}
        {% assign gh_repo =  gh_split[1]  %}

        <div id="header-gh-btns">
          {% if page.gh-badge.size > 0 %}
            {% for badge in page.gh-badge %}
              {% case badge %}
                {% when 'star'%}
                  <iframe src="https://ghbtns.com/github-btn.html?user={{ gh_user }}&repo={{ gh_repo }}&type=star&count=true" frameborder="0" scrolling="0" width="120px" height="20px"></iframe>
                {% when 'watch'%}
                  <iframe src="https://ghbtns.com/github-btn.html?user={{ gh_user }}&repo={{ gh_repo }}&type=watch&v=2&count=true" frameborder="0" scrolling="0" width="120px" height="20px"></iframe>
                {% when 'fork'%}
                  <iframe src="https://ghbtns.com/github-btn.html?user={{ gh_user }}&repo={{ gh_repo }}&type=fork&count=true" frameborder="0" scrolling="0" width="120px" height="20px"></iframe>
                {% when 'follow'%}
                  <iframe src="https://ghbtns.com/github-btn.html?user={{ gh_user }}&type=follow&count=true" frameborder="0" scrolling="0" width="220px" height="20px"></iframe>
              {% endcase %}
            {% endfor %}
          {% endif %}
        </div>
      {% endif %}

      <!-- 文章前内容部分 -->
      {% if page.before-content %}
        <div class="before-content">
          {% for file in page.before-content %}
            {% include {{ file }} %}
          {% endfor %}
        </div>
      {% endif %}

      <!-- 博文正文内容 -->
      <div class="blog-post">
        {{ content }}
      </div>

      <!-- 文章底部只显示标签，字号统一 -->
      {% if page.tags.size > 0 %}
        <div class="blog-tags d-flex flex-wrap align-items-center" style="font-size: 0.9rem; margin-top: 1rem;">
          <span class="me-2">标签：</span>
          {% for tag in page.tags %}
            <a href="{{ '/tags' | relative_url }}#{{- tag -}}" class="badge bg-light text-dark border me-1 mb-1">{{- tag -}}</a>
          {% endfor %}
        </div>
      {% endif %}

      <!-- 文章后内容部分 -->
      {% if page.after-content %}
        <div class="after-content">
          {% for file in page.after-content %}
            {% include {{ file }} %}
          {% endfor %}
        </div>
      {% endif %}

      <!-- 如果有社交分享按钮，显示分享部分 -->
      {% if page.social-share %}
        {% include social-share.html %}
      {% endif %}

      <!-- 分页按钮 -->
      <ul class="pagination blog-pager justify-content-between">
        {% if page.previous.url %}
        <li class="page-item previous">
          <a class="page-link" href="{{ page.previous.url | relative_url }}" data-toggle="tooltip" data-placement="top" title="{{page.previous.title | strip_html | xml_escape}}">
            <i class="fas fa-arrow-left" alt="上一篇"></i>
            <span class="d-none d-sm-inline-block">上一篇</span>
          </a>
        </li>
        {% endif %}
        
        {% if page.next.url %}
        <li class="page-item next">
          <a class="page-link" href="{{ page.next.url | relative_url }}" data-toggle="tooltip" data-placement="top" title="{{page.next.title | strip_html | xml_escape}}">
            <span class="d-none d-sm-inline-block">下一篇</span>
            <i class="fas fa-arrow-right" alt="下一篇"></i>
          </a>
        </li>
        {% endif %}
      </ul>

      <!-- 评论部分 -->
      {% include comments.html %}
    </div>
  </div>
</main>

✅ 主要修改点：

  1. 移除了原本的 categories 部分，只保留标签。
  2. 标签统一在一行（使用 d-flex flex-wrap align-items-center），保证字体大小统一。
  3. 标签与“标签：”文字之间有间距，多个标签之间也有小间距（me-1 mb-1）。

如果你希望标签在小屏幕上自动换行显示，这个写法也能自适应。
