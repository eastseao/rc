01

Markdown 语法速查

2025-10-09

作者日常用 Markdown 写推文、发 Hugo/Jekyll 博客，先要一份完整语法表。这次对话把常用语法按类别列全，可直接当备忘录。

语法写法要点
标题# 到 ###### 六级，井号后空一格。
文本样式*斜体*、**加粗**、~~删除线~~；行尾两个空格强制换行。
引用 / 列表> 嵌套引用；无序用 - * +，有序用数字加句号。
代码行内 `code`，三反引号包代码块可注明语言（python/js…）。
链接图片[文字](url)、![替代](图片url "说明")；尖括号裸链接自动识别。
表格竖线分隔，第二行用 |:|:--:|--:| 控制左/中/右对齐。
进阶分隔线 ---、任务列表 - [x]、脚注 [^1]、转义反斜杠、内嵌 HTML（<details> 折叠等，部分平台支持）。
为什么用 Markdown：写作体验简洁、跨平台兼容（GitHub / Hugo / Jekyll）、可嵌 HTML 做轻量图文混排。作者后续直接把这份做成「Markdown 语法备忘录.md」放进博客。
02

把长文排成「卡片式」

2025-10-10

作者丢进一篇《采购为什么必须具备战略眼光》的长文，要求排成网页风格卡片、带折叠块、图标和间距。这次反复调整了三版：先带 CSS 样式，再改纯 Markdown，最后不要折叠。

带 CSS 折叠卡片

用 <details><summary> 做折叠块，配一段 <style>：卡片浅底、圆角、阴影，summary 左侧 4px 主题色条，::marker 换 emoji 图标。适合真·网页观感。

纯 Markdown 折叠

去掉 CSS，仍用 <details><summary> 做折叠，正文段落用 Markdown 写。兼容性更好，Hugo/Jekyll 都认。

不折叠卡片版

每个主题用 ## emoji 小标题 切开，段间插 --- 模拟卡片间距，全文展开不折叠，阅读最清爽。

排版取舍
  • 长文适合「分主题 + 小标题 + 分隔线」，让手机上一屏一个意思。
  • 图标用 emoji 直接放在标题前，不用图标字体，零外部依赖。
  • 三版的核心都是：把一大段散文拆成「引言 / 省钱 / 供应链 / 跨部门 / 新机会 / 趋势 / 总结」这种可扫读的模块。

案例：21 个顶级思维的排版

2025-11-13

另一次是把「21 个顶级思维」（蓝斯登原则、托利得定理、卢维斯定理……这类管理学定律）用 Markdown 排版并放进代码框展示。

这类「名词解释 + 一句大白话注解」的素材，排版要点是：每条思维用三级标题立住，定理原文和白话解读分成两行，条与条之间用分隔线断开，方便读者一次记一个。和上一页的卡片思路一致——把密集信息切成可扫读的小块，而不是堆成一面文字墙。
