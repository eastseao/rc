# Ruby 日期格式，用于显示文章日期 date_format: "%B %-d, %Y"

这段是config里的，可以改成中文吗

可以改成中文，但要注意两件事：

  1. Jekyll 默认使用 Ruby 的 strftime 格式化日期，你写的 %B %-d, %Y 代表：

- %B → 月份全名（January, February…） - %-d → 去掉前导零的日期（1, 2, …） - %Y → 四位年份（2025）

  1. 中文月份 Ruby 默认不支持直接用 %B 输出中文，需要设置本地化（locale）。你可以在 Jekyll 里这样做：

方法一：直接在 config 里改格式输出数字月份 

date_format: "%Y年%-m月%-d日"
  • %-m → 月份数字（1~12）
  • 输出示例：2025年11月8日

方法二：如果想要中文月份名称（比如“十一月”） 需要在 _plugins 或模板里做本地化，例如在 Liquid 模板里用一个小函数： 

{% assign months = "一月,二月,三月,四月,五月,六月,七月,八月,九月,十月,十一月,十二月" | split: "," %}
{{ months[page.date | date: "%-m" | minus: 1] }} {{ page.date | date: "%-d, %Y" }}
  • 输出示例：十一月 8, 2025

⚠️ 小结：如果只是简单显示中文日期，推荐方法一，简单可靠，不依赖插件。

头像全屏显示了

明白了，你说的“头像全屏显示”通常是因为 CSS 没有限制头像尺寸或者容器的宽高。根据你用的是 Beautiful Jekyll，头像通常在 _config.yml 中配置，或者在 index.html / home.html 里用 <img> 标签显示。

解决方法是 限制头像的最大宽高，并保持比例：

方法一：在 CSS 中限制

在你的自定义 CSS 文件或者 <style> 里加：

.avatar-img {
  width: 120px;      /* 控制宽度 */
  height: 120px;     /* 控制高度 */
  object-fit: cover; /* 保持比例并裁剪 */
  border-radius: 50%; /* 圆形头像 */
}
注意：类名要和你博客里 <img> 的类名一致，比如 avatar-img 或 avatar。

方法二：在 HTML 中直接设置

<img src="{{ site.avatar }}" alt="头像" style="width:120px; height:120px; object-fit:cover; border-radius:50%;">

左上角

明白了，你想要头像固定在首页左上角的小图，不占满屏幕。可以通过 CSS 控制布局和大小：

在你的 自定义 CSS 文件（或者 <style> 标签）中添加：

/* 左上角固定头像 */
.site-avatar {
  width: 80px;             /* 控制头像宽度 */
  height: 80px;            /* 控制头像高度 */
  object-fit: cover;       /* 保持比例裁剪 */
  border-radius: 50%;      /* 圆形 */
  position: fixed;         /* 固定在页面 */
  top: 20px;               /* 顶部距离 */
  left: 20px;              /* 左侧距离 */
  z-index: 1000;           /* 确保在最前面 */
  border: 2px solid #fff;  /* 可选：加白色边框 */
  box-shadow: 0 2px 6px rgba(0,0,0,0.3); /* 可选：阴影 */
}

然后在 home.html 或 _includes/header.html 中，头像 <img> 改为：

<img src="{{ site.avatar }}" alt="头像" class="site-avatar">

✅ 这样头像就会固定在页面左上角，小尺寸显示，不会全屏，同时滚动页面也会一直可见。
