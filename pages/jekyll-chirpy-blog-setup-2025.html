02

_config.yml 关键配置

remote theme 写法

最早用 theme: chirpy 网页端无法 bundle install，于是改成 remote theme 交给 GitHub Pages 构建。〔2025-10-06〕

title: 海上升明月
url: "https://seamoonappear.github.io"
baseurl: ""
lang: zh-CN
timezone: Asia/Shanghai

remote_theme: chirpythemes/chirpy@v5.4.0   # tag 必须真实存在
plugins:
  - jekyll-feed
  - jekyll-sitemap
  - jekyll-seo-tag

markdown: kramdown
kramdown:
  input: GFM
  syntax_highlighter: rouge

gitalk:
  client_id: "xxx"
  client_secret: "xxx"
  repo: "seamoonappear.github.io"
  owner: "seamoonappear"
  admin: ["seamoonappear"]

busuanzi: true

踩坑 · remote theme 404

日志 Error: 404 - Not Found - Loading URL: .../chirpy/zip/v6.0.0 —— 写了不存在的 tag。解决：去 chirpythemes/chirpy 的 Releases 页核对真实版本号（当时用 v5.4.0），不要凭记忆写 v6.0.0。临时可先 remote_theme: jekyll-theme-primer 保底。

03

部署报错排查

git 128 / Actions

另一类报错是 The process '/usr/bin/git' failed with exit code 128。〔2025-10-06〕

  • actions/checkout 要 fetch-depth: 0，浅克隆会导致拉 remote theme 失败。
  • 需要 push 产物时配 GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}。
  • 全程网页端操作最稳的做法其实是：不用自定义 Actions，直接用 GitHub Pages 自带构建 + remote theme，网页端提交文件即触发，绕开所有 git 操作。

后续 Build and Deploy Jekyll site 在改 about.md 时又报 1 error 失败，本质仍是分支/主题版本与 Pages Source（Settings → Pages → main/root）没对上。〔2025-11-06〕

04

切换 chirpy-starter 与 Chirpy 7.4.1 重建

2025-10-25 / 11-08

最终路线转为官方模板：cotes2020/chirpy-starter → 绿色 Use this template → 命名 seamoonappear.github.io → Public → Create。模板里 Gemfile 为 gem "jekyll-theme-chirpy", "~> 7.4"，Pages Source 选 main 分支。〔2025-10-25〕

2025-11-08 决定「从 Chirpy 7.4.1 从零开始」：因只能网页端操作，方案是下载 chirpy 的 ZIP 后 Add file → Upload files 整包上传，再网页端改 _config.yml 的 title/description/author/avatar，Settings → Pages → Source → main，等待构建。〔2025-11-08〕

网页端建仓步骤

  • New repository → seamoonappear.github.io → Public
  • Use this template（chirpy-starter）或上传 ZIP
  • 网页端 Edit _config.yml
  • Settings → Pages → Source → main / root
  • 等几分钟访问 https://seamoonappear.github.io

网页端可用主题参考

只网页端、不本地操作时，适合的主题要求是「GitHub Pages 原生支持或 remote_theme 可拉取」。当时对比了 Chirpy、Beautiful Jekyll 等，最终 Chirpy 走 starter 模板、Beautiful Jekyll 走 fork，两条线并行。〔2025-11-08〕
