Beautiful Jekyll汉化字体导航栏
背景：fork 了 Beautiful Jekyll 到 seamoonappear.github.io，目标是汉化 config、换 Chirpy 字体、改日期为中文、修页脚、改 navbar 下拉。共 17 条会话。
01

fork 主题与汉化 config

2025-11-08

把 Beautiful Jekyll fork 进自己的库后，第一件事是把 _config.yml 里 Welcome to Beautiful Jekyll 那段英文逐项汉化：〔2025-11-08〕

  • name / description / avatar / favicon 等站点信息翻成中文。
  • navbar-links 改成 - [首页, /] / - [回顾, /archives/] / - [更多, "#", about]。
  • 注释也一并中文，方便后续维护。
02

日期格式改中文

config 里的 Ruby 格式

config 里默认 date_format: "%B %-d, %Y"（英文 11 月 8 日风格）。改成中文：〔2025-11-08〕

# _config.yml
date_format: "%Y年%-m月%-d日"      # 2025年11月8日

模板里再兜底（Beautiful Jekyll 的 post/layout 片段）：

{% assign date_format = site.date_format | default: "%Y年%-m月%-d日" %}
{% if page.last_modified_at %}
  最后更新：{{ page.last_modified_at | date: date_format }}
{% endif %}

文章页想显示「更新时间」，前提是文章 Front Matter 写了 last_modified_at:，否则模板拿不到值。〔2025-11-09〕

03

字体与字号改 Chirpy 风格

beautifuljekyll.css

Beautiful Jekyll 想采用 Chirpy 的默认字体和大小。全局样式集中在 assets/css/beautifuljekyll.css（layout: null 那个文件，开头 @import "pygment_highlights.css"，用 :root CSS 变量）。〔2025-11-08 / 11-09〕

想改的东西改哪个文件 / 位置
全站字体族beautifuljekyll.css 的 :root 或 body font-family
所有页面文字大小同一文件的 base font-size、--text-color 附近变量
首页文章标题大小首页 post-list / .post-preview 标题选择器
缩小整体字号调 body{font-size} 或根变量，不要逐个元素写死
取消标题加粗对应 h1/h2 选择器 font-weight:400

汉化整套 CSS 时，把 :root 里注释、中文文案与字号变量一起改，并保持 --page-col / --text-col 等原有变量引用不断。〔2025-11-09〕

04

页脚居中 / navbar 下拉

base.html & footer.html

改了 base.html、footer.html 后部分页面页脚仍居左：原因是个别页面没走统一 footer 片段，或容器有 text-left。统一在 footer 容器上加居中规则。〔2025-11-10〕

导航栏把「回顾」做成下拉（navbar-links 配置）：

# _config.yml
navbar-links:
  - 首页: /
  - 回顾: /archives/
  - 标签: /pages/tags/
  - 更多:
      - 关于: /pages/about/
      - 归档: /archives/

layouts/pages.html 的作用：它是 layout: page 的列表页模板，遍历 paginator.posts | default: site.posts，渲染文章卡片、缩略图、meta。〔2025-11-10〕 layouts/page.html 则是单页容器（include header + container-md 主栏）。〔2025-11-13〕
