番茄小说盈利模式：免费阅读 + 广告分成

00904 · 2026-04-12

收入主要来自读者阅读 / 听书时观看广告产生的广告费，叠加多种奖励与版权开发。签约是大门：后台累计发布 2 万字且不少于 30 章，系统开放签约入口。

盈利方式核心逻辑 / 门槛特点与适合人群
广告分成核心收入；需签约，作者 55% : 平台 45%；与有效阅读、完读率强相关。所有签约作者；收入天花板高，新手基础保障。
全勤奖2025 起须同时：日更 4000/6000 字、月更 ≥10 万字、当月听读收益 ≥500 元。日更 4000 约奖 600 元、6000 约奖 800 元；稳定更新型。
读者打赏无需签约，作者拿打赏 70%（扣渠道费）。所有作者；占比小但精神激励强。
版权开发短剧 / 有声 / 影视 IP 改编；保底数万到数百万；平台有短剧专项计划。有爆款潜力者；近期重点扶持、爆发性强。
扶持计划长篇「乘风」「揽星」、短篇「灵思」、头部「皓月」等。符合方向者；新人起势 / 老人超车。
其他福利完本超 100 万字可领完结奖励；大神可签千字 30-3000 元保底 / 买断。完本奖励适合长篇；保底买断适合成熟大神。

收入数据参考（截至 2024-10）

  • 累计超 50 万作者获得收入。
  • 近一年 9374 人年收入超 3 万，3228 人超 10 万。
  • 普通作者月入三四千元；头部少数大神可达百万。
  • 2025 上半年版权分账超 1 亿元，同比增长 800%。

新人四条建议

  1. 盯完读率而非堆字数。
  2. 平衡更新频率与作品质量。
  3. 研究乘风计划等扶持方向主动靠拢。
  4. 积累不同平台经验，找最适合自己的方向。

01023

章节顺序搞反了怎么调

手机端
番茄作家助手 App → 作品页「章节」→ 长按第一章条目拖到第二章位置（右侧三横线即拖拽手柄），松开自动保存。
电脑端
登录「番茄小说作家平台」网页后台 → 作品管理 → 章节管理 → 直接拖拽排序。
救急方案
删错两章、按正确顺序重发（会清阅读 / 评论数据）；或「我的 → 帮助与反馈」联系人工客服，提供书名与问题描述。
注意
只在作家助手 App / 网页后台操作，不在读者端「番茄免费小说」；操作前确认章节已审核通过；改内容别忘改「第一章 / 第二章」标题。

把多个 MD 按章节合并成 EPUB

01195 · 2026-05-23

按章节顺序把多个 Markdown 合并成 EPUB，最直接可靠的是 Pandoc + 文件清单 title.txt，跨 macOS / Windows / Linux。

步骤操作
1 安装macOS 用 brew install pandoc（Windows / Linux 思路相同）。
2 封面（可选）做一个 cover.html 或 cover.jpg 作封面。
3 排序文件名用 01-、02- 前缀保证稳定排序；Pandoc 不支持按文件内标题排序，需先 Python 提取 H1 生成清单。
4 清单建 title.txt，按最终顺序一行一个章节文件路径。
5 命令pandoc -o 输出.epub title.txt --toc --toc-depth=2 --epub-cover-image=cover.jpg
方案优点缺点
Pandoc（推荐）最专业灵活、跨平台、开源免费、功能强需一点命令行基础
Typora简单直观、所见即所得15 天试用后收费、手动复制易出错
Calibre电子书管理强，可作 Pandoc 引擎不能直接合并 MD，EpubMerge 只能合并已有 EPUB

结论（照录）：追求灵活专业首选 Pandoc；只想快速完成用 Typora 复制粘贴；Calibre 更适合管理已有 EPUB 而非制作 MD。
