02

微信「无法确认网页安全性」的成因

00194

在微信里打开 http://gervas.wang 出现「无法确认该网页的安全性，请谨慎访问。」——这是微信严格的网址安全检测触发的，笔记列了五个成因。

00194 · 2025-10-09

五个主要原因

原因说明
未用 HTTPS（最可能）网站是 http://；微信倾向信任 HTTPS，对纯 HTTP、新域名默认判「不安全」。
域名信誉不足.wang 是较新顶级域，不如 .com/.cn/.net 常见，安全库还没建立信任数据。
未备案 / 未被收录服务器在国内必须 ICP 备案；微信爬虫还没抓取分析你的内容。
内容触发规则敏感话题、大量可疑外链、或结构像钓鱼站。
被用户举报曾被访问者通过投诉入口举报，网址进待审核列表。
03

把网站变成 https://gervas.wang

00194

GitHub Pages + 腾讯云买域名，要让它走 HTTPS 自定义域名，笔记给了四步流程。

00194 · 2025-10-09

四步走

步骤操作
① GitHub 设域名仓库 Settings → Pages，Custom domain 填 gervas.wang，勾选 Enforce HTTPS。
② 腾讯云 DNS解析加两条 CNAME：www 与 @ 都指向 你的用户名.github.io（TTL 600，不带 http:// 或尾斜杠）。
③ 建 CNAME 文件仓库根目录建无扩展名文件 CNAME，内容一行 gervas.wang。
④ 等生效DNS 通常 10 分钟~2 小时、最多 24 小时；GitHub 验证与签发证书可能再等几小时。
验证与常见问题
  • 验证：nslookup gervas.wang 或 dnschecker.org；回 Settings→Pages 确认域名与 Enforce HTTPS 绿勾。
  • HTTPS 选项不可用：DNS 未传播完或 GitHub 未检测到，等 2-24 小时；可先取消自定义域名、等几分钟再重设。
  • 访问 GitHub 404：检查 CNAME 文件内容正确、Pages 源分支正确。
04

仍报警告：申诉与加速

00194

配好 HTTPS 后微信仍提示，最有效是走微信官方申诉，配合 QQ 浏览器安全检测平台，并耐心等审核。

00194 · 2025-10-09

两条申诉通道

微信内申诉
发现 → 搜一搜 搜 https://gervas.wang → 进网站 → 右上角「···」→ 举报 → 页面内容 → 网页可能存在问题 → 申请恢复访问。
QQ 安全检测
访问 http://urlsec.qq.com/ 输入网址查检测结果，按提示整改后重检；另用 ssllabs.com/ssltest 查证书与混合内容。
时间与技巧
  • 微信审核通常 3-7 个工作日；网站信誉建立需几周到几个月。
  • 加速：完善「关于我」与联系方式、保持更新、多触发微信爬虫（聊天/朋友圈/文件助手发链接）。
  • 不要重复频繁申诉；保存申诉凭证；被拒后补个人介绍、等两周再申。
