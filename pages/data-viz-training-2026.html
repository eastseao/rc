01

课程定位与五步极简操作流

00736 / 00740

课程专为职场人士设计：用 AI（ChatGPT/DeepSeek 等）把会议纪要、Excel 报表、PDF 文档、产品提案等转化为带可视化元素的 Markdown 文档，并在 Typora / Markor 中渲染为图片或 PDF，实现高效、美观的办公信息传递。三个关键数字：7+ 办公场景覆盖、4 个可视化核心组件、3 个核心工具、5 步极简操作。

工具平台核心功能 / 输出格式 / 特色
TyporaWindows / macOS实时渲染 Markdown，完美支持内联 CSS / HTML / Mermaid；输出 PDF、HTML、图片（通过 Pandoc）；Pandoc 集成，一键导出 word。
MarkorAndroid手机端 Markdown 编辑 / 预览，渲染内联样式；输出 PNG、PDF、TXT；直接分享到微信 / 相册。
AI（ChatGPT 等）Web / API理解文档、提炼数据、生成带内联 CSS 的 Markdown 代码；纯文本（Markdown）输出；可上传 PDF/Word/Excel 并遵循提示词。
Pandoc命令行 / 集成文档格式转换（Word 转 Markdown 等）；输出 docx、html、PDF、LaTeX；Typora 默认集成。
步动作说明
1📤 提交内容 + 提示词在 AI 对话框粘贴文字 / 上传文件（PDF/Word/Excel），附通用或专用提示词，可以是问题列表或原始文档。
2🤖 AI 整理总结生成代码AI 理解内容、提炼结构化信息，返回带内联 CSS、卡片、表格、Mermaid 的完整 Markdown 文本。
3💻 粘贴至 Typora / Markor电脑端用 Typora（可配合 Pandoc 导出 word），手机端用 Markor 打开。
4🖼️ 预览并导出图片 / PDFTypora 直接导出或截图；Markor 分享为 PNG。
5📲 微信预览并发送先发文件助手预览，满意后转发给同事 / 群聊。

工作流（Mermaid 从左往右）：用户提交文档 + 提示词 → AI 理解整理 → 生成带内联 CSS/卡片/图表的 Markdown → 复制代码 → 选择平台（电脑 Typora+Pandoc / 手机 Markor）→ 渲染导出 PDF/PNG/Word → 发微信文件助手预览 → 满意后转发。

03

提示词模板库（通用 + 五场景）

00736 / 00688

通用万能模板要求：用 Markdown 标题分章节、所有条目尽量用卡片展示；通过内联 CSS 嵌入 Flex 特性卡片、彩色容器、样式化表格、渐变背景总结框，配色以橙色调为主；可适当加 Mermaid 图表或任务列表；确保 Typora 中 HTML/CSS 正常、导出 PDF/图片清晰；直接输出可用 Markdown，不包裹在代码块中、不含注释。

场景专用提示词结构要求可视化与增强
📝 会议纪要专用会议概况、关键决策、待办任务、风险与建议、总结。决策用 flex 卡片；关键数据用彩色容器；方案对比用样式表；待办加 Mermaid 甘特图 + 任务列表。
📊 Excel 报表 / 数据看板核心指标概览、维度对比、趋势分析、异常警示、运营建议。KPI 用大号数字卡片（橙色渐变）；极值用彩色容器；对比表带背景色；时间序列加 Mermaid 折线图，占比用比例条。
📄 产品提案 / PDF 专用背景痛点、产品方案、核心优势、实施计划、预算分配、预期收益。功能点用 flex 卡片（含 emoji）；预算/里程碑用彩色容器；竞品对比用表格；实施计划加 Mermaid 甘特图。
🔍 调研报告 / 知识问答主题概述、关键数据、多维对比、注意事项、总结建议。知识点用 flex 卡片分类；重要数据用彩色容器；对比项用样式表；可加 Mermaid 展示关系或流程。
🔄 项目复盘专用项目概览、关键成果、数据回顾、经验与不足、改进行动。"做得好/待改进"用 flex 卡片分类；完成率/延期用彩色容器；计划与实际对比用表格；关键成果加 Mermaid 时间线。

优化后的 Typora 可视化提示词 + Mermaid 版本说明

Typora 内置对 Mermaid 的支持，无需手动指定版本，它使用自身捆绑的 Mermaid 库（通常为较新稳定版），直接写标准 Mermaid 语法即可，导出 PDF/图片时自动处理清晰度。

优化后提示词五要点：①明确内容占位——用【】提示用户自定义主题，避免生成空泛文档；②结构化指令——分点列出要求便于 AI 逐项执行；③细化样式描述——强调配色和可读性；④澄清输出格式——明确不要代码块包裹，复制后 Typora 直接渲染；⑤保留灵活性——允许按需加 Mermaid 和任务列表，而非强制。

与原版的关键差异
  • 原版要求"所有内容放在一个 markdown 代码框内"；优化版改为"直接输出可用的 Markdown 文本，不要包裹在代码块中"，以便复制后在 Typora 中即时渲染。
  • 补充"若未指定主题则创建一个示例文档"的兜底，并用【】占位符引导。

图表选择指南与设计规范

00860

00860 给出了一套可直接放进对话的数据可视化提示词。核心是先按"数据关系"选对图表，再遵守坐标轴、颜色、文字三类设计规范，并跑一遍常见错误检查。

数据关系最佳图表不要用
随时间变化折线图饼图
类别比较条形图（类别多用水平条形）折线图
部分与整体堆叠条形、矩形树图（treemap）饼图（条形总是更清晰）
分布直方图、箱线图条形图
相关性散点图条形图
排名水平条形图竖直条形、饼图
地理分级填色地图（choropleth）条形图
随时间的构成堆叠面积图多张饼图
单一指标大数字（KPI 卡片）任何图表（过度设计）
流程 / 流向桑基图（Sankey）条形图

坐标轴与文字规范

  • 条形图 Y 轴必须从 0 开始；折线图可从非 0 开始（看变化而非绝对值）。
  • 两轴都标单位与含义；去掉多余网格线；用水平标签；条形图按值排序。
  • 标题直接写出洞察（"Q2 收入翻倍"而非"季度收入图"）；图例能省则省，直接标在图上；字号≥12px，大数字用 K/M/B 缩写。

颜色规范

  • 每图 ≤5–7 色；高亮关键项，其余置灰；顺序数据用同色系深浅，正负对比用红–灰–蓝。
  • 色盲友好：避免红绿组合，加形状或标签；同一含义颜色保持一致。
  • 禁止：3D 效果、双 Y 轴、无排序的字母序条形图、过度装饰（chartjunk）。

红线 · 饼图几乎总是错的选择

比较相似扇面困难、放不下 5–6 类以上、3D 饼图永远错误、读不出精确值

替代方案：水平条形图（易比较）、堆叠条形（部分与整体）、矩形树图（层级构成）；若精确值重要，直接用表格。

案例：枸杞知识全景报告（七节）

00736

课程以"AI 整理知识问答（枸杞专题）"为完整案例：用户提交 7 个问题，AI 输出一份可直接粘贴至 Typora 的可视化 Markdown 报告。下表照录报告的七节结构与关键数据。

报告章节核心内容与数据
一、主要产地与品种宁夏·中宁（宁杞 1 号、7 号，粒大肉厚药效佳）；青海·柴达木（柴杞，颗粒更大多糖高）；甘肃·靖远（甘杞，甜度适中硒丰富）；新疆·精河（精杞，日照长色泽鲜艳）。
二、鲜榨原浆多维特点口感清甜微酸；高倍保留枸杞多糖与维生素，吸收率＞90%；NFC 非浓缩还原，-18℃ 冷链或巴氏杀菌；护肝明目、增强免疫，见效快于干果。
三、性味归经与功效甘、平；归肝、肾经。核心功效：滋补肝肾、益精明目。调理方向：肝肾阴虚、视力衰退、增强免疫。
四、禁忌与慎用人群感冒发烧（温热身体加重病情）；内有实热（高血压、急躁易怒慎用）；脾胃虚弱（大便溏薄不宜多食）；服抗凝药物者（可能增加出血风险）。
五、产业数据国内年产量约 45 万吨（2024 年数据，占全球 90%）；核心有机产地为青海·诺木洪，另甘肃、内蒙古部分基地。
六、加工工艺对比传统晾晒（暗红/营养一般/干硬/保质期长）；热风烘干（红润/中等/酥脆/较长）；冷冻干燥（鲜红/高/酥脆鲜香/中等）；鲜榨原浆（自然/极高/鲜爽/冷链短保）。
总结与建议日常泡水选宁夏干果；追求高效滋补选鲜榨原浆；有机认证更安全；需注意体质禁忌、适量食用；建议建立产地溯源档案、开发差异化产品。

课程结语：最好的工具，是你愿意每天使用的工具。核心收获——掌握 AI + 内联 CSS 生成可视化报告、打通 Typora / Markor 输出全链路、拥有可直接套用的通用 + 场景提示词库、学会把零散问答整理为结构化知识卡片。
