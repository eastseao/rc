我仔细看了你的代码，这个产品展示页面已经有基本布局和响应式设计了，但如果参考你之前的“物料查询页面风格”，可以做一些美化和交互优化，让页面看起来更现代、整洁、产品居中且可互动。下面我整理了具体修改方案，并给出完整示例：

---

美化建议

  1. 产品卡片居中：当前 grid 已有间距，但可以在中小屏幕下居中显示，并在大屏幕增加适当的左右内边距。
  2. 卡片悬浮动画：增加轻微放大效果，鼠标悬浮时阴影加深。
  3. 图片点击放大：可使用一个简单的弹窗遮罩（Lightbox 风格）展示大图。
  4. 卡片信息分层：价格和关键属性突出显示，减少文字拥挤感。
  5. 整体配色：延续黄色悬浮按钮，可搭配浅灰背景和白色卡片，统一风格。
  6. 左侧导航美化：按钮圆角、渐变背景或者 hover 动画，让系列选择更明显。
  7. 移动端优化：初始隐藏左侧导航，点击按钮滑出。点击系列后收起导航。

手机端产品卡片太小，扩到最大的尺寸

明白了，你希望在手机端（小屏幕）产品卡片扩大到最大宽度，让图片和文字更清晰。我们可以针对 Tailwind 的响应式类修改 grid 和卡片宽度，使其在小屏幕下占满可用空间，同时保持居中。

---

修改方案

  1. 产品容器 grid

- 原来小屏幕：grid-cols-1 → 一列显示，但卡片宽度默认 w-32，太小。 - 修改卡片宽度：在小屏幕下使用 w-full max-w-xs sm:max-w-sm，保证卡片在屏幕上尽量大。

  1. 图片宽度

- 图片随卡片宽度自适应：w-full h-auto，保持比例。

---

修改后的核心卡片代码

function renderProducts(series) {
  productsDiv.innerHTML = '';
  data[series].forEach(product => {
    const card = document.createElement('div');
    card.className = 'product-card bg-white rounded-xl shadow p-4 fade-in flex flex-col items-center transition cursor-pointer w-full max-w-xs sm:max-w-sm';
    card.innerHTML = `
      <img src="../assets/product/${product.image}" alt="${product.name}" class="w-full h-auto object-cover mb-3 rounded-lg">
      <h3 class="font-semibold text-lg text-center">${product.name}</h3>
      <p class="text-gray-600 text-sm">项目号: ${product.project}</p>
      <p class="text-gray-600 text-sm">规格: ${product.spec}</p>
      <p class="text-red-600 font-semibold mt-1">零售价: ${product.price}</p>
    `;
    const img = card.querySelector('img');
    img.addEventListener('click', e => {
      lightboxImg.src = img.src;
      lightbox.style.display = 'flex';
      e.stopPropagation();
    });
    productsDiv.appendChild(card);
  });
}

---

解释

  • w-full max-w-xs sm:max-w-sm

- 小屏幕（手机）卡片占满屏幕宽度，但不超出 max-w-xs（约 20rem）。 - 中屏幕稍大：sm:max-w-sm（约 24rem），让卡片更大。

  • 图片 w-full h-auto 会自动适配卡片宽度，高度按比例缩放。
  • 保留原来的居中 justify-items-center，在手机端看起来居中且最大化显示。

明白了，你现在的 手机端卡片很好，但电脑端卡片太细长，原因是卡片宽度被限制在 max-w-xs sm:max-w-sm，在大屏幕上会显得拉长。我们可以通过以下方法优化电脑端布局：

---

优化方案

  1. 卡片在大屏幕上固定最大宽度：

- 使用 Tailwind w-full sm:max-w-sm md:max-w-md lg:max-w-md，即： - 手机：占满屏幕宽度 - 平板：最大宽度 24rem - 电脑：最大宽度 28rem - 保证卡片不随屏幕拉长。

  1. 保持响应式网格居中：

- 使用 justify-items-center + grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 - 大屏幕每行最多四个卡片，居中显示，不拉长。

  1. 图片自适应宽度：

- 使用 w-full h-auto object-cover，让图片随卡片宽度缩放。

---

修改示例

card.className = 'product-card bg-white rounded-xl shadow p-4 fade-in flex flex-col items-center transition cursor-pointer w-full sm:max-w-sm md:max-w-md lg:max-w-md';
