# 🧩 SKILL: Topic Cluster Generator

## 🎯 技能目标
围绕一个核心主题，自动生成结构化主题簇（Topic Clusters），用于：

- SEO流量布局
- 内容矩阵搭建
- 知识体系构建
- 商业转化路径设计

---

## ⚙️ 工作流程

### Step 1：意图解析
调用：`prompt/intent_parse.md`

- 判断主题类型（产品 / 行业 / 技术 / 认知）
- 判断用户目标（流量 / 转化 / 品牌）

---

### Step 2：种子扩展
调用：`prompt/seed_expand.md`

生成：

- 核心关键词
- 同义词
- 长尾词
- 用户问题

---

### Step 3：主题簇构建
调用：`prompt/cluster_build.md`

构建结构：

- Pillar Page（核心支柱）
- Cluster Topics（子主题）
- Supporting Content（支撑内容）

---

### Step 4：SEO优化
调用：`prompt/seo_optimize.md`

输出：

- 搜索意图分类
- 关键词密度建议
- 内容机会点

---

### Step 5：结构输出
调用：`prompt/output_format.md`

生成：

- 表格结构
- 内容规划
- 类脑图结构

---

## 🧠 Memory机制

路径：`memory/Memory.md`

记录：

- 已生成主题
- 已覆盖关键词
- 内容空白点

避免：

- 重复主题
- 关键词冲突

# 🧩 prompt/intent_parse.md

# 任务：解析用户主题意图

输入：
{{core_topic}}

输出：

1. 主题类型：
- 产品型 / 信息型 / 技术型 / 行业型

2. 用户意图：
- 搜索型 / 学习型 / 购买型 / 比较型

3. 内容方向建议：
- 流量导向 / 转化导向 / 品牌导向

# 🌱 prompt/seed_expand.md

# 任务：扩展关键词种子

围绕核心主题：

{{core_topic}}

生成：

1. 核心关键词（5-10）
2. 长尾关键词（20+）
3. 用户问题（10+）
4. 相关场景（5+）

要求：
- 贴近真实搜索行为
- 包含商业意图词

# 🧱 prompt/cluster_build.md

# 任务：构建主题簇

基于关键词，生成：

## 1. Pillar Page
- 核心主题页面

## 2. Cluster Topics
每个包含：
- 子主题名称
- 目标关键词
- 搜索意图

## 3. Supporting Content
- 具体文章标题
- 解决的问题

要求：
- 结构清晰
- 避免重复
- 覆盖不同搜索阶段

---

- 次关键词

- 低竞争词
- 高转化词
