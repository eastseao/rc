V2rayNG is a V2Ray client for Android devices that supports both Xray and v2fly cores. It allows VPN connections to be created with VMess, a communication protocol designed specifically for VPN use. The software is an open-source project available on GitHub, with various releases that users can download and install.

The software can be compiled directly in Android Studio or using Gradle wrapper, but the v2ray core inside the aar may be outdated. To address this, the aar can be compiled from the Golang project AndroidLibV2rayLite or AndroidLibXrayLite. V2rayNG can also run on Android emulators, although VPN mode will not work if the system does not support it.

Users can find more information about V2rayNG on the project's wiki page, which includes guides for Go Mobile and Makefiles for Go Developers. The software is also available on various app stores, such as Google Play and APKPure, with user reviews indicating positive experiences with the software's performance and reliability.

V2rayNG is not limited to Android devices, as other versions of the software are available for Windows and macOS platforms. V2rayN is a V2Ray client running on Windows, while V2rayU is a macOS client based on V2Ray core. Both support VMess, Shadowsocks, SOCKS5, and other protocols.

The V2rayNG project is an active open-source project with ongoing development and community support. Users can find additional information, submit bug reports, and participate in development discussions through the project's GitHub page, including a list of known issues and feature requests.
