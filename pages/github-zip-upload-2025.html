01

GitHub 不能在线解压 ZIP：三条路

00177

「上传了一个 zip 到库里怎么解压」——直接在仓库里在线解压是不可能的，GitHub 没这功能。按场景选下面一条。

方法适用怎么做
本地解压个人查看/改文件仓库里 Download 下来 → 本地解压 →（可选）再 git push 回去。
GitHub ActionsCI/CD 自动处理写 .github/workflows/unzip.yml，push 含 zip 的提交自动解压。
前端 JSZipWeb 应用内浏览器解压引入 JSZip，用户选文件后在浏览器读解压，不经仓库。
给普通用户的结论：快速查看就下载到本地解压最简单；要自动化才上 Actions；要网页里在线解压才用 JSZip。
02

解压后怎么上传：Git 命令行 vs 网页端

00180

解压出来一堆文件和文件夹，往哪传？两条路，按是否要版本控制选。

对比Git 命令行（推荐）GitHub 网页端
适合要版本控制、频繁更新、文件较大快速、一次性、文件较小
版本管理完整支持仅初始提交
单文件上限网页端 25MB；>100MB 用 Git LFS网页端 ≤ 25MB
git init git add . git commit -m "Initial commit: add unzipped code package" git remote add origin <你的仓库Git地址> git push -u origin main
00180 实录排错
  • 文件夹拖不进网页：浏览器安全限制/文件夹过大——改用 Git 命令行（最可靠）、GitHub Desktop 图形界面、逐子文件夹上传，或重新压缩成 ZIP 再传。
  • push 被拒（failed to push some refs）：远程有本地没有的更新，先 git pull origin main --rebase 再 push。
  • 认证：GitHub 已不支持账户密码，用个人访问令牌（PAT，勾 repo 权限）当密码。
03

PaperMod 主题：ZIP 还是子模块装

00177 / 00179

PaperMod 文件夹很大，要么下 ZIP，要么用 git 拉。网页端没法本地部署时，源笔记直接让你写 .gitmodules 声明子模块。

ZIP 方式

  1. 从 releases 下载 Source code (zip)。
  2. 解压 → 把文件夹重命名为 PaperMod。
  3. 整体放进 themes/，确保文件直接在 themes/PaperMod 下、不嵌套一层。

子模块 / 克隆

# .gitmodules（网页端直接建文件） [submodule "themes/PaperMod"] path = themes/PaperMod url = https://github.com/adityatelange/hugo-PaperMod.git branch = "master"

或本地 git clone … themes/PaperMod --depth=1。记得 Hugo 用扩展版，配置 theme: "PaperMod"。

04

Hugo + PaperMod 不本地部署：Actions 自动构建

00177

用户「是新手、不要本地部署」，于是全程在网页端用 GitHub Actions 自动跑 Hugo 构建。

00177 · 两个仓库 + 一个工作流

源码仓库与托管仓库分离

项说明
源码仓库放 Hugo 源文件、主题、配置、文章（即用已建好的 blog）。
托管仓库必须叫 <用户名>.github.io，存构建产物。
工作流.github/workflows/deploy.yml：checkout(submodules) → setup Hugo → hugo --minify → upload artifact(./public) → deploy to Pages。
Pages 源托管仓库 Settings → Pages → Source 选 GitHub Actions。
发文章在 content/posts/ 新建 md 并 push，Actions 自动构建发布。
关键点：文章头里 draft: false 才会发布（默认 true 的草稿不构建）；baseURL 要替换成你的 https://用户名.github.io/。
05

Pages 构建失败：远程主题 404 怎么排

00181

00181 给的真实构建日志：远程主题 chirpythemes/chirpy@v6.0.0 在下载 zip 时 404 Not Found，构建挂掉。

# 报错关键行 Theme: chirpythemes/chirpy@v6.0.0 Remote Theme: Downloading https://codeload.github.com/chirpythemes/chirpy/zip/v6.0.0 github-pages 232 | Error: 404 - Not Found - Loading URL: https://codeload.github.com/chirpythemes/chirpy/zip/v6.0.0
排查动作说明
验证链接浏览器直接打开报错那个 codeload URL，也 404 就坐实主题资源不存在。
核对仓库与版本确认仓库名/owner 对不对；releases/标签里 v6.0.0 是否真存在——常是版本号拼错。
目录结构兼容主题资源得放在 assets/_layouts/_includes/_sass 标准目录，否则被忽略。
退一步用默认分支替代版本：remote_theme: chirpythemes/chirpy；或 Fork 主题本地化后自建。
