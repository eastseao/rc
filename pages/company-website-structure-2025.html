经典公司网页结构（通用推荐）

00185

先解决「公司站到底该有哪几块」。笔记给出一套适用于大多数中小企业和初创公司的经典结构：顶部导航栏 + 页脚两个全局件，再加首页 / 关于我们 / 产品服务 / 案例 / 新闻 / 联系我们六个主页面。

00185 · 2025-10-07

两个全局件：导航栏与页脚

顶部导航栏
Logo 点击回首页；核心菜单含 首页 / 关于我们 / 产品服务 / 案例 / 新闻 / 联系我们；右侧放醒目行动号召按钮（如「免费咨询」「获取报价」）。
页脚
重复公司名、地址、电话、邮箱；社交媒体图标（微信、微博、LinkedIn）；快速链接再次列出重要页面；版权声明与认证。
00185 · 2025-10-07

六个主页面的目标与内容

页面核心目标必含板块
首页10 秒内让访客知道你是谁、做什么、有何价值首屏大图/轮播 + 主副标题 + 1-2 个 CTA；客户信任标识；3-4 个核心服务摘要；关键数据；2-3 个精选案例；客户评价；最新动态；底部再放一次联系表单或 CTA。
关于我们讲品牌故事、建情感连接使命愿景价值观；核心团队照片与简介；发展历程时间轴；企业文化与工作环境。
产品/服务清晰展示价值、促成咨询服务概览卡片；单服务详情（服务内容、为何选我、FAQ、相关案例、定价、咨询表单）。
案例研究用事实证明能力按行业/服务筛选；卡片列表；详情页含 客户背景挑战 → 解决方案 → 可量化成果 → 客户证言。
新闻/博客分享见解、提升 SEO文章列表（标题/摘要/日期/标签）；搜索与分类；热门文章推荐。
联系我们让客户能无障碍找到你简洁联系表单（字段不宜多）；地址/电话/邮箱/工作时间 + 地图；社交链接；FAQ 快捷入口。
设计要点与趋势（照录）
  • 响应式设计：手机、平板、电脑都要有完美浏览体验。
  • 极简与留白；高质量视觉元素；一致的品牌形象。
  • 快速加载——每延迟 1 秒都可能损失客户；每个页面都要有明确的行动号召。
  • 实用工具：原型 Figma / Sketch / Adobe XD；内容管理 WordPress、Webflow 或国内「上线了」「凡科建站」；灵感 Awwwards、Dribbble、Behance。

生产型食品企业 · GitHub Pages 结构

00185

把通用结构收窄到「生产型食品企业 + GitHub Pages」：GitHub Pages 只跑静态站，不数据库、不登录，正好契合企业展示、产品介绍与品牌传播；结构上突出食品企业的四个关键词——安全、质量、溯源、品牌故事。

00185 · 2025-10-07

导航与页脚的食品企业定制

部位内容
全局导航首页 / 关于我们 / 产品中心 / 质量与创新 / 新闻动态 / 联系我们；行动号召用「样品申请」或「合作咨询」。
页脚公司全称与品牌口号；工厂地址、销售电话、客服邮箱；官方认证（ISO22000、HACCP、有机认证、绿色食品——食品企业的信任基石）；微信公众号/视频号/抖音；法律信息。
00185 · 2025-10-07

六个页面的内容规划

首页 index.html：视觉冲击、建立信任核心
  • 首屏大图/视频（洁净生产线、产品特写或原料农场）+ 主标题「天然美味，品质传承」与副标题；CTA「了解我们的产品」「成为合作伙伴」。
  • 核心优势三点：严选原料 / 先进工艺 / 全程质检。
  • 3-4 个明星产品；合作客户 Logo 与资质证书；企业数据（年产量、服务品牌数、出口国数）；2 篇最新动态。
关于我们 about.md：讲品牌故事、展示工厂OEM 客户最关心
  • 品牌故事/使命；发展历程时间轴；我们的工厂是重点——厂区外观、洁净车间、自动化包装线；团队风采（可选）。
产品中心 products.md：清晰分类、支持 OEM/ODM生产型核心业务
  • 产品分类导航（休闲零食/营养代餐/调味酱料等）；卡片含图片、名称、简要特点，点击进独立详情页。
  • 详情页：多角度图册、规格（净重/配料/保质期）、适用场景人群、OEM/ODM 定制说明。
质量与创新 quality.md：深度建立信任专业度
  • 原料入库 → 生产过程 → 成品出库的全链条质检；研发团队与高校/科研合作；完整资质证书墙。
新闻动态 / 联系我们活力 + 转化
  • 新闻：参展、新厂投产、战略合作 + 行业洞察，列表布局。
  • 联系：表单字段 姓名/公司/电话/邮箱/咨询内容；GitHub Pages 无后端，用 Formspree、Getform 等第三方服务收邮件；销售部与客服电话邮箱；工厂地址嵌百度/高德地图；FAQ 解答 MOQ、样品、交期。
技术实现建议（针对 GitHub Pages）
  • 静态站点生成器强烈推荐 Jekyll（GitHub Pages 原生支持，Markdown 写内容、Liquid 管布局）；替代 Hugo、Hexo。
  • 主题找免费/付费 Jekyll 主题，多为响应式；主色建议 绿（健康）/ 棕黄（自然谷物）/ 蓝（安全科技）；大量留白；专业产品与工厂摄影是食品站的灵魂。

十条需求整理成的站点结构

页面职责
首页 index列出采购需求与供应商登记表单入口。
个人简介 profile头像 + 电话按钮（直接拨打）+ 微信按钮（一键复制微信号）；工作经历、常驻工作地、工作目标。

全站要求每页统一导航栏；每页都有返回顶部按钮；部分页面加二级导航。

选型结论：Jekyll + Minimal Mistakes 主题

理由：GitHub Pages 原生支持、无需本地部署、可直接在 GitHub 网页端编辑、响应式适配手机。推荐主题 Minimal Mistakes——简单易用、支持多页面导航、移动端友好、组件丰富。

建库
新建公开仓库 gervasw.github.io。
配置
新建 _config.yml，写 theme: minimal-mistakes-jekyll 与 navigation 导航列表。
建页
用 Markdown（layout: single + permalink）逐个建 index / profile / requirements / group / qinghai / products。
部署
每保存一个文件自动更新，约 5 分钟后访问 https://gervasw.github.io。
两个复用代码片段（照录）：电话按钮 <a href="tel:电话号码">拨打电话</a>；微信复制用 navigator.clipboard.writeText(微信号)。返回顶部按钮 position:fixed;bottom:20px;right:20px，监听 scroll 在滚动超过 20px 时显示。

网页端落地：导航栏 / 播放器 / 复制

00185

00185 后半段是一系列「只在网页端操作」的迭代：产品中心/关于我们/联系我们三页、导航栏布局调整、加视频播放器、把视频改成 URL 链接，以及给文件路径加可复制按钮。

产品中心 / 关于 / 联系

按食品企业结构补齐三个核心页：产品中心用卡片网格列产品；关于我们放品牌故事与工厂；联系我们放表单与地图。

导航栏布局

调整顶栏菜单顺序与 CTA 位置，保证 Logo 回首页、核心菜单一行排开、右侧行动号召醒目。

视频播放器

在页面嵌入播放器；最初想直接引用本地上传路径，最终改为用企业视频的 URL 链接方式加载，网页端更稳。

可复制按钮（照录思路）
  • 把「文件路径」单独列出来，旁边放一个复制按钮，点一下即复制完整路径——给后续照抄代码、填图片地址用。
  • 复制 trthealth.com 页面代码时同样用「路径单列 + 复制按钮」，避免长代码在对话里找不全。

第三份是一段非技术的真实记录：有编程基础的新手，第一次用 ChatGPT 完整搭站，体会到理论与工程之间的差距。

00198 · 2025-10-07

时间线：从职业站到个人博客

时间事件
1 日 ~ 2 日搭建职业介绍网站 http://gervas.wang，特意买域名并完成 DNS 解析；看着网站从无到有上线，成就感十足。
3 日 回连云港另做个人博客 https://seamoonappear.github.io/；初版仅两小时完成。
之后几天看到别人更好的网站，换主题时毫不犹豫删了整个库；前前后后删库十几次，一次次从头开始。
心得（照录要点）：代码是极其严谨的事——不讲情绪、不靠猜测、没有「差不多」，一行错了就是错了，一个标点都可能让整个程序无法运行。删库十几次后又回到最初的博客，不再急着求快、也不再追求完美，因为每一段成长都是在「重建」中完成的。改写过程还尝试了 Markdown 排版优化与「更技术化」两种文风。
