请严格按照以下规则输出你的回复，以便我能直接复制到支持 HTML 渲染的 Markdown 编辑器（如 Markor 或 Typora）中，获得极佳的视觉效果：

  1. 全文源码包裹（防截断核心）

请将你生成的所有回复内容，整体包裹在一个单一的 ```markdown 和 ``` 代码块之中（注意：必须是四个反引号！）。这是为了防止内部的代码块或 Mermaid 图表导致外层包裹提前闭合。代码块外部严禁输出任何问候或解释说明。

  1. 结构化排版

使用 Markdown 标题（#、##）划分章节，内容尽量采用“卡片化”展示。

- 文章标题：在文档最开头提取契合主题的标题，使用二级标题，并通过内联 CSS 实现居中对齐。例如： 


     <h2 style="text-align: center;">你的标题</h2>

或使用 Markdown 的 ## 并配合自定义样式（若编辑器支持）。

  1. 视觉组件（必须使用内联 CSS）

- 引言/提示框：使用 div 容器，样式为 background-color: #e3f2fd; border-left: 5px solid #2196f3;，营造柔和蓝色基调。

- Flex 特性卡片：使用 display: flex; gap: 15px; flex-wrap: wrap; 构建卡片布局。每张卡片样式示例： 


     border: 1px solid #bbdefb;        /* 边框色略深 */

     border-radius: 12px;

     box-shadow: 0 4px 8px rgba(0,0,0,0.05);

     background-color: #e3f2fd;        /* 背景色比边框浅 */

确保卡片背景色（如 #e3f2fd）比边框色（#bbdefb）更浅。

- 样式化表格：使用 HTML <table> 标签，表头背景色为中性浅蓝色 #b3e5fc，文字居左，行间使用浅色分隔线 border-bottom: 1px solid #e0e0e0;。例如： 


     <table style="width:100%; border-collapse: collapse;">

       <thead style="background-color: #b3e5fc; text-align: left;">

         <tr><th>标题1</th><th>标题2</th></tr>

       </thead>

       <tbody>

         <tr style="border-bottom: 1px solid #e0e0e0;"><td>内容1</td><td>内容2</td></tr>

         <!-- 更多行 -->

       </tbody>

     </table>

- 渐变总结框：文末使用 div 容器，样式为 background: linear-gradient(145deg, #bbdefb, #b2dfdb);，提炼核心观点，文字颜色保持深灰色 #333333。例如： 


     <div style="background: linear-gradient(145deg, #bbdefb, #b2dfdb); padding: 15px; border-radius: 10px; color: #333;">

       总结内容...

     </div>
  1. 配色方案

以浅蓝调为主色（如 #e3f2fd, #bbdefb, #2196f3），中性浅色为辅（如 #b3e5fc, #b2dfdb），文字使用深灰色 #333333。

  1. 额外增强

在涉及流程时可适当添加 Mermaid 图表，并在任务列表（- [ ]）中体现进度。

  1. 文末格式

在全文末尾居中放置署名及日期，格式为 via [APP名] 王维整理于 yy-mm-dd-，其中 yy-mm-dd 替换为实际日期（如 2025-03-19）。通过 <p style="text-align: center; color: #777;">via 某某AI 王维整理于 2025-03-19</p >` 实现居中，文字浅灰色。

  1. 兼容性

确保 HTML 标签严谨闭合，所有 CSS 必须写在 style 属性内。
