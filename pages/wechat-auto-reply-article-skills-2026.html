01

赞赏后的自动回复句子

00436 · 2025-11-15

微信推文收到赞赏后，按账号风格挑一句感谢语。下面这张表汇总了四种风格，每种三句，可直接取用。

风格分类自动回复句子示例
文艺走心型1. 感谢认可，这份鼓励是我持续创作的星光。
2. 你在阅读上花的时间，使得我这一刻变得不同。
3. 唯有美食与爱不可辜负，感谢你认可我的文字与心意。
俏皮可爱型1. 收到赞赏，镜子里的我好像又变好看了点！
2. 叮！你的喜欢已成功到账，它将为我续航一整天～
3. 仙女（或帅哥）的赞赏已收到，我这就去买点糖吃！
简洁直接型1. 感谢支持，我会继续用心创作。
2. 赞赏收到，谢谢你的鼓励。
3. 承蒙厚爱，必不负期待。
互动引导型1. 收到你的心意啦！比起赞赏，更期待你在留言区分享看法哦～
2. 感谢厚爱！告诉我你还想听什么话题？
3. 你的赞赏是我前进的油，已加满！我们下一篇推送见。

设置时的四点小建议

真诚为先
真诚的感谢是首要的，让读者感到支持被珍视。
保持简洁
自动回复不宜过长，简短有力更易被记住。
匹配风格
回复语气要和公众号一贯形象保持一致。
巧妙引导
感谢之余可委婉引导评论、分享或关注下一篇，增加互动。

如何落地

微信公众平台目前没有为「赞赏」提供专门、独立的自动回复设置，感谢互动通常靠两种方式实现：

文末统一感谢
在推文结尾处，统一写一段对所有读者的感谢语。
私信自动回复
利用公众号私信自动回复功能，用户赞赏留言后，手动或借工具向其发一条感谢消息。
02

关注后自动回复与公众号简介

00437 · 2025-11-15

以一个发散文的个人号「城际地平线」为例：关注后自动回复给了三个完整版本，外加一套可自由拼装的句子组件；公众号简介另给三个风格版本，并按「120 字以内」再压缩一轮。

关注后自动回复 · 版本一 文艺舒缓型（最推荐）完整文案

嗨，你来了。

穿过数字世界的喧嚣，很高兴在「城际地平线」与你相遇。这里是我的精神自留地，也是一方安静的角落。

我习惯用散文记录生活——关于城市的剪影、旅途的风尘、书籍里的光影，以及那些无处安放的细微情绪。它们不成体系，只是我与你分享的、关于世界的私人注脚。

在这里，希望你能慢下来。愿我的文字，能成为你繁忙生活里一次短暂的出逃，像在疾行的列车里，望见窗外那一道宁静而遥远的地平线。

那么，就从这里开始我们的旅程吧。你可以：翻阅往期散文，看看是否有故事能触动你；随时给我留言，分享你的感悟或只是打个招呼；保持关注，期待下一篇文章里，与你再次神交。

感谢关注，期待与你同行。

关注后自动回复 · 版本二 简洁清新型 / 版本三 亲切互动型两版

版本二 · 简洁清新：你好，欢迎来到「城际地平线」。这是一个用散文记录世界的地方。写写城市，写写旅途，写写生活里那些值得被定格的光影和情绪。希望我的文字，能为你提供一片安静的栖息地。接下来你可以：点开主页读一篇旧文；告诉我你对什么主题感兴趣；放松心情，期待下一次更新。感谢相遇。

版本三 · 亲切互动：嘿！终于等到你踏上这片「城际地平线」！我是这里的主理人，一个喜欢用散文唠嗑的记录者。在这里，我们不谈宏大的议题，只聊那些发生在城市角落、旅途驿站和内心深处的真实故事。为了更快地了解你，我想邀请你：回复数字 1，看看我最受欢迎的几篇散文；回复一个关键词（比如「旅行」「读书」「城市」），告诉我你想看什么；或者直接跟我分享你此刻的心情。很高兴认识你，新朋友！

可自由组合的「组件」

开场白 / 定位 / 预告 / 行动号召

开场白
「脚步匆匆，感谢你在此驻足。」／「欢迎光临这片文字栖息地。」／「嘿，能在这里遇见，真好。」
公众号定位
「这里主要分享不设限的私人散文。」／「用文字素描生活，用散文锚定时光。」／「一个记录思想碎片与生活美学的角落。」
内容预告
「你会读到关于城市观察、阅读札记和偶尔的诗。」／「内容关乎我们共同经历的生活，与偶尔超脱现实的想象。」
行动号召 CTA
「不妨现在就逛逛历史消息，或许会有惊喜。」／「如果有什么想聊的，随时留言，我都在。」／「期待在下一篇文章的留言区，看到你的身影。」
使用建议
  • 回复中可点缀一些柔和的表情符号，但不宜过多，以免破坏散文的沉静感。
  • 版本一综合效果最好，强烈推荐。
公众号简介 · 三风格 + 120 字版

从完整版到精炼版

版本简介文案
文艺意象版在城际之间漂泊，于地平线处停歇。这里是一处文字驿站，收藏旅途的见闻、城市的剪影、书页间的光影，以及那些细碎却闪光的思绪。不谈大道理，只写小日子。愿我的散文，能成为你奔忙生活里一次温柔的出逃。
简约直接版「城际地平线」个人散文集。用文字记录：城市观察｜阅读随笔｜生活漫想。在快节奏的时代，为你留存一份慢思考的质地。关注我，一同在字里行间漫步。
互动共鸣版我们都在人生的旅途上，穿梭于一座座名为「生活」的城。欢迎来到「城际地平线」，这里分享我的散文与思考，关于走过的路、读过的书和遇见的人。希望我的文字，能映照出你的心情。累了就来坐坐，也期待，听到你的故事。

压缩到 120 字以内后，三版分别是：

文艺风格版
在城际之间漂泊，于地平线处思索。这里是我的文字驿站，记录旅途的见闻、城市的剪影与书页间的光影。不谈大道理，只写小日子。愿这些散文，成为你奔忙生活里一次温柔的出逃。
简约清晰版
「城际地平线」是一个个人散文空间，专注于分享城市观察、阅读随笔与生活漫想。在快节奏的时代，旨在为你留存一份慢思考的质地。欢迎关注，在字里行间相遇。
互动共鸣版
我们穿梭于一座座名为「生活」的城。这里分享我的旅途见闻、城市观察与生活随想，希望映照出你的心情。愿「城际地平线」成为你思绪停靠的驿站。期待你的故事。

公众号文章发布工作流技能

00964 · 2026-04-19

这是一个端到端的公众号文章生产与发布自动化技能（wechat-hot-article-publisher）：从百度 / 头条热点发现选题，经用户确认后走完「研究 → 写作 → 人工化润色 → 配图 → 格式化 → 发布到草稿箱」的完整闭环，强调可复用、固定流程。

触发场景示例用户表述
完整工作流请求「写一篇公众号文章」「发布到微信草稿箱」
含话题研究「先搜热点再写」
含配图要求「匹配图片并发布」
明确工具调用「使用 wenyan 发布」
复用之前的流程「用之前一样的微信工作流」

不应使用：纯博客写作（无微信发布）、纯编辑校对（无研究和发布）、微信回复或客服文案。

固定工作流 · 八步

从热点到草稿箱的八步闭环

步环节要求
1热点发现浏览百度热搜、头条热点或可靠聚合源；先输出 10 个选题（含话题名、热度原因、写作角度、发布安全评级），等用户选定后再写。
2来源核实用官方发布、主流报道、原始采访 / 演讲 / 数据页核实关键事实，写作前确认日期与事件上下文。
3撰写初稿结构：强标题、吸引人开头、清晰小标题、主体分析、结尾、来源列表；读起来像成熟公众号文章，不是报告或备忘录。
4人工化润色强制独立第二遍：删生硬 AI 套话与空洞宏观词、打破对称句式、长短句交替、保持有判断力的真人视角。
5选图3～5 张与文章强相关的图，优先报道页 / 官方页现场图，杜绝随机库存图。
6图片本地化下载到本地文章图片文件夹，Markdown 用相对路径引用，避免远程热链失效。
7Wenyan Markdown带 frontmatter（title / cover），正文含标题、分节、嵌图、图注、引用。
8发布用本地 wenyan CLI 发布，默认目标为微信草稿箱。

三条不可跳过的硬约束

10 个选题必出 · 人工化润色必经 · 图片必须本地化

除非用户明确给出最终选题并要求直接进行，否则必须先给 10 个选题；人工化润色是初稿完成后的显式第二阶段，不是写作中的模糊意图；图片先下载到本地相对路径再由 wenyan 上传，远程热链发布失败时切换本地副本重试。

质量验收清单

  • 选题来自当前热点研究
  • 用户被提供了 10 个选项
  • 终稿经过独立人工化润色
  • 图片与新闻事件强相关
  • Markdown 可被 wenyan 发布
  • 已发布到草稿箱或给出明确阻断原因

潜在风险与改进

工具依赖
需本地安装 wenyan CLI 且微信凭证有效，否则走不到发布步。
图片版权
从新闻页直接下载图片可能涉版权，可加「仅作草稿配图、标注来源」或改用 CC0。
可选优化
允许用户自定义选题数量；wenyan 未装或登录失效时降级为「输出 Markdown 并提示手动发布」。

提取近一周 10 万+ 爆文的技能设计

00973 · 2026-04-20

这套技能（WeChatHotArticleExtractor）的目标是：提取发表时间在最近一周以内、阅读量 10 万+的公众号爆款文章，输出含标题、公众号名、发表时间、阅读量、链接的列表。

输入与时间范围

怎么界定「近一周」

时间范围
以当前日期往前算 7 天（例：今天 2026-04-20，则范围为 2026-04-13 00:00:00 至 2026-04-20 23:59:59）。
输入建议
无强制输入，但建议提供可用的数据获取渠道（搜狗微信、新榜 API、清博接口等）权限或密钥；未提供则基于公开可访问的模拟搜索步骤指导。
三种数据源 · 任选其一

搜狗 / 第三方数据 / 自有库

方式怎么做
A · 搜狗微信搜索访问 weixin.sogou.com，按关键词或时间排序浏览，提取标题 / 摘要 / 公众号 / 相对时间（转绝对时间）；阅读量不直接显示，需进详情页解析，注意 User-Agent 与 Cookie。
B · 第三方数据服务（推荐）新榜（newrank.cn）或清博（gsdata.cn）：筛选「微信 → 文章 → 时间近 7 天 → 阅读数 ≥ 100000」导出；有 API 密钥则直接调接口。
C · 自有数据库 / RSS已有文章库则直接 SQL：publish_time 在近 7 天且 read_count ≥ 100000，按时间倒序。

过滤与去重：只保留近 7 天内文章，去除重复链接或同题（保留最新一条），按发表时间从近到远输出；结果为空时输出「未找到最近一周内阅读量 10 万+ 的文章」。

三条注意事项
  • 反爬限制：微信页面需登录态、阅读量常异步加载，直接抓取很难，优先用新榜、清博等正规数据平台。
  • 法律与合规：使用合法渠道，遵守微信与第三方平台的 robots.txt 及服务条款。
  • 时效性：每周跑一次即可，结果可能因平台数据更新延迟有 1～2 小时误差。
