Windows 一键清理脚本（BAT）

2026-05-03

跑 OpenClaw 这种 Agent 工具后临时文件暴涨。先给了安全版，再升级成「开发者增强版」。

安全版（先跑这个）

clean.bat

@echo off echo ============================== echo Windows 垃圾清理开始 echo ============================== :: 清理用户临时文件 echo 清理用户临时文件... del /f /s /q %temp%\* >nul 2>&1 rd /s /q %temp% >nul 2>&1 mkdir %temp% :: 清理系统临时文件 del /f /s /q C:\Windows\Temp\* >nul 2>&1 :: 清理 Prefetch del /f /s /q C:\Windows\Prefetch\* >nul 2>&1 :: 清理回收站 rd /s /q C:\$Recycle.Bin >nul 2>&1 :: 清 DNS 缓存 ipconfig /flushdns :: 清 Windows 更新缓存 net stop wuauserv >nul 2>&1 del /f /s /q C:\Windows\SoftwareDistribution\Download\* >nul 2>&1 net start wuauserv >nul 2>&1 echo 清理完成！ pause
用法
新建文本文件 → 粘贴 → 另存为 clean.bat → 右键以管理员身份运行。
安全边界
不删个人文档 / 图片 / 代码；正在使用的文件删不掉是正常的；OpenClaw 类缓存基本能清掉 70%+。
增强版可以再加
  • Chrome / Edge 缓存、Node/npm 缓存、Python __pycache__、Git 残留。
  • 定时每天自动跑；只清超过 7 天的文件更安全。

Codex Windows 桌面应用设中文

2026-06-14

OpenAI Codex 桌面端的中文支持当时是半残状态，按四个方法排查。

方法操作
软件内设置File → Settings → General → Language → 中文（zh-CN）→ 完全退出后台进程 → 重开。
查配置文件打开 C:\Users\<用户名>\.codex\config.toml，确认有 [desktop] localeOverride = "zh-CN"；或全局 JSON 里 "localeOverride":"zh-CN"。
更到最新版官方持续修中文；当时仍存在一级菜单中文、二级菜单英文的中英混合状态。
社区汉化补丁GitHub 有第三方完整汉化，但更新官方版后可能失效，有安全维护风险。
已知 Bug：很多用户反馈语言已改成中文、配置文件已写 zh-CN，重启后 UI 仍是英文——官方已确认，未完全修复。

诗词数据库桌面应用：产品结构与技术选型

2026-06-27

数据源是 github.com/eastseao/chinese-poetry。目标是 Windows 桌面：每天打开随机推荐一首，不喜欢就换；能搜索诗名/作者/内容。

四个核心页面

  • 首页：每日一首（按 date seed 固定，换一首重随机）；显示诗名/作者/正文/朝代；收藏按钮。
  • 搜索页：关键词搜诗名/作者/内容；高级筛选朝代、作者、类型。
  • 详情页：标准排版阅读；上一首/下一首；收藏/分享。
  • 收藏页：个人诗单，可分类（喜欢/背诵/待学习）。

三条技术路线

首选 Electron + React
跨平台、UI 好做、社区成熟；SQLite + 本地 poetry JSON。
更轻 Tauri + React
Rust 壳，比 Electron 轻很多、启动快、内存低。
Windows 原生 WinUI 3 / WPF
偏工程，性能最好但开发慢、不跨平台。
体验目标：「像打开一本每天都会变的诗词书」。本质是离线诗词知识库 + 随机推荐阅读器 + 检索工具。
