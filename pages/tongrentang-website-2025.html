每个产品要展示的五个字段

用户明确：每个系列单独一个数据文件，产品要展现产品图片、产品标题、产地、规格、零售价五项。JSON 字段示例（_data/fresh-cordyceps.json）：

字段示例值

路径结论（照录）
  • 数据文件放项目根目录的 _data/，不是 assets/_data/ 也不是 assets/data/。
  • Jekyll _data 支持 YAML / JSON / CSV / TSV；模板里用 site.data.系列名 访问。
  • 图片放 assets/images/，JSON 的 image 字段路径要与实际一致。
00245 · 2025-10-14

渲染方式：从 JS 动态加载回到 Jekyll 模板

最初方案是 fetch JSON 动态加载，但页面报「产品信息加载失败」。排查后推荐改用 Jekyll 模板方式：在 product-display 里为每个系列写一段 {% for product in site.data.xxx %}，点标签只做 display:none/block 切换。

为什么改用模板渲染

更稳定，不依赖 JS 动态加载；对 SEO 更友好。

方形小图

用户要求产品图片方形小图：容器 120px × 120px、圆角、阴影边框，object-fit:cover，一行能看更多产品。

地理位置加坐标的四种方案

工厂位于德令哈，坐标约 97.37°E, 37.37°N。笔记给了四种嵌入方案：

方案说明
百度地图（推荐）国内访问友好、中文地址支持最好；BMap.Point(97.37,37.37) + 标注 + 滚轮缩放。
高德地图AMap.Map 中心 [97.37,37.37]，另给「在高德地图中查看」URI 链接。
Google 地图面向国际用户；{lat:37.37, lng:97.37}。
静态地图图片（过渡）无需 API 密钥，一张可点的渐变卡片链到地图搜索页。

拿精确坐标的方法：手机地图 App 定位、网页版搜地址右键取坐标、GPS 设备测量；也可在 _config.yml 里加 location_coords 字段统一管理。

00245 · 2025-10-14

「APP 服务被禁用」三查

百度地图报「APP服务被禁用」，根因多为 AK 配置，按下表逐项查：

检查项正确配置
应用类型JavaScript API 必须用「浏览器端」类型 AK，选成「服务端」就会报此错。
服务开关控制台对应 AK 的「设置」里，把 JavaScript API 勾上（用到的地理编码等一并开）。
授权白名单开发测试可临时填 *，上线后改成正式域名。
验证与兜底：改完后确认 ak= 后面是正确的浏览器端 AK；仍不行就清缓存/无痕模式测试，或去百度地图开放平台工单反馈。
