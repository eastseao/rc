01

计划单的三步处理流程

从 Excel 到可采购清单
流程

原始列 → 分类拆分 → 同名合并

  • ① 转 Markdown：把计划单 Excel 输出为 Markdown 表格，保留 计划单 / 序号 / 名称 / 规格 / 数量 / 单位 / 类别 / 文件 / 供应商 / 备注 等列。
  • ② 按类拆分：按"文件"列把整张表拆成独立小表——PET 瓶子、PE 袋、复合膜、卡盒、礼盒、圆卡纸、标签等。
  • ③ 同名合并：同一类别内名称相同的项合并数量，计划单号与原序号用逗号连接；最后在最左侧加一列连续"新序号"。

03

同名合并的列规则

新序号 · 原序 · 名称 · 数量
合并后表结构

每行五列

  • 新序号：最左侧新增的连续序号，方便按行点单。
  • 原序：被合并的原计划单号（如 A2、A36、B29），多个用逗号连接，便于回溯原始计划单。
  • 名称 / 数量 / 单位：同名物料的数量相加后单列一行。
