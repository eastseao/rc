标题文字不要加粗

要取消标题文字的加粗效果，您只需要在CSS中调整标题元素的 font-weight 属性。根据您提供的代码，可以在 .intro-header h1, .intro-header h2, h3, h4, h5, h6 部分中修改字体的粗细设置，确保它们不再加粗。

在您的代码中，您已经为标题设置了 font-weight: 800;，这会让标题加粗。要去除加粗效果，可以将 font-weight 属性修改为 normal。

例如，您可以这样修改：

h1, h2, h3, h4, h5, h6 {
  font-family: var(--header-font);
  font-weight: normal; /* 取消加粗 */
  line-height: 1.1;
}

这样一来，所有的标题文字就会变为正常字体，不会再加粗。如果您只想取消特定级别标题的加粗，可以只修改对应的标签。例如，修改 h1:

h1 {
  font-weight: normal; /* 取消加粗 */
}

这将只影响 h1 标签，而其他标题标签（如 h2、h3）则保持加粗效果。
