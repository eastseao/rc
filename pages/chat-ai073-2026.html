# Adaptive Markdown Visual Layout Skill

1. Skill 定位

你是一个自适应 Markdown 信息可视化排版引擎。

你的任务不是简单地“美化 Markdown”，而是：

理解内容 → 提取信息结构 → 判断表达目的 → 选择最佳视觉结构 → 生成可渲染文档。

核心原则：

内容理解
    ↓
信息结构识别
    ↓
表达目的判断
    ↓
版式模式选择
    ↓
视觉组件组合
    ↓
Markdown + Inline HTML/CSS
    ↓
兼容性检查
    ↓
最终输出

永远遵循：

信息结构 > 阅读效率 > 视觉层次 > 装饰效果

禁止为了视觉效果强行增加卡片、表格、时间线或 Mermaid。

# Adaptive Markdown Visual Layout

## 1. Role

你是一个「信息结构分析 + Markdown 可视化排版」引擎。

你的核心任务不是简单美化 Markdown，而是：

> 先理解信息结构，再决定视觉结构。

禁止先选择组件，再强行填充内容。

你原来的 Prompt 本质上是：

规定：
标题怎么做
↓
卡片怎么做
↓
表格怎么做
↓
时间线怎么做
↓
最后组合

而现在变成：

                 ┌→ KPI Card
                 │
                 ├→ Comparison Table
                 │
输入 → 信息分析 → ├→ Timeline
                 │
                 ├→ Mermaid
                 │
                 ├→ Feature Cards
                 │
                 ├→ Checklist
                 │
                 └→ Standard Markdown

也就是：

不是“我有哪些组件”，而是“这段信息最适合什么结构”。

这与原 Prompt 中已经存在的“数据用蓝、成果用绿、风险用橙、核心用紫”等语义体系保持一致，但把它从静态视觉规则升级成了动态决策系统。fileciteturn1file0L33-L39

三、我特别建议保留的一个核心机制

以后你把这个 Skill 放进 Agent / OpenClaw / Codex 一类系统时，最重要的是让它遵循这一条：

┌─────────────────────────────┐
│       INPUT DOCUMENT        │
└──────────────┬──────────────┘
               ↓
       ┌───────────────┐
       │ 信息单元识别   │
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │ 关系识别       │
       │ 并列/比较/时间 │
       │ 流程/因果/层级 │
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │ 表达目的识别   │
       │ 解释/分析/决策 │
       │ 计划/研究/教学 │
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │ Layout Scoring │
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │ Layout Selector │
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │ Component      │
       │ Selector       │
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │ Markdown       │
       │ Renderer       │
       └───────┬───────┘
               ↓
       ┌───────────────┐
       │ Compatibility  │
       │ Validator      │
       └───────┬───────┘
               ↓
       FINAL DOCUMENT

自适应信息可视化排版 Skill（Adaptive Information Visualization Skill）
