function initPhotoTabs() {
  const container = document.querySelector(".photo-container");
  if (!container) return;

  const nav = container.querySelector(".photo-nav");
  const tabPanes = container.querySelectorAll(".tab-pane");
  const highlight = nav.querySelector(".nav-highlight");

  if (!nav || !tabPanes.length || !highlight) return;

  nav.addEventListener("click", function(e) {
    const button = e.target.closest(".nav-btn");
    if (!button) return;
    const targetTab = button.dataset.tab;

    nav.querySelectorAll(".nav-btn").forEach(b => b.classList.remove("active"));
    button.classList.add("active");
    
    tabPanes.forEach(p => p.classList.remove("active"));
    const targetPane = container.querySelector("#" + targetTab);
    if (targetPane) targetPane.classList.add("active");
    
    const rect = button.getBoundingClientRect();
    const containerRect = nav.getBoundingClientRect();
    highlight.style.width = rect.width + "px";
    highlight.style.left = (rect.left - containerRect.left) + "px";
  });

  const activeButton = nav.querySelector(".nav-btn.active") || nav.querySelector(".nav-btn");
  if (activeButton) {
    const rect = activeButton.getBoundingClientRect();
    const containerRect = nav.getBoundingClientRect();
    highlight.style.width = rect.width + "px";
    highlight.style.left = (rect.left - containerRect.left) + "px";
  }

打开连接后，如果地址类似这样，就能显示：“https://gervas.wang/about/”

明白了，你希望 URL 不是直接指向 about.html，而是像 /about/ 这样“干净”的路径形式（即目录形式），这在 Jekyll 中叫做 permalink 目录风格。

要实现这个效果，需要两件事：

---

1️⃣ 修改页面文件的 front matter

例如 about.html（在根目录）：

---
layout: page
title: 关于我
permalink: /about/
---

同理，把其他页面也改成类似：

# hobby.html
permalink: /hobby/

# photos.html
permalink: /photos/

# stops.html
permalink: /stops/

# tags.html
permalink: /tags/

# categories.html
permalink: /categories/
这样访问 /about/ 时，Jekyll 会生成一个 /about/index.html，浏览器自动显示 /about/。

---

2️⃣ 修改导航栏链接

因为现在路径是目录风格，就直接指向目录即可：

<div class="dropdown-menu dropdown-menu-right" aria-labelledby="navbarDropdown">
  <a class="dropdown-item" href="/about/">关于我</a>
  <a class="dropdown-item" href="/hobby/">爱好</a>
  <a class="dropdown-item" href="/photos/">照片</a>
  <a class="dropdown-item" href="/stops/">驻足</a>
  <div class="dropdown-divider"></div>
  <a class="dropdown-item" href="/tags/">标签索引</a>
  <a class="dropdown-item" href="/categories/">分类索引</a>
</div>

---

✅ 这样，你打开导航栏链接时，地址栏显示的就是干净路径 /about/ 而不是 about.html，同时 Jekyll 会正确渲染页面内容。
