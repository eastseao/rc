01

润色指令的基本打法：把需求说清楚

2025-10-10

最早的一次对话先回答了「怎么给 AI 下一条有效的润色指令」。结论是：润色效果不好，多半不是 AI 不行，而是指令太笼统。指令里要交代目标风格、语气、受众和润色重点，而不是只甩一句「帮我润色一下」。

一条润色指令要交代四件事

  • 目标效果：风格（正式 / 口语 / 幽默 / 商业化）、语气（温柔 / 坚定 / 中立 / 激励）、受众（学生 / 专业人士 / 大众）。
  • 润色范围：是只改语句流畅度，还是动逻辑结构，还是增强表达力。
  • 具体要求：字数压缩到原来 80%、用专业术语、加分段加标题。
  • 参考示例（可选）：附一段你想要的风格样本，比形容词管用。

标准指令模板

目标效果
{风格 / 语气 / 受众}
润色重点
{流畅性 / 逻辑 / 表达力 / 字数}
具体要求
{分段、标题、术语、压缩}
内容
{粘贴原文}
使用技巧
  • 长文分段喂给 AI，每段分别润色，效果比整篇一把梭好。
  • 第一轮后可再补一句「在不改变意思的前提下，再提升文风优雅度和逻辑清晰度」做多轮迭代。
02

全场景润色指令库（十二大类）

2025-10-13

第二次对话把润色指令按语气、文体、场景、专业领域彻底铺开，做成一张可直接复制的速查表，并导出成 Obsidian 模板。核心用法：先定「指令」，再贴「原文」。

类别代表性指令（可直接套用）
基础润色「润色以下文字，使其语句通顺、逻辑清晰」「改写得更简洁，删多余词」「改善逻辑衔接」。
语气调整正式 / 专业 / 礼貌婉转 / 冷静理性 / 激情 / 温柔安抚 / 轻松幽默 / 坚定有力，逐类各一句指令。
文体转换散文、新闻报道、学术论文、演讲稿、报告体、说明文、随笔、广告文案、书信体、教程体。
写作场景商务邮件、政府公文、工作总结、发言稿、论文摘要、招聘文案、电商产品文案、剧本对白、简历、申请信。
专业领域技术文档、财经分析、法律文书、医学论文、科研报告、艺术评论、市场营销文案。
创意文学文学化、哲思化、抒情化、诗意化、超现实、戏剧化（强化冲突张力）。
结构调整重组段落、改写三段论（引入-论证-总结）、拆分长句合并重复、自动生成标题、重新分段。
批改增强语法标点检查、指出不足并给修改建议、一次给 3 个不同风格改写版、压缩成 100 字摘要、生成 5 个标题。
Obsidian 模板用法：把模板存为 AI润色模板.md 放进 Templates 文件夹，插入后在 {{text}} 处贴原文，再把对应指令连同文本发给 ChatGPT / Claude / 通义等即可。速查一句话版：「润色以下文字，使表达自然流畅」「改为正式专业语气」「改写得轻松口语化」「用诗意语言重写」「提供 3 个不同风格改写版」。
03

系统化润色：先诊断，再动刀

2026-03-05

半年后这次对话把润色升级成一套多阶段编辑系统。核心观点：多数人润色失败是因为一上来就改句子，而真正的写作质量是「结构决定上限、逻辑决定厚度、表达决定锋利度」。

润色四层结构（从下往上修）

正确
语法、拼写、标点、消歧——地基。
清晰
拆长句、语序优化、因果显性化、段落主题明确。
有力
弱动词升级、抽象改具体、长短句交替、提高信息密度。
高级
结构重排、冲突强化、思想升级、反方压力测试。

五阶段任务流程

  • ① 文本诊断：先判类型（公众号情绪类 / 商业决策类 / 学术类 / 通用类），列出问题清单。
  • ② 选路径：公众号→强化钩子冲突；商业→结论前置；学术→术语校准。
  • ③ 分层优化：基础校正→逻辑结构→表达增强→风格适配→密度提升。
  • ④ 深度测试：隐含假设检查、反方攻击模拟、情绪曲线分析。
  • ⑤ 输出：诊断 / 策略 / 优化全文 / 改动说明 / 风险建议。
一行总控指令

三档极简母 Prompt

标准版
先诊断文本类型与核心问题，再重构逻辑结构，提升信息密度与表达力量，最后按最合适的风格重写，并说明关键优化点。
深度版
作为高级编辑，先判类型做诊断，再按「校正→重构逻辑→增强表达→风格适配→密度提升」优化，最后做反方攻击测试与隐含假设检查。
效率版
分析结构问题，重排逻辑，清理冗余，提升密度与节奏，压力测试后输出终稿。
隐藏开关
任何指令后加一句「如有必要，可重构整体结构」——等于给模型开了重排权限，质量跃迁常发生在结构被打破的一刻。
04

洗稿 / 二次创作：拆—重构—重写

2026-03-20

「怎么给文章洗稿」这次对话先划了边界：简单改词换句、拼接他人内容当原创有版权与平台风险；合理的目标是高质量改写与二次创作——不是换皮，而是重构。

人工改写五步

  • 先拆再写：读一遍→关掉原文→用自己的话复述。写的是「理解」不是「原句」。
  • 改结构：把「观点→解释→举例→总结」换成「例子开头→提问→观点→延伸」，结构一变文章就脱胎换骨。
  • 换表达层级：不是换同义词，而是换思维方式。原句「失去后才懂珍惜」→「很多东西不是你不在意，而是你以为它不会消失」。
  • 加你的变量：自己的经验、行业案例、新数据、不同立场——一旦有「你自己的东西」就成了创作。
  • 改语气人设：干货型 / 情绪型 / 吐槽型 / 老板视角，风格一变读者感知完全不同。

用 AI 的正确姿势

  • Step1 让 AI 拆文章：提炼核心观点（≤3条）、列结构、逐段说明、判断写作风格。别直接让它改写。
  • Step2 重建结构：要求「不参考原文表达」，换行文逻辑、调段落顺序、可增删。
  • Step3 重写：不用原文句式，口语化、有观点。
  • Step4 加人味：一个真实场景、一点个人视角，像人说话而非机器总结。
  • Step5 改标题开头：出 5 个标题、改一个前 3 行抓人的开头。
判断标准与进阶玩法
  • 自测：把原文删掉，你还能不能完整写出来？能→在创作；不能→在抄。AI 写完再问「这篇像不像一个人写的」。
  • 多文融合（最强）：把 3 篇同主题文章丢给 AI，要求不按任何一篇结构、融合观点重写——原创度高且更有深度。
  • 风格迁移：指定「像在聊天 / 有点犀利点评 / 有观点而非总结」，或自媒体风、老板思维、行业分析。
05

敏感词与规避：同音字替换

2026-03-19

「把『纪委』换成所有同音字并组词」是一次很具体的内容安全练习：写文章遇到敏感词时，如何既保留意思又顺利过审。

场景建议替换
写现实内容优先用「监督机构 / 内控部门 / 合规委员会 / 风控部门 / 相关部门」，比单纯谐音自然。
句子改写「纪委介入调查」→「相关监督部门介入调查」；「被纪委约谈」→「被相关部门约谈」；「纪委通报」→「官方通报」。
小说人名化不考虑音调时可重组为「纪伟 / 纪炜 / 纪纬」（最像真名），文艺向用「纪蔚 / 纪唯」，完全脱离原词可用「纪文 / 纪然 / 纪川」。

配套的「公众号写作助手」对话则是把这套能力固定成一个项目：后续每次给一句话，就让它按约定的角色与输出格式产出推文。
