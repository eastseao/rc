我想给文章都加上分类，并在pages/里加入一个分类的.md页面

你可以通过以下方式为文章添加分类，并创建一个新的分类页面：

1. 为文章添加分类

在每篇文章的 front matter 中，添加 categories 字段。你可以为每篇文章添加一个或多个分类。

例如：

---
layout: post
title: "我的第一篇文章"
date: 2025-11-09
categories: [技术, 编程]
tags: [Jekyll, Blog]
---

2. 创建分类页面

在 pages/ 目录下，创建一个新的 .md 文件，用来展示所有分类的列表。例如，创建一个 categories.md 文件。

---
layout: page
title: "分类"
permalink: /categories/
icon: fas fa-list-alt
---

<h2>文章分类</h2>

<ul>
  {% for category in site.categories %}
    <li><a href="{{ site.baseurl }}/categories/{{ category[0] }}">{{ category[0] }}</a> ({{ category[1].size }})</li>
  {% endfor %}
</ul>

这段代码会列出你所有的分类，并且每个分类都会链接到该分类的页面。

3. 显示特定分类的文章

你可以为每个分类创建一个页面，列出属于该分类的文章。为此，在 categories/ 目录下创建一个新的 .md 文件，并按以下方式修改：

---
layout: category
title: "技术"
permalink: /categories/技术/
icon: fas fa-laptop-code
---

{% for post in site.categories.技术 %}
  <h3><a href="{{ post.url }}">{{ post.title }}</a></h3>
  <p>{{ post.date | date: "%B %d, %Y" }}</p>
  <p>{{ post.excerpt }}</p>
{% endfor %}

这段代码会在 categories/技术/ 页面上列出所有属于 技术 分类的文章。

4. 调整 _config.yml

确保在 _config.yml 中启用分类功能：

defaults:
  - scope:
      path: "posts"
    values:
      categories: []

完成后，你的博客会有一个分类页面，并且每个分类下会显示对应的文章。

点击3的页面，一片空白

明白了，这种情况通常是 布局模板 layout: category 不存在或不兼容，所以页面渲染为空。你有两个解决方案：

---

方案 1：使用已有布局 page，在 Markdown 中用 Liquid 生成分类列表

修改你的分类页面，例如 pages/category-tech.md：

---
layout: page
title: "技术分类"
permalink: /categories/技术/
---

<h2>技术分类下的文章</h2>

<ul>
  {% assign posts_in_category = site.categories.技术 %}
  {% for post in posts_in_category %}
    <li>
      <a href="{{ post.url }}">{{ post.title }}</a> - {{ post.date | date: "%Y-%m-%d" }}
    </li>
  {% endfor %}
</ul>

这里不用 layout: category，直接用 page 就可以显示列表。

---

方案 2：自定义一个 category.html 布局

如果你希望用专门的布局：

  1. 在 _layouts/ 目录下创建 category.html，内容示例：
---
layout: default
---

<h1>{{ page.title }}</h1>

<ul>
  {% assign posts_in_category = site.categories[page.category] %}
  {% for post in posts_in_category %}
    <li><a href="{{ post.url }}">{{ post.title }}</a></li>
  {% endfor %}
</ul>
  1. 然后在页面 front matter 中引用：
---
layout: category
title: 技术分类
category: 技术
permalink: /categories/技术/
---

---

✅ 总结： 空白页大多数是因为 layout: category 不存在或 Liquid 变量没写对。最简单方法是直接用 layout: page + 在页面内写 Liquid 循环生成文章列表。

明白了，你遇到 404 是因为 GitHub Pages 并不会像本地 Jekyll 那样自动生成新的页面文件，如果你只是写了循环生成的链接，但是对应的 .md 文件不存在，点击就会报 404。

    {% assign category_slug = category[0] | slugify %}

      </a>
    </li>
  {% endfor %}

在 pages/categories/ 下手动创建一个 .md 文件，例如 技术.md：

还是不显示文章

明白了，你现在遇到的问题是分类页不显示文章，即使模板正确，也没有文章被渲染出来。这在 Jekyll / GitHub Pages 上最常见的原因是 文章的 front matter 分类没有被正确识别 或 文章文件路径不在 _posts 目录。我们一步步排查：

---

1️⃣ 确认文章位置

  • GitHub Pages 默认只会读取 _posts 目录下的文章。
  • 文件命名必须符合 Jekyll 规范：YYYY-MM-DD-标题.md

例如：_posts/2025-11-09-感悟文章.md

如果你的文章不在 _posts 目录，site.categories 是无法识别的。

---

2️⃣ 确认 front matter 分类字段

每篇文章必须包含：

---
layout: post
title: "我的感悟文章"
date: 2025-11-09
categories: [感悟]
---

✅ 注意事项：

  • categories 必须是 数组形式 [感悟] 或单值 categories: 感悟。
  • 中文分类名必须和分类页里使用的完全一致。
  • 不要写成 category（少了 s）或者其他拼写。

---

3️⃣ 测试分类是否识别

在分类页里临时加一行：

<p>感悟分类文章数量：{{ site.categories.感悟 | size }}</p>
  • 如果输出是 0 → 说明 Jekyll 没有识别文章分类。
  • 如果输出大于 0 → 说明模板循环有问题。

---

4️⃣ 简单可用模板（确保显示文章）

---
layout: page
title: "感悟分类"
permalink: /categories/感悟/
---

{% endfor %}

{% if posts_in_category.size == 0 %}
<p>目前还没有文章归类到“感悟”。</p>
{% endif %}
用最简单的 Markdown 列表和链接渲染，确保不会因为 HTML 或 CSS 问题导致空白。

  1. 文章必须在 _posts 目录。

❌ posts/xxx.md 或 pages/xxx.md 或 文章名.md → 不算博客文章

pages/xx.md

_posts/  ✅

---

🧭 第一步：确认 Markdown 是否干扰了 Liquid 渲染

Jekyll 对 .md 文件的处理顺序是：

Front matter → Liquid → Markdown → Layout

有时，如果分类页面写成 .md 且模板中有 HTML 或 Liquid 逻辑， 它会被 Markdown “吃掉”一部分标签。

解决方法：把分类页从 .md 改成 .html。

---

✅ 操作

把原来的：

pages/categories/ganwu.md

改名为：

pages/categories/ganwu.html

内容改成：

---
layout: simple
category_name: "感悟"
permalink: /categories/ganwu/
title: "感悟分类"
---

<h1>{{ page.title }}</h1>

{% assign posts_in_category = site.categories[page.category_name] %}
<p>共 {{ posts_in_category | size }} 篇文章</p>

{% if posts_in_category.size > 0 %}
  <ul>
    {% for post in posts_in_category %}
      <li>
        <a href="{{ post.url }}">{{ post.title }}</a> - 
        <span style="color: #888;">{{ post.date | date: "%Y-%m-%d" }}</span>
      </li>
    {% endfor %}
  </ul>
{% else %}
  <p>目前还没有文章归类到“{{ page.category_name }}”。</p>
{% endif %}

---

🧭 第二步：确认 layout: simple 真被加载

打开页面后，按 F12 → 查看页面源代码。 看看最上方 <title> 是否是 “感悟分类”。

如果 <title> 没变，那 Jekyll 仍在用主题默认的 layout，而不是我们的 simple.html。

如果是这样，请尝试：

layout: null

直接让页面不使用任何布局，确保渲染逻辑来自文件本身。

---

🧭 第三步：临时调试输出所有分类和文章
