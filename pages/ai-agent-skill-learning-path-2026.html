系统学习 8 模块 + 4 阶段路线

来源：055
模块学什么
Prompt Engineering角色、任务、约束、输出格式、few-shot
Workflow多步任务拆分、状态传递、分支
Tool Use工具描述、参数设计、错误处理
Memory短期/长期记忆、向量检索、遗忘
PlanningReAct、Chain-of-Thought、反思
Multi-Agent分工、通信、冲突解决
Knowledge Base / RAG切片、索引、召回、重排
Framework主流框架怎么选、怎么搭
4 阶段路线：L1 会用（写 Prompt）→ L2 会搭（拼 Workflow）→ L3 会设计（定架构）→ L4 会商业化（落业务）。不要跳级——直接学框架会因为没体感而劝退。
