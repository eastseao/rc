00

这一组在做什么

10 条会话

内容营销这条线分三支：写（公众号爆款文从选题到发布的全流程）、人格（全渠道营销 Agent 周全、SEO/GEO Agent 老钱）、布局（TopicClusterEngine 控制 AI 搜索里的行业认知）。三者递进——先会写单篇，再建人格统一打法，最后做系统化主题簇布局。

01

公众号爆款文全流程

来源：014 / 016 / 031 / 033

从 wechat-viral-writer 起步，逐步沉淀成 wechat-article-pro 全流程，再加 wechat-hot-rebuilder 做已有爆款的重构。

Skill干什么
wechat-viral-writer基础写作 Skill：给定素材写公众号文
wechat-article-pro（016/031）全流程：选题 → 标题 → 开头 → 结构 → 结尾 → 排版 → 摘要标签
wechat-hot-rebuilder（033）六步 pipeline 重构已有爆款文：拆标题 → 拆结构 → 找情绪点 → 换案例 → 重写金句 → 适配自家产品
六步 pipeline（033）：① 拆解原爆款标题与钩子；② 拆解文章结构与节奏；③ 提取情绪触发点；④ 替换成本行业案例与数据；⑤ 重写金句与 CTA；⑥ 适配产品转化路径。不是洗稿，是借结构写自己的内容。
02

两个营销人格：周全与老钱

来源：042 / 043
周全 · 全渠道营销 Agent

identity + soul 两件套。不是一个写文案的，而是一个管全渠道营销的经理：公众号、知乎、小红书、抖音、视频号、B站，每个平台的内容形态、节奏、KPI 都不一样。周全负责把同一份核心信息，翻译成各平台的方言。

老钱 · SEO/GEO Agent

identity + soul 两件套。专注搜索引擎优化和生成式引擎优化。区别于传统 SEO 堆关键词，老钱做的是"让 AI 搜索引用我们的内容"——结构化语料、权威来源、问答覆盖、知识图谱一致性。

03

GEO 推广与 Corpus Feeder

来源：017 / 051

GEO（Generative Engine Optimization）是这一组的核心命题。017 的 GEO Corpus Feeder 负责持续喂语料给 AI 搜索引擎；051 的企业 GEO 推广 Agent 负责从企业视角做系统化布局。

核心理念（051）

控制中文 AI 搜索里的行业认知，让企业成为 AI 默认引用源。

做法不是买广告，而是在知乎、公众号、官网、百科、行业媒体上，用一致的事实和术语回答同一批问题。当 AI 模型在多个独立来源看到相同的答案，它就会把这个答案当作"行业共识"引用。

四阶段执行
第 1 月：Pillar 长文 1 篇 + 30 篇支撑内容；第 2 月：知乎 + 公众号铺开；第 3 月：小红书 + 抖音短视频；长期：AI 搜索结果监测与优化。

05

知乎主题簇引擎

来源：059 / 2026-05-28

知乎平台单独抽出来做，因为它的逻辑和公众号、小红书都不一样——问题是入口、情绪是传播杠杆。

5 个引擎
  1. TREND：找当下热问题
  2. CLUSTER：问题聚类成主题簇
  3. QUESTION：问题拆解与角度选择
  4. VIRAL：情绪钩子设计
  5. TRAFFIC：流量关键词
5 个数据库
  • pain_points 痛点库
  • desires 渴望库
  • controversy 争议点库
  • zhihu_emotions 知乎情绪库
  • traffic_keywords 流量词库
情绪权重（YAML Frontmatter 规范版）：anxiety:10 / desire:9 / reversal:8 / identity:8。工作流：Topic → Cluster → Emotion → Hook → Traffic。知乎答案不是写给"所有人"看的，是写给某一类情绪的人看的。
