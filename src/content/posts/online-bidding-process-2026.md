## 01 · 四阶段流程与关键要求（招标 → 投标 → 开标评标 → 中标履约）

线上招投标流程主要包含四个阶段，每阶段的流程节点与合规要求照录如下。

<details open><summary>一、招标阶段（发布公告前）<span>项目准备 → 编标 → 发公告</span></summary><div><p>流程：项目准备与登记 → 编制与确认招标文件 → 发布招标公告。</p><ul><li><b>主体责任</b>：招标人（或代理机构）是组织核心，需对文件内容负责。</li><li><b>公平竞争</b>：严禁设置不合理条件限制、排斥潜在投标人或外地经营者。</li><li><b>信息公开</b>：招标计划、公告等需在指定公共平台发布。</li></ul></div></details>

<details><summary>二、投标阶段（公告发布后）<span>注册 → 取文件 → 加密上传</span></summary><div><p>流程：供应商注册/登录 → 获取招标文件 → 编制/加密投标文件 → 在截止前上传。</p><ul><li><b>主体注册</b>：需在交易平台完成信息注册和审核。</li><li><b>文件制作</b>：必须使用官方指定工具制作，符合格式要求。</li><li><b>文件递交</b>：须在截止时间前完成加密上传。</li></ul></div></details>

<details><summary>三、开标与评标阶段<span>解密 → 资格审查 → 评标 → 结果</span></summary><div><p>流程：(线上)开标与解密 → 资格审查 → (线上)评标 → 发布评标结果。</p><ul><li><b>在线开标</b>：投标人远程在线解密，过程公开。</li><li><b>专家抽取</b>：系统从专家库随机抽取，评标可能远程异地。</li><li><b>评审方式</b>：推广「暗标评审」（隐藏投标人信息）；探索「评定分离」。</li></ul></div></details>

<details><summary>四、中标与履约阶段<span>公示 → 通知 → 签合同 → 履约验收</span></summary><div><p>流程：结果公示 → 发出中标通知 → 签订并公开合同 → 履约与验收。</p><ul><li><b>结果公示</b>：对未中标者需告知原因。</li><li><b>合同管理</b>：需在线签订合同并公开。</li><li><b>履约跟踪</b>：招标人需跟踪项目履约、强化验收；资料保存期<b>不少于 15 年</b>。</li></ul></div></details>

## 02 · 需要特别关注的新变化（2026 政策动态）

| 方向 | 要点 |
|---|---|
| **招标人责任加强** | 2026 年 1 月起实施的《招标人主体责任履行指引》要求招标人加强**中标后履约管理**（如核查人员到岗、监督分包），并赋予其**定标前对候选人的深度核验权**。 |
| **全国统一大市场** | 2026 年 2 月起施行的新规，严厉禁止在招投标中**设置地方保护、所有制歧视等不合理限制**。 |
| **降低成本** | 全面推广**电子保函**替代现金保证金。 |
| **评审创新** | 广泛应用**远程异地评标、智能辅助评标**等方式。 |

## 03 · 参与线上招投标的具体建议（投标人视角）

| 建议 | 要点 |
|---|---|
| **1. 准备数字证书（CA 锁）** | 参与全流程电子招投标的「网络身份证」，需提前向交易平台认可的机构申办。 |
| **2. 仔细阅读招标文件** | 特别关注资质要求、技术规范、评标办法和格式化条款（如投标函、承诺书）；可参考最新行业示范文本。 |
| **3. 合规编制投标文件** | 使用官方指定工具制作确保格式兼容；确保所有资质、业绩、人员证明真实有效，**杜绝任何造假**（新规下造假风险极高）；合理报价，避免「异常低价」。 |
| **4. 熟练掌握线上操作** | 提前熟悉交易平台，练习文件上传、加解密、在线开标等操作。 |
| **5. 重视投标后工作** | 关注异议（质疑）和投诉的法定时限；一旦中标，**严格履行合同**，履约表现会影响未来投标机会。 |

> **说明**：如需特定行业（政府采购、建筑工程）或具体省市线上平台的更详细规则，需结合当地平台规则进一步确认。
