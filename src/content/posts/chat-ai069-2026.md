## Q1 · 安卓版OpenClaw怎么连接（第 1 轮对话）

> **提问：** 安卓版OpenClaw怎么连接

如果你安装的是**安卓版 OpenClaw 官方 App**，它**不能单独运行**，必须先连接到一台运行**OpenClaw Gateway**的电脑（Windows、Linux 或 macOS）。Android 只是一个 Companion（伴侣）节点。citeturn0search1turn0search2

##### 连接步骤

###### 1️⃣ 先在电脑启动 Gateway

安装 OpenClaw 后，在电脑执行：

```
openclaw gateway --port 18789 --verbose
```

默认会监听：

```
ws://电脑IP:18789
```

如果在公网或 Tailscale 上使用，建议开启 TLS（`wss://`）。citeturn0search1

---

###### 2️⃣ 打开 Android App

进入**Connect**页面。

有两种连接方式：

- Setup Code（推荐）

- 在电脑生成 Setup Code 或二维码。 - 手机输入或扫描即可。

- Manual（手动）

填写：

```
Host：电脑IP
Port：18789
TLS：关闭（局域网）
```

如果是公网/Tailscale：

```
Host：你的域名
Port：443（或你的端口）
TLS：开启
```

citeturn0search1turn0search0

---

###### 3️⃣ 电脑批准配对

第一次连接需要批准设备：

```
openclaw devices list
```

查看请求，然后：

```
openclaw devices approve <requestId>
```

批准后手机就会连接成功。citeturn0search0turn0search1

---

##### 常见连接失败原因

- ❌ Gateway 没启动

- ❌ 手机和电脑不在同一局域网

- ❌ Host 填写错误（建议填写电脑局域网 IP，不要写 localhost ）

- ❌ 18789 端口被防火墙拦截

- ❌ 第一次连接后没有执行 devices approve

## Q2 · 是Google play版本（第 2 轮对话）

> **提问：** 是Google play版本

如果是**Google Play 官方版 OpenClaw Android**，那么它本身**不是独立版**，必须连接到一台运行**OpenClaw Gateway**的电脑（Windows/macOS/Linux）才能使用。citeturn0search1turn0search0

##### 我先确认一下你的情况

你现在是哪一种？

1. 已经在 Windows 上安装好了 OpenClaw ，只是手机不知道怎么连接。

1. 还没有安装电脑端 ，只有手机 App。

---

##### 如果电脑已经安装好了

在 Windows 上：

1. 启动 Gateway

```
   openclaw gateway --port 18789
```

或按照新版安装流程： ```bash openclaw onboard --install-daemon``` Gateway 默认运行在 18789 端口。citeturn0search7turn0search1

1. 手机打开 Connect 页面。

1. 选择：

-**Setup Code（推荐）**- 或**Manual（手动）**

1. 如果选择 Manual，填写：

-**Host**：电脑局域网 IP（例如`192.168.1.100`） -**Port**：`18789`-**TLS**：关闭（同一 Wi-Fi）

1. 第一次连接后，需要在电脑批准配对：

```
   openclaw devices list
   openclaw devices approve <requestId>
```

批准后即可正常连接。citeturn0search1turn0search0

## Q3 · 有官方独立版吗（第 3 轮对话）

> **提问：** 有官方独立版吗

目前**没有官方独立版 Android**。❌

官方已经明确说明：

- Google Play 版 OpenClaw 是 Companion Node（伴侣节点） 。

- 不能在 Android 手机上直接运行 Gateway 。

- 必须连接一台运行 OpenClaw Gateway 的主机 （macOS、Linux 或 Windows/WSL2）。citeturn0search0turn0search1

也就是说，目前官方架构是：

```
Windows / Linux / macOS
        │
 OpenClaw Gateway
        │
   WebSocket (ws/wss)
        │
 Android / iPhone
 Companion Node
```

手机负责提供：

- 📷 摄像头

- 🎤 麦克风

- 📍 定位

- 📱 通知

- 🖥️ 屏幕共享

- 💬 聊天界面

而真正运行 AI Agent、工具调用、记忆、MCP 等能力的是 Gateway。citeturn0search5turn0search0

##### 如果你想要「手机单独运行」

目前有几种替代方案：

- Termux + OpenClaw ：理论上可以自行部署，但官方并未提供支持，配置复杂且稳定性一般。citeturn0reddit15

- andClaw 等第三方项目：可在 Android 上直接运行，但不是官方产品，兼容性和后续维护需自行评估。

---

##### 我的建议 💡

如果你的目标是**打造真正的 AI 助手**，目前最稳定的方案仍然是：

- 一台 Windows 11 电脑长期运行 OpenClaw Gateway。

- Android 手机安装官方 App，作为随身节点（语音、相机、通知等）。

这种架构也是 OpenClaw 官方重点支持的发展方向。citeturn0search5turn0search0

如果你的需求是**完全离线、仅靠安卓手机运行 AI Agent**，我也可以推荐几款目前比 OpenClaw 更适合纯安卓独立运行的方案。
