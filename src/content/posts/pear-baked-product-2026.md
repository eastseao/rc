## 02 · 工业化烤梨工艺流程（封口+高温杀菌）

工业化烤梨区别于传统现做现吃，核心是灌装封口后高温杀菌，保质期可达12-18个月。

| 工序 | 关键参数与操作要点 |
|---|---|
| **原料挑选** | 砀山酥梨、雪梨等肉质细脆品种；单果200-300g，无机械伤，果核小 |
| **清洗护色** | 去皮后立即浸入1%-2%食盐水，防止氧化变红；护色衔接要快 |
| **预煮热烫** | 95-100°C沸水烫5-10分钟，至梨肉半透明、中心温度≥75°C；灭酶排气软化组织 |
| **配料糖水** | 糖水浓度14%-18%，灌装温度≥85°C热灌装；银耳温水泡发2-4小时撕成小朵 |
| **灌装封口** | 固形物≥55%，顶隙6-8mm；真空封罐0.04-0.05MPa；蒸煮袋热封宽度≥8mm |
| **高温杀菌** | 杀菌公式 10min-20min-15min / 100°C；蒸煮袋需反压0.12-0.15MPa；CCP关键控制点 |
| **反压冷却** | 冷水+压缩空气反压冷却至中心温度≤40°C；玻璃瓶需分段降温 |
| **干燥检漏** | 热风吹干表面；37°C±2°C恒温库静置7天，剔除胀袋胖听 |
| **贴标入库** | 喷码生产日期，常温避光储存；保质期12-18个月 |

> **工艺核心提醒**
> - **护色衔接要快**：去皮后暴露空气极易变红，建议30秒内进入护色池。
> - **杀菌公式需验证**：配料含银耳、枸杞等低酸辅料，建议做热穿透测试（F值测定）确保商业无菌。
> - **反压冷却不可省略**：蒸煮袋杀菌结束必须维持反压，否则极易破袋渗漏。

## 04 · 枇杷原料形态说明（入碗前是什么样）

制作258g碗装枇杷烤梨时，枇杷原料在投入生产前的状态是**去皮、去核并经护色处理的完整果肉或果块**。

| 环节 | 标准与要求 |
|---|---|
| **鲜果选择** | 新鲜良好、成熟适度（八九成熟）、风味正常；剔除霉烂、病虫害及机械损伤果 |
| **外观标准** | 个头大而匀称、倒卵形、果皮鲜艳橙黄色、表面茸毛完整 |
| **内在品质** | 肉质致密而厚、甜酸适口、果核小、形态完整；优选洛阳青、大红袍等品种 |
| **热烫去皮** | 85-90°C热水短时热烫，果皮易剥时立即冷水冷却，剥皮去核 |
| **护色分选** | 剥皮后立即浸入1%盐水护色；分选保留色泽黄或橙黄、形态完整的优质部分 |

> **商业备选方案**：为简化操作、稳定品质并实现全年生产，部分商用配方直接选用合规的**枇杷罐头**作为原料，已通过杀菌工艺，可直接投入烤梨碗复配。无论鲜果还是罐头，最终入碗枇杷均应达到：**色泽自然橙黄、形态完整、软糯成型、风味甜酸**。
