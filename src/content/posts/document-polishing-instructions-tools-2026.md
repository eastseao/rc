## 01 · 文档润色指令大全（00652 · 2026-03-05）

整合学术论文、技术文档、商业报告、新媒体文案等多场景润色需求，按优化维度与应用场景分类。以下为十大维度核心指令，附精细化操作、高级策略、场景深度优化与润色流程方法论。

| 维度 | 核心指令（可直接复制） |
|---|---|
| **基础语言优化** | ①语法纠错与通顺："修正文本中的语法语病与标点错误，删除冗余修饰成分，确保语句通顺简洁。" ②词语精准度："替换重复出现的动词/形容词，优化词语搭配。" ③长难句拆分："将超过30个字的句子拆分为两个独立句子。" ④语序调整：核心信息前置。 ⑤冗余词删除：删除"基本上、大概、其实"等填充词。 ⑥被动语态转主动。 |
| **逻辑与结构** | ⑦逻辑连接强化：段落间添加过渡句。 ⑧因果链强化：用"由于…导致…因此…"重建逻辑链。 ⑨信息重组：按重要性/时间线/逻辑递进排列。 ⑩主题一致性。 ⑪结构化拆分：长段拆为"观点+论据+小结"并加小标题。 |
| **文体与风格适配** | ⑫学术严谨化：口语转学术，增加"综上所述""本研究表明"。 ⑬商务简练化：金字塔结构，核心观点段首。 ⑭新媒体化：短句、钩子开头、留白。 ⑮技术文档正式化。 ⑯风格模仿特定作家。 |
| **学术论文专项** | ⑰摘要优化：提炼研究问题与学术价值。 ⑱文献综述提升：批判性评价，找到研究空白。 ⑲研究方法严谨化。 ⑳讨论与结论深化。 ㉑批判性思维增强。 |
| **降重与去AI化** | ㉒降AIGC率：自然人类风格，避免程式化。 ㉓句式多样化：长短句、反问、陈述交替。 ㉔加入个人化细节。 ㉕同义词替换与句式重组。 |
| **表达强化** | ㉖数据具象化："留存提升25%"→"每4个用户多1个持续使用"。 ㉗感官细节补充。 ㉘修辞手法植入（比喻+排比）。 ㉙情感共鸣设计。 |
| **技术与数据文档** | ㉚术语统一。 ㉛流程可视化（转 Mermaid）。 ㉜风险明确化："当…时，会出现…"。 ㉝操作步骤化：有序列表+预期结果。 |
| **商务与营销** | ㉞价值转化：技术参数→商业价值。 ㉟FAB结构改写（特性-优势-利益）。 ㊱行动号召强化。 |
| **字数与格式** | ㊲文章缩写/扩写至指定字数。 ㊳格式规范化（学术格式、APA/GB-T 参考文献）。 |
| **综合终审** | ㊹全维度优化："作为资深编辑，从术语准确性、逻辑严密性、可读性、格式标准化全维度优化本文，输出对比说明。" |

> **使用建议**
> - **组合使用：**按"基础修正 → 逻辑重建 → 风格统一 → 细节完善"流程进行。

## 03 · 面板图标说明（01295 · 2026-06-11）

"Panel 图标"指软件界面中代表面板、侧边栏、控制面板或仪表盘的图标。从典型视觉样式、Unicode 符号、主流图标库名称三方面整理。

| 图标库 | 面板图标名称与代码 |
|---|---|
| **Unicode 符号** | ▤ (U+25A4) 上三行填充方块；▥ (U+25A5) 下三行填充方块；▦ (U+25A6) 左三列填充方块；⛶ (U+26F6) 四角方块；⚙ (U+2699) 齿轮（常代指控制面板）。 |
| **Material Icons (Google)** | dashboard（仪表盘）、space_dashboard（空间面板）、view_quilt（宫格面板）、widgets（小部件面板）、tune（调谐滑块）。用法：`<span class="material-icons">space_dashboard</span>` |
| **Font Awesome** | fa-border-all（全边框表格）、fa-th / fa-th-large（网格面板）、fa-grip-horizontal（水平抓手）、fa-sliders-h（水平滑块）、fa-chalkboard（演示面板）。 |
| **Tabler / Feather 等** | layout-sidebar（侧边栏面板）、layout-dashboard（仪表盘布局）、settings（通用控制面板）。 |

> **典型视觉样式**：带分栏的矩形（暗示侧面板）；滑块与旋钮组合（参数调节）；多窗口层叠（仪表盘）；方块内嵌横线/竖线（仪表盘布局）。
