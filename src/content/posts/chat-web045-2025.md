## Q2 · 采购单价加载失败，请检查路径或格式（第 2 轮对话）

> **提问：** 采购单价加载失败，请检查路径或格式

明白了，这说明你的页面无法正确加载`TZ/data.json`文件。出现这个问题的原因通常有以下几种：

---

##### 1️⃣ 路径错误

你现在的 fetch 是：

```
fetch('TZ/data.json?_v=' + Date.now())
```

- 这个路径是相对于当前 HTML 页面的。

- 如果你的 HTML 在 根目录/index.html ，而 data.json 在 根目录/TZ/data.json ，这个写法是对的。

- 如果 data.json 在别的目录或 HTML 在子目录里，就会找不到文件。

✅**解决办法**：

- 确认 HTML 文件位置与 TZ/data.json 相对路径正确。

- 如果 HTML 在 root/page/index.html ，而 data.json 在 root/TZ/data.json ，就要改为：

```
fetch('../../TZ/data.json?_v=' + Date.now())
```

---

##### 2️⃣ JSON 格式错误

- fetch 成功返回，但 JSON 格式有问题（例如不是数组，或者字段名不对）。

- 你可以在浏览器直接访问 http://你的域名/TZ/data.json ，看看能否正常打开。

- 脚本里我写了：

```
if (!Array.isArray(data)) throw new Error("采购单价数据格式错误，必须为数组");
```

如果 JSON 是对象而不是数组，就会报错。

✅**解决办法**：

- 确认 data.json 是数组形式：

```json
[
  {"物料项目号":"M001", "采购单价":12.3},
  {"物料项目号":"M002", "采购单价":9.8}
]
```

---

##### 3️⃣ CORS / 本地直接打开问题

- 如果你直接用浏览器打开本地 HTML（ file:// 协议），浏览器可能禁止 fetch 本地 JSON 文件，导致加载失败。

✅**解决办法**：

function searchData() {
  const year = document.getElementById("year").value.trim();

    const projectNameStr = item["项目名称"] || "";
