## Q1 · github desktop汉化（第 1 轮对话）

> **提问：** github desktop汉化

GitHub Desktop 官方版本暂时**没有内置中文界面**，但可以通过**第三方汉化补丁**来实现中文显示。下面我教你两种方法：

---

#### 🧩 方法一：使用第三方汉化补丁（推荐）

##### ✅ 适用系统

Windows / macOS

##### ⚙️ 操作步骤

1. 下载 GitHub Desktop 原版

- 官网地址：https://desktop.github.com/ - 安装好后不要启动程序（或先退出）。

1. 下载汉化补丁

- 汉化补丁项目地址（推荐开源安全来源）： 👉[https://github.com/baokangwang/GitHubDesktopZh](https://github.com/baokangwang/GitHubDesktopZh)

1. 运行补丁程序

- 进入上面项目页面，点击右侧的「Releases」标签。 - 下载最新的`.zip`文件。 - 解压后双击运行`GitHubDesktopZh.exe`。 - 按提示选择你电脑上的 GitHub Desktop 安装目录（一般在`C:\Users\<用户名>\AppData\Local\GitHubDesktop`）。 - 程序会自动替换语言包。

1. 重新打开 GitHub Desktop

- 启动后界面就会变成中文。

---

#### 🧼 方法二：手动替换语言文件（适合进阶用户）

如果不想运行补丁程序，可以手动替换：

1. 找到 GitHub Desktop 的安装目录

```
   C:\Users\<用户名>\AppData\Local\GitHubDesktop\app-<版本号>\resources\app\renderer
```

1. 下载语言文件（同上项目中的 zh-CN.json 文件）。

1. 替换原目录下的英文语言文件（或编辑 main.js 语言加载逻辑）。

> ⚠️ 手动方法适合对 Electron 应用结构熟悉的用户，一般建议直接用自动补丁。

---

#### 🚀 其他提示

- 汉化补丁不会修改程序逻辑，只是替换界面文字。

- 每次 GitHub Desktop 更新后， 需要重新打汉化补丁 。

- 如果出问题，可以删除整个安装目录重新安装原版。

#### ⚠️ 风险与注意事项

- 版本兼容性关键 ：大多数汉化补丁只能适用于特定版本的 GitHub Desktop。若你安装的版本高于补丁支持范围，可能导致程序报错或无法启动。

- 安全性问题 ：第三方汉化补丁属于对程序的修改，可能带有安全风险（被篡改、植入恶意代码等）。尤其是来源不明的补丁资源要特别小心。

- 更新覆盖 ：GitHub Desktop 更新后，汉化补丁经常会被覆盖或失效，你需要在每次升级后重新汉化或等待补丁作者更新。

- 官方未支持 ：因为官方并没有官方中文界面，使用汉化补丁属于非官方行为，应做好备份与风险承担。

---

#### 🔧 给你的建议：如果要 “可控可用”的汉化方案

1. 锁定 GitHub Desktop 的版本

安装一个与现有汉化补丁兼容的版本（例如 3.4.5、3.4.8 等），避免随意升级。

1. 使用较新的社区汉化版本 / 中文版程序

像**zetaloop / desktop**提供已经汉化的客户端安装包，是一种“跳过补丁制作”的方式 citeturn0search1。如果这个项目还在维护，可以尝试看它最新的版本是否兼容你系统。

1. 自行手动汉化（如果懂技术的话）

如果你有一定技术功底，可以尝试自己寻找`main.js`/`renderer.js`中的英文字符串，将它们替换为中文版本，然后重新打包或覆盖。这种方式灵活，但需要非常小心备份原文件。

1. 参与社区 / 发起新的汉化项目

由于现有的补丁维护可能不稳定，如果你有意愿或时间，可以考虑在 GitHub 上开一个新的汉化项目，跟踪新版 GitHub Desktop 的更新，持续维护汉化。
