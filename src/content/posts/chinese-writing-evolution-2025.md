## 01 · 汉字演变七体（00087 · 上半）

汉字的演变总体沿「**由繁趋简、由象形趋符号化、由篆趋隶楷**」的方向展开。下面按出现先后列出七种主要书体。

| 书体 | 流行时代 | 特点 |
|---|---|---|
| **甲骨文** | 商代 | 刻在龟甲兽骨上，象形程度高，结构不定，是现存最早的成熟汉字系统。 |
| **金文（钟鼎文）** | 商周 | 铸刻在青铜器上，笔画肥厚、结构渐趋整齐。 |
| **小篆** | 秦 | 秦统一文字后的标准字体，线条匀净、字形长圆，奠定「书同文」。 |
| **隶书** | 秦汉 | 变圆转为方折，笔画有波磔，是古今文字的分水岭（隶变）。 |
| **楷书（真书）** | 汉末至今 | 形体方正、笔画平直，成为后世通用的标准手写与印刷字体。 |
| **行书** | 汉末至今 | 介于楷书与草书之间，流畅易识，最实用的手写体。 |
| **草书** | 汉以后 | 笔画简省连绵，艺术性强而辨识难，分章草、今草、狂草。 |

一句话主线：**甲骨文 → 金文 → 小篆 → 隶书 → 楷书**是字形规范化的主轴，行书与草书则是书写速度与艺术性的两翼。

## 02 · 先秦：夏商西周与春秋战国（00087 · 中段）

文字成熟之后，笔记把镜头拉到王朝本身：从传说中的夏，到有甲骨文实证的商，再到分封制的周与礼崩乐坏的春秋战国。

<details open><summary>夏与商：从传说到实证<span>约前21—前11世纪</span></summary><div><ul><li><b>夏</b>：传统史载中的第一个世袭王朝，禹传启、家天下；考古上仍在探索其与二里头文化的对应。</li><li><b>商</b>：有甲骨文与青铜器实证的成熟王朝，盘庚迁殷后稳定，末代纣王败于牧野之战。</li></ul></div></details>

<details><summary>西周与东周：分封与争霸<span>前1046—前221</span></summary><div><ul><li><b>西周</b>：武王伐纣建立，行分封、宗法、礼乐；西周晚期幽王失国，平王东迁。</li><li><b>东周（春秋 / 战国）</b>：王室衰微，诸侯争霸；春秋五霸、战国七雄相继登场，由分裂走向局部统一，最终由秦完成。</li></ul></div></details>

## 03 · 秦汉与魏晋：大一统到分裂（00087 · 中段）

| 政权 | 时间 | 关键线索 |
|---|---|---|
| **秦** | 前221—前207 | 嬴政统一六国，书同文、车同轨、行郡县；二世而亡，陈胜吴广起义后天下大乱。 |
| **楚汉战争** | 前206—前202 | 项羽、刘邦相争，垓下之战后刘邦胜出，建立汉朝。 |
| **西汉** | 前202—公元8 | 文景之治、汉武盛世；武帝北击匈奴、独尊儒术、通西域。 |
| **新 / 东汉** | 8—220 | 王莽代汉改「新」，旋即天下大乱；刘秀重建东汉，后有黄巾起义。 |
| **三国** | 220—280 | 魏、蜀、吴鼎立：曹魏篡汉、蜀汉刘备、孙吴据江东。 |
| **西晋 / 东晋** | 266—420 | 西晋短暂统一后八王之乱、永嘉南渡；东晋偏安江南，门阀政治。 |

## 04 · 南北朝、隋唐与五代十国（00087 · 后段）

东晋之后是长期南北分裂，再由隋重新统一；唐盛极而衰，又陷入五代十国的军阀割据。

<details open><summary>南北朝：南北对峙<span>420—589</span></summary><div><ul><li><b>北朝</b>：鲜卑拓跋北魏统一北方，后分裂为东魏、西魏，再演为北齐、北周。</li><li><b>南朝</b>：宋、齐、梁、陈相继，定都建康，与北朝长期对峙。</li></ul></div></details>

<details><summary>隋与唐：统一与鼎盛<span>581—907</span></summary><div><ul><li><b>隋</b>：北周外戚杨坚代周，灭陈统一；开科举、修大运河，旋即因徭役重而速亡。</li><li><b>唐</b>：李渊建唐，贞观之治、开元盛世为鼎盛；安史之乱由盛转衰，末年藩镇、宦官、党争交织。</li></ul></div></details>

<details><summary>五代十国：分裂重组<span>907—979</span></summary><div><ul><li><b>五代</b>：中原相继更替后梁、后唐、后晋、后汉、后周。</li><li><b>十国</b>：南北各地并立多个割据政权，最终由后周赵匡胤（宋）收束。</li></ul></div></details>

## 05 · 宋元明清与民国（00087 · 尾段）

最后一段从宋的文治、辽金西夏的并立，讲到元的大一统、明清的专制集权，直至清末民初的共和转型。

| 政权 | 时间 | 关键线索 |
|---|---|---|
| **北宋 / 南宋** | 960—1279 | 重文抑武、经济文化繁盛；北宋与辽、西夏并立，靖康之变后南宋偏安江南。 |
| **辽 / 西夏 / 金** | 916—1234 | 北方游牧渔猎政权并立：契丹辽、党项西夏、女真金，金后灭辽与北宋。 |
| **元** | 1271—1368 | 忽必烈定国号元，灭南宋完成大一统；行省制度影响深远。 |
| **明** | 1368—1644 | 朱元璋建立，废丞相、强化皇权；郑和下西洋、明末外忧内患，李自成入京。 |
| **南明** | 1644—1662 | 明亡后宗室在南方建立的流亡政权，最终被清逐一平定。 |
| **清** | 1636—1912 | 满族入关，康雍乾盛世后由盛转衰；鸦片战争后内忧外患，1912 年宣统退位。 |
| **北洋 / 国民政府** | 1912—1949 | 辛亥革命后共和肇建，先后经历北洋政府与国民政府时期。 |
