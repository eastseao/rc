## 01 · 六大模块核心字段体系（结构化提取）

将分散在各份立项报告中的信息归并为六类核心字段，便于横向对比与入库。

| 模块 | 核心字段 |
|---|---|
| **产品定义** | 产品名称、品类定位、目标人群、核心卖点、规格与定价。 |
| **市场与竞争** | 市场规模、增长趋势、主要竞品、差异化机会。 |
| **原料与工艺** | 主要原料、产地与供应、配方工艺、生产方式（自产 / 代工）。 |
| **成本与财务** | 单位成本、毛利率、投资估算、营收预测、回本周期。 |
| **渠道与营销** | 主销渠道、上市节奏、推广预算、品牌打法。 |
| **风险与合规** | 法规标准、标签合规、供应链与市场风险及应对。 |

## 02 · 八大模块编码（检索标签）

为便于按模块快速检索与归类，将立项内容编码为八个模块标签。

| 编码 | 模块 | 说明 |
|---|---|---|
| **M1** | 项目背景 | 立项缘起、市场机会与战略必要性。 |
| **M2** | 市场分析 | 行业规模、趋势、竞争格局与目标市场。 |
| **M3** | 产品方案 | 产品定义、配方、工艺与规格。 |
| **M4** | 资源与建设 | 原料供应、场地、产能与生产组织。 |
| **M5** | 营销计划 | 品牌、渠道、定价与上市推广。 |
| **M6** | 财务评价 | 投资估算、收入成本、回报与敏感性。 |
| **M7** | 风险分析 | 政策、市场、供应链、技术与管理风险。 |
| **M8** | 结论建议 | 综合评价、推荐方案与下一步行动。 |

## 03 · Qclaw 撰写指令模板（可直接套用）

将以下指令交给 Qclaw（或同类文档 Agent），按字段体系自动生成新品立项报告初稿。

指令模板

你是一名食品行业产品经理。请根据以下信息撰写一份新品立项报告，严格按八大模块（M1 项目背景 / M2 市场分析 / M3 产品方案 / M4 资源与建设 / M5 营销计划 / M6 财务评价 / M7 风险分析 / M8 结论建议）组织，每模块用小标题。要求： 1. 数据有据可依，缺数据处标注【待补充】； 2. 财务部分给出单位成本、毛利率、投资估算与回本周期的测算逻辑； 3. 产品宣称须符合食品标签合规，不得出现未获批的保健功能声称； 4. 结尾给出明确的立项建议与下一步行动清单。 已知信息：产品=___；目标人群=___；规格定价=___；主销渠道=___。

> **使用提示**：先按"六大模块字段体系"整理素材，再填入指令模板的已知信息空位，可显著提高生成报告的完整度与可落地性。
