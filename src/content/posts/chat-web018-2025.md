> **提问：** 利用github生成前端网页，可以制作哪些工具，列举越多越好，分类列举

#### 🏠 一、个人与作品类网页

| 类型 | 可制作的工具/网站示例 |
|---|---|

| 📝 博客系统 | Jekyll / Hugo / Hexo / VuePress / Astro / Next.js 博客 |
| 📸 相册与展示 | 图片墙、旅行记录、作品集（Portfolio Gallery） |

| 🎵 音乐展示页 | 喜欢的专辑/歌曲卡片展示，可接入 Spotify/网易云 API |
| 🗺️ 旅行地图 | 展示去过的城市、国家，使用 Leaflet.js / Mapbox 可视化地图 |

#### ⚙️ 五、前端逻辑（js/app.js）

```html
async function loadMaterials() {
  const res = await fetch('data/materials.json');
  const data = await res.json();
  return data;
}

function renderTable(data) {
  const tbody = document.querySelector("#materialTable tbody");
  tbody.innerHTML = "";

  data.forEach(item => {
    const tr = document.createElement("tr");
    tr.innerHTML = `
      <td>${item["物料编码"]}</td>
      <td>${item["物料名称"]}</td>
      <td>${item["供应商"]}</td>
      <td>${item["入库日期"]}</td>
      <td>${item["数量"]}</td>
      <td>${item["单位"]}</td>
    `;
    tbody.appendChild(tr);
  });
}

document.addEventListener("DOMContentLoaded", async () => {
  const materials = await loadMaterials();
  renderTable(materials);

  const searchInput = document.getElementById("searchInput");
  const supplierFilter = document.getElementById("supplierFilter");
  const searchBtn = document.getElementById("searchBtn");

  searchBtn.addEventListener("click", () => {
    const keyword = searchInput.value.trim();
    const supplier = supplierFilter.value;

    const filtered = materials.filter(item => {
      const matchKeyword =
        item["物料名称"].includes(keyword) ||
        item["物料编码"].includes(keyword);
      const matchSupplier = supplier ? item["供应商"] === supplier : true;
      return matchKeyword && matchSupplier;
    });

    renderTable(filtered);
  });
});
```
