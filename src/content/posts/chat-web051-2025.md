## Q1 · 我要调整版权信息的链接：<footer class="text-center t…（第 1 轮对话）

> **提问：** 我要调整版权信息的链接： <footer class="text-center text-gray-500 text-sm mt-8 mb-4"> © 2025 采购部 | <a href="tz/index.html" class="hover:underline">物料单价</a> | <a href="bom/index.html" class="hover:underline">BOM</a> | <a href="CP/index.html" class="hover:underline">成品信息</a> | <a href="product/index.html" class="hover:underline">产品手册</a> </footer> 我的库是trtjkqh.github.io 首页是根目录的index.html 物料单价链接到根目录TZ文件夹下的index.html， BOM链接到根目录bom文件夹下的index.html， 成品信息链接到根目录CP文件夹下的index.html， 产品手册到根目录product文件夹下的index.html 帮我修整下

你已经把说明写得很清楚啦，我帮你把路径按 GitHub Pages 根目录结构修好。 你的站点根是：`https://trtjkqh.github.io/`所以子目录都从根开始写`/`会更稳。

这是修正后的 footer 代码：

```html
<footer class="text-center text-gray-500 text-sm mt-8 mb-4">
  © 2025 采购部 |
  <a href="/TZ/index.html" class="hover:underline">物料单价</a> |
  <a href="/bom/index.html" class="hover:underline">BOM</a> |
  <a href="/CP/index.html" class="hover:underline">成品信息</a> |
  <a href="/product/index.html" class="hover:underline">产品手册</a>
</footer>
```

##### ✅ 这样修改的原因

- 在 GitHub Pages 下，使用 /目录/文件 是 绝对路径 ，不会因为页面在子目录而跳错地址。

- 原来的 tz/index.html 改成了 /TZ/index.html ，注意大小写一致。

你现在只要把这段替换到你的页脚即可。

## Q2 · 链接到首页的，提供单行代码吧（第 2 轮对话）

> **提问：** 链接到首页的，提供单行代码吧

如果只是加一个**链接到首页**的单行代码，给你最简版本：

```html
<a href="/" class="hover:underline">首页</a>
```

👉`"/"`就是根目录首页（index.html） 适用于 GitHub Pages 结构。

如果你想放在版权栏开头，可以变成：

```html
© 2025 采购部 | <a href="/" class="hover:underline">首页</a> |
```
