## Q2 · 图片路径我是不是要加到data文件里？（第 2 轮对话）

> **提问：** 图片路径我是不是要加到data文件里？

非常好的问题 👍 你问得非常关键——**如果每个产品有不同的图片**，那确实需要在`data.json`里加上图片路径字段，否则网页无法知道每个产品该显示哪张图。

下面我来详细说明两种情况👇：

---

#### 🧩 一、如果所有产品都用同一张占位图（比如 Z1.jpg）

那你**不需要修改 data.json**。 在我上面的代码里，这一行：

```
<img src="../assets/product/Z1.jpg" ...>
```

就是直接写死的路径，只要确保这张图片在：

```
assets/product/Z1.jpg
```

位置正确，所有产品都会显示这张图片。 👉 适合你暂时没有具体产品图片时使用。

---

#### 🖼️ 二、如果每个产品都有不同图片（推荐）

那就要在`data.json`每个产品对象里增加一个字段，比如`"图片"`或`"image"`：

```json
[
  {
    "系列": "鲜虫草系列",
    "产品名称": "鲜冬虫夏草-2A",
    "规格": "2A（0.61g-0.8g/支）-27支",
    "价格": 2199,
    "说明": "null",
    "图片": "Z1.jpg"
  },
  {
    "系列": "鲜虫草系列",
    "产品名称": "鲜冬虫夏草-2A",
    "规格": "2A（0.61g-0.8g/支）-81支",
    "价格": 4799,
    "说明": "null",
    "图片": "Z2.jpg"
  },
  {
    "系列": "鲜虫草系列",
    "产品名称": "鲜冬虫夏草-3A",
    "规格": "3A（0.81-1.0g/支）-81支",
    "价格": 9699,
    "说明": "null",
    "图片": "Z3.jpg"
  }
]
```

然后在 HTML 代码中，找到我之前这行：

```
<img src="../assets/product/Z1.jpg" alt="${product.产品名称}" ...>
```

替换成这一行 👇：

```
<img src="../assets/product/${product.图片}" alt="${product.产品名称}" class="w-full h-40 object-cover mb-3 rounded-lg">
```

这样每个产品就会显示它对应的图片了。

---

#### ✅ 最佳实践建议

- 图片统一放在 /assets/product/ 目录中；

- JSON 中只保存文件名（如 "Z1.jpg" ），不要写完整路径；

- 图片名最好与产品名称有逻辑关系，比如 Xian-2A.jpg ，方便维护。
