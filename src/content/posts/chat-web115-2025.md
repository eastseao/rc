## Q1 · 我想在博客里采用Twikoo（第 1 轮对话）

> **提问：** 我想在博客里采用Twikoo

Twikoo 在 Jekyll（尤其是 Beautiful Jekyll、Chirpy 之类的主题）里是个很爽的评论系统，轻量、免备案、前端友好，你的博客又是 GitHub Pages 部署，这正是 Twikoo 的主场。

我给你讲得通透一点，把原理和实际改法都说清楚，让你能顺利接进去。

---

#### 1. Twikoo 的运行方式是前后端分离

前端加载一段 JS 后端是一个数据库 + 云函数 你可以选择：

**A. 腾讯云 CloudBase 免费版（简单、适合新手）** **B. Vercel 部署 Twikoo（也简单）**

你要是在国内访问，CloudBase 更稳；你博客放 GitHub Pages，两种都行。

---

#### 2. 先搭建 Twikoo 云端服务

我给你两个方案，你选一个：

##### **方案 A：CloudBase（推荐）**

1. 打开：https://cloudbase.net/

1. 注册后创建一个环境，选择 按量计费免费套餐

1. 控制台 → 云函数 → 创建云函数，名称填： twikoo

1. 模板选择 “Hello World”

1. 创建后，把 Twikoo 云函数上传：

下载：https://github.com/twikoojs/twikoo 选择`/function/twikoo`这个文件夹压进去

1. 部署 → 得到一个 HTTPS Endpoint

这个地址类似： ```https://xxx-xxxxxx.tcloudbase.net/twikoo```

这个 URL 等下要填到博客里。

---

##### **方案 B：Vercel**

1. fork 项目：https://github.com/twikoojs/twikoo

1. 登录 Vercel，点击 New Project

1. 导入 twikoo 仓库

1. Build 之后你会得到一个 URL，例如：

```
   https://twikoo-yourname.vercel.app
```

也可以用。

---

#### 3. 把 Twikoo 加进你的博客主题

你当前博客是**Beautiful Jekyll 或者 Chirpy**，两种方式都一样 —— 在文章底部插入一段评论区域，然后加载 Twikoo。

我给你一个万能可用的代码。

##### **在你的`_includes/footer.html`或`_layouts/post.html`里加：**

```html
<div id="tcomment"></div>
<script src="https://cdn.jsdelivr.net/npm/twikoo/dist/twikoo.all.min.js"></script>
<script>
  twikoo.init({
    envId: '你的 twikoo url 或 envId',
    el: '#tcomment'
  })
</script>
```

`envId`：

- CloudBase 用你的 环境ID （比如： blog-123abc ）

- 如果你用 Vercel，就填完整的 URL，如：

```
  https://twikoo-yourname.vercel.app
```

别加斜杠。

---

#### 4. 在 Jekyll 页面里显示评论

确保你的博客文章模板（post.html）里有：

```
{% if page.comments != false %}
  {% include comments.html %}
{% endif %}
```

如果没有，你需要创建一个`_includes/comments.html`：

```html
<div id="tcomment"></div>
<script src="https://cdn.jsdelivr.net/npm/twikoo/dist/twikoo.all.min.js"></script>
<script>
  twikoo.init({
    envId: '你的 envId 或 URL',
    el: '#tcomment'
  })
</script>
```

然后在布局文件的结尾加：

```
{% include comments.html %}
```

---

#### 5. 验证你的博客能否成功加载 Twikoo

部署后，随便点开一篇文章，底部应该出现评论框。

第一次加载可能有点慢，你刷新一下。

## Q2 · Beautiful Jekyll（第 2 轮对话）

> **提问：** Beautiful Jekyll

那咱们就对着**Beautiful Jekyll**来接 Twikoo，这个主题的结构比较清爽，只要把评论模块插进去就能工作。你不用担心“放哪”，我已经帮你挑好最稳妥、不会冲突的位置。

下面这套是完全可用的整合方式，只要按步骤操作，你的博客就能直接跑 Twikoo。

---

# 一、在`_includes`里新增一个`comments.html`

你在 GitHub 网页端操作即可。

路径：**`_includes/comments.html`**

内容复制进去（只改 envId 一处）：

```html
<div id="tcomment"></div>

<script src="https://cdn.jsdelivr.net/npm/twikoo/dist/twikoo.all.min.js"></script>
<script>
  twikoo.init({
    envId: '你的 Twikoo envId 或 URL',
    el: '#tcomment'
  })
</script>
```

envId 示例：

- CloudBase： blog-xxxxxx

- Vercel： https://twikoo-yourname.vercel.app

---

# 二、在文章模板底部引入评论模块 Beautiful Jekyll 的文章页面模板是：

**`_layouts/post.html`**

你往文件**最底部**（通常在标签`<article>`结束之后）加入这段：

```
{% if page.comments != false %}
  {% include comments.html %}
{% endif %}
```

这样每篇文章默认都会显示评论。 如果你想让某篇文章不显示，就在 front matter 设置：

```
comments: false
```

---

# 三、确保你的文章布局真的用的是`post`Beautiful Jekyll 写文章通常用 front matter：

```
layout: post
title: xxx
```

如果 layout 是`page`，默认不会载入评论（这是正常的）。

---

# 四、Twikoo 后端说明（你可能已经弄好了） 你只要确保 envId 可用，比如：

CloudBase：

```
blog-xxxxxx
```

Vercel：

```
https://twikoo-yourname.vercel.app
```

直接填进去就能开始用。

path: '{{ page.url }}'
