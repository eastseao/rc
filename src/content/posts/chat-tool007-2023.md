WinXray is a Windows-based software tool for Internet proxy and security management. It is based on the XRay core and supports the protocols V2Ray, Shadowsocks, and Trojan. WinXray is designed to automatically detect and connect to the fastest proxy server, and can switch to an alternate server when connection issues arise. The software also provides the ability to import and configure proxy server settings, including batch import of subscription links and URLs. WinXray is available as a free download and requires Windows 10 or later. The software has been criticized for being slow to respond when switching nodes, and for difficulty in manually configuring new nodes.
