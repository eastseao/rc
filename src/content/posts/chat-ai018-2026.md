```
# 🧠 Competitor Analysis Skill

## 🎯 功能
本技能用于对指定产品或行业进行竞品分析，包括：

- 竞品识别
- 产品对比
- 定价分析
- 渠道拆解
- 营销策略分析
- 用户人群分析
- SWOT分析
- 机会点挖掘

---

输入示例：
```

```
或
```

```

- 价格带分析

- 用户画像

- 增长机会建议
```

```
# 🧩 分析步骤（必须严格执行）

## 1. 竞品识别
- 找出{competitor_count}个核心竞品
- 覆盖不同价格带 & 不同定位

---

## 2. 产品对比（表格输出）
维度：
- 品牌
- 价格
- 规格
- 核心卖点
- 成分/功能
- 包装形式

---

## 3. 价格带分析
- 低 / 中 / 高价格区间划分
- 主流价格带
- 溢价逻辑

---

## 4. 渠道分析
- 各竞品主要渠道
- 渠道占比（估算）
- 是否依赖单一渠道

---

## 5. 营销策略分析
- 内容营销（抖音/小红书）
- 广告打法
- 爆品逻辑
- 是否有IP/人设

---

## 6. 用户画像
- 核心人群
- 使用场景
- 购买动机

---

## 7. SWOT分析（重点）
每个竞品简要SWOT + 行业整体SWOT

---

## 8. 机会点（最重要）
必须输出：
- 产品机会（配方/包装/规格）
- 渠道机会
- 定价机会
- 差异化路径

---

# ⚠️ 输出要求

- 必须结构化
- 多用表格
- 不说废话
- 偏商业决策
```

# 4️⃣ run.py（执行逻辑）

```python
import json
from utils import generate_competitor_list, analyze_price_band, build_swot


def run(params):
    product = params.get("product_name")
    market = params.get("market", "中国")
    platform = params.get("platform", "全渠道")
    count = int(params.get("competitor_count", 5))

    # 1. 获取竞品列表
    competitors = generate_competitor_list(product, count)

    # 2. 构建产品对比
    product_table = []
    for c in competitors:
        product_table.append({
            "brand": c,
            "price": "待分析",
            "spec": "待分析",
            "selling_point": "待分析"
        })

    # 3. 价格分析
    price_analysis = analyze_price_band(competitors)

    # 4. SWOT
    swot = build_swot(competitors)

    result = {
        "product": product,
        "market": market,
        "platform": platform,
        "competitors": competitors,
        "product_table": product_table,
        "price_analysis": price_analysis,
        "swot": swot
    }

    return json.dumps(result, ensure_ascii=False, indent=2)
```

# 5️⃣ utils.py（工具函数）

```python
def generate_competitor_list(product, count):
    base_list = [
        f"{product}品牌A",
        f"{product}品牌B",
        f"{product}品牌C",
        f"{product}品牌D",
        f"{product}品牌E",
        f"{product}品牌F"
    ]
    return base_list[:count]


def analyze_price_band(competitors):
    return {
        "low": "0-20元",
        "mid": "20-50元",
        "high": "50元以上",
        "mainstream": "20-30元"
    }


def build_swot(competitors):
    result = {}
    for c in competitors:
        result[c] = {
            "strength": "品牌/渠道优势",
            "weakness": "产品同质化",
            "opportunity": "市场增长",
            "threat": "价格竞争"
        }
    return result
```
