## 02 · 设计哲学创作指南：任务与哲学生成（00976 · 原文指令中译（一~四））

这是一份英文创作指令的中文翻译与要点提炼。任务分两步：**先建设计哲学**（一种美学运动，输出 .md），**再用画布视觉表达**（输出单页 .pdf 或 .png），作品应为 90% 视觉设计 + 10% 必要文字。

## 03 · 画布创作、隐含参考推导与精修（00976 · 原文指令中译（五~八））

哲学与概念框架立好之后，进入画布阶段：把抽象哲学当作一门"想象学科"的科学圣经来对待——用系统化观察的视觉语言，去研究那些本不可见的主题。

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>00976 · 2026-04-20</span><h3>推导微妙参考：把灵魂织进 DNA</h3></div><div style="padding:14px 16px"><p>在创作画布之前，先识别原始请求中隐含的概念线索。该参考应<b>嵌入艺术本身</b>——不一定是字面的，却始终考究：熟悉该主题的人能直觉感受到，其他人则只体验为精湛的抽象构图。设计哲学提供美学语言，推导出的主题提供灵魂——那条安静的概念 DNA，无形地编织进形态、色彩与构图。</p><div style="border:1px solid #fcd9a8;background:#fdf3e3;border-radius:8px;padding:12px 16px;margin:14px 0"><h5>Jazz 式引用（照录比喻）</h5><ul><li>参考必须被打磨到增强作品深度却不自我声张。像爵士乐手引用另一首歌——只有内行听得出来，但所有人都享受这首曲子。</li></ul></div></div></div>

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>00976 · 2026-04-20</span><h3>画布执行要求：单页、高视觉、零重叠</h3></div><div style="padding:14px 16px"><div style="display:grid;gap:14px;margin:14px 0;grid-template-columns:repeat(2,minmax(0,1fr))"><div style="border:1px solid #dfe6ef;border-radius:8px;padding:16px 20px;background:#fff;margin:14px 0"><dl style="display:grid;grid-template-columns:110px 1fr;gap:8px 16px;margin:14px 0"><dt>视觉语言</dt><dd>采用重复图案与完美形状；借用系统观察的视觉语言——密集的标记积累、重复元素、层次化图案，靠耐心的重复积累意义。</dd><dt>排版气质</dt><dd>稀疏、临床式字体与系统化参考标记，暗示这是一门想象学科中的图表，用对待可观测现象的同等敬畏去对待不可见主题。</dd><dt>调色板</dt><dd>有限、有意、统一的配色；文字始终最少且视觉优先，多数时候字体应为细体。</dd></dl></div><div style="border:1px solid #dfe6ef;border-radius:8px;padding:16px 20px;background:#fff;margin:14px 0"><dl style="display:grid;grid-template-columns:110px 1fr;gap:8px 16px;margin:14px 0"><dt>边界与呼吸</dt><dd>所有元素必须在画布边界内，无重叠，有恰当边距与呼吸空间——这是不可谈判的专业执行底线。</dd><dt>字体处理</dt><dd>从 ./canvas-fonts 目录取用不同字体，让字体本身成为艺术的一部分，而非事后数字排版。</dd><dt>工艺感</dt><dd>作品要看起来花费了无数小时，出自顶尖专家之手，每个细节都完美无瑕，可直接拿去证明专业水准。</dd></dl></div></div></div></div>

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>00976 · 2026-04-20</span><h3>最终精修：不添新物，只炼已成之物</h3></div><div style="padding:14px 16px"><p>用户已声明：&quot;它不够完美。必须是一尘不染的杰作，如同即将在博物馆展出。&quot;精修原则不是加更多图形，而是<b>精炼已有内容</b>，让它极其清晰，完全尊重设计哲学与极简主义。</p><div style="border:1px solid #fcd9a8;background:#fdf3e3;border-radius:8px;padding:12px 16px;margin:14px 0"><h5>精修自问（照录）</h5><ul><li>不要加滤镜、不要重构字体；想的应该是&quot;如何让现有构图更具艺术完整性&quot;。</li><li>如果本能是调用新函数或画一个新形状——<b>停下</b>，转而问：&quot;我如何让已经在这里的东西，更成为一件艺术品？&quot;</li><li>二次打磨：回到代码，进一步精炼抛光，使之成为符合哲学的设计杰作。</li></ul></div><p style="margin-top:14px;margin-bottom:0"><b>多页选项：</b>需要更多页面时，沿同一设计哲学创作各具特色的新页，合入同一 .pdf 或多张 .png。第一页只是整本咖啡桌书的开篇，后续页面提供独特变奏与记忆，有品位地讲述故事。</p></div></div>

## 04 · GitHub 古诗词数据库：六类玩法（01338 · 由简到繁）

手里有一个放在 GitHub 仓库里的古诗词数据库，本身就是一座富矿。按从简单到复杂，可整理出六大类用法。

| 类别 | 具体玩法 |
|---|---|
| **一、在线查询 / 鉴赏站** | 静态站：JSON/Markdown 数据用 VitePress、Docusaurus 生成，GitHub Pages 零成本上线；动态站：Next.js/Nuxt 配 MeiliSearch 或 Lunr.js 前端搜索，或 Flask/FastAPI 做后端，支持模糊搜索、按朝代/作者/词牌筛选；每日诗词 API：无服务器函数返回随机一首，供他人调用。 |
| **二、自动推送与机器人** | 公众号/企业微信/钉钉/飞书机器人：GitHub Actions 定时抽一首经 Webhook 推群；Telegram/Discord 机器人：/random 返回随机诗、/author 李白 列作品；邮件 / RSS 订阅：定时生成诗词邮件，或更新 XML 做成"每日诗词 RSS"。 |
| **三、数据可视化与知识图谱** | 诗人游历地图（有写作地点就标"李白一生足迹"，Leaflet/Mapbox）；唱和赠答关系图谱（Gephi / D3.js）；词频与风格分析（词云、李杜用词对比、"酒/剑/月"等意象的朝代变迁）。 |
| **四、AI / NLP 实验** | 诗词生成：GPT 或 LLaMA 微调，或 RAG 先检索相似再生成；智能问答：function calling 查库后回答"这首诗表达了什么""有哪些写秋天的七言绝句"；对联 / 集句 / 藏头诗：基于词库自动对下联、跨诗集句、按名字藏头。 |
| **五、教育与游戏** | 诗词接龙小程序（首字接尾字）；飞花令 / 闯关答题（判字诗句是否来自库，积分排名）；诗词卡片 / Anki 牌组，或"每日一首"手机壁纸生成器。 |
| **六、开源协作与社区** | 统一 JSON/CSV 格式招募注释、翻译、赏析、注音贡献者，做全唐诗开源语料库；多语言翻译项目吸引国际贡献者；数据集镜像同步到 Kaggle / Hugging Face Datasets，扩大影响力。 |
