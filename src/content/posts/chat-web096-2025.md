你可以在文章标题后面加上对应的分类，利用`post.categories`。每篇文章的`categories`在 Jekyll 中是一个数组，所以可以用`join`来显示。修改你的循环部分如下：

```html
{% for post in posts_by_month %}
<div>
  <span>{{ post.date | date: "%m-%d" }}</span> — 
  <a href="{{ post.url }}">{{ post.title }}</a>
  {% if post.categories %}
    <span style="color:#888;">[{{ post.categories | join: " / " }}]</span>
  {% endif %}
</div>
{% endfor %}
```

这样每篇文章后面就会显示它的分类，如果有多级分类，会用 “/” 分隔。例如：

```
09-15 — 我的文章标题 [感悟 / 学习]
```

你只需将原来的这段：

```html
<span>{{ post.date | date: "%m-%d" }}</span> — <a href="{{ post.url }}">{{ post.title }}</a>
```

替换为上面带分类的版本即可。

```html
  <a href="{{ post.url }}">{{ post.title }}</a>
  {% if post.categories %}
    <span style="color:#888;">[
      {% for cat in post.categories %}
        <a href="{{ site.baseurl }}/categories/{{ cat | slugify }}/">{{ cat }}</a>{% unless forloop.last %} / {% endunless %}
      {% endfor %}
    ]</span>
  {% endif %}
</div>
{% endfor %}
```

效果示例：

```
09-15 — 我的文章标题 [感悟 / 学习]
```

其中“感悟”和“学习”都是可点击的分类链接，自动指向你的博客分类页面（确保你已有对应的分类页面或启用了 Jekyll 分类生成功能）。
