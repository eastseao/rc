- 有身份

- 有规则

- 有流程

- 有约束

- 可组合

- 可长期迭代

你之前做的：

# 四、真正拉开差距的技巧：人格固定化

很多人 AI 输出不稳定。

原因：

# 人格漂移

解决方法：

#### 每个 Skill 必须固定：

##### 1. 身份

例如：

```
identity:
  role: "番茄顶级爽文操盘手"
```

---

##### 2. 审美

```
taste:
  prefers:
    - "情绪递进"
    - "压抑后爆发"
    - "电影化描写"
```

---

##### 3. 禁止项

```
forbidden:
  - "流水账"
  - "AI套话"
  - "解释型描写"
```

---

##### 4. 输出节奏

```
style:
  pacing: "快"
  sentence: "短句优先"
```
