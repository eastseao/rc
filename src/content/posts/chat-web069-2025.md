要把现在的“直接一条直线”换成“折线”，我们可以改写`drawLine`函数，让它画 path（折线路径）而不是`<line>`。

核心思想： 先水平，再垂直 → 出现清晰的拐角，更像思维导图线路。

给你改好的 JS 部分，只需要替换`<script>`里的`drawLine()`和内部调用部分：

```html
<script>
  function drawPolyline(svg, x1, y1, x2, y2) {
    // 计算折点：先水平移动到中间，再垂直下去
    const midX = (x1 + x2) / 2;

    const path = document.createElementNS("http://www.w3.org/2000/svg", "path");
    const d = `M ${x1} ${y1} L ${midX} ${y1} L ${midX} ${y2} L ${x2} ${y2}`;
    path.setAttribute("d", d);
    path.setAttribute("stroke", "#ef4444");
    path.setAttribute("stroke-width", "2");
    path.setAttribute("fill", "none");
    path.setAttribute("stroke-linecap", "round");
    path.setAttribute("opacity", "0.4");

    svg.appendChild(path);
  }

  function connectCards() {
    const svg = document.getElementById('connector');
    svg.innerHTML = '';

    const main = document.getElementById('mainGroup').getBoundingClientRect();
    const chartOffset = document.getElementById('chart').getBoundingClientRect();

    // 总集团 → 二级集团
    document.querySelectorAll('#col2 .card').forEach(card => {
      const c = card.getBoundingClientRect();
      drawPolyline(
        svg,
        main.right - chartOffset.left,
        main.top + main.height / 2 - chartOffset.top,
        c.left - chartOffset.left,
        c.top + c.height / 2 - chartOffset.top
      );
    });

    // 健康药业集团 → 基地
    const healthGroup = document.getElementById('g4').getBoundingClientRect();
    document.querySelectorAll('#col3 .card').forEach(card => {
      const c = card.getBoundingClientRect();
      drawPolyline(
        svg,
        healthGroup.right - chartOffset.left,
        healthGroup.top + healthGroup.height / 2 - chartOffset.top,
        c.left - chartOffset.left,
        c.top + c.height / 2 - chartOffset.top
      );
    });
  }

  window.addEventListener('load', connectCards);
  window.addEventListener('resize', connectCards);
</script>
```

效果：

- 连线从“主集团”出来 → 横折 → 竖直连接目标

- 视觉更清晰、有“组织架构图”味道

- 也保留了 hover 动画不动

如果你想更丝滑些，可以加圆角折线弧度（贝塞尔曲线）。等你说一声，我就给你升级成“奶油顺滑”路径版。

## Q2 · 奶油顺滑”路径版（第 2 轮对话）

> **提问：** 奶油顺滑”路径版

来了，“奶油顺滑版”，线条不再硬邦邦拐角，而是优雅弯过来。像乌龙茶的香气一样顺滑，不急不躁。

思路：用`C`（三阶贝塞尔曲线）让线条从 A 点轻轻探出，再顺弯到 B 点。 控制点设在中间偏水平，更像思维导图的柔线。

把你当前`<script>`全部换成下面这个：

```html
<script>
  function drawSmoothCurve(svg, x1, y1, x2, y2) {
    const midX = (x1 + x2) / 2;

    const path = document.createElementNS("http://www.w3.org/2000/svg", "path");

    // 三阶贝塞尔曲线
    // 控制点在水平中点
    const d = `
      M ${x1} ${y1}
      C ${midX} ${y1},
        ${midX} ${y2},
        ${x2} ${y2}
    `;

    path.setAttribute("d", d);
    path.setAttribute("stroke", "#ef4444");
    path.setAttribute("stroke-width", "2");
    path.setAttribute("fill", "none");
    path.setAttribute("stroke-linecap", "round");
    path.setAttribute("opacity", "0.45");

    // 动画：淡淡柔滑出现
    path.style.transition = "stroke 0.3s ease, opacity 0.3s ease";
    svg.appendChild(path);
  }

  function connectCards() {
    const svg = document.getElementById("connector");
    svg.innerHTML = "";

    const chartOffset = document.getElementById("chart").getBoundingClientRect();
    const main = document.getElementById("mainGroup").getBoundingClientRect();

    // 连接主集团 → 二级集团
    document.querySelectorAll("#col2 .card").forEach(card => {
      const c = card.getBoundingClientRect();
      drawSmoothCurve(
        svg,
        main.right - chartOffset.left,
        main.top + main.height / 2 - chartOffset.top,
        c.left - chartOffset.left,
        c.top + c.height / 2 - chartOffset.top
      );
    });

    // 连接健康药业集团 → 全部基地
    const health = document.getElementById("g4").getBoundingClientRect();
    document.querySelectorAll("#col3 .card").forEach(card => {
      const c = card.getBoundingClientRect();
      drawSmoothCurve(
        svg,
        health.right - chartOffset.left,
        health.top + health.height / 2 - chartOffset.top,
        c.left - chartOffset.left,
        c.top + c.height / 2 - chartOffset.top
      );
    });
  }

  window.addEventListener("load", connectCards);
  window.addEventListener("resize", connectCards);
</script>
```

现在的线条效果—— 不是“企业组织架构要严肃正气⚔️”， 而是“品牌架构优雅活泼🌿”， 滑进视线，轻盈又有科技感。

再说一句有趣的事： 贝塞尔曲线原本设计用来画汽车车身轮廓。所以你这个组织图，骨子里也带了点豪华跑车灵魂。

接下来如果你想让线条“动态生长出现”，我可以给你一个`stroke-dasharray`+`stroke-dashoffset`版本，让树脉络一笔一笔长出来，像毛细血管扩展。
