## 01 · 计划单的三步处理流程（从 Excel 到可采购清单）

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>流程</span><h3>原始列 → 分类拆分 → 同名合并</h3></div><div style="padding:14px 16px"><ul><li><b>① 转 Markdown</b>：把计划单 Excel 输出为 Markdown 表格，保留 计划单 / 序号 / 名称 / 规格 / 数量 / 单位 / 类别 / 文件 / 供应商 / 备注 等列。</li><li><b>② 按类拆分</b>：按&quot;文件&quot;列把整张表拆成独立小表——PET 瓶子、PE 袋、复合膜、卡盒、礼盒、圆卡纸、标签等。</li><li><b>③ 同名合并</b>：同一类别内名称相同的项合并数量，计划单号与原序号用逗号连接；最后在最左侧加一列连续&quot;新序号&quot;。</li></ul></div></div>

## 03 · 同名合并的列规则（新序号 · 原序 · 名称 · 数量）

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>合并后表结构</span><h3>每行五列</h3></div><div style="padding:14px 16px"><ul><li><b>新序号</b>：最左侧新增的连续序号，方便按行点单。</li><li><b>原序</b>：被合并的原计划单号（如 A2、A36、B29），多个用逗号连接，便于回溯原始计划单。</li><li><b>名称 / 数量 / 单位</b>：同名物料的数量相加后单列一行。</li></ul></div></div>
