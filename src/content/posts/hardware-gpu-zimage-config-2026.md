## 01 · 显卡内存解读：5966MB VRAM 与 10010MB 总显存（00727 · 2026-03-14）

原笔记里用户的查询结果是：显卡总内存**10010MB**、显卡内存（VRAM）**5966MB**。这两个数字揭示了一种「分工合作」模式：一块约 6GB 显存的独立显卡，再加系统借调约 4GB 的后备内存。

| 数字 | 含义 |
|---|---|
| **5966MB 显卡内存（VRAM）** | 独立显卡上的专用「高速工作台」，存储 GPU 正在实时处理的图像、纹理和数据，读写极快，对 Photoshop 大画布、大型 3D 游戏至关重要。 |
| **10010MB 总显存** | 「总仓库」概念：5966MB 专用 VRAM + 从系统内存条划分出来的「共享系统内存」约 4GB。专用显存用满时系统自动调用这部分，速度慢一些但防崩溃。 |

## 02 · Windows 安装 Z-Image Turbo（ComfyUI 新手方案）（00728 · 2026-03-14）

6GB 显存跑 Z-Image Turbo 完全可行，关键是**选对量化模型版本 + 显存优化**。新手最稳路径：装 ComfyUI 免安装版 → 下载三个量化模型文件放到指定目录 → 搭工作流 → 按 KSampler 推荐参数出图。

| 项目 | 推荐配置 | 低显存配置 |
|---|---|---|
| **GPU** | NVIDIA，16GB 及以上显存，可用标准模型 | NVIDIA，6–8GB 显存，**必须用 FP8/INT8 量化版模型** |
| **系统** | Windows 10/11 | Windows 10/11 |
| **存储** | 50GB 以上可用空间 | 20GB 以上可用空间 |

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>第一步 · 装 ComfyUI</span><h3>免安装版 + 首次启动</h3></div><div style="padding:14px 16px"><dl style="display:grid;grid-template-columns:110px 1fr;gap:8px 16px;margin:14px 0"><dt>下载</dt><dd>官方 GitHub Releases 页找同时含<code>windows</code>、<code>portable</code>、<code>nvidia</code>的压缩包（<code>ComfyUI_windows_portable_nvidia.7z</code>）。</dd><dt>解压</dt><dd>解压到好找的目录（如<code>D:\ComfyUI</code>），<b>路径不要含中文和空格</b>。</dd><dt>启动</dt><dd>双击<code>run_nvidia_gpu.bat</code>；首次启动自动下载依赖，看到<code>Starting server...</code>或<code>http://127.0.0.1:8188</code>即成功，浏览器打开该地址进入界面。</dd><dt>git 报错</dt><dd>提示「'git' 不是内部或外部命令」说明没装 Git：装 Git（安装时 PATH 界面选「Git from the command line and also from 3rd-party software」），或手动把 GitHub 上<code>ComfyUI-GGUF</code>的 Code → Download ZIP 解压到<code>ComfyUI/custom_nodes/</code>。</dd></dl></div></div>

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>第二步 · 模型三件套</span><h3>放到 ComfyUI 指定目录（放错是新手最常见错误）</h3></div><div style="padding:14px 16px"><div style="overflow-x:auto;margin:16px 0;margin-bottom:12px"><table><thead><tr><th style="width:130px">组件</th><th>文件名（照录）</th><th>放置目录</th></tr></thead><tbody><tr><td><b>扩散模型</b></td><td><code>z-image-turbo_fp8_scaled_e4m3fn_KJ.safetensors</code>（约 6.5GB，FP8 量化版）</td><td><code>ComfyUI\models\checkpoints\</code>（新版也可能要求<code>models\diffusion_models\</code>，以节点下拉能看到为准）</td></tr><tr><td><b>文本编码器</b></td><td><code>Qwen3-4B-Q4_K_M.gguf</code>（约 2.5GB）</td><td><code>ComfyUI\models\text_encoders\</code></td></tr><tr><td><b>VAE</b></td><td><code>ae.safetensors</code>（约 335MB，不需量化）</td><td><code>ComfyUI\models\vae\</code></td></tr></tbody></table></div><p style="font-size:13.5px;color:inherit">来源：Hugging Face 搜索<code>drbaph/z-img</code>、<code>bartowski/Qwen_Qwen3-4B-GGUF</code>、<code>black-forest-labs/FLUX.1-dev</code>；官网慢可用镜像<code>hf-mirror.com</code>。遇「rate limit / IP 限制」需注册免费 HF 账号生成 read 权限的 Access Token 登录后再下。文本编码器 Q4_K_M 在质量与显存间平衡；显存再紧换 Q4_K_S，质量有余换 Q5_K_M。放好后点右下角「刷新」或重启 ComfyUI。</p></div></div>

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>第三步 · 工作流与采样参数</span><h3>节点连接 + KSampler 推荐值</h3></div><div style="padding:14px 16px"><p style="margin-bottom:10px">双击画布空白处添加节点：Load Checkpoint（主模型）→ 两个 CLIP Text Encode（正/负提示词）→ Empty Latent Image（尺寸）→ KSampler → VAE Decode → Save Image，按接口连线。Z-Image Turbo 负向提示词影响很弱，可简单填<code>low quality, blurry</code>或置零。</p><div style="overflow-x:auto;margin:16px 0;margin-bottom:12px"><table><thead><tr><th style="width:150px">KSampler 参数</th><th>推荐值</th></tr></thead><tbody><tr><td><b>steps</b></td><td><b>9</b>（该模型专为低步数优化，9 步即可出高质量图）</td></tr><tr><td><b>sampler_name</b></td><td><code>res_multistep</code>或<code>euler</code></td></tr><tr><td><b>scheduler</b></td><td><code>simple</code>或<code>normal</code></td></tr><tr><td><b>cfg</b></td><td><b>1.0–1.5</b>（模型已内置提示词引导，不要高 CFG）</td></tr><tr><td><b>宽×高</b></td><td>先 512×512 / 768×768 试跑，稳了再上 1024×1024</td></tr><tr><td><b>denoise</b></td><td>文生图保持<b>1.0</b></td></tr></tbody></table></div><p style="font-size:13.5px;color:inherit">出图：点右上角「Queue Prompt / 队列提示」，图片落在 ComfyUI 目录的<code>output</code>文件夹。6GB 显存若报<code>CUDA out of memory</code>：启动脚本<code>run_nvidia_gpu.bat</code>里<code>main.py</code>后加<code>--medvram</code>（或设置里把 VRAM 管理模式设为 lowvram、UNET 精度设 fp8_e4m3fn），并降低分辨率、关掉占显存程序。</p></div></div>

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>排障 · GGUF</span><h3>文本编码器用不了 GGUF 的连环坑</h3></div><div style="padding:14px 16px"><ul style="margin:0;padding-left:18px;font-size:13.5px;color:inherit"><li style="margin-bottom:8px"><b>报<code>ModuleNotFoundError: No module named 'gguf'</code></b>：在 ComfyUI 目录地址栏输<code>cmd</code>打开命令行，运行<code>.\python_embeded\python.exe -m pip install gguf</code>（慢则加<code>-i https://pypi.tuna.tsinghua.edu.cn/simple</code>），装完重启。</li><li style="margin-bottom:8px"><b>CLIP 下拉没有可用选项</b>：标准 CLIP Text Encode 不认识 .gguf。在 ComfyUI Manager 里安装<code>ComfyUI-GGUF</code>扩展并重启，改用<code>DualCLIPLoaderGGUF</code>（加载 gguf 文本编码器）、<code>UnetLoaderGGUF</code>（加载主模型）、<code>VAELoader</code>（加载 ae.safetensors）三个节点重连。</li><li style="margin-bottom:8px"><b>加载器里看不到模型文件</b>：文件放对目录（文本编码器在<code>text_encoders\</code>，扩散模型在<code>diffusion_models\</code>，别改名）；删节点重新添加或完全重启；还不行就更新 ComfyUI 核心（<code>update\update_comfyui.bat</code>）和 GGUF 扩展。</li><li><b>working around nvidia conv3d memory bug</b>：不是报错，是 ComfyUI 检测到已知 CUDA 3D 卷积显存问题后自动启动绕过方案，正常忽略继续即可。</li></ul></div></div>

## 04 · Visual C++ 运行库修复多次无效的根治流程（01349 · 2026-06-26）

运行库修复多次无效，通常是**旧版本残留、注册表损坏、系统文件被锁定或杀软干扰**——单纯覆盖安装治标不治本。按「彻底清理 → 官方重装 → 系统修复」逐级深入，不必全部执行。
