## Q1 · 如何本地部署OpenClaw（第 1 轮对话）

> **提问：** 如何本地部署OpenClaw

先把这个东西说清楚一点： entity["software","OpenClaw","AI agent framework"] 本质上不是一个简单的聊天机器人，而是一个**本地运行的 AI Agent 框架**。它可以接入模型、调用工具、执行命令、浏览网页、定时任务等，所以部署结构比普通 AI 稍微复杂一点。它通常包含三层：

- 模型（LLM） ：如 DeepSeek / Qwen / GPT / 本地模型

- OpenClaw Agent ：负责理解任务和调用工具

- Gateway / Channel ：Telegram、飞书、钉钉等入口 citeturn0search0turn0search1

换句话说，它更像一个“自动干活的 AI 管家”。

下面给你一套**最稳定的本地部署方法（Node.js 方式）**。

---

# 一、本地部署 OpenClaw（标准方法）

#### 1 安装 Node.js

OpenClaw 需要 Node ≥ 22。

安装完成后检查：

```bash
node -v
npm -v
```

---

#### 2 全局安装 OpenClaw

```bash
npm install -g openclaw
```

安装成功后：

```
openclaw --version
```

---

#### 3 初始化配置

运行：

```
openclaw configure
```

会进入一个交互式配置：

主要配置这些：

**1 模型提供商**

例如：

- OpenAI

- OpenRouter

- 本地模型

- Ollama

**2 API Key**

比如：

```
sk-xxxxx
```

**3 默认模型**

例如：

```
gpt-4o
deepseek-chat
qwen2.5
```

---

#### 4 启动 OpenClaw

```
openclaw start
```

启动后会看到类似：

```
Gateway running on http://localhost:18789
```

默认端口：

```
18789
```

浏览器打开：

```
http://localhost:18789
```

就能进入控制面板。

---

# 二、连接本地大模型（推荐）

很多人部署 OpenClaw 的目的其实是：

**完全本地 AI**

常见方案是：

```
OpenClaw
     ↓
Ollama
     ↓
本地模型
```

比如安装：

entity["software","Ollama","local LLM runtime"]

##### 安装 Ollama

Mac / Linux

```
curl -fsSL https://ollama.com/install.sh | sh
```

Windows 下载安装包。

---

##### 下载模型

例如：

```
ollama run qwen2.5
```

或

```
ollama pull deepseek-coder
```

---

##### 在 OpenClaw 里配置

模型地址填：

```
http://localhost:11434/v1
```

模型名：

```
qwen2.5
```

---

# 三、推荐的完整架构（很多人这样用）

稳定结构通常是：

```
Telegram / 飞书
        ↓
     OpenClaw
        ↓
      Ollama
        ↓
     本地大模型
```

这样可以做到：

- 私有化 AI

- 自动任务

- 自动浏览网页

- 自动执行脚本

---

# 四、最低电脑配置建议

如果跑本地模型：

| 模型 | 内存 |
|---|---|

7B | 16GB | 14B | 32GB | 32B | 64GB |

没有 GPU 也能跑，只是慢一点。

```
手动安装 = 容易踩坑
```

# 六、很多人第一次部署会踩的坑

最常见三个：

1️⃣ Node 版本太低 2️⃣ 没配置模型 provider 3️⃣ Gateway 没启动

表现就是：

```
AI 不回复
```
