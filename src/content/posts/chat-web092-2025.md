##### ✅ 一、在`header.html`中删除以下部分：

```html

<h1>{% if page.title %}{{ page.title | strip_html }}{% else %}<br/>{% endif %}</h1>

<!-- 副标题 -->
{% if page.subtitle %}
  {% if include.type == "page" %}
    <hr class="small">
    <span class="{{ include.type }}-subheading">{{ page.subtitle | strip_html }}</span>

  {% endif %}

{% if include.type == "post" %}
  <!-- 仅在文章页面显示元数据 -->
  <div class="post-meta">
    {% if page.author %}
      <span class="author">作者：<strong>{{ page.author | strip_html }}</strong></span>
    {% endif %}

    <span class="published-date">发表于 {{ page.date | date: date_format }}</span>

    {% if page.last-updated %}
      <span class="updated-date">

  {% endif %}
```

## Q4 · 阅读时间的插件加在哪里（第 4 轮对话）

> **提问：** 阅读时间的插件加在哪里

非常好的问题——阅读时间 (`readtime`) 并不是 Jekyll 自带的功能，而是一个**可选的插件或生成逻辑**。 它的作用是自动计算文章字数，然后估算读完需要的分钟数（例如“阅读时间：3分钟”）。

在你的`post.html`中，`{{ page.readtime }}`这一变量不会自动生效，除非我们在构建阶段让 Jekyll 生成它。

下面我详细告诉你两种实现方式：**插件自动计算**和**脚本生成**，你只需选择一种即可。

---

#### ✅ 方法一：使用插件（推荐，最简洁）

如果你用的是**GitHub Pages + Jekyll**，那么你只能使用**白名单插件**。 幸运的是，有个插件叫`jekyll-reading-time`，**GitHub Pages 支持它**！

##### 1️⃣ 在你的`_config.yml`里添加：

```
plugins:
  - jekyll-reading-time
```

如果已经有其他插件（例如 sitemap、feed 等），只需在它们下面加一行：

```
plugins:
  - jekyll-feed
  - jekyll-sitemap
  - jekyll-reading-time
```

##### 2️⃣ 插件会自动在每个`page`或`post`对象里添加：

```
{{ page.reading_time }}
```

它默认是英文（例如`"1 min read"`），我们可以自己在模板里汉化成：

```
阅读时间：{{ page.reading_time | replace: " min read", "分钟" }}
```

或者更细一点：

```
{% assign mins = page.reading_time | remove: " min read" %}
阅读时间：{{ mins }} 分钟
```

> ⚠️ 注意：你原本用的是`{{ page.readtime }}`，改成`{{ page.reading_time }}`才能和插件对接。

---

#### ✅ 方法二：不用插件（纯 Liquid 实现，适合无法安装插件的情况）

在你的`_layouts/post.html`里，在文章开头添加这段逻辑计算阅读时间（假设每分钟读 200 字）：

```html
{% assign words = content | number_of_words %}
{% assign minutes = words | divided_by:200 %}
{% if minutes < 1 %}
  {% assign minutes = 1 %}
{% endif %}
<span class="reading-time"><span class="middot d-none d-md-inline">&middot;</span> 阅读时间：{{ minutes }} 分钟</span>
```

替换掉原先的：

```html
{% if page.readtime %}
  <span class="reading-time">
    <span class="middot d-none d-md-inline">&middot;</span>
    阅读时间：{{ page.readtime }} 分钟
  </span>
{% endif %}
```

---

#### ✅ 建议总结

| 场景 | 推荐方法 | 优点 |
|---|---|---|
| 你在 GitHub Pages 上部署 | **使用插件`jekyll-reading-time`** | 自动计算，无需改模板 |
| 你不能启用插件 | **使用 Liquid 脚本计算字数** | 不依赖插件，兼容所有环境 |

```html
      const d = day || now.getDate();

      const date = y + '-' +
                   String(m).padStart(2, '0') + '-' +
                   String(d).padStart(2, '0');

      const fileName = date + '-' + title.replace(/\s+/g, '-') + '.md';
      document.getElementById('filename').textContent = fileName;

      const frontMatter =
`---
layout: post
title: "${title}"
date: ${date}
last_modified_at: ${date}
author: Gervas
categories: [${category}]
tags: [${tag1}${tag2 ? ', ' + tag2 : ''}]
${cover === 'yes' ? 'cover-img: /assets/img/cover.jpg' : ''}
---

${content || '（在这里写正文内容）'}
`;

      document.getElementById('output').textContent = frontMatter;
    }

    function copyText(id) {
      const el = document.getElementById(id);
      const text = el.textContent || el.value;
```
