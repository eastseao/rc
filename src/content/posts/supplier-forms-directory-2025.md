> **Excel 落地要点（照录）**
> - 下拉选项来源串：企业类型生产商,经销商,贸易商,个体；合作状态潜在,合格,暂停,黑名单；主营品类外包装,内包装,原料,辅料,设备,其他；付款方式预付款,货到付款,月结,其他；付款币种人民币,美元,其他；开票类型增值税普票,增值税专票。
> - 电脑端：数据 → 数据验证 → 允许“序列”，来源用英文逗号分隔；手机端 WPS：长按选中单元格 → 工具栏“数据” → “插入下拉列表”，手动添加或从单元格区域选择。
> - 使用建议：电子化便于筛选排序；财务、资质等敏感信息设查看权限；专人每季度/半年更新证照、绩效与财务；增“附件”列链接营业执照、许可证、检测报告扫描件。

## 02 · 常用打样供应商名录表结构（00275）

名录是“一行一家、随时可调”的表，核心是类别、打样能力、报价特点、打样周期与合作评价五列。表名建议“常用打样供应商名录”，并注明制表部门/人与更新日期。

| 列名 | 说明 |
|---|---|
| **序号** | 自动编号，便于快速查找和统计。 |
| **类别** | 核心列，一级分类方便按需筛选：印刷类 / 包装类 / 塑胶·模具类 / 五金类 / 硅胶·橡胶类 / 样品·手板制作 / 纺织·服装类。 |
| **供应商名称** | 公司全称。 |
| **主要打样能力** | 核心列，写最擅长的打样领域与具体产品，如“精密塑胶零件模具”“高速 SMT 贴片”“高端服装面料”。 |
| **联系人/电话/邮箱** | 关键联系信息，建议把最常用联系方式（如微信）放前面。 |
| **地址/网址** | 物理地址与公司网站，网址帮助新同事快速了解供应商实力。 |
| **报价参考/特点** | 核心列，记录大致价格水平（偏高/适中/有竞争力）与核心优势（质量顶尖、交期快、支持复杂结构、服务好）。 |
| **打样周期** | 核心列，常规项目平均打样时间（如 3-5 天、1 周），对项目排期至关重要。 |
| **合作评价/备注** | 核心列、表格“灵魂”：星级（⭐~⭐⭐⭐⭐⭐）或“优秀/良好/一般”；备注特殊信息（需提供 3D 图、最小订单金额、曾交期延误需紧盯等）。 |
| **最后合作时间** | 记录最后一次下单打样时间，便于识别长期未合作供应商、清理更新名录。 |

> **进阶优化建议（照录）**
> - 用 Google Sheets、腾讯文档、飞书文档等在线表格，方便团队多人实时查看与更新。
> - 增加“状态”列，用颜色或文字标识 活跃 / 备用 / 停止合作。
> - 在线表格中可在供应商名称旁加超链接，直接链到资质文件、合同或历史报价单。
> - 指定专人每季度或每半年审核名录，更新信息并淘汰不合格供应商。

## 03 · 邀填说明与提交感谢语（00380）

同仁堂健康青海基地采购用于“邀供应商填信息”的两段话术：一段是表单开头的邀填说明（商务润色版），一段是提交成功后的感谢语（三种风格备选）。

邀填说明 · 商务润色版

我是同仁堂健康青海基地的采购负责人，为便于日常联络及推进潜在合作，现诚挚邀请您填写基本信息，以便我们更好地了解贵司所能提供的服务内容。若我们尚未建立合作关系，也期待通过此表开启沟通，为未来合作奠定基础。感谢您的支持与配合！

改写说明：将口语化表达调整为商务书面语；重组顺序先讲身份与目的、再表合作期望；补充“诚挚邀请”“感谢支持与配合”等礼貌用语。
