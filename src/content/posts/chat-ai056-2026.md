## Q1 · 中国国内有哪些agent学习的教程（第 1 轮对话）

> **提问：** 中国国内有哪些agent学习的教程

如果你想系统学习 AI Agent（尤其是国内生态），现在国内已经形成了几条比较成熟的学习路线：

- Prompt → Workflow → Agent → Multi-Agent

- OpenAI/Claude → 国内模型 → 本地模型 → 自动化系统

- 单工具 → Skill → MCP → 企业级 Agent 平台

下面我按「适合新手 → 进阶 → 实战开发 → 中文社区」给你整理一套目前国内最值得看的教程体系。

---

#### 1. B站 AI Agent 系列（最适合零基础）

##### 推荐搜索关键词

- “LangChain 教程”

- “Dify 教程”

- “Coze 扣子”

- 自动化工作流

- AI 编程

urlLangGraphhttps://www.langchain.com/langgraph
