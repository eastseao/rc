## Q1 · QUETTA浏览器有电脑版吗（第 1 轮对话）

> **提问：** QUETTA浏览器有电脑版吗

有，而且是**刚刚推出不久的电脑版**。如果你说的是**Quetta Browser（不是 qutebrowser）**，截至**2026 年 8 月 24 日**：

##### 💻 Quetta 已经有 Windows 版

官方已经发布了**Quetta for Windows Beta**，首个 Windows 版本于**2026 年 8 月 4 日**发布，目前仍处于 Beta 阶段。citeturn0search0turn0search1

urlQuetta Windows 官方下载页https://www.quetta.net/products/windows

目前电脑版主要功能包括：

- 🤖 AI 广告拦截

- 🛡️ 隐私保护 / Tracker 拦截

- 🎬 内置视频下载器

- 📥 支持部分 HLS / M3U8 / MP4 / WebM

- 🔐 隐私与指纹保护

- 🌐 基于 Chromium

- 🪟 Windows

- 🍎 macOS

官方也明确说明 Windows 版本目前是**Beta**，可能存在网站兼容性、功能不完整以及版本变化等问题。citeturn0search0

##### ⭐ 如果你是想把它作为 Windows 主力浏览器

我觉得**现在值得试，但暂时不建议完全替代 Edge/Chrome**。

尤其是你如果看重：

> **视频下载 + 广告拦截 + 隐私 + Chromium + 简洁界面**

Quetta 的定位其实非常有意思。官方把它定位成**video-first browser**，而且现在已经正式开始向 Windows/macOS 扩展。citeturn0search2

## Q2 · 这个浏览器是哪个国家的哪个公司出的 安全可靠吗（第 2 轮对话）

> **提问：** 这个浏览器是哪个国家的哪个公司出的 安全可靠吗

我查了一下 Quetta 的官方资料。这个浏览器**确实是英国公司运营的**，但有几个地方值得你特别注意。

#### 1. Quetta 是哪个国家的？

Quetta 的运营主体是：

**Quetta Networks Limited**

官方条款明确写明，公司注册地址是：

> Office Suite 29A, 23 Wharf Street, London, England, SE8 3GG

也就是说，**法律主体注册在英国伦敦**。citeturn0search1

官方网站：

urlQuetta 官方网站https://www.quetta.net/

官网底部同样标注：

**© 2025 Quetta Networks Limited — 23 Wharf Street, London, SE8 3GG, United Kingdom 🇬🇧**citeturn0search6

##### 但要注意一个区别

“英国注册公司”≠“一定是英国本土大型科技公司”。

Quetta 是一家**规模比较小、比较新的浏览器公司/团队**，不是 Google、Microsoft、Mozilla、Brave 这种成熟的大型浏览器厂商。

官方早期文章显示，团队在 2023 年已经开始运营 Quetta Browser，产品负责人署名为 Stephen，产品管理负责人署名为 Cherysun。citeturn0search3turn0search9

所以我会把它归类为：

> **英国注册的小型/新兴浏览器厂商，而不是英国传统互联网巨头。**

---

# 2. 安全可靠吗？

我的判断是：

##### 🟢 日常普通上网：可以使用

##### 🟡 隐私要求较高：可以尝试，但不要盲目信任

##### 🟠 银行、证券、企业核心账号：目前我不会把它作为第一选择

##### 🔴 Windows 主力浏览器：暂时不建议完全替代 Edge / Firefox / Brave

原因非常明确：**Windows 版才刚进入 Beta。**

官方 Release Notes 显示，Quetta Windows 的**首个 Windows 版本是 2026 年 8 月 4 日发布的 2.0.2**。也就是说，到现在只有不到一个月。citeturn0search11

官方自己也明确称：

> **Quetta for Windows · Beta**

并邀请早期用户帮助测试。citeturn0search7

所以安全性不能仅仅看“有没有隐私功能”，还要看：

**代码透明度 + 安全审计 + 漏洞响应历史 + 软件供应链 + 公司信誉 + 更新机制。**

在这些方面，Quetta 目前的成熟度显然还不能和 Firefox、Chrome、Edge、Brave 相提并论。

# 3. Quetta 自己声称收集什么？

这一点我仔细看了它最新的隐私政策。

Quetta 声称：

- 默认 不要求注册账号

- 默认不收集个人信息

- 不出售个人信息

- 不未经同意分享个人信息

- 可以关闭匿名数据报告

- 可以关闭崩溃报告

- 收集的主要是匿名/聚合使用数据

例如：

- 日活跃趋势

- Tab 使用情况

- 插件使用情况

- 功能使用统计

- 崩溃诊断信息

- 匿名用户数量统计

这些内容官方隐私政策都有明确说明。citeturn0search0

但是这里有一个非常重要的细节：

##### 它使用 Google Analytics

Quetta 官方隐私政策明确写着，它集成了**Google Analytics**来收集和分析匿名使用数据，而且用户可以在设置中关闭。citeturn0search0

所以如果你对隐私非常敏感，我建议：

> **安装后第一件事情就是把 Analytics、匿名使用数据、Crash Report 等遥测选项全部关闭。**

# 5. 真正让我比较谨慎的是这一点

##### Quetta 是一个相当年轻的浏览器。

而浏览器其实是非常特殊的软件。

它拥有的权限和能力非常大：

```
浏览器
 ├── 访问你打开的网站
 ├── 保存 Cookie
 ├── 保存登录状态
 ├── 保存密码
 ├── 读取下载内容
 ├── 扩展程序权限
 ├── 浏览器历史
 ├── 网站权限
 ├── 摄像头/麦克风权限
 └── 可以处理大量网络流量
```

所以：

**“没有恶意”只是安全的最低要求。**

真正值得关注的是：

> **它有没有能力长期、稳定、透明地保护这些数据。**

这方面 Quetta 的历史还太短。
