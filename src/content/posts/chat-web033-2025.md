## Q1 · 现在我想在根目录创建一个product文件夹，内部存放公司的产品系列：鲜虫草系列…（第 1 轮对话）

> **提问：** 现在我想在根目录创建一个product文件夹，内部存放公司的产品系列：鲜虫草系列 燕窝系列 黑果枸杞系列 藜麦系列 冻干枸杞系列 深加工系列 电商原浆系列 其他系列 代工系列 礼盒系列 我们先整理需求

明白，我们先把这个**产品系列目录需求**整理清楚，再考虑网页呈现或数据管理方式。为了方便管理和未来扩展，我建议从几个角度梳理需求：

---

#### 1️⃣ 文件夹结构需求

根目录下创建`product`文件夹，每个产品系列作为子文件夹，例如：

```
/product
  /鲜虫草系列
  /燕窝系列
  /黑果枸杞系列
  /藜麦系列
  /冻干枸杞系列
  /深加工系列
  /电商原浆系列
  /其他系列
  /代工系列
  /礼盒系列
```

- 每个子文件夹可存放该系列产品的 图片、说明文档、规格表 等资源。

- 未来可以根据需要增加子分类，例如「鲜虫草系列」下面有「礼盒装」、「散装」等。

---

#### 2️⃣ 产品信息需求

每个产品系列的每个产品可能需要包含以下信息（方便展示或生成网页）：

| 字段 | 描述 |
|---|---|
| 产品名称 | 产品的具体名称 |
| 产品图片 | 图片资源 |
| 产品描述 | 文字介绍 |
| 产品规格 | 重量、成分、包装等信息 |
| 价格 | 可选 |
| 标签 | 便于搜索或分类（如“高端”、“礼盒”） |

---

#### 3️⃣ 数据存储形式

可以有几种方式：

1. JSON 文件 （便于网页前端读取）

每个系列一个`data.json`，例如：

```json
[
  {
    "name": "鲜虫草1号",
    "image": "xunchongcao1.jpg",
    "description": "高品质鲜虫草，适合泡茶",
    "spec": "50g/瓶",
    "price": "￥299",
    "tags": ["高端", "礼盒"]
  }
]
```

1. Markdown 文件 （便于内容编辑）

每个产品一个`.md`文件，Front Matter 中写产品信息，正文写描述。

1. 混合方式

图片放在文件夹内，JSON 或 Markdown 记录文字和规格。

---

#### 4️⃣ 前端展示需求

如果将来做网页展示，可考虑：

- 产品列表页：显示每个系列的缩略图和名称

- 系列详情页：展示该系列所有产品

- 搜索和筛选功能：按标签、价格、规格筛选

- 可点击查看产品详情，显示图片和详细信息

---

#### 5️⃣ 可扩展性需求

- 新增系列只需在 product 下建子文件夹

- 可直接在 JSON 或 Markdown 里添加产品

- 前端可自动扫描 product 文件夹生成页面

- 支持多语言（中文/英文）或多端（网页/APP）

## Q5 · 写吧（第 5 轮对话）

> **提问：** 写吧

好的，我帮你写一个完整的**`/product/index.html`页面模板**，满足你的要求：

- 左侧可折叠系列按钮

- 右侧产品卡片网格展示

- 每个产品卡片显示：图片、产品名称、项目号、规格、零售价格

- 数据来源 data.json （同目录）

- 图片来自 /assets/product/

下面是代码：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>产品展示</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <style>
    /* 左侧折叠按钮样式 */
    .sidebar {
      transition: all 0.3s ease;
    }
    .sidebar.collapsed {
      width: 3rem;
    }
  </style>
</head>
<body class="bg-gray-100">

<div class="flex h-screen">

  <!-- 左侧系列栏 -->
  <div id="sidebar" class="sidebar bg-white shadow-md w-64 p-4 flex flex-col transition-all">
    <button id="toggleBtn" class="mb-4 p-2 bg-blue-500 text-white rounded">☰</button>
    <div id="seriesList" class="flex flex-col gap-2 overflow-auto">
      <!-- 系列按钮由 JS 动态生成 -->
    </div>
  </div>

  <!-- 右侧产品展示区 -->
  <div class="flex-1 p-6 overflow-auto">
    <div id="productGrid" class="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-6">
      <!-- 产品卡片由 JS 动态生成 -->
    </div>
  </div>

</div>

<script>
  const sidebar = document.getElementById('sidebar');
  const toggleBtn = document.getElementById('toggleBtn');
  const seriesList = document.getElementById('seriesList');
  const productGrid = document.getElementById('productGrid');

  // 左侧折叠按钮
  toggleBtn.addEventListener('click', () => {
    sidebar.classList.toggle('collapsed');
    seriesList.classList.toggle('hidden');
  });

  // 加载产品数据
  fetch('data.json')
    .then(response => response.json())
    .then(data => {
      // 生成系列按钮
      for (const seriesName in data) {
        const btn = document.createElement('button');
        btn.textContent = seriesName;
        btn.className = 'text-left p-2 bg-gray-200 hover:bg-gray-300 rounded';
        btn.addEventListener('click', () => showProducts(seriesName));
        seriesList.appendChild(btn);
      }

      // 默认显示第一个系列
      const firstSeries = Object.keys(data)[0];
      if(firstSeries) showProducts(firstSeries);

      function showProducts(seriesName) {
        productGrid.innerHTML = ''; // 清空
        const products = data[seriesName];
        products.forEach(p => {
          const card = document.createElement('div');
          card.className = 'bg-white rounded shadow p-4 flex flex-col items-center';

          const img = document.createElement('img');
          img.src = `../assets/product/${p.image}`;
          img.alt = p.name;
          img.className = 'w-32 h-32 object-contain mb-2';
          card.appendChild(img);

          const name = document.createElement('h3');
          name.textContent = p.name;
          name.className = 'font-bold text-center mb-1';
          card.appendChild(name);

          const project = document.createElement('p');
          project.textContent = `项目号: ${p.project}`;
          project.className = 'text-sm text-gray-600 mb-1';
          card.appendChild(project);

          const spec = document.createElement('p');
          spec.textContent = `规格: ${p.spec}`;
          spec.className = 'text-sm text-gray-600 mb-1';
          card.appendChild(spec);

          const price = document.createElement('p');
          price.textContent = `零售价: ${p.price}`;
          price.className = 'text-red-500 font-semibold';
          card.appendChild(price);

          productGrid.appendChild(card);
        });
      }
    })
    .catch(err => {
      console.error('加载产品数据失败:', err);
      productGrid.innerHTML = '<p class="text-red-500">产品数据加载失败</p>';
    });
</script>

</body>
</html>
```
