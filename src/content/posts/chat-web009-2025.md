---

#### ✅ 一、问题核心定位

根据你的描述：

> 首页能显示，但 - 左侧导航栏（或顶部菜单）点击无反应； - 进入文章后报 404。

这种情况在**GitHub Pages + Jekyll**部署时非常常见，原因通常有以下几种👇

---

#### ⚠️ 二、常见原因分析（结合你的配置）

##### 🧩 1.`baseurl`为空导致路径错误

你的网站 URL 是

```
https://seamoonappear.github.io
```

并且`_config.yml`中：

```
baseurl: ""
```

✅**这种设置是正确的**，只要仓库名是`seamoonappear.github.io`（即用户页），路径就不需要额外的`/blog`或`/site`。

❌ 但如果你的仓库名是：

```
seamoonappear/blog
```

那就要改成：

```
baseurl: "/blog"
```

> ⚠️ 如果`baseurl`错了，所有导航和文章链接都会 404（尤其在微信、手机浏览器里，因为缓存路径不同）。

👉**请先确认**： 你的仓库名是否为`seamoonappear.github.io`？

---

##### ⚙️ 2. 微信内置浏览器不支持`Service Worker`/`PWA`缓存逻辑

你启用了：

```
pwa:
  enabled: true
  cache:
    enabled: true
```

Chirpy 的 PWA 机制会在第一次访问时注册`service-worker.js`，但微信内置浏览器经常**屏蔽或缓存旧版本**，这会导致：

- 导航 JS 加载失败；

- 链接缓存旧路径，点进去 404；

- 左侧菜单点击无响应。

✅ 临时解决方案： 先禁用 PWA 缓存。

```
pwa:
  enabled: false
```

然后重新部署网站，看是否恢复正常。

---

##### 🔗 3. 链接路径未加`relative_url`或文章路径规则不一致

在`_config.yml`里你使用：

```
permalink: /posts/:title/
```

这会生成：

```
https://seamoonappear.github.io/posts/文章标题/
```

请检查你的文章文件：

```
_posts/2025-10-01-test.md
```

是否有`permalink`字段或是否与此路径冲突。 另外，**模板中链接必须用：**

```
{{ '/path' | relative_url }}
```

否则在微信端缓存路径下可能变成：

```
https://seamoonappear.github.io/posts/posts/文章标题/
```

导致 404。

---

##### 🧱 4. Jekyll 构建的静态路径缓存未刷新

微信内置浏览器会**强制缓存所有静态资源**，包括 JS、CSS、manifest.json。 如果你最近修改了`_config.yml`或文章路径，旧缓存可能仍在生效。

✅ 解决：

1. 打开微信网页 → 点击右上角菜单 → 复制链接；

1. 在手机浏览器（如 Chrome、Safari）打开；

1. 看是否恢复正常。

如果浏览器可用，而微信内不行，则是缓存问题。 最终可以通过：

- 改动 _config.yml 中 url 末尾加一个版本号参数，比如：

```
  url: "https://seamoonappear.github.io?v=20251012"
```

- 或暂时关闭 pwa 。

---

#### 🧭 三、推荐排查顺序（最有效步骤）

1. ✅ 确认仓库名

- 如果是`seamoonappear.github.io`→`baseurl: ""`- 如果是`blog`或别的仓库 →`baseurl: "/blog"`

1. ✅ 暂时关闭 PWA

```
   pwa:
     enabled: false
```

1. ✅ 重新部署

在 GitHub Actions 完成后访问 👉`https://seamoonappear.github.io/?clear_cache=1`

1. ✅ 清空微信缓存

- 关闭网页重新打开； - 或在桌面浏览器测试对比。

---

#### 🧩 四、额外优化建议

##### 1️⃣`avatar`路径要相对

```
avatar: "/assets/img/avatar.jpg"
```

✅ 建议改为：

```
avatar: "{{ '/assets/img/avatar.jpg' | relative_url }}"
```

防止在子目录部署时图片丢失。

##### 2️⃣ 添加 SEO og:image

```
social_preview_image: "/assets/img/preview.jpg"
```

##### 3️⃣ 添加 sitemap 插件

在`_config.yml`最下方加：

```
plugins:
  - jekyll-seo-tag
  - jekyll-sitemap
  - jekyll-feed
```

| 问题原因 | 解决方案 |
|---|---|
| 微信端导航无反应 | 暂时关闭 PWA |
| 点击文章 404 | 检查`baseurl`和`permalink`设置 |
| 页面样式异常 | 清除微信缓存 |
| 图片或资源加载失败 | 路径统一使用`relative_url` |

那问题就只剩两个主要因素：

---

#### 1️⃣ 微信端导航失效

原因：

- 你启用了 PWA + service worker ：

```
pwa:
  enabled: true
  cache:
    enabled: true
```

- 微信内置浏览器对 service worker 支持不好，可能导致：

- 左侧导航栏 JS 事件不触发； - 部分静态资源缓存异常。

✅ 解决办法： 暂时禁用 PWA：

```
pwa:
  enabled: false
```

部署后，导航栏应该立即生效。

---

#### 2️⃣ 文章点击 404

原因：

- Chirpy 的文章路径配置是：

```
defaults:
  - scope:
      path: ""
      type: posts
    values:
      layout: post
      comments: true
      toc: true
      permalink: /posts/:title/
```

- 文章文件 _posts/2025-10-01-example.md 会生成 URL：

```
https://seamoonappear.github.io/posts/example/
```

- 404 可能是因为：

1. Jekyll 构建未完成； 2. 微信缓存了旧的链接； 3. 本地文章标题中有特殊字符（空格、中文符号），URL 转换后不一致。

✅ 解决办法：

1. 确认文章文件命名规范：

```
_posts/YYYY-MM-DD-文章标题.md
```

- 中文标题 Jekyll 会自动转成拼音或 UTF-8 编码，最好保持英文或拼音，避免微信端乱码。

1. 清缓存：

- 微信内置浏览器关闭页面 → 重新打开；

- 或桌面浏览器访问确认是否可用。

1. 如果仍然 404，可在 _config.yml 中添加 permalink 前缀：

```
permalink: /posts/:title/
```

确保与文章`defaults`保持一致。

---

#### 3️⃣ 补充优化（防止再出问题）

```
avatar: "{{ '/assets/img/avatar.jpg' | relative_url }}"
social_preview_image: "{{ '/assets/img/preview.jpg' | relative_url }}"
```

- 所有静态资源用 relative_url 处理，避免路径错误。

- 禁用 PWA 后，微信端资源加载会更稳定。

---

##### ✅ 小结

1. 禁用 PWA → 微信端导航栏生效

1. 确认文章命名 → 避免 404

1. 静态资源用 relative_url → 避免图片或 JS 加载失败
