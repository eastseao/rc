###### 行内编辑逻辑：

- 用户点击单元格 → 该格变为 <input> 或 <select> 。

- 编辑完成后按 Enter 或失焦自动保存。

###### 新增逻辑：

- 点击“新增合同” → 在表格末尾自动插入一空白行（序号自动 +1）。

- 用户直接填写内容（无需弹窗）。

###### 删除逻辑：

- 可单选复选框多选删除。

- 点击“删除选中”后二次确认。

###### 搜索逻辑：

- 顶部输入框可模糊匹配“物料名 / 供应商 / 进展 / 比价”字段。

- 输入后实时过滤。

###### Excel导出：

- 使用 SheetJS ，自动导出当前筛选结果为 Excel。

## Q43 · 后三个板块的高优先级显示了灰色，请全面修正（第 43 轮对话）

> **提问：** 后三个板块的高优先级显示了灰色，请全面修正

明白了，你遇到的问题是**默认数据里后三个板块的`priority`没有初始化或者没有被正确渲染**，导致“高优先级”显示灰色，而不是红色。

我们可以做两个修正：

---

##### 1️⃣ 新增行时默认优先级为`'中'`（已加）

确保每个板块新增行对象里都有`priority`字段：

```
function addRow(id){

  const data=getData(id);

  renderTable(id);

```

---

##### 2️⃣**渲染行时严格读取`row.priority`并赋背景**

在`renderRows()`里，必须用`row.priority`字符串严格判断，不能依赖默认样式：

```
if(row.priority==='高') tr.className='bg-red-400 text-white';
else if(row.priority==='中') tr.className='bg-yellow-300';
else tr.className='bg-gray-200';
```

> 注意：不要用`row.priority || '中'`在 className 里，否则未初始化会被判为`'中'`的黄色，但数据里可能是`undefined`。一定要保证数据里每条都有`priority`。

---

如果本地存储里之前的行没有`priority`字段，可以在初始化时自动补上：

```

    }

});
```

```html
              ${block.keys.map(k=>`<th class="border px-2 py-1">${k}</th>`).join('')}
              <th class="border px-2 py-1">优先级</th>
              <th class="border px-2 py-1">操作</th>
            </tr>
          </thead>
          <tbody id="${id}-table-body" class="cursor-move"></tbody>
        </table>
      </div>
    `;
```
```html
    container.dataset.inited=true;
    Sortable.create(document.getElementById(id+'-table-body'),{
      animation:150,
      onEnd:()=>saveOrder(id)
    });
  }

  const tbody=document.getElementById(id+'-table-body');
  tbody.innerHTML='';
  data.forEach((row,index)=>{
    const tr=document.createElement('tr');
    tr.innerHTML=`
      <td class="border px-2 py-1 text-center"><input type="checkbox"></td>
      <td class="border px-2 py-1 text-center">${index+1}</td>
      ${block.keys.map(k=>`<td class="border px-2 py-1" contenteditable="true">${row[k]||''}</td>`).join('')}
      <td class="border px-2 py-1 text-center">
        <select onchange="updatePriority('${id}',${index},this.value)" class="border-none px-1 py-0.5 rounded w-full">
          <option value="高" ${row.priority==='高'?'selected':''}>高</option>
          <option value="中" ${row.priority==='中'?'selected':''}>中</option>
          <option value="低" ${row.priority==='低'?'selected':''}>低</option>
        </select>
      </td>
      <td class="border px-2 py-1 text-center">
        <button class="bg-green-400 text-white px-1 rounded" onclick="saveRow('${id}',${index})">保存</button>
        <button class="bg-red-400 text-white px-1 rounded" onclick="deleteRow('${id}',${index})">删除</button>
      </td>
    `;
    tbody.appendChild(tr);
  });

  document.getElementById(id+'-count').innerText = data.length;
}

// === 初始化渲染 ===
blocks.forEach(b=>renderTable(b.id));
</script>
```
