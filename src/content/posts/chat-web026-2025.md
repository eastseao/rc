## Q2 · ❌ 无法读取数据文件，请检查路径 tz/data.json（第 2 轮对话）

> **提问：** ❌ 无法读取数据文件，请检查路径 tz/data.json

非常好，我们来**一步步定位问题**。这个错误说明页面没能正确加载`tz/data.json`文件。

下面是最常见的**5 种原因与对应解决办法**👇

---

##### ✅ 一、路径问题（最常见）

检查你的文件目录结构。 确保是👇这样摆放的：

```
📁 你的项目根目录
│
├─ index.html
└─ 📁 tz
   └─ data.json
```

👉**注意事项：**

- 文件夹名字必须是 tz （大小写一致）。

- data.json 必须放在 tz 文件夹里。

- 你的 index.html 必须和 tz 文件夹在 同一级目录 。

如果不是这样，请调整。

---

##### ✅ 二、在本地直接用浏览器打开（file://）时

浏览器的安全策略（CORS）会**禁止读取本地 JSON 文件**。**症状**：用 Chrome 打开会报

> "Access to fetch at 'file:///.../tz/data.json' from origin 'null' has been blocked by CORS policy"

###### 🔧 解决方案有三种：

1. 最简单 ：用 VSCode 的插件 “Live Server” 启动网页

- 右键`index.html`→ 选择「Open with Live Server」 - 页面地址变成`http://127.0.0.1:5500/index.html`- 此时能正常加载 JSON。

1. 或者 ：用 Python 启一个本地服务器

```
   python -m http.server 8000
```

然后浏览器打开： ```http://localhost:8000/index.html```

1. 或者 ：放到 GitHub Pages

例如仓库结构： ```your-repo/ ├─ index.html └─ tz/data.json```推送后在`https://你的用户名.github.io/your-repo/` 打开就能用了。

---

##### ✅ 三、文件名或扩展名不正确

请确认文件名是：

```
data.json
```

不是：

```
data.json.txt
```

可以右键查看文件属性或在 VSCode 中看右上角文件类型。

---
