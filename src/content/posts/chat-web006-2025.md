## Q1 · GitHub Settings → Developer settings → P…（第 1 轮对话）

> **提问：** GitHub Settings → Developer settings → Personal access tokens → Tokens (classic) 找不到 developer setting

✅ 很好问题！这是很多人在 GitHub 新界面下容易遇到的困惑。 GitHub**已经调整了 Personal Access Token 的位置**，默认入口不再是旧版 “Developer settings → Personal access tokens → Tokens (classic)”。

---

##### 🔍 新版 GitHub 入口路径如下：

###### **方式一：新版 Token（推荐）**

1. 登录 GitHub → 点击右上角头像 → Settings

1. 左侧边栏拉到最底部 → 点击 Developer settings

1. 在展开的菜单中选择： Personal access tokens → Fine-grained tokens

1. 点击右上角 “Generate new token”

这是新的「细粒度令牌」（Fine-grained tokens），比 classic token 安全。

---

###### **方式二：旧版 Classic Token（如果你的界面还有）**

如果你确实需要旧版 classic token（例如旧的部署工具要求），可以这样找：

1. 登录 GitHub → 点击头像 → Settings

1. 左侧最底部选择 Developer settings

1. 点击 Personal access tokens → Tokens (classic)

1. 点击 Generate new token (classic)

> ⚠️ 注意：GitHub 正在逐步隐藏 “classic” 入口，有些用户账号已经默认不显示该选项。

---

###### **方式三（快速直达链接）**

你也可以直接访问以下链接：

- 新版（Fine-grained tokens）

👉[https://github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens)

- 旧版（Classic tokens）

👉[https://github.com/settings/tokens](https://github.com/settings/tokens)

如果你打开第二个链接出现 404，说明你的账号已经不支持 classic token，只能用 Fine-grained token。
