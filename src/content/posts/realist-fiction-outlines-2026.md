## 02 · 《流水人家》：杭州四十年五卷史诗（00899 · 2026-04-11）

仿《活着》笔法，第一人称口述体——晚年王浩向孙辈讲述。以「水」为意象：西湖静水、钱塘江潮、大运河活水、数字经济数据流。历史大事不正面铺陈，化作粮票换盒饭、BP 机换 iPhone、老宅拆迁搬滨江公寓等生活切面。

| 卷次 | 时间 / 主题 | 行业变迁 · 城市空间 · 人物命运 |
|---|---|---|
| **卷一 水上人家** | 1980-1990<br> | 运河船民第三代。水运衰落 / 纺织技改；运河—拱宸桥；父亲王德发 1987 年被迫「上岸」买二手货车。尾声搬离运河，把祖传船桨挂上新家墙。 |
| **卷二 潮涌钱塘** | 1990-2000<br> | 旧城改造 / 汽车消费兴起；老城—庆春路；父亲开杭州第一批搬家公司，母亲环北小商品市场卖服装，王浩 1999 开汽车美容店。望江对岸萧山仍是一片漆黑。 |
| **卷三 数字浪潮** | 2000-2010<br> | 电商崛起 / 房地产起飞；滨江—钱江新城；娶阿里客服林晓雨，2008 金融危机三店关门、地铁征迁，2010 转做二手车并打通淘宝。 |
| **卷四 大城崛起** | 2010-2020<br> | 移动互联 / G20 与亚运；全城—国际舞台；2017 晓雨查出癌症晚期、2018 病逝，王浩酗酒，疫情后被儿子教用钉钉、决定重新开始。 |
| **卷五 江流入海** | 2020-2026<br> | AI 浪潮 / 新能源；全域—智慧城市；改行经典车修复工作室，2023 父亲八十八岁睡梦中辞世，儿子王远帆机器人社团拿全省冠军。全书终幕回到拱宸桥。 |

## 04 · 盐选情感系列：单身时光 · 陈小麦（01227 · 2026-05-28）

## 05 · 《四站心动》：地铁邂逅 30 章慢爱情（00965 · 2026-04-16）

灵感即开头那一幕：早高峰地铁挤到脸贴脸，男生双手举高四站没动，女孩终于小声说「你可以放下来的……放我腰上」。书名建议《四站心动》或《地铁三十三号线》。时间跨度从初遇到结婚约 2-3 年。

| 阶段 | 章节 | 节拍 |
|---|---|---|
| **一、相遇** | 1-6 | 四站的距离 → 借你的手 → 第三天默契 → 她叫沈溪（广告公司设计师）→ 公司隔一条街、带早餐回赠咖啡 → 第一次约饭。 |
| **二、靠近** | 7-14 | 周末看展 → 撞见她前任 → 深夜送回家 → 他告白咽回 → 她在他怀里抬头问「你到底要不要和我在一起」→ 确定关系、见朋友。 |
| **三、深陷** | 15-20 | 第一次争吵 → 地铁上她握他手无声和解 → 她生日惊喜 → 回家见父母 → 他工作低谷她陪着。 |
| **四、考验** | 21-26 | 她异地三个月、他写日记 → 他偷偷飞去在地铁站等她下班 → 她有留任升职机会 → 她放弃机会回来「好工作到处有，好人只有一个」→ 在最初站台求婚。 |
| **五、余生** | 27-30 | 筹备婚礼 → 婚礼上伴郎讲「举了四站的手」全场笑 → 蜜月 → 婚后回到那个站台闭环：「现在不用举了，我有扶手了。」 |
