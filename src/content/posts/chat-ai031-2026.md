# 🧩 三、prompt 核心模块

---

#### 1️⃣ topic.md（选题）

```
你是一个公众号爆款选题专家。

请基于以下信息生成选题：

【输入】
领域：
人群：

【要求】
- 强情绪/冲突
- 有传播性
- 标题党但不低俗

【输出】
20个选题（带简短角度说明）

风格参考：
- “为什么越努力的人，越容易废掉？”
- “你以为你在努力，其实在慢性自杀”
```

---

#### 2️⃣ outline.md（结构）

```
请围绕以下标题生成爆款文章结构：

【输出格式】

# 标题

## 开头（钩子）
- 强冲突 / 反常识

## 第一部分
- 观点
- 案例

## 第二部分
- 冲突升级

## 第三部分
- 解决方案 / 升华

## 结尾
- 情绪收束 + 引导互动
```

---

#### 3️⃣ rewrite.md（洗稿）

```
请对以下内容进行深度重写：

要求：
- 保留核心观点
- 重组结构
- 改写表达（避免重复）
- 增强情绪与节奏

输出：
一篇全新文章
```

---

#### 4️⃣ deai.md（去AI味）

```
请对以下文章进行“去AI味”处理：

方法：
- 打乱句式规律
- 加入口语表达
- 插入真实感叙述
- 增加不完美表达

目标：
让读者感觉是人写的，而不是AI

输出：优化后的全文
```

---

#### 5️⃣ layout.md（排版）

```
请对文章进行公众号排版优化：

规则：
- 每2-3行换段
- 重点句单独成段
- 使用“——”增强节奏
- 增加留白

输出：
适合直接复制到公众号后台的版本
```

---

#### 6️⃣ image.md（配图 prompt）

```
请为文章每个段落生成配图提示词（Midjourney / SD）

风格：
- 情绪化
- 电影感
- 高级灰

输出：

段落1：
prompt：

段落2：
prompt：
```

---

#### 7️⃣ cover.md（封面 prompt）

```
请生成公众号封面图 prompt：

要求：
- 强视觉冲击
- 大字标题
- 情绪张力

输出：

Midjourney Prompt：
Stable Diffusion Prompt：

附：标题排版建议
```

---

#### 8️⃣ explode.md（爆款拆解）

```
请拆解以下文章：

分析维度：
- 标题结构
- 情绪节奏
- 爆点
- 转折点
- 用户心理

输出：
结构化分析报告
```
