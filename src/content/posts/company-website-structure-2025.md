## 01 · 经典公司网页结构（通用推荐）（00185）

先解决「公司站到底该有哪几块」。笔记给出一套适用于大多数中小企业和初创公司的经典结构：**顶部导航栏 + 页脚**两个全局件，再加**首页 / 关于我们 / 产品服务 / 案例 / 新闻 / 联系我们**六个主页面。

## 02 · 生产型食品企业 · GitHub Pages 结构（00185）

把通用结构收窄到**「生产型食品企业 + GitHub Pages」**：GitHub Pages 只跑静态站，不数据库、不登录，正好契合企业展示、产品介绍与品牌传播；结构上突出食品企业的四个关键词——**安全、质量、溯源、品牌故事**。

## 03 · 新手网站需求整理与模板选型（00197）

另一篇笔记把角色换成**「采购负责人 + 完全新手」**：不会本地部署，只能通过网页和手机端操作，要求尽量简单。需求先逐条整理成结构，再据此推荐模板。

> **可复制按钮（照录思路）**
> - 把「文件路径」单独列出来，旁边放一个复制按钮，点一下即复制完整路径——给后续照抄代码、填图片地址用。
> - 复制 trthealth.com 页面代码时同样用「路径单列 + 复制按钮」，避免长代码在对话里找不全。

## 05 · 假期搭建心得：删库十几次与「知易行难」（00198）

第三份是一段非技术的真实记录：有编程基础的新手，第一次用 ChatGPT 完整搭站，体会到理论与工程之间的差距。
