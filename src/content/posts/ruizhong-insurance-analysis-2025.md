## 04 · 保险代位追偿详解（00240 · 2025-10-14）

**代位追偿（代位求偿）**：保险事故由第三方责任造成时，保险公司赔付被保险人后，在赔偿金额范围内取代被保险人位置向责任第三方追偿——"你的损失我先赔，索赔权归我，我去找肇事者要钱"。

<div style="border:1px solid #dfe6ef;border-radius:8px;overflow:hidden;background:#fff;margin:14px 0"><div style="padding:12px 16px;border-bottom:1px solid #dfe6ef;background:#f6f8fa;font-weight:700"><span>法律依据</span><h3>《保险法》第六十条</h3></div><div style="padding:14px 16px"><p style="font-size:13.5px;color:inherit">&quot;因第三者对保险标的的损害而造成保险事故的，保险人自向被保险人赔偿保险金之日起，在赔偿金额范围内代位行使被保险人对第三者请求赔偿的权利。&quot;</p><dl style="display:grid;grid-template-columns:110px 1fr;gap:8px 16px;margin:14px 0;margin-top:12px"><dt>核心要素 1</dt><dd>第三方责任——事故须由合同双方之外的第三方造成。</dd><dt>核心要素 2</dt><dd>保险标的受损——造成合同约定损失。</dd><dt>核心要素 3</dt><dd>保险人已支付赔款——代位权产生的前提。</dd><dt>核心要素 4</dt><dd>权利范围以赔款为限——不得超过实际赔付金额。</dd></dl></div></div>

| 流程步骤 | 说明 |
|---|---|
| 1. 发生事故 | 确认事故由第三方责任引起。 |
| 2. 通知保险公司 | 向己方保险公司报案，说明第三方责任。 |
| 3. 申请理赔 | 提交索赔申请。 |
| 4. 获得赔偿 | 审核通过后向被保险人支付赔款。 |
| 5. 权益转让 | 签署"权益转让书"，追偿权正式转移。 |
| 6. 保险公司追偿 | 凭事故认定书、维修发票、权益转让书等向责任方追偿。 |

> **重要注意事项**
> - 获赔前**不得擅自放弃**对第三方的索赔权，否则保险公司可相应扣减或拒赔。
> - 被保险人无责任时，使用代位追偿一般**不影响次年保费**（视为"无赔款"记录），具体以承保公司政策为准。
> - 主要适用**财产险**（车险、家财险、企财险）；人身险（寿险、意外险）一般不适用，医疗费用报销部分或有例外。

## 05 · 瑞众常青树（特惠3.0版）重疾险分析（00362 · 2025-10-30）

一款面向**0-65 周岁**的重疾险，核心特点是保障期限灵活、基础与可选责任可拆分。

| 项目 | 内容 |
|---|---|
| **投保年龄** | 0 周岁（满 28 日）- 65 周岁 |
| **保障期限** | 可选 20 年、30 年、至 60/70/80 岁或终身 |
| **缴费方式** | 趸交或分期（5/10/20 年等） |
| **等待期** | 90 天（意外导致无等待期） |
| **基础责任（必选）** | 重疾保险金：130 种重疾赔 1 次，给付基本保额 / 已交保费 / 现金价值最大者；身故 / 全残保险金：18 岁前赔已交保费，18 岁后赔三者最大者。 |
| **可选责任** | 轻症疾病保险金：50 种轻症赔 1 次，为基本保额 30%；轻症豁免：确诊轻症后豁免后续保费，合同继续有效。 |
