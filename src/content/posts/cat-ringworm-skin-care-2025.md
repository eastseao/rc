## 01 · 脖子硬结痂的可能原因与自查（00053）

猫咪脖子出现两个硬硬的结痂，最常见的是**跳蚤过敏性皮炎**与**猫癣**，但也可能是外伤、螨虫、细菌感染、过敏甚至罕见的肿瘤。先按下表对照，再做自查清单，最后就医。

| 可能原因 | 典型表现 |
|---|---|
| **跳蚤过敏性皮炎** | 最常见之一。对跳蚤唾液过敏，几只叮咬就剧烈瘙痒；疯狂抓挠啃咬后颈与背部，结痂继发于抓挠损伤。 |
| **猫癣（真菌）** | 主要由犬小孢子菌引起；圆形脱毛、皮屑、红斑与黄褐色或灰色硬结痂；脖子是常见部位；可传染动物与人。 |
| **打架或外伤** | 抓伤、咬伤或自挠愈合中结痂；若感染则结痂更厚、周围红肿或有分泌物。 |
| **螨虫感染** | 疥螨引起剧烈瘙痒、脱毛、皮肤增厚结痂，常从耳缘、脸部开始可蔓延到脖子；蠕形螨在猫较少见。 |
| **细菌 / 酵母菌感染** | 细菌性脓皮病继发于跳蚤、过敏、外伤，形成脓疱结痂；马拉色菌则皮肤油腻发红瘙痒。 |
| **食物或环境过敏** | 除跳蚤过敏外，食物与环境过敏也引起瘙痒，导致抓挠继发结痂，脖子是常见瘙痒部位。 |
| **内分泌问题（较少见）** | 甲状腺功能亢进（老年猫常见）或糖尿病，有时伴随皮肤问题，但通常不是唯一症状。 |
| **肿瘤（罕见）** | 鳞状细胞癌等皮肤肿瘤早期可能表现为不愈合的结痂或溃疡，年轻猫中非常少见。 |

| 兽医诊断手段 | 说明 |
|---|---|
| 伍德氏灯检查 | 初步筛查猫癣，某些真菌在灯下发苹果绿荧光；阴性不能完全排除。 |
| 皮肤刮片检查 | 显微镜下寻找螨虫、真菌孢子或细菌。 |
| 真菌培养 | 确诊猫癣的金标准，但需要时间。 |
| 拔毛 / 细胞学检查 | 显微镜查毛根真菌或螨虫；取结痂表面或分泌物查细菌、酵母菌。 |

## 02 · 猫癣由什么引起：传染三要素（00055）

猫癣是皮肤真菌感染，最常见为**犬小孢子菌**。发病是「病原体（真菌孢子）+ 传播途径（直接或间接接触）+ 易感宿主（免疫力低下的猫）」共同作用的结果。

## 03 · 为什么不能等猫癣自愈（00054 / 00055）

猫癣**理论上可能自愈，但不是普遍现象，强烈不建议等待**。成年、健康、免疫极强且感染极小局限的猫，在理想环境下可能数月内自行清除；但现实中风险极大。

##### 红线 · 等待自愈的代价

传染人、扩散、环境污染——赌不起

等待「可能」自愈期间，患猫不断向环境散播孢子：极易传染其他猫狗兔子，并作为人畜共患病传染儿童、老人、免疫力低下者（人患环形红斑「钱癣」，治疗需时且可能留疤留色素）；病灶可能扩散全身并继发细菌感染；孢子在环境可存活**18 个月甚至更久**，易复发；部分猫转为无症状携带者持续排毒；全程瘙痒脱毛影响生活质量。

| 正确做法 | 要点（照录） |
|---|---|
| **及时就医确诊** | 发现圆形脱毛、皮屑、结痂、红斑立即就医；伍德氏灯 + 皮肤刮片/拔毛真菌培养或镜检确诊。 |
| **外用药物** | 抗真菌药膏、喷剂或药浴（含咪康唑、克霉唑、特比萘芬等成分）；长毛猫或大面积感染剃毛有助渗透。 |
| **口服药物** | 严重、大面积或难愈者服伊曲康唑、特比萘芬；**严格按医嘱剂量疗程**，可能影响肝功能需定期监测。 |
| **坚持疗程** | 治疗通常需**4-8 周甚至更长**；即使症状消失也要用完整个疗程，直到兽医确认痊愈，否则极易复发。 |
| **环境彻底消毒** | 治疗成功的关键：带 HEPA 吸尘器每日清理毛发皮屑并立即弃尘袋；用 1:10 稀释漂白水、过硫酸氢钾复合盐等擦拭猫窝用具地板；织物热水加消毒液清洗；贯穿治疗期及愈后数周。 |
| **隔离与防护** | 病猫隔离在易消毒房间；接触后洗手、避免衣物沾染孢子；提供营养均衡食物、减少应激。 |

> **「看似自愈」其实更危险**
> - **无症状携带者**：没有明显脱毛皮屑，却仍脱落有传染性的孢子——不是真正自愈。
> - **症状暂时缓解**：环境干燥、免疫短期提升时症状减轻，一旦潮湿、应激、免疫下降便卷土重来。

## 04 · 人患猫癣症状与日常预防（00055）

猫癣是人畜共患病，由犬小孢子菌等真菌引起，人感染后主要表现为皮肤、毛发、指甲病变。了解症状才能早发现、早就医。

| 部位 | 症状 |
|---|---|
| **皮肤（最常见）** | 红色圆形或椭圆形斑块、边缘清晰略隆起、中央趋于平坦，呈「环状」；表面覆白色或黄色鳞屑，抓后可糜烂渗出结痂；边缘伴丘疹、水疱甚至脓疱；持续瘙痒、夜间加重。 |
| **毛发** | 头皮或体毛区圆形脱发斑、边界清晰常伴边缘红肿；毛囊受损致断发。 |
| **指甲** | 变形增厚、凹凸不平、易碎或条纹；变色发黄发灰，严重时脱落。 |
| **全身（少见）** | 免疫低下者可发热、头痛、乏力、局部淋巴结肿大。 |

感染后 1~2 周首发小丘疹或红色小斑块、伴轻痒脱屑，易误判为蚊虫叮咬或湿疹；常见于暴露部位（手臂、面部）或与病猫接触处（如抱猫的胸前）。儿童、老人、孕妇及免疫缺陷者症状更重。确诊靠真菌镜检或培养，轻症外用酮康唑、特比萘芬等抗真菌药膏，重症需口服，同时治疗患猫并加强环境消毒。
