## 🧠 技能简介
自动提取最近7天微信公众号10万+爆款文章，并完成内容重构、去AI化、排版优化与配图生成，输出可直接发布的公众号成品文章。

## 🚀 能力列表

1. 📊 爆款文章采集
- 抓取最近7天内阅读量 ≥10万的公众号文章
- 按分类输出（默认：情感 / 商业 / 认知 / 热点 / 成长）

3. 🧬 去AI味处理
- 消除模板化表达
- 增强人类写作特征（情绪、节奏、口语化）
- 降低重复率

4. 🎨 排版优化
- 公众号风格排版（短段落 + 留白）
- 小标题优化
- 强化阅读节奏

5. 🖼️ 图片生成提示
- 封面图 prompt
- 正文配图 prompt（插入位置标注）

6. ❤️ 结尾引导
- 自动生成点赞 / 在看 / 关注引导文案

# 🧠 run.py（核心执行逻辑｜一体化）

```python
from prompts import fetch, rewrite, deai, layout, image, ending

class WeChatHotRebuilder:

    def __init__(self, config):
        self.config = config

    def run(self):
        # 1. 获取爆款文章
        articles = fetch.get_hot_articles(self.config)

        results = []

        for art in articles:
            # 2. 重构
            rewritten = rewrite.process(art)

            # 3. 去AI味
            humanized = deai.process(rewritten)

            # 4. 排版
            formatted = layout.process(humanized)

            # 5. 图片
            images = image.generate(formatted)

            # 6. 结尾
            final_content = ending.append(formatted)

            results.append({
                "origin_title": art["title"],
                "new_title": rewritten["title"],
                "account": art["account"],
                "publish_time": art["time"],
                "views": art["views"],
                "url": art["url"],
                "content": final_content,
                "images": images
            })

        return {"articles": results}
```
