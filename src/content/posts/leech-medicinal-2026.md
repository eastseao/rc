## 01 · 水蛭功效与使用方法（破血逐瘀 · 通经消癥）

水蛭为水蛭科动物蚂蟥、水蛭或柳叶蚂蟥的**干燥全体**，是中医传统的破血逐瘀要药。核心活性成分为**水蛭素**。

| 项目 | 内容 |
|---|---|
| **基原** | 水蛭科动物——蚂蟥（宽体金线蛭）、水蛭（日本医蛭）、柳叶蚂蟥。 |
| **性味归经** | 性平，味咸、苦；有小毒。归肝经。 |
| **核心功效** | 破血通经、逐瘀消癥。用于血瘀经闭、癥瘕痞块、中风偏瘫、跌扑损伤。 |
| **活性成分** | 水蛭素（强效凝血酶抑制剂）、肝素、抗血栓素等。 |
| **现代应用** | 心脑血管疾病辅助（血栓、脑梗）、跌打损伤、妇科血瘀证。 |
| **用法用量** | 煎服1-3g；研末吞服0.3-0.5g。以研末装胶囊吞服效果为佳。 |

##### 红线 · 使用禁忌

活血力强，孕妇及出血倾向者禁用

水蛭有小毒，活血破瘀力猛。**孕妇禁用**；有出血倾向（凝血功能障碍、消化道出血、月经期）者忌用；不宜与抗凝药物（阿司匹林、华法林等）自行叠加。用量须严格遵医嘱。

## 02 · 水蛭干制品详解（炮制工艺 · 品质鉴别）

水蛭干制品是临床最常用的药用形态。传统炮制方法包括**烫水蛭**（滑石粉烫制）等，以降低毒性、便于粉碎和服用。

| 炮制规格 | 炮制方法 | 特点与适用 |
|---|---|---|
| **清水蛭** | 捕后洗净，晒干或低温烘干。 | 生品性峻烈，破血力强，毒性也大。一般不直接内服。 |
| **烫水蛭** | 滑石粉置锅加热，投入水蛭段烫至鼓起酥松。 | 毒性降低，质地酥脆易粉碎，临床最常用。 |
| **炒水蛭** | 文火炒至微黄略鼓起。 | 药性缓和，适合体弱需活血者。 |

## 品质鉴别要点

| 鉴别维度 | 优质水蛭干品 |
|---|---|
| **来源** | 宽体金线蛭（蚂蟥）为主流商品，体大条宽为佳。 |
| **颜色** | 背部黑棕色，腹部黄棕色，有细密环节。 |
| **质地** | 质脆易断，断面胶质样，有光泽。 |
| **气味** | 气微腥，味咸。 |
| **警惕** | 颜色过浅发白可能掺假增重；霉变、虫蛀不可药用。 |

## 03 · 水蛭粉胶囊检测指南（选购指标 · 质量检测）

水蛭粉胶囊是现代便捷剂型，选购时应关注以下检测指标，确保产品真实有效。

| 检测指标 | 合格标准/关注点 | 说明 |
|---|---|---|
| **水蛭素活性** | 标示含量或活性单位 | 核心功效成分。优质产品应标含水蛭素含量或抗凝活性单位。 |
| **水分** | ≤12% | 水分过高易霉变、有效成分降解。 |
| **总灰分** | ≤10% | 反映泥沙杂质多少。 |
| **酸不溶性灰分** | ≤2% | 严控无机杂质。 |
| **微生物限度** | 符合药典 | 细菌总数、霉菌酵母数、致病菌不得检出。 |
| **重金属** | 铅≤5mg/kg等 | 按药典重金属及有害元素限量执行。 |
| **浸出物** | 醇溶性浸出物≥15% | 反映有效成分溶出水平。 |

> **选购建议**：① 选有正规GMP药企生产、有批号的产品；② 查看检测报告，关注水蛭素活性指标；③ 不买三无散装粉；④ 按说明书或医嘱服用，**不可自行加量长期服用**。
