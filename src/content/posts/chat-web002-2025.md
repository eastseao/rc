## Q23 · 【None】页面显示还是有些问题（第 23 轮对话）

> **提问：** 【None】 页面显示还是有些问题

非常好 👍 我看到了页面截图（谢谢上传！），问题确实出在**Chirpy 主题的 Markdown 渲染器**：它默认把三栏里的内容再包成`<p><code>`或`<pre>`等 Markdown 区块，导致标题 (`###`) 被当成纯文本显示，而不是标题样式。

👉 简单讲，就是**你写的 Markdown 没有被当成 HTML 渲染**。

---

##### ✅ 解决思路

要在 Chirpy 里实现三栏卡片布局，必须让内部内容**以 HTML 而不是 Markdown 渲染**。 Markdown 在`<div>`里默认不会被二次解析（除非你启用`kramdown`的`parse_block_html: true`，而 GitHub Pages 默认关闭）。

所以我们改写成纯 HTML 格式，这样保证 100% 渲染一致，不再被当作代码块。
