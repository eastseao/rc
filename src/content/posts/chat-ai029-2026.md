## Q1 · 结构化输出优化版提示词请严格按照以下规则生成回复内容，确保在 Typora（或（第 1 轮对话）

> **提问：** # 结构化输出优化版提示词 请严格按照以下规则生成回复内容，确保在 Typora（或其他支持 HTML 渲染的 Markdown 编辑器）中呈现精美、可截图的视觉效果。 --- 1. 全文源码包裹（防截断） 将你生成的所有回复内容，**整体包裹**在一个 ````markdown`和 ```` 代码块中（**四个反引号**，内部可安全包含三个反引号的代码块或 Mermaid 图表）。 代码块外部**严禁**输出任何问候、解释或说明文字。 2. 结构化排版 使用 Markdown 标题（`#`、`##`、`###`）划分章节。 **文章主标题**：使用一级标题`#`，并通过内联 CSS 实现居中对齐。 示例：`<h1 style="text-align: center;">你的主标题</h1>` （Typora 中也可直接用`#`配合自定义 CSS，但内联样式更稳妥） **章节标题**：使用二级标题`##`，左对齐，不强制居中。 3. 视觉组件（必须使用内联 CSS） 所有样式写在`style`属性内，不引入外部样式表。 3.1 引言/提示框 `<div style="background-color: #e3f2fd; border-left: 5px solid #2196f3; padding: 12px 16px; margin: 16px 0; border-radius: 6px; color: #333;"> 这里放置提示或引言内容。 </div>` 3.2 Flex 特性卡片 使用`display: flex; gap: 16px; flex-wrap: wrap;`的容器包裹卡片。 每张卡片样式： `background-color: #e3f2fd; /* 浅蓝背景 */ border: 1px solid #bbdefb; /* 略深边框 */ border-radius: 12px; box-shadow: 0 4px 8px rgba(0,0,0,0.05); padding: 16px; flex: 1 1 200px; /* 自适应宽度，最小200px */ color: #333;` 卡片内可包含标题（`<h3>`或`###`）、段落、列表等，**推荐全部使用 HTML 标签**以确保渲染一致。 3.3 样式化表格 使用 HTML`<table>`标签，样式如下： `<table style="width:100%; border-collapse: collapse; margin: 16px 0;"> <thead style="background-color: #b3e5fc; text-align: left;"> <tr><th style="padding: 8px;">标题1</th><th style="padding: 8px;">标题2</th></tr> </thead> <tbody> <tr style="border-bottom: 1px solid #e0e0e0;"> <td style="padding: 8px;">内容1</td> <td style="padding: 8px;">内容2</td> </tr> <!-- 更多行 --> </tbody> </table>` 3.4 渐变总结框 文末使用： `<div style="background: linear-gradient(145deg, #bbdefb, #b2dfdb); padding: 20px; border-radius: 12px; color: #333; margin-top: 24px;"> 总结内容... </div>` 4. 配色方案（主色调：浅蓝 + 中性浅色） 背景浅蓝：`#e3f2fd` 边框浅蓝：`#bbdefb` 强调蓝：`#2196f3` 表头蓝：`#b3e5fc` 渐变辅助：`#b2dfdb` 文字颜色：`#333333`（深灰，保证对比度） 5. 额外增强元素 **Mermaid 图表**：使用 ````mermaid`代码块，内部编写流程图/时序图，确保缩进正确。 **任务列表**：使用 Markdown 格式`- [ ] 未完成`和`- [x] 已完成`，Typora 原生支持。 **图片**：若插入图片，添加`style="max-width:100%; height:auto;"`确保自适应。 6. 文末署名与日期 全文末尾居中放置： `<p style="text-align: center; color: #777; margin-top: 32px;"> [AI名称] 整理于 2026-04-19</p>` 日期使用实际生成日期，格式`yyyy-mm-dd`。 将`[AI名称]`替换为具体 AI 名称（如 ChatGPT、DeepSeek 等）。 7. 兼容性注意事项（针对 Typora） **所有 HTML 标签必须严格闭合**（包括`<div>`、`<p>`、`<table>`等）。 不要在 HTML 容器内混用 Markdown 语法（例如`<div>**粗体**</div>`可能无效），请全部使用 HTML 标签（如`<strong>粗体</strong>`）。 Mermaid 图表和任务列表可以放在 HTML 容器外部（即直接写在 Markdown 层级），不影响布局。 Flex 卡片容器内若想换行，使用`<br>`或块级元素（如`<p>`、`<div>`）。 避免使用过于复杂的 CSS 属性（如`grid`、`clip-path`），优先选择 Typora 渲染稳定的属性。 8. 完整输出结构示例（供参考） `<h1 style="text-align: center;">主标题</h1> ## 章节一 <div style="background-color:#e3f2fd; # 🧠 run.py（执行逻辑层）

~~~~html
from datetime import datetime
import re

class TyporaVisualArchitect:

    def __init__(self):
        self.date = datetime.now().strftime("%Y-%m-%d")

    def transform(self, text: str) -> str:
        content = self._build_structure(text)
        return f"```markdown\n{content}\n```"

    def _build_structure(self, text: str) -> str:
        title = self._extract_title(text)

        body = f"""
<h1 style="text-align:center;">{title}</h1>

## 内容结构

<div style="background:#e3f2fd;border-left:5px solid #2196f3;padding:12px;border-radius:6px;">
{text}
</div>

## 总结

<div style="background:linear-gradient(145deg,#bbdefb,#b2dfdb);padding:16px;border-radius:12px;">
核心内容已完成结构化重组与视觉增强。
</div>

<p style="text-align:center;color:#777;">
Typora Visual Architect · {self.date}
</p>
"""
        return body

    def _extract_title(self, text):
        match = re.search(r"^.{5,30}", text)
        return match.group(0) if match else "Visual Document"


def run(input_text: str):
    engine = TyporaVisualArchitect()
    return engine.transform(input_text)
~~~~
