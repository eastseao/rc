## Q1 · 我要把我的技能都上传到我的github里，怎么操作，告诉我详细流程（第 1 轮对话）

> **提问：** 我要把我的技能都上传到我的github里，怎么操作，告诉我详细流程

好，这件事本质就是：**把你的 Skill 文件夹 → 推到 GitHub 仓库**。我给你一套**小白也能走通的完整流程（纯网页版 + 本地版两种）**，你按你当前能力选一种就行。

---

# 🚀 一、最简单（推荐）：纯网页上传（不用装任何工具）

适合你现在这种：**不会本地操作 / 不想折腾环境**

#### ✅ 第一步：创建仓库

1. 打开 👉 entity["website","GitHub","code hosting platform"]

1. 登录账号（你是 seamoonappear 对吧）

1. 右上角点 “+” → New repository

填写：

- Repository name： my-skills （随便起）

- 选择：✅ Public（建议公开）

- 勾选：✅ Add a README

点击：**Create repository**

---

#### ✅ 第二步：创建目录结构

在仓库页面：

点击：**Add file → Create new file**

文件名输入：

```
wechat-article-pro/skill.md
```

👉 注意：这样会自动创建文件夹

然后粘你 skill.md 内容 → Commit

---

#### ✅ 第三步：继续补全结构

重复操作，创建这些文件：

```
wechat-article-pro/config.yaml

wechat-article-pro/prompt/topic.md
wechat-article-pro/prompt/outline.md
wechat-article-pro/prompt/rewrite.md
wechat-article-pro/prompt/deai.md
wechat-article-pro/prompt/layout.md
wechat-article-pro/prompt/image.md
wechat-article-pro/prompt/cover.md
wechat-article-pro/prompt/explode.md

wechat-article-pro/templates/article.md
wechat-article-pro/templates/title.txt

wechat-article-pro/Memory.md
```

---

#### ⚡ 一个关键技巧（避免你手动建太慢）

你可以：

👉 先在本地用记事本整理好一个文件夹 👉 压缩成 zip 👉 用 GitHub 网页直接拖进去上传

---

# 🧠 二、进阶版（推荐你以后用）：Git + 本地上传

如果你想走“专业路线”，一定要学这个。

---

#### ✅ 第一步：安装 Git

去下载 👉 entity["software","Git","version control system"]

安装一路 Next 就行

---

#### ✅ 第二步：克隆仓库

打开终端（或 Git Bash）：

```
git clone https://github.com/seamoonappear/my-skills.git
```

进入目录：

```
cd my-skills
```

---

#### ✅ 第三步：把你的 Skill 丢进去

比如你本地结构：

```
wechat-article-pro/
```

直接拖进`my-skills`文件夹

---

#### ✅ 第四步：提交 + 上传

```
git add .
git commit -m "upload my skill"
git push
```

---

# ⚠️ 常见坑（提前帮你踩掉）

##### ❌ 上传失败

→ 没登录 GitHub / 没权限

##### ❌ 文件夹传不上去

→ GitHub 不允许空文件夹 👉 解决：放一个`.gitkeep`

##### ❌ 中文乱码

→ 文件统一 UTF-8
