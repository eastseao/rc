## Q5 · comments是什么功能？（第 5 轮对话）

> **提问：** comments是什么功能？

在**Jekyll Chirpy**主题中，`comments`是 Front Matter 中的一个布尔字段，用于**控制文章是否启用评论功能**。

---

##### 💬 作用说明

在你的文章 Markdown 文件头部（Front Matter）中：

```
---
title: 我的文章
comments: true
---
```

- comments: true → 页面底部会显示评论区域（通常是 Disqus、Giscus、Utterances 等评论系统）。

- comments: false → 隐藏评论区域。

---

##### ⚙️ 配置要求

这个功能依赖你在`_config.yml`里**正确配置了评论系统**。 Chirpy 主题支持以下几种常见评论方式（任选其一）：

| 评论系统 | 对应配置字段 | 说明 |
|---|---|---|
| **Disqus** | `disqus.shortname` | 传统博客评论平台 |
| **Utterances** | `utterances.repo` | 基于 GitHub Issues |
| **Giscus** | `giscus.repo` | 基于 GitHub Discussions |
| **Cusdis** | `cusdis.id` | 国人开发的轻量评论系统 |

---

##### 📘 示例：启用 Giscus 评论

在`_config.yml`中添加：

```
comments:
  active: giscus
  giscus:
    repo: seamoonappear/seamoonappear.github.io
    repo_id: YOUR_REPO_ID
    category: Announcements
    category_id: YOUR_CATEGORY_ID
    mapping: pathname
    reactions_enabled: 1
    emit_metadata: 0
```

然后在文章 Front Matter 里设置：

```
comments: true
```

你的文章底部就会自动出现 Giscus 评论区。
