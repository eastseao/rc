## Q2 · 进入文章页面，文章的宽度在哪个模块里修改（第 2 轮对话）

> **提问：** 进入文章页面，文章的宽度在哪个模块里修改

在 Beautiful Jekyll 或类似 Jekyll 主题中，文章页面（单篇文章）的宽度通常不是在 Markdown 文件里设置的，而是在**CSS 样式或布局模板**中控制的。你可以从两个方向去修改：

---

##### 1️⃣ 修改布局模板（HTML 文件）

文章页一般使用`post`或`default`布局。例如：

```
---
layout: post
---
```

对应的布局文件可能在：

```
_layouts/post.html
_layouts/default.html
```

里面通常有一个容器`<div class="post-container">`或`<div class="content">`控制文章区域。示例：

```html
<div class="post-container container">
  <div class="row justify-content-center">
    <div class="col-lg-8 col-md-10">
      {{ content }}
    </div>
  </div>
</div>
```

- col-lg-8 决定文章宽度占屏幕的 8/12（大约 66%）

- col-md-10 中等屏幕时占 10/12（大约 83%）

- 如果想加宽或缩窄文章内容，修改这两个类即可，例如 col-lg-10 col-md-12 。

---

##### 2️⃣ 修改 CSS

如果你只想通过 CSS 调整宽度：

```css
.post-container {
  max-width: 900px; /* 控制最大宽度 */
  margin: 0 auto;   /* 居中显示 */
  padding: 0 20px;  /* 左右内边距 */
}
```

- max-width ：文章区域的最大宽度

- margin: 0 auto ：水平居中

- padding ：控制左右留白

---

💡**总结**

- 最直接 ：修改 _layouts/post.html 或 _layouts/default.html 中的 .col-xx-x 类。

- 灵活控制 ：在 CSS 里设置 .post-container 的 max-width 和 padding 。

#### 2️⃣ 完整的`post`页面

```html
---
layout: default
---

{% assign date_format = site.date_format | default: "%Y年%-m月%-d日" %}

<div class="post-container py-5" style="background-color:#fff;">
  <div class="container">
    <div class="row justify-content-center">
      <!-- 大屏 col-lg-8，中屏 col-md-10，小屏 col-sm-12 -->
      <div class="col-lg-8 col-md-10 col-sm-12 px-3">

        <article class="post-content">

          <!-- 文章标题和副标题 -->
          <header class="post-header text-center mb-4">
            <h1 class="post-title">{{ page.title | strip_html }}</h1>
            {% if page.subtitle %}
              <h2 class="post-subtitle">{{ page.subtitle | strip_html }}</h2>
            {% endif %}

            <!-- 元数据一行显示，手机端自动换行 -->
            <div class="post-meta mt-3 small text-muted d-flex flex-wrap justify-content-center gap-2">
              {% if page.author %}
                <span class="author">作者：<strong>{{ page.author | strip_html }}</strong></span>
              {% endif %}
              <span class="published-date">&middot; 发表于 {{ page.date | date: date_format }}</span>
              {% if page.last-updated %}
                <span class="updated-date">&middot; 更新于 {{ page.last-updated | date: date_format }}</span>
              {% endif %}
              {% assign words = content | number_of_words %}
              {% assign minutes = words | divided_by:200 %}
              {% if minutes < 1 %}{% assign minutes = 1 %}{% endif %}
              <span class="reading-time">&middot; 阅读时间：{{ minutes }} 分钟</span>
            </div>
          </header>

          <!-- 封面图 -->
          {% if page.cover-img %}
            <div class="post-cover text-center mb-4">
              {% if page.cover-img.first %}
                <img src="{{ page.cover-img[0].first.first | relative_url }}" alt="Cover image" class="img-fluid rounded">
              {% else %}
                <img src="{{ page.cover-img | relative_url }}" alt="Cover image" class="img-fluid rounded">
              {% endif %}
              {% if page.cover-img-desc %}
                <p class="img-desc mt-2 text-muted small">{{ page.cover-img-desc }}</p>
              {% endif %}
            </div>
          {% endif %}

          <!-- 正文内容 -->
          <div class="post-body" style="line-height:1.8; font-size:1rem;">
            {{ content }}
          </div>

          <!-- 页脚：标签和分类 -->
          <footer class="post-footer mt-5 pt-3 border-top d-flex flex-wrap gap-3 justify-content-start">
            {% if page.tags %}
              <div class="post-tags">
                <strong>标签：</strong>
                {% for tag in page.tags %}
                  <a href="{{ '/tags#' | append: tag | relative_url }}" class="tag-badge">{{ tag }}</a>
                {% endfor %}
              </div>
            {% endif %}

            {% if page.categories %}
              <div class="post-categories">
                <strong>分类：</strong>
                {% for category in page.categories %}
                  <a href="{{ '/categories#' | append: category | relative_url }}" class="category-badge">{{ category }}</a>
                {% endfor %}
              </div>
            {% endif %}
          </footer>

        </article>

      </div>
    </div>
  </div>
</div>
```

✅**说明**：

- col-lg-8 col-md-10 col-sm-12 px-3 ：大屏固定宽度，中小屏自适应。

- d-flex flex-wrap justify-content-center ：文章元数据一行显示，手机端换行显示。

- 页脚标签和分类也用 flex-wrap ，手机端会自动换行。

- img-fluid 保证封面图响应式，自适应屏幕宽度。
