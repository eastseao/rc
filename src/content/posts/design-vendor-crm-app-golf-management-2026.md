## 01 · 设计公司选型对比与决策（三家 · 两周出样）

三家设计公司均承诺**两周出样**，但报价、案例类型与合作条件差异显著。最终建议选择**福鼎空格品牌设计**——山姆成功案例多、价格合适。

**成本估算**：按首批量产 10 万盒计，盒均设计成本 = 23,000 ÷ 100,000 =**0.23 元/盒**。下一步：签合同明确需求与验收 → 付 50% 定金（11,500 元）→ 两周内收样评审 → 确认后付尾款、交付源文件。

## 02 · 客户管理 APP · 产品需求文档（手动录入 · 离线可用）

目标是一款轻量级、以手动录入为主的 CRM：客户分四级，每个客户下手动添加其产品采购记录（产品、时间、金额）。V1.0 单机离线、本地存储、无需登录。

<div style="display:grid;gap:14px;margin:14px 0;grid-template-columns:repeat(2,minmax(0,1fr))"><div style="border:1px solid #dfe6ef;border-radius:8px;padding:16px 20px;background:#fff;margin:14px 0"><h3>客户四级分类（颜色标签）</h3><ul><li><b>资深客户</b>：金色；<b>VIP 客户</b>：紫色</li><li><b>普通客户</b>：蓝色；<b>潜在客户</b>：灰色（默认）</li><li>列表支持按分类筛选、关键词模糊搜索（名称/电话/备注）</li><li>分类完全由用户手动调整，不设自动升降级</li></ul></div><div style="border:1px solid #dfe6ef;border-radius:8px;padding:16px 20px;background:#fff;margin:14px 0"><h3>采购记录（客户详情页手动添加）</h3><ul><li>字段：产品名称（必填，自由输入）、采购时间（默认当天）、金额（两位小数）、数量（选填）、备注（选填）</li><li>按时间倒序排列；同客户可加多条、产品名不要求唯一</li><li>保存后即时更新客户列表&quot;最近采购摘要&quot;</li></ul></div></div>

数据模型（两表）

| 客户表 Customer | 类型 | 说明 |
|---|---|---|
| id / name | 主键 / 文本 | 唯一标识 / 客户名称（必填） |
| phone / level | 文本 / 枚举 | 电话（选填）/ senior·vip·normal·potential |
| notes / created_at / updated_at | 文本 / 时间戳 | 备注 / 创建时间 / 最后修改 |

| 采购记录表 PurchaseRecord | 类型 | 说明 |
|---|---|---|
| id / customer_id | 主键 / 外键 | 唯一标识 / 关联客户（删客户级联删除） |
| product_name / purchase_date | 文本 / 日期 | 产品名称（必填）/ 采购时间（必填） |
| amount / quantity / notes | 浮点 / 整型 / 文本 | 金额两位小数 / 数量 / 备注 |

非功能：1000 条客户内滚动流畅、启动 ≤2s、本地读写 ≤100ms；iOS 12+/Android 8.0+；飞行模式全功能可用；支持 CSV/Excel 导出。验收含分类筛选准确、无级联残留、必填与金额校验等 8 条。
