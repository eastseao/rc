## 01 · 调研报告的九段式结构（00720）

一份完整的产品市场调研报告，按「背景目的 → 方法 → 外部环境 → 竞品 → 用户 → 数据 → 结论」递进，共九段。每段都有明确目的，避免写着写着跑题。

| 段落 | 目的 | 必含内容 |
|---|---|---|
| **一、前言与摘要** | 让高层 5 分钟看懂 | 封面、目录、Executive Summary——提炼背景、核心发现、关键数据与建议，是最重要的部分。 |
| **二、调研背景与目的** | 界定范围不跑题 | 项目背景、具体调研目的、调研范围与对象（城市、人群年龄/收入/职业）。 |
| **三、调研方法** | 证明数据可靠 | 资料来源（一手/二手）、样本设计（样本量与配额）、执行方式、局限性说明。 |
| **四、市场环境分析** | 判断顺势还是逆流 | 宏观环境 PEST（政策/经济/社会/技术）、近三年市场规模与未来三年 CAGR。 |
| **五、竞品分析** | 知彼知己找空隙 | 竞争格局与份额；选 3—5 个核心竞品做产品/价格/渠道/营销声量详析。 |
| **六、消费者/用户分析** | 谁买、为何买 | 用户画像（人口+心理）、购买行为（动机/信息渠道/决策因素/场景）、满意度与痛点。 |
| **七、核心数据分析** | 量化证据支撑 | NPS、购买意愿、价格敏感度 PSM 测试；不同人群/城市的交叉分析。 |
| **八、结论与建议** | 数据转策略 | 核心发现（SWOT）、产品/定价/营销建议、风险提示。 |
| **九、附录** | 备查 | 问卷样本、访谈记录摘录、数据统计原始表格。 |

## 02 · 字数分级与篇幅分布（00720）

总原则：**结论比数字重要，数字比文字重要**。按用途选择报告体量，再按比例分配篇幅。

| 用途 | 建议字数 | 应含内容 |
|---|---|---|
| 最低可行性（内部快速沟通） | **2000—4000 字** | 摘要、核心数据图表、结论建议。 |
| 标准商业报告（立项会/投资方） | **8000—12000 字** | 完整背景、详尽消费者洞察、多维竞品对比、严谨的财务/规模预测。 |
| 深度学术/咨询级（麦肯锡风格） | **15000—30000 字以上** | 大量原始数据附录、复杂统计模型、分区域/分人群详读。 |

| 篇幅分布 | 占比 |
|---|---|
| 摘要与背景 | 10% |
| 市场与竞品 | 30%（外部数据多，易扩字数） |
| 用户与数据分析 | **40%（核心价值，数据说话）** |
| 结论与建议 | 20%（分析到位时可很短，但要精准） |

特别提示：商业环境追求高效，建议多用饼图、柱状图、雷达图代替大段描述文字，好报告应「字少图多」，关键结论高亮。
