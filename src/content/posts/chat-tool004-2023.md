Query: tun模式有什么用

The content of these web pages is about the TUN and TAP modes in the Clash program, which is used to improve the network experience, especially in games or software that do not follow the system proxy. TUN and TAP modes are used to intercept system traffic and redirect it to the Clash program, which can improve its ability to handle UDP traffic, intercept DNS, and work well with some operating systems' network stacks. The pages provide tutorials on how to configure TUN and TAP modes in different operating systems, including Windows and Linux, as well as explain the differences between TUN and TAP modes in terms of their ability to handle different types of data packets.
