当然可以，你可以在页面加载时加一个全屏遮罩层，遮罩上有一个密码输入框，用户输入正确密码后才显示页面内容。下面是一个改造后的示例代码（只修改了`<body>`内相关部分并新增样式和脚本）：

```html
<body class="bg-gray-50 font-sans text-gray-800">

<!-- 遮罩层 -->
<div id="passwordOverlay" class="fixed inset-0 bg-black bg-opacity-70 flex flex-col justify-center items-center z-50">
  <div class="bg-white rounded-xl p-6 shadow-lg w-80 text-center fade-in">
    <h2 class="text-xl font-semibold mb-4">请输入访问密码</h2>
    <input id="passwordInput" type="password" placeholder="密码" class="border border-gray-300 rounded-lg p-2 w-full mb-4 focus:ring-2 focus:ring-red-400" />
    <button onclick="checkPassword()" class="bg-red-600 text-white px-4 py-2 rounded-lg hover:bg-red-700 transition shadow w-full">确认</button>
    <p id="passwordError" class="text-red-600 mt-2 text-sm hidden">密码错误，请重试</p>
  </div>
</div>

<!-- 查询区域 -->
<div id="mainContent" class="opacity-0 transition-opacity duration-500">

  <!-- 这里放原来的查询区域、汇总区、结果表格等 HTML 内容 -->

</div>

<script>
const correctPassword = "123456"; // 设置访问密码

function checkPassword() {
  const input = document.getElementById("passwordInput").value.trim();
  if(input === correctPassword) {
    document.getElementById("passwordOverlay").style.display = "none";
    document.getElementById("mainContent").style.opacity = 1;
  } else {
    const err = document.getElementById("passwordError");
    err.classList.remove("hidden");
  }
}
</script>
```

##### 功能说明：

1. 页面初始时， #passwordOverlay 遮罩层覆盖整个页面，阻止访问内容。

1. 输入正确密码（上例是 "123456" ）后：

- 遮罩层隐藏； - 主内容 (`#mainContent`) 渐显。

1. 密码错误时显示错误提示。

function searchData() {
  const year = document.getElementById("year").value.trim();
  const supplier = document.getElementById("supplier").value.trim();
  const projectNo = document.getElementById("projectNo").value.trim();
  const projectName = document.getElementById("projectName").value.trim();

    alert("请输入至少一项查询条件！");

    const supplierStr = item["供应商名称"] || "";
    const projectNoStr = item["物料项目号"] ? String(item["物料项目号"]) : "";
    const projectNameStr = item["物料名称"] || "";
