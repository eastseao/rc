## 01 · 同仁堂青海高原工厂（高原生态 · 道地原料）

同仁堂健康在青海布局高原生态工厂，依托青藏高原独特的地理环境与资源优势，打造集道地药材种植、加工、研发于一体的产业基地。

| 特色维度 | 具体内容 |
|---|---|
| **高原环境优势** | 高海拔、低氧、强日照、大温差，药材有效成分积累更丰富。 |
| **道地原料** | 立足青海及周边高原产区，精选枸杞、虫草、雪莲、藏红花等特色药材。 |
| **产业定位** | 大健康产品研发生产基地，覆盖食养汤包、滋补饮品、功能食品等品类。 |
| **核心产品** | 银耳烤梨、枇杷烤梨、燕窝烤梨、当归黄芪土鸡汤、人参蛹虫草花胶汤、陈皮雪梨土鸡汤等即食滋补品。 |
| **工艺特色** | 现代锁鲜技术，开盖即食，保留食材营养与风味。 |

## 03 · 道地原料溯源（产地为本 · 食养天成）

同仁堂秉承"品味虽贵必不敢减物力，炮制虽繁必不敢省人工"的古训，精选全国核心产区药食同源食材。

| 道地原料 | 产地 | 特色亮点 |
|---|---|---|
| **砀山酥梨** | 安徽砀山 | "世界梨都"国家地理标志。黄河故道沙质土壤，果大核小、皮薄多汁，含糖量约13%。 |
| **宁夏枸杞** | 宁夏中宁 | "中国枸杞之乡"。日照充足昼夜温差大，粒大饱满，富含枸杞多糖。 |
| **有机银耳** | 福建古田 | "中国食用菌之都"。有机认证，朵形完整、胶质丰厚。 |
| **新疆红枣** | 新疆 | 光照长、无霜期长，碱性沙质土壤雪水灌溉，果大肉厚。 |
| **长白山人参** | 吉林长白山 | "百草之王"，富含人参皂苷，大补元气。 |
| **深海花胶** | 深海产地 | "海洋人参"，"海味四宝"之一，富含胶原蛋白。 |
| **新会陈皮** | 广东新会 | "一两陈皮一两金"，理气健脾、祛湿化痰。 |
| **黄山玉竹** | 安徽黄山 | 《神农本草经》上品，补益五脏，润泽皮肤。 |
