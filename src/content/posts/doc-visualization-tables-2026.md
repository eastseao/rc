## 01 · 多场景文档视觉化：六类文档的提示词模板（00739）

一套「明确场景 → 列必要模块 → 给原始信息占位符 → 指定输出格式」的方法，覆盖日常约 80% 的文档需求；统一用内联 CSS、Flex 卡片、样式化表格、任务列表与流程图呈现。

| 场景 | 核心要素 | 输出格式建议 |
|---|---|---|
| **会议纪要** | 基本信息（时间/地点/参会人）、讨论点、决议、待办（负责人+DDL） | Markdown 表格 |
| **Excel 报表** | 列标题、数据行、合计行 | Markdown 表格 |
| **PDF 文档** | 主副标题、作者/日期、摘要、分章节正文、页脚页码 | Markdown 标题 + 段落 |
| **产品提案** | 背景与问题、目标用户、解决方案、核心功能、预期收益、资源与风险 | 项目符号 + 表格 |
| **调研报告** | 背景/目的、方法（可配流程图）、关键发现、交叉分析、结论建议 | 图表 + 表格 |
| **项目复盘** | 按 STAR（情境/任务/行动/结果）回顾，附经验教训与改进计划 | 任务列表 + STAR |

提示词核心心法：**明确场景 → 列出必要模块 → 提供原始信息（占位符）→ 指定输出格式（表格/列表/图表）→ 一键生成专业文档**。
