## Q10 · 点击头像可放大（第 10 轮对话）

> **提问：** 点击头像可放大

可以的！我们可以让你的头像点击后弹出一个放大的预览框（俗称“灯箱效果”）。 这种功能只需在 HTML + CSS + JS 层面加一点代码即可，不需要额外库。

假设你的头像在 Beautiful Jekyll 的页眉（`_includes/header.html`或`_includes/sidebar.html`）中，比如：

```
<img src="{{ site.avatar }}" alt="头像" class="avatar-img">
```

你可以这样修改👇

---

##### ✅ 修改后代码（带中文注释）

```html
<!-- 头像 -->
<img src="{{ site.avatar }}" alt="头像" class="avatar-img" id="avatar">

<!-- 放大显示的遮罩层（默认隐藏） -->
<div id="avatarModal" class="avatar-modal">
  <span class="close">&times;</span>
  <img class="avatar-modal-content" id="avatarLarge">
</div>

<!-- 添加样式 -->
<style>
/* 头像样式 */
.avatar-img {
  width: 80px;
  height: 80px;
  border-radius: 50%;
  cursor: pointer;
  transition: transform 0.3s;
}
.avatar-img:hover {
  transform: scale(1.05);
}

/* 遮罩层样式 */
.avatar-modal {
  display: none; /* 默认不显示 */
  position: fixed;
  z-index: 9999;
  padding-top: 60px;
  left: 0;
  top: 0;
  width: 100%;
  height: 100%;
  overflow: auto;
  background-color: rgba(0,0,0,0.8);
}

/* 放大后的图片样式 */
.avatar-modal-content {
  margin: auto;
  display: block;
  max-width: 400px;
  width: 80%;
  border-radius: 10px;
}

/* 关闭按钮 */
.close {
  position: absolute;
  top: 30px;
  right: 45px;
  color: #fff;
  font-size: 40px;
  font-weight: bold;
  cursor: pointer;
}
.close:hover {
  color: #ccc;
}
</style>

<!-- 添加脚本 -->
<script>
  const modal = document.getElementById("avatarModal");
  const avatar = document.getElementById("avatar");
  const avatarLarge = document.getElementById("avatarLarge");
  const closeBtn = document.getElementsByClassName("close")[0];

  // 点击头像 -> 打开放大图
  avatar.onclick = function() {
    modal.style.display = "block";
    avatarLarge.src = this.src;
  }

  // 点击关闭按钮 -> 关闭
  closeBtn.onclick = function() {
    modal.style.display = "none";
  }

  // 点击遮罩层 -> 关闭
  modal.onclick = function(event) {
    if (event.target === modal) {
      modal.style.display = "none";
    }
  }
</script>
```
