明白，你的文章页面两边的边距丢失，可能是因为 Bootstrap 的`container`或`row`没有正确限制宽度，或者`col-xl-8 col-lg-10`的左右间距被覆盖。可以通过优化结构和增加左右 padding 来解决，同时保留响应式布局。下面是优化版：

```html
---
layout: default
---

{% assign date_format = site.date_format | default: "%Y年%-m月%-d日" %}

<div class="post-container py-5" style="background-color:#fff;">
  <div class="container">
    <div class="row justify-content-center">
      <div class="col-xl-8 col-lg-10 col-md-12 px-3">

        <article class="post-content">

          <!-- 文章标题和副标题 -->
          <header class="post-header text-center mb-4">
            <h1 class="post-title">{{ page.title | strip_html }}</h1>
            {% if page.subtitle %}
              <h2 class="post-subtitle">{{ page.subtitle | strip_html }}</h2>
            {% endif %}

            <!-- 元数据一行显示 -->
            <div class="post-meta mt-3 small text-muted">
              {% if page.author %}
                <span class="author">作者：<strong>{{ page.author | strip_html }}</strong></span>
              {% endif %}
              <span class="published-date"><span class="middot d-none d-md-inline">&middot;</span> 发表于 {{ page.date | date: date_format }}</span>
              {% if page.last-updated %}
                <span class="updated-date"><span class="middot d-none d-md-inline">&middot;</span> 更新于 {{ page.last-updated | date: date_format }}</span>
              {% endif %}
              {% assign words = content | number_of_words %}
              {% assign minutes = words | divided_by:200 %}
              {% if minutes < 1 %}{% assign minutes = 1 %}{% endif %}
              <span class="reading-time"><span class="middot d-none d-md-inline">&middot;</span> 阅读时间：{{ minutes }} 分钟</span>
            </div>
          </header>

          <!-- 封面图 -->
          {% if page.cover-img %}
            <div class="post-cover text-center mb-4">
              {% if page.cover-img.first %}
                <img src="{{ page.cover-img[0].first.first | relative_url }}" alt="Cover image" class="img-fluid rounded">
              {% else %}
                <img src="{{ page.cover-img | relative_url }}" alt="Cover image" class="img-fluid rounded">
              {% endif %}
              {% if page.cover-img-desc %}
                <p class="img-desc mt-2 text-muted small">{{ page.cover-img-desc }}</p>
              {% endif %}
            </div>
          {% endif %}

          <!-- 正文内容 -->
          <div class="post-body" style="line-height:1.8; font-size:1rem;">
            {{ content }}
          </div>

          <!-- 页脚：标签和分类 -->
          <footer class="post-footer mt-5 pt-3 border-top">
            {% if page.tags %}
              <div class="post-tags mb-2">
                <strong>标签：</strong>
                {% for tag in page.tags %}
                  <a href="{{ '/tags#' | append: tag | relative_url }}" class="tag-badge">{{ tag }}</a>
                {% endfor %}
              </div>
            {% endif %}

            {% if page.categories %}
              <div class="post-categories">
                <strong>分类：</strong>
                {% for category in page.categories %}
                  <a href="{{ '/categories#' | append: category | relative_url }}" class="category-badge">{{ category }}</a>
                {% endfor %}
              </div>
            {% endif %}
          </footer>

        </article>

      </div>
    </div>
  </div>
</div>
```

✅ 改动点：

1. 增加了 <div class="container"> ，保证左右响应式边距。

1. 给 col 增加了 px-3 ，防止在小屏幕左右紧贴。

1. post-container 增加 py-5 ，上下留白更舒适。

1. 正文 post-body 设置了 line-height 和字体大小，让文章可读性更好。

1. 页脚增加 border-top 和 pt-3 ，分隔感更明显。

如果你愿意，我可以帮你加上**两侧固定宽度阴影或背景色**，让文章在大屏幕下更像“书本居中”，视觉上更舒适。
