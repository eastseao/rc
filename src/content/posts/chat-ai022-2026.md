# 一、核心结论（先说人话）

你这套 prompt 的设计思路是对的，但有**3个致命问题**：

##### ❶ 最大风险：四反引号包裹 = 极不稳定

```

```

```

```

👉 在很多模型输出中，会出现：

- 提前闭合（尤其遇到 ```mermaid）

- 被截断

- Typora 粘贴后异常

➡️ 这是你整个 Skill**最大不稳定来源**

---

##### ❷ HTML + Markdown 混写：Typora 兼容 ≠ 完全安全

Typora 虽然支持 HTML，但：

- flex 在不同版本渲染不一致

- 阴影、渐变在导出 PDF 时容易丢失

- <div> 过多会导致：

- 复制到其他编辑器崩掉 - GitHub 渲染异常

---

##### ❸ prompt 是“展示导向”，不是“生成导向”

现在的 prompt 更像：

👉「帮我做一个好看的文章」

但你真正要的是：

👉「稳定生成结构化 .md 文件（可复用、可自动化）」

# 🧪 run.py（执行逻辑）

```html
import datetime
import json

def generate_document(topic, doc_type="report", render_mode="typora_pro", depth="标准"):
    date = datetime.datetime.now().strftime("%Y-%m-%d")

    structure_map = {
        "report": [
            "行业背景",
            "市场现状",
            "竞争格局",
            "用户分析",
            "趋势预测",
            "结论建议"
        ],
        "analysis": [
            "问题定义",
            "数据拆解",
            "关键洞察",
            "结论"
        ],
        "sop": [
            "目标",
            "适用范围",
            "流程步骤",
            "注意事项"
        ],
        "brief": [
            "项目背景",
            "目标",
            "策略",
            "执行方案"
        ]
    }

    sections = structure_map.get(doc_type, structure_map["report"])

    doc = f"## {topic}\n\n"
    doc += f"<p style='text-align:center;'>自动生成文档</p>\n\n"

    doc += f"<div style='background:#e3f2fd; padding:10px;'>本报告围绕「{topic}」展开分析</div>\n\n"

    for sec in sections:
        doc += f"### {sec}\n\n"
        doc += f"- 内容生成中...\n\n"

    doc += f"<div style='background:linear-gradient(145deg,#bbdefb,#b2dfdb); padding:10px;'>总结内容</div>\n\n"
    doc += f"<p style='text-align:center; color:#777;'>Document Engine · {date}</p>"

    return doc


if __name__ == "__main__":
    result = generate_document("测试主题")
    print(result)
```
