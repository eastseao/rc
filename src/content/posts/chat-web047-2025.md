#### **一、代码分析**

##### **1. 页面结构**

- 使用了 TailwindCSS ，结构清晰，分为：

1.**标题区**：LOGO + BOM查询 + 提示信息。 2.**查询输入区**：4个输入框（模糊/精准搜索）+ 查询/重置按钮。 3.**查询结果区**：默认显示“正在加载数据”，数据加载后显示表格。 4.**页脚**：版权信息。

- HTML 结构整体合理，Tailwind 辅助样式使用较好。

##### **2. 样式**

- 使用了渐变背景、悬浮行高亮、sticky 表头。

- fadeIn 动画用于淡入效果。

- mark 用于高亮匹配文本。

- 问题点 ：

- 渐变背景和颜色对比不够一致（如 parent-row 和 child-row 可能对比度不够高）。 -`tbody tr:hover`与渐变背景可能冲突。 - sticky 表头只在桌面端有效，移动端可能不够友好。

##### **3. 数据加载**

- 分别从：

-`bom_data.json`-`../tz/data.json`两个 JSON 文件加载。

- 使用 fetch() + then() 处理，加载成功后设置标志位。

- 潜在问题 ：

- 两个 fetch 并行，未处理加载顺序，但`checkAllLoaded()`简单处理了。 - 未考虑 fetch 失败重试或本地缓存。 - 数据量大时，渲染全部 DOM 可能性能下降。

##### **4. 查询逻辑**

- 支持：

- 品名模糊搜索 - 项目号精准搜索 - 物料项目号/物料名称精准/模糊搜索

- 实现方式 ：

1. 初步按品名/项目号筛选。 2. 再用物料 ID/物料名称匹配，再过滤项目号。

- 高亮 ：用 <mark> 标签。

- 表格渲染 ：

- 按项目号分组，显示 parent-row + child-row - 子表头`child-header`显示物料信息。

- 问题点 ：

- 当数据量大时，全部渲染 DOM 会卡顿。 - 过滤逻辑稍复杂，嵌套`.filter()`可能效率低。 - 高亮使用正则，每次都重新生成 HTML，数据量大可能有性能瓶颈。 - 查询按钮没有禁用状态，用户可能重复点击导致渲染重叠。 - 表格样式在移动端可能溢出。

##### **5. 事件绑定**

- 查询按钮：调用 renderFiltered() 。

- 重置按钮：清空输入框并清空结果。

- 优化点 ：

- 可以增加`Enter`键触发查询。 - 可以在查询期间禁用按钮，防止重复点击。 - 可以增加输入节流，减少频繁查询。

---

#### **二、优化方案**

##### **1. 数据与性能优化**

1. 数据加载 ：

- 可以使用`Promise.all`并行加载两个 JSON，统一处理加载状态。 ```js Promise.all([ fetch('bom_data.json').then(res => res.json()), fetch('../tz/data.json').then(res => res.json()) ]).then(([bom, prices]) => { ... });``` - 对大数据量，考虑使用**分页加载或虚拟列表**（如只渲染当前可见行）。 - 可增加**本地缓存**（LocalStorage/sessionStorage）避免重复 fetch。

1. 查询优化 ：

- 将原始数据索引化，例如用 Map 存储项目号 -> 子项，物料项目号 -> 采购价。 - 对模糊搜索，可以用**小写统一比较**： ```js item.品名.toLowerCase().includes(nameKeyword.toLowerCase())``` - 对于大量 DOM，可以先生成**DocumentFragment**再一次性 append。

1. 高亮优化 ：

- 正则每次生成可能慢，可以只在可见数据中生成。 - 或使用**CSS`::mark`替代 HTML mark 标签**（配合 class）减少 DOM 操作。

---

##### **2. 用户体验优化**

1. 输入体验 ：

- 支持按回车查询。 - 输入框自动清空高亮或保留历史查询。 - 查询时显示**loading**状态。

1. 表格体验 ：

-**移动端优化**：使用`overflow-x-auto`已有，但表格太宽时可以考虑**折叠列**。 -**交互优化**：子行可折叠/展开，提升大表格可读性。 - 表头背景与子行渐变颜色可以再调，保证对比度足够。

1. 按钮体验 ：

- 查询期间禁用按钮，并显示 loading。 - 重置按钮清空并恢复初始状态。

---

##### **3. 代码结构优化**

1. 模块化 JS ：

- 将高亮、查询、渲染分成独立函数。 - 数据处理与 DOM 渲染分离。

1. 避免内联 HTML 拼接 ：

- 使用模板字符串可读性可以，但大表格拼接复杂时，建议用`createElement`或小型模板引擎。

1. 日志与错误处理 ：

- fetch 错误信息可显示到页面，而非仅 console。 - 增加**重试或刷新按钮**。

---

##### **4. 安全与规范**

- 输入内容已用于正则，需要转义，已处理。

- 高亮的 <mark> 仅用于显示，避免 XSS 风险。

- 采购单价显示 "-" 对于无数据情况明确。

---

##### **5. 可选增强**

1. 导出 Excel / CSV 查询结果。

1. 本地保存查询历史 。

1. 高级筛选 ：按数量、零售价范围过滤。

1. 分页或虚拟滚动 大数据优化。

1. 可折叠树形结构 显示 parent-child。

---

#### ✅**总结**

- 优点 ：

- 页面结构清晰，功能齐全，查询逻辑完整。 - 样式美观，使用 TailwindCSS 和渐变效果。 - 支持多条件搜索，显示 parent-child 结构。

- 缺点 ：

- 大数据渲染性能不佳。 - 移动端表格可能溢出。 - 查询与渲染逻辑未充分模块化。 - 用户体验可优化（加载、按钮状态、折叠功能）。

- 优化方向 ：

1.**数据加载与查询性能**：Promise.all、Map索引、DocumentFragment、分页/虚拟列表。 2.**用户体验**：回车查询、折叠子行、loading 状态、移动端优化。 3.**代码结构**：模块化函数，避免大量内联 HTML。 4.**功能增强**：导出、历史查询、筛选、折叠树形。

      if (!nameKeyword && !projectID && !materialID && !materialName) {
        alert("请输入至少一项查询条件！");
        return;
      }

      let filtered = bomData.filter(item =>
        (!nameKeyword || item.品名.includes(nameKeyword)) &&
        (!projectID || item.项目号 === projectID)
      );

      if (materialID || materialName) {
        const matchedProjects = new Set(
          bomData
            .filter(item =>
              (!materialID || item.物料项目号 === materialID) &&
              (!materialName || item.物料名称.includes(materialName))
            )
            .map(item => item.项目号)
        );
        filtered = filtered.filter(item => matchedProjects.has(item.项目号));
      }

      if (filtered.length === 0) {
        resultDiv.innerHTML = "<p class='text-center text-gray-500'>未找到匹配结果。</p>";
        return;
      }

      const grouped = {};
      filtered.forEach(item => {
        if (!grouped[item.项目号]) grouped[item.项目号] = [];
        grouped[item.项目号].push(item);
      });

      const table = document.createElement("table");
      table.className = "w-full text-sm text-center border border-gray-200 rounded-lg shadow-sm";
      const thead = document.createElement("thead");
      thead.className = "parent-header";
      thead.innerHTML = `
        <tr>
          <th>项目号</th>
          <th>品名</th>
          <th>规格</th>
          <th>零售价</th>
          <th>物料项目号</th>
          <th>物料名称</th>
          <th>数量</th>
          <th>计量单位</th>
          <th>采购单价</th>
        </tr>
      `;
      table.appendChild(thead);
      const tbody = document.createElement("tbody");

      for (const [proj, items] of Object.entries(grouped)) {
        const parent = items[0];
        const parentRow = document.createElement("tr");
        parentRow.className = "parent-row";
        parentRow.innerHTML = `
          <td>${highlight(parent.项目号, projectID)}</td>
          <td>${highlight(parent.品名, nameKeyword)}</td>
          <td>${highlight(parent.规格, "")}</td>
          <td>${highlight(parent.零售价, "")}</td>
          <td colspan="5"></td>
        `;
        tbody.appendChild(parentRow);

        items.forEach(child => {
          const tr = document.createElement("tr");
          tr.className = "child-row";
          const id = child.物料项目号;
          const purchasePrice = priceData[id] !== undefined ? priceData[id] : "-";
          tr.innerHTML = `
            <td colspan="4"></td>
            <td>${highlight(child.物料项目号, materialID)}</td>
            <td>${highlight(child.物料名称, materialName)}</td>
            <td>${highlight(child.数量, "")}</td>
            <td>${highlight(child.计量单位, "")}</td>
            <td>${purchasePrice}</td>
          `;
          tbody.appendChild(tr);
        });
      }

      table.appendChild(tbody);
      resultDiv.appendChild(table);
    }

    document.getElementById("searchBtn").addEventListener("click", renderFiltered);
    document.getElementById("resetBtn").addEventListener("click", () => {
      ["nameSearch","projectSearch","materialIDSearch","materialNameSearch"].forEach(id => document.getElementById(id).value = "");
      document.getElementById("result").innerHTML = "";
    });

    document.querySelectorAll("#nameSearch,#projectSearch,#materialIDSearch,#materialNameSearch").forEach(input => {
      input.addEventListener("keypress", e => {
        if(e.key === "Enter") renderFiltered();
      });
    });
  </script>
</body>
