1. 年份和文章样式 ：为年份和文章标题添加了更清晰的字体样式，方便区分。

## Q3 · 我想是一条从上到下的时间轴，轴上有年份时间点，右侧对应月日和文章（第 3 轮对话）

> **提问：** 我想是一条从上到下的时间轴，轴上有年份时间点，右侧对应月日和文章

明白了，你想要的是典型的“垂直时间轴”效果：左侧是一条纵向的时间轴，年份（或时间点）在轴上显示，右侧是对应年份下的文章列表（含具体月日）。这种布局在 Jekyll 上可以通过 HTML + CSS + Liquid 循环实现。下面给你一个可直接使用的示例：

---

##### 修改后的页面代码

```html
---
layout: page
title: "时间轴"
permalink: /pages/archives/
---

<div class="timeline-container">
  {% assign posts_by_year = site.posts | group_by_exp: "post", "post.date | date: '%Y'" %}
  
  {% for year in posts_by_year %}
  <div class="timeline-year">
    <!-- 年份点 -->
    <div class="timeline-year-marker">
      <span class="year">{{ year.name }}</span>
    </div>
    
    <!-- 年份下的文章 -->
    <div class="timeline-posts">
      {% for post in year.items %}
      <div class="timeline-post">
        <div class="post-date">{{ post.date | date: "%m-%d" }}</div>
        <div class="post-title"><a href="{{ post.url }}">{{ post.title }}</a></div>
      </div>
      {% endfor %}
    </div>
  </div>
  {% endfor %}
</div>
```

---

##### CSS 样式示例

```css
.timeline-container {
  position: relative;
  max-width: 800px;
  margin: 0 auto;
  padding-left: 60px; /* 给时间轴留空间 */
}

.timeline-year {
  position: relative;
  margin-bottom: 40px;
}

.timeline-year-marker {
  position: absolute;
  left: 0;
  top: 0;
  width: 20px;
  height: 20px;
  background: #007BFF;
  border-radius: 50%;
  text-align: center;
  line-height: 20px;
  color: #fff;
  font-weight: bold;
}

.timeline-year-marker .year {
  position: absolute;
  left: 30px;
  top: -2px;
  font-size: 18px;
  color: #007BFF;
}

.timeline-posts {
  margin-left: 40px; /* 文章靠右显示 */
  border-left: 2px solid #007BFF; /* 时间轴线 */
  padding-left: 20px;
  padding-top: 5px;
}

.timeline-post {
  display: flex;
  align-items: center;
  margin-bottom: 10px;
}

}

  color: #333;
  text-decoration: none;
}

.timeline-post .post-title a:hover {
  text-decoration: underline;
}
```

---

##### 效果说明

1. 左侧竖线 ： border-left 模拟纵向时间轴。

1. 年份点 ：用圆点标记年份，年份文字显示在左侧圆点旁。

1. 右侧内容 ：每条文章显示月-日和标题，按年份分组。

1. 层次清晰 ：年份作为大节点，文章作为小节点排列在右侧。
