## 01 · 一键清理系统垃圾的 bat 脚本（00753 · 2026-03-17）

原笔记给出了从简到繁四个版本：**基础版**只删临时文件；**全面深度版**加入 DISM 组件清理、更新缓存、DNS 与浏览器缓存；**专项版**专治 C 盘被 Windows 更新文件占用；**极简版**只释放空闲内存；最后再把全部功能整合成一个**菜单版全能脚本**。创建方法统一：记事本粘贴代码 → 另存为时「保存类型」选「所有文件」→ 文件名以`.bat`结尾 → 右键「以管理员身份运行」。

##### 红线 · 批处理安全

脚本会批量执行删除命令，一个笔误就可能误删文件

## 03 · WinSxS 组件存储与 C 盘空间清理（01322 · 2026-06-17）

WinSxS 是 Windows 系统核心目录，**绝不能直接用 del / rd 删除**，否则会导致系统崩溃。原笔记的脚本只调用 Windows 官方自带的 DISM 工具做安全清理：先分析可回收空间，再标准清理（保留更新回滚能力），深度清理（/ResetBase）可选。
